# Part 8: 特化型AIツール

汎用チャットツール(Part 3)以外の、用途特化型のAIツールを扱う。

## 章構成(分類の地図)

### 第1章 検索・リサーチ特化
- Perplexity、GenSpark、NotebookLM

### 第2章 コーディング支援AI
- Cursor、GitHub Copilot、Cline、Windsurf

### 第3章 画像・動画・音声の生成AI
- 画像生成: Midjourney、Stable Diffusion、DALL-E 3
- 動画生成: Sora、Runway(Gen-3)、Luma Dream Machine、Kling
- 音声・音楽生成: Suno、Udio、ElevenLabs

### 第4章 ローカル・オープンモデル
- ローカルLLM、オープンウェイトの選び方
- Ollama、Hugging Face、量子化(モデル軽量化)
- オープンソースモデルのライセンス比較(「オープンウェイト」と「オープンソース」の違い、Apache/MIT/独自ライセンスで商用利用時に押さえる論点)。
  モデル別のライセンス早見表は[ローカルLLMの基本](local-llm-basics.md)に既にあるため重複させず、
  再配布・派生モデル・責任範囲など法務・調達目線の論点を中心に書く

### 第5章 ツール横断の選び方
- 用途別のツール選定マップ、コスト・機能比較

### 第6章 会議・議事録AI
- 議事録・文字起こしAI(Notta、Rimo、tl;dv、Otter.aiなど)の基本、Teams/Google Meetの会議メモ機能との使い分け
