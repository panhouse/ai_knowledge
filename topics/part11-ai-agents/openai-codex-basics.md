# OpenAI Codexの基本

## これは何か

Codex は OpenAI のコーディングエージェントで、**ChatGPT の契約にそのまま含まれる**点が
最大の特徴である。ChatGPT を既に契約している組織なら、追加契約なしでエージェントを試せる。

Codex のもう一つの軸は**クラウド実行**である。手元のマシンではなく OpenAI 側の環境で
タスクを走らせられるため、**複数のタスクを並列に投げて、あとで結果を回収する**使い方ができる。
「PCを占有せずに、10個のIssueを同時に片付けさせる」といった運用が成り立つ。

同じ Codex エージェントを、専用アプリ・CLI・IDE拡張・クラウドのどこからでも使え、
利用上限は入口をまたいで共通で管理される。

## 仕組み・背景

### 4つの入口

| 入口 | 特徴 |
|---|---|
| **Codex アプリ** | デスクトップアプリ。macOS 版が先行し、2026年3月4日の更新で Windows 対応 |
| **Codex CLI** | ターミナルから。**オープンソース**で公開されている |
| **IDE 拡張** | VS Code、Cursor など VS Code 系エディタに Codex エージェントを組み込む |
| **Codex クラウド** | OpenAI 側の環境で実行。多数のタスクを並列処理できる |

CLI がオープンソースである点は、社内での挙動確認や独自の組み込みをしたい場合に効いてくる。

### モデルと「クレジット」

Codex の消費量は**クレジット**という単位で管理される。クレジットはトークン使用量を
分かりやすい単位に換算したもので、モデルごとに単価が異なる。
2026年8月時点の主なレートは次のとおり([Codex rate card](https://help.openai.com/en/articles/20001106-codex-rate-card))。

| モデル | 入力(100万トークンあたり) | キャッシュ入力 | 出力 |
|---|---|---|---|
| GPT-5.6 Sol | 125 | 12.5 | 750 |
| GPT-5.6 Terra | 50 | 5 | 300 |
| GPT-5.6 Luna | 5 | 0.5 | 30 |
| GPT-5.4 | 62.50 | 6.25 | 375 |

**Sol / Terra / Luna は同じ世代の中で「賢さと価格」が違うモデル**という関係にある。
Luna は Sol の25分の1の入力単価で、日常的な作業はこちらで足りることが多い。
難しい設計判断だけ Sol に上げる、という使い分けがコストに直結する。

### 利用上限(5時間のローリングウィンドウ)

上限は「直近5時間」で数える方式である。Plus プランの目安は次のとおり。

| モデル | Plus プランのメッセージ数目安 |
|---|---|
| Sol | 10〜100 |
| Terra | 25〜200 |
| Luna | 250〜2,000 |

Pro 5x は Plus の5倍、Pro 20x は20倍の上限になる。Business は Plus と同等。
API キー方式なら固定上限なしで、通常のAPI料金がかかる。

**幅があるのは、1メッセージあたりの実際のトークン消費量がタスクによって大きく変わるため**である。
コードベースが大きいほど1回のやりとりで読むファイルが増え、消費が増える。

## 使いどころ・使い分け

### 向く場面・向かない場面

| 向く | 向かない |
|---|---|
| すでに ChatGPT を全社契約している | Claude / Gemini 系でツールを統一している |
| 独立したタスクを大量に並列で片付けたい | 対話しながら少しずつ進めたい作業 |
| ローカル環境を汚さずに試したい(クラウド実行) | ローカル環境に強く依存する作業 |
| コストをモデル選択で細かく制御したい | 上限管理を意識せず使いたい |
| CLI の中身を確認して社内展開したい | GUI で並列エージェントを俯瞰したい(→ Antigravity) |

### 3製品の使い分け

| こういう場合 | 選ぶもの |
|---|---|
| ChatGPT の契約が既にある / 並列タスクを回したい | **Codex** |
| ターミナルで対話しながら委任したい / Claude を使っている | [Claude Code](claude-code-basics.md) |
| GUI で複数エージェントを管理したい / ブラウザ検証を任せたい | [Google Antigravity](google-antigravity-basics.md) |

詳しい比較は[主要AIエージェントの比較と選び方](ai-agent-tools-comparison.md)にまとめている。

## 実務での使い方

### 使えるプラン(2026年8月時点)

Codex は **ChatGPT の Free / Go / Plus / Pro / Business / Edu / Enterprise すべてに含まれる**
([Codex pricing](https://learn.chatgpt.com/docs/pricing))。

| プラン | 月額 | Codex の位置づけ |
|---|---|---|
| Free | $0 | 動作を試す程度 |
| Go | 低価格帯 | 軽い用途 |
| Plus | $20 | 個人利用の標準 |
| Pro | $100 / $200(5x / 20x) | 日常的に回す |
| Business | $20/ユーザー | 上限は Plus 相当。組織管理機能つき |
| Enterprise / Edu | 個別 | 大規模導入 |

**実際のコスト感**として、OpenAI 自身が「Codex は平均で開発者1人あたり月 $100〜$200 程度」
と示している。ただしモデル・並列数・自動化の有無で大きく変動するとも明記されている。
つまり **Plus($20)の枠内で本格運用するのは現実的でない**と考えておくのが安全である。

### コスト管理の具体策

1. **既定モデルを Luna に寄せる。** 難しい作業だけ Terra / Sol に上げる
2. **キャッシュを効かせる。** 同じコードベースで連続して作業すると
   キャッシュ入力(単価が10分の1)の比率が上がる
3. **クラウド実行の並列数を決める。** 「同時3本まで」のような社内ルールを先に決める
4. **タスクを小さく切る。** 巨大なタスクは失敗して再試行するぶん高くつく

部門単位の予算管理は
[生成AI利用コストの管理・予算配分](../part12-business-practice/ai-cost-management-and-budgeting.md)を参照。

### 承認モードの考え方

Codex には「どこまで自動で実行してよいか」を決める承認の設定がある。
どの製品でも共通する考え方として、**取り消せない操作は必ず人を通す**を基準にする。

```
## 自動実行してよい
- ファイルの読み取り・検索
- テスト、lint、型チェックの実行
- ローカルブランチへのコミット

## 毎回確認する
- 依存パッケージの追加・更新
- ファイル・ディレクトリの削除
- 設定ファイル(CI、デプロイ設定)の変更

## 実行させない
- 共有ブランチへの push、本番へのデプロイ
- 本番データベースへの接続
- 外部への送信(メール、Webhook、決済)
```

### クラウド実行を使うときの注意

クラウド実行では**コードが OpenAI 側の環境に渡る**。
契約上のデータ取り扱い条件(学習利用の有無、保存期間)を確認し、
機密性の高いリポジトリで使う場合は事前に社内承認を取る。
判断材料は[情報漏洩を防ぐデータ管理](../part04-risk-security/information-leakage-prevention.md)にまとめている。

## 注意点・よくある誤解

- **「ChatGPT に含まれる」は「追加費用ゼロ」ではない。** 含まれるのは一定の上限までで、
  本格運用すると上限に当たる。実質的なコストは月 $100〜$200/人が目安
- **モデル名が価格差を表している。** Sol / Terra / Luna の違いを知らずに既定のまま使うと、
  同じ作業で10倍以上のコスト差が出る
- **5時間ウィンドウの罠。** 上限に当たると回復まで待つことになる。
  締切前に集中して使う運用は詰まりやすいので、余裕を持って回す
- **並列実行はレビューのボトルネックを作る。** 10本走らせても、レビューできるのは
  せいぜい数本である。**AIの実行速度ではなく人のレビュー速度が上限**になる
- **間接プロンプトインジェクション**: Issue やコメント、取り込んだ依存パッケージに
  仕込まれた指示に従う可能性がある([プロンプトインジェクションとは何か](../part04-risk-security/prompt-injection-basics.md))
- **料金・上限は頻繁に変わる。** 本ページの数値は2026年8月時点。導入判断のたびに公式を確認する

## 最初の一歩

ChatGPT を契約しているなら、Codex CLI を入れて既存プロジェクトで
「テストを実行して、落ちているものがあれば原因だけ教えて(修正はしないで)」と頼んでみる。
**書き込みをさせない指示から始める**のが、承認モードの感覚をつかむ最短路である。
