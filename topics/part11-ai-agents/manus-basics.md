# Manusの基本(汎用自律型業務エージェント)

## これは何か

Manus は、目標を1文で渡すと**クラウド上の仮想コンピュータ(サンドボックス)の中で、
ブラウザ操作・コード実行・ファイル作成を何時間も自律的に続け**、調査結果や資料を
成果物として返す汎用業務エージェントである。開発元は中国発のスタートアップ Butterfly Effect で、
2025年半ばに本社をシンガポールへ移転している。

[Claude Cowork](claude-cowork-basics.md)と同じ「非コーディングの知識労働を任せる」タイプの
エージェントだが、Manusは**PCの電源を切っても止まらないクラウド完結の実行環境**と、
**長時間の自律リサーチに強い**という評価が特徴である。

## 仕組み・背景

### Planner・Executor・Verifierの3役構成

Manusは内部で「計画する役」「実行する役」「検証する役」を分けたマルチエージェント構成を取り、
ブラウザ操作・コード実行・表計算生成・スライド作成・PDF調査といった複数の作業を
1つの依頼から連鎖させる。目標を渡すと、実行前に**タスクプラン(手順の一覧)を提示**し、
ユーザーはそれを見てから実行を許可できる。

### サンドボックス環境

Manusは、Chromiumブラウザ・Linuxターミナル(Python・bash)・ファイルシステムを備えた
**専用の仮想コンピュータ**の中で動く。画面には「Manusのコンピュータ」という
作業実況パネルが表示され、タブを開く・フォームに入力する・サイトを移動する様子が
リアルタイムで見える(ブラックボックスにしない設計)。セッションは再生可能で、
どのような手順で結果が作られたかを後から遡って確認できる。

### Meta買収騒動と現在の位置づけ(2026年8月時点)

2025年12月、Meta がManusを約20億ドルで買収する計画を発表したが、
2026年4月に中国の国家発展改革委員会(NDRC)がこの買収を阻止し、
両社に取引の解消を指示した。Metaは同年6月までに買収の解消(社内システムの分離など)を
進めており、**2026年8月時点でManusはMetaの傘下ではなく、シンガポールを本拠とする
独立企業として運営されている**。この経緯は、海外拠点に移転した中国発AI企業の
買収・データガバナンスがどれだけ地政学的な影響を受けやすいかを示す事例でもあり、
導入検討時にはベンダーの資本関係・データ取り扱い方針を最新の状態で確認したい。

## 使いどころ・使い分け

### 向く仕事・向かない仕事

| 向く | 向かない |
|---|---|
| 競合10社の価格・機能をWebで調べてスプレッドシートにまとめる | 数値の正しさが致命的な確定作業(決算・契約) |
| 複数ソースを横断する長時間の調査・市場分析 | 対話しながら方針を調整していく作業 |
| CSV/Excelを読み込んでの分析・可視化 | 機密情報を含むデータの処理(サンドボックス内でのデータ取り扱いを事前確認) |
| スライド・簡易Webアプリの試作 | リアルタイム性が必要な業務 |

### Claude Coworkとの違い

| | Manus | [Claude Cowork](claude-cowork-basics.md) |
|---|---|---|
| 提供元 | Butterfly Effect(シンガポール) | Anthropic |
| 実行場所 | クラウドのサンドボックス完結 | 手元PC中心(Web/モバイルはベータ) |
| 得意分野 | 長時間の自律Webリサーチ、コード実行を伴う分析 | ローカルファイルを扱う文書作成 |
| ファイル操作 | クラウド上で生成 | 指定フォルダを読み書き |
| 料金 | 無料枠あり、有料は$20〜$200/月 | Claude Pro($17〜)以上に含まれる |

**「手元のファイルを触らせるか、Web上の情報収集をクラウドで完結させるか」**が
選定の分岐点になる。詳しい横断比較は[主要AIエージェントの比較と選び方](ai-agent-tools-comparison.md)を参照。

## 実務での使い方

### 使えるプラン(2026年8月時点)

| プラン | 月額 | クレジット | 目安 |
|---|---|---|---|
| Free | $0 | 300(デイリー) | 試用 |
| Pro(下位) | $20 | 4,000/月 | 個人利用 |
| Pro(中位) | $40 | 8,000/月 | 日常的な業務利用 |
| Pro(上位) | $200 | 40,000/月 | 常時Deep Research・長時間タスク向け |
| Team | $20/シート〜 | 8,000+/シート(共有プールあり) | 組織利用(2名以上) |

Manusは**クレジット制の従量的な消費モデル**で、ブラウジング・コード実行・ファイル分析など
1つずつの操作がクレジットを消費する。年払いで17%引きになる。

### 始め方とコピペで使える依頼文

1. Manusのサイトでアカウントを作成する
2. 目標を自然文で入力する(例: 下記)
3. 提示されたタスクプランを確認し、実行を許可する
4. 「Manusのコンピュータ」パネルで進行を確認し、完了通知を受け取る

```
競合A社・B社・C社の最新の料金プランと主要機能を公式サイトから調べて、
比較表(機能・料金・対象企業規模)をスプレッドシートにまとめてください。
有料資料のダウンロードが必要な場面では、実行を止めて確認してください。
```

## 注意点・よくある誤解

- **資本関係・データガバナンスは流動的である**: 2025年12月のMeta買収発表から
  2026年4月の中国当局による阻止、6月の買収解消まで、半年で状況が大きく変わった経緯がある。
  導入判断時は「今の資本関係」「データの保存先・取り扱い方針」を必ず最新の公式情報で確認する
- **クレジット消費は見えにくい**: 長時間の自律タスクや複数ソースを横断する調査は
  クレジットを大きく消費する。重要な調査から始める前に、軽いタスクで消費ペースを把握しておく
- **サンドボックス内でも機密データの扱いには注意する**: クラウド完結という設計上の利点は、
  裏を返せば「機密情報がクラウド環境を経由する」ことでもある。個人情報・契約金額などを
  扱う前に、社内の情報管理ルールと契約上のデータ取り扱い条件を確認する
  ([情報漏洩を防ぐデータ管理](../part04-risk-security/information-leakage-prevention.md))
- **間接プロンプトインジェクション**: Web上の情報を読み込みながら動くため、
  閲覧先に埋め込まれた悪意ある指示に従うリスクがある
  ([プロンプトインジェクションとは何か](../part04-risk-security/prompt-injection-basics.md))
- **タスクプランは必ず確認する**: 実行前に提示されるプランを読まずに許可すると、
  想定外の範囲まで作業が広がることがある

## 最初の一歩

無料プランで、送信・決済を含まない軽い調査タスク(競合1〜2社の情報収集など)を1件試し、
タスクプランの提示内容と「Manusのコンピュータ」パネルでの実行過程を確認してみる。
