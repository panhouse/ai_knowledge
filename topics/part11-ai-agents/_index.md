# Part 11: AIエージェント

**目標を渡すと、計画・実行・検証まで自分で進めるAI**を扱うパート。
Claude Code・Codex・Antigravity・Claude Cowork のような「委任型」の製品を各論で押さえ、
権限設計・コスト・レビュー体制といった**任せるための運用**までを1箇所に集める。

Part 1〜10 が「AIに指示を出して答えをもらう」前提の教科書であるのに対し、
このパートは **人が手を動かさない時間にAIが作業を進める**ことを前提にする。
そのため技術解説だけでなく、「どこまで承認なしでやらせるか」「何をレビューするか」が主題になる。

## 他パートとの住み分け

エージェントの話題は複数のパートに散らばりやすいので、境界を明示しておく。

| パート | 扱うもの | 例 |
|---|---|---|
| **Part 11(このパート)** | **エージェント製品そのものと、任せるための運用** | Claude Code、Codex、Antigravity、Cowork |
| Part 3 AIチャットツール | チャットUIに付いた**機能としての**エージェント | ChatGPT Agent、スケジュールタスク |
| Part 6 カスタムAIの作成 | 自分専用のボットを**設定で**作る | GPTs、Gem、Copilot Agent Builder |
| Part 8 特化型AIツール | 開発者の**エディタに寄り添う**コーディング支援 | GitHub Copilot、Cursor、Cline、Windsurf |
| Part 9 API・開発連携 | エージェントを**自分で実装する**ための部品 | MCP、A2A、Function Calling |
| Part 10 ノーコード | エージェントを**ノーコードで組む** | Dify・n8n・Make のエージェント機能 |

判断の目安:

- **既製品を導入して使う話 → Part 11**。自分で作る話 → Part 9(コード)/ Part 10(ノーコード)
- **エディタ内の補完・チャットが主用途のツール → Part 8**。
  タスクを丸ごと委任して待つ使い方が主用途のもの → Part 11
  (Cursor や Copilot のようにどちらの顔も持つツールは Part 8 に置き、
  エージェント機能の比較が必要な場合はこのパートの比較ページから相互リンクする)
- 境界が曖昧なツールは**主たる利用形態**で置き場所を決め、もう一方から相互リンクする

## 書き方の指針(このパート固有)

雛形は `templates/topic-page.md`。このパート特有の必須項目を加える。

1. **何を任せられて、何を任せられないか** — できることの列挙で終わらせない
2. **権限モデル** — どのファイル・どのツールに触れるか、承認はどこで入るか、
   取り消せない操作(削除・送信・課金・push)の扱い
3. **料金と上限** — サブスク込みか従量課金か、上限に当たったときどうなるか。
   **エージェントはチャットの数十倍トークンを使う**ため、コストは必ず書く
4. **レビューの実務** — 出てきた成果物のどこを人が見るか(差分・出典・数値の裏取り)
5. **ツール横断の対応付け** — 同じ概念が各製品で何と呼ばれるか
   (例: 権限の事前許可 = Claude Code の permissions / Codex の approval mode)

注意:

- **この分野は数か月で変わる。** モデル名・料金・上限値には必ず「◯年◯月時点」を付け、
  一次情報(公式ドキュメント・公式ブログ)を出典にする
- 「自律的にできる」という宣伝文句をそのまま書かない。**実際に人の確認が必要な箇所**を書く
- セキュリティは Part 4 に丸投げせず、エージェント固有のリスク
  (間接プロンプトインジェクション、権限の過剰付与、認証情報の扱い)を各ページで触れる

## 章構成(分類の地図)

### 第1章 エージェントの基礎
- エージェントとは何か、チャットボット・ワークフローとの違い、エージェントループ
- 自律度のレベル分け、権限設計、Human in the Loop の入れ方

### 第2章 コーディングエージェント
- Claude Code、OpenAI Codex、Google Antigravity など、コードを書かせる委任型ツール
- 非エンジニアが「動くものを作る」用途で使う場合の勘所も含む

### 第3章 業務エージェント(非コーディング)
- Claude Cowork、Manus など、資料作成・調査・ファイル整理といった知識労働を任せるツール

### 第4章 エージェントの選び方・比較
- 製品横断の比較、用途別の使い分け、その他の新興エージェント

### 第5章 運用・ガバナンス
- 権限ポリシー、監査ログ、コスト管理、社内ルールの作り方
- エージェント特有のセキュリティリスクと対策

### 第6章 その他・未分類
- 上記に当てはまらないエージェント関連トピックの一時受け皿
