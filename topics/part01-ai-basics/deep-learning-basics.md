# ディープラーニング(深層学習)の基礎

## これは何か

ディープラーニング(深層学習)は、機械学習(データからパターンを学ぶAIの手法群)の中の1手法で、人間の脳の神経細胞のつながりを簡略に模した「ニューラルネットワーク」を何層にも重ねて使うのが特徴です。一番の違いは、**何に注目すればよいか(特徴量)を人間が設計しなくても、AIが大量データから自動で見つけ出せる**こと。この「自動で特徴を掴む力」が、画像認識・音声認識・そして今の生成AI(文章や画像を作るAI)ブームの土台になっています。ChatGPTやGeminiがなぜ急に賢くなったのか、なぜNVIDIAの半導体(GPU)が世界中で奪い合いになっているのかを理解する土台として、ビジネスパーソンも「仕組みの要点」だけは押さえておく価値があります。

## 仕組み・背景

### 従来の機械学習との違いは「特徴量を誰が作るか」

第3章で扱う従来型の機械学習(回帰・決定木など)では、「この顧客は解約しそうか」を予測するのに人間が「利用頻度」「契約年数」「問い合わせ回数」といった**着目点(特徴量)を先に設計**し、それをアルゴリズムに与えて学習させます。人間の業務知識が精度を左右するイメージです。

ディープラーニングは、この特徴量選びまでをAI自身に任せます。画像なら「これは輪郭のパターン」「これは質感のパターン」といった着目点を、ネットワークの層を重ねる過程で自動的に作り出します。そのため、「何に注目すべきか」を言語化しにくいタスク(画像・音声・自然な文章)で従来手法を圧倒的に上回るようになりました。これが生成AIの文章生成・画像生成の土台です。

| | 従来の機械学習 | ディープラーニング |
|---|---|---|
| 特徴量(着目点) | 人間が設計 | データから自動学習 |
| 得意なデータ | 表形式の構造化データ(売上・顧客属性など) | 画像・音声・テキストなどの非構造化データ |
| 必要なデータ量 | 少量〜中量でも機能 | 大量(数百万〜数十億単位)が前提 |
| 必要な計算資源 | CPUで十分なことが多い | GPU・専用チップがほぼ必須 |
| 精度の伸び方 | データを増やしてもいずれ頭打ち | データ・計算量を増やすほど性能が伸びる傾向(スケール則) |
| 判断根拠の説明しやすさ | 比較的説明しやすい | ブラックボックス化しやすい |

### ニューラルネットワークの超シンプルな中身

ニューラルネットワークは「入力層→中間層(何層も)→出力層」という構造で、各層に並ぶ「ノード」が前の層から受け取った数値に重み(重要度)を掛けて合計し、「活性化関数」という関数を通して次の層に渡します。活性化関数は、単純な足し算・掛け算だけでは表現できない複雑なパターン(非線形な関係)を扱えるようにするためのスイッチのようなもので、現在はReLU(入力が正ならそのまま通し、負なら0にする単純な関数)が主流です。「深層(ディープ)」とは、この中間層を何層にも積み重ねている、という意味です。

学習(重みの調整)は「誤差逆伝播(バックプロパゲーション)」という仕組みで行います。出力の答え合わせをして「どれくらい間違えたか」を計算し、その誤差を出力側から入力側へ逆向きに伝えながら、各層の重みを少しずつ修正していきます。何百万回もこの微調整を繰り返すことで、AIは徐々に「正解に近い出力」を出せるようになります。

### なぜ長年「深くできなかった」のか(勾配消失問題)

理屈の上ではニューラルネットワークは層を深くするほど賢くなるはずでしたが、2010年代前半までは「層を深くしすぎると、逆に学習がうまく進まなくなる」という壁がありました。これが**勾配消失問題**です。誤差を逆方向に伝える際、層を1つ遡るごとに信号がどんどん小さくなり、入力に近い層まで届くころにはほぼゼロになってしまい、その層の重みがまったく更新されなくなる現象です([ネットアテスト](https://www.netattest.com/vanishing-gradient-problem-2024_mkt_tst))。ReLUなどの活性化関数の改良や、学習の工夫(層をまたいで情報を橋渡しする「残差接続」など)によってこの壁が緩和されたことで、何十層・何百層という「本当に深い」ネットワークが実用化されました。

### 2012年の転機とGPUの役割

この技術が一気に実用段階に入ったきっかけが、2012年の画像認識コンペティション「ImageNet」での出来事です。「AlexNet」という深層ニューラルネットワークが、従来手法を大差で上回る精度で優勝し、以降のAI研究の主流がディープラーニングに一気にシフトしました。この時に決定的だったのが、学習にGPU(画像処理用の半導体、後述)を使ったことです。深いネットワークを現実的な時間で学習させるには膨大な計算量が必要で、GPUなしでは同じ規模の学習に何倍もの時間がかかっていました。

GPU(Graphics Processing Unit)はもともとゲームや映像のために大量の画素を同時に描画する目的で発達した半導体で、「単純な計算を大量に同時並行でこなす」のが得意です。ニューラルネットワークの計算の実体は行列(数字を格子状に並べたもの)同士の掛け算の繰り返しで、これはまさにGPUが得意とする「同じ計算をたくさん並列に行う」処理と相性が良いのです。CPU(中央処理装置)が「少数の複雑な計算を順番に賢くこなす」設計なのに対し、GPUは「単純な計算を数千個のコアで同時にこなす」設計だからです。NVIDIAはこの用途に向けてCUDAという開発基盤や、AI計算に特化した「Tensor Core」をGPUに搭載するなど、早くからAI向けの投資を続けてきました。

その後、2017年に登場した「Transformer」というアーキテクチャ(注意機構により文章中の離れた単語同士の関係を並列に計算できる仕組み)が、それまで文章や時系列データの処理に使われていたRNN(再帰型ニューラルネットワーク、データを1つずつ順番にしか処理できず並列計算に向かない・長い文章で勾配消失が起きやすいという弱点があった)を置き換え、現在のLLM(大規模言語モデル)の基盤技術になりました。画像分野では同時期にCNN(畳み込みニューラルネットワーク。画像の一部分を小さなフィルタでなぞって「輪郭」「模様」などのパターンを検出する層を積み重ねる方式)が標準となり、顔認識・自動運転の物体検出などに広く使われています。CNN・RNN・Transformerはいずれも「ディープラーニングというフレームワークの上に成り立つ、データの種類に応じた工夫」だと理解しておけば十分です。

## 使いどころ・使い分け

ビジネスの現場で「ディープラーニングか、従来型の機械学習か」を意識すべき場面は、主に次の判断軸です。

| 状況 | 向いている手法 | 理由 |
|---|---|---|
| 売上予測・需要予測・与信スコアリングなど表形式データ | 従来型の機械学習(決定木系など) | 少ないデータでも精度が出やすく、判断根拠も説明しやすい。計算コストも低い |
| 画像・音声・自然文などの非構造化データを扱う | ディープラーニング(多くは既存の学習済みモデル・LLM APIを利用) | 特徴量の手作業設計が事実上不可能。既製の基盤モデルを使うのが現実的 |
| 判断根拠の説明責任が重い(与信・採用・医療など規制業種) | 従来型の機械学習、または説明可能性を補うツールを併用 | ディープラーニングはブラックボックス化しやすく、監督官庁・監査への説明が難しい |
| 自社でゼロからモデルを学習させたい | 基本的に非推奨 | 大量データ・GPU計算コストが必要。既存の基盤モデルのAPI利用やファインチューニング(追加学習)で十分なことが多い |

「AIを導入する」といっても、裏側が従来型の機械学習なのかディープラーニングなのかで、必要なデータ量・コスト・説明責任のハードルがまったく違います。ベンダーの提案を評価する際は、「対象データは表形式か、それとも画像・音声・文章か」を最初に確認すると、過不足のない手法選定の土台になります。

## 実務での使い方

- **ベンダー提案を評価するときの質問リスト**: 「学習データは何件用意する必要があるか」「判断根拠を説明できるか」「独自モデルを学習するのか、既存の基盤モデルを使うのか」を聞くと、従来型の機械学習で足りる案件に対して不必要に高コストなディープラーニング案件が提案されていないか見極められます。
- **AI関連ニュースの読み方**: 「NVIDIAの決算」「GPU不足」「大手クラウドの設備投資額」といったニュースは、ディープラーニング(特にLLM)の学習・推論に必要な計算資源の需給を映しています。NVIDIAは2026年5月発表の2027会計年度第1四半期(2026年2〜4月期)決算で売上高816億ドル(データセンター部門は前年同期比92%増の752億ドル)という過去最高を記録し、株式時価総額は2025年に世界で初めて4兆ドルを突破しました([日本経済新聞](https://www.nikkei.com/article/DGXZQODK117FR0R10C25A7000000/)、[マイナビTECH+](https://news.mynavi.jp/techplus/article/20260525-4499982/))。さらに、Google・Amazon・Microsoft・Metaの米大手4社の2026年の設備投資額は前年比76%増の7,250億ドルと見積もられており、その多くがGPU購入とデータセンター増強に充てられています([TradingKey](https://www.tradingkey.com/jp/analysis/stocks/us-stocks/262007983-largest-company-us-stock-nvidia-google-apple-microsoft-amazon-2026-tradingkey))。この「計算資源への莫大な投資競争」の理由をひとことで言えば、**ディープラーニングは計算量を増やすほど性能が伸びる傾向があり、その計算量の大半をGPUが担っているから**です。「なぜAI企業は赤字覚悟で巨額投資を続けるのか」「なぜAIサービスの利用料が今後変動しうるのか」を理解する軸として押さえておくと、自社のAI投資判断や中期計画の説明にも使えます。
- **社内勉強会・資料作成での説明**: 「機械学習は人間が着目点を教える方式、ディープラーニングはAIが着目点を自分で見つける方式」という一言で、非エンジニアの経営層にも違いを説明できます。

## 注意点・よくある誤解

- **「AI=ディープラーニング」ではない**: 需要予測や与信スコアリングなど、表形式データを扱う業務では今でも従来型の機械学習の方が精度・コスト・説明可能性のバランスが良いことが多いです。「とにかくディープラーニング(LLM)を使う」は必ずしも最適解ではありません。
- **判断根拠が説明しにくい(ブラックボックス問題)**: 層が深くなるほど「なぜその出力になったか」を人間が追いにくくなります。与信・採用・医療など説明責任が重い領域で導入する場合は、判断根拠を補足する仕組み(説明可能AI、人間によるレビュー工程)とセットで検討する必要があります。
- **計算コストは指数関数的に増えうる**: 性能を上げようとしてモデルやデータを大きくすると、必要な計算量(=GPU利用料・電力コスト)も跳ね上がります。データセンターの電力調達は既に現実の制約になりつつあり、AI活用のコスト計画には計算資源のコストを織り込む必要があります。
- **GPU調達は地政学リスクにも直結する**: 高性能GPUの輸出規制や供給逼迫は、AIベンダーのサービス提供能力・価格に直接影響します。自社のAI戦略を「特定ベンダー・特定チップへの依存度」という観点でも点検しておくと安心です。

## 最初の一歩

次にNVIDIAの決算やAIデータセンター投資のニュースを見かけたら、「これはディープラーニングの計算量が増え続けていることの裏返しだ」と一度結び付けて読んでみてください。そのひと手間で、AI関連ニュースの「なぜ」が格段に読み解きやすくなります。
