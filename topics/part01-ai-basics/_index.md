# Part 1: AI基礎

LLM以前のAI(機械学習・ディープラーニング・認識系AI)を含む、AI全体の基礎知識。
G検定(JDLA)のシラバスを参考に、試験対策ではなく
「LLM以前のAIも含めて全体像を語れるビジネスパーソン」を目指す構成とする。
※「法律と倫理」は Part 4(リスク管理)、「AIの社会実装」は Part 11(業務活用)で扱う。

## 章構成(分類の地図)

### 第1章 人工知能とは
- AIの定義、AI効果、強いAI/弱いAI、特化型/汎用型

### 第2章 AIの歴史とブーム
- 3次のAIブーム(探索・推論 → 知識表現・エキスパートシステム → 機械学習/DL)、冬の時代
- フレーム問題・シンボルグラウンディング問題、チューリングテスト、生成AIブームの位置づけ

### 第3章 機械学習の基礎
- 教師あり学習(回帰・分類)、教師なし学習(クラスタリング・次元削減)、強化学習
- 代表アルゴリズム(線形回帰、決定木、ランダムフォレスト、SVM、k-means)

### 第4章 ディープラーニングの基礎
- ニューラルネットワーク、活性化関数、誤差逆伝播、勾配消失、GPUの役割
- CNN・RNNの登場

### 第5章 認識系AIの応用
- 画像認識(分類・物体検出・セグメンテーション・OCR)、音声認識
- 従来型の自然言語処理、異常検知・需要予測(業務のどこで使われているか)

### 第6章 AIプロジェクトと評価の基礎
- 学習データの用意、過学習、精度指標(正解率・適合率・再現率)、PoCの進め方
