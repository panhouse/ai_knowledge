# ChatGPTの初期設定とデータ利用のオプトアウト

## これは何か

ChatGPTはアカウントを作っただけでは「何も知らない汎用アシスタント」のままで、毎回同じ自己紹介や前提条件を書かされて非効率になる。逆に、初期設定を放置していると、自分の会話がOpenAIのモデル学習に使われる設定が既定でオンになっていることに気づかないまま、社外秘の情報を含む相談を続けてしまうリスクもある。ここでは、アカウント作成直後にやっておくべき「カスタム指示（Custom Instructions、毎回の回答に反映させる自分・会社の情報）」「メモリ（Memory、会話から自動的に学習される記憶）」の設定と、会話データをモデル学習に使わせない「オプトアウト」設定をまとめる。

## 仕組み・背景

ChatGPTの個人利用がデフォルトで学習利用を前提としているのは、OpenAIが無料版・Plus・Proなど個人向けプランの会話データを、安全性向上やモデル改善のための学習材料として利用するポリシーを採っているためである。これはBusiness/Enterprise（法人向けプラン。詳細は[ChatGPTのプラン比較](chatgpt-plan-comparison.md)を参照）が「学習に使わない」を既定値にしているのとは対照的で、個人アカウントでは利用者自身が明示的にオフにしない限り学習対象になり続ける。

設定は大きく3層に分かれている。

- **カスタム指示（Custom Instructions）**: 「自分について」「どう応答してほしいか」を一度登録すると、以降のすべての新規チャットの冒頭に自動で差し込まれる仕組み。プロンプト（AIへの指示文）を毎回書く手間を減らす
- **メモリ（Memory）**: ChatGPTが会話の中から「覚えておくべき」と判断した情報を自動的に保存し、後の会話で参照する仕組み。カスタム指示が「利用者が能動的に書く設定」なのに対し、メモリは「AIが会話から拾って蓄積する記憶」という違いがある
- **データコントロール（Data Controls）とモデル学習のオプトアウト**: 会話内容をOpenAIのモデル学習に使わせるかどうかを切り替えるプライバシー設定。カスタム指示・メモリとは独立した設定で、オフにしても回答の質やパーソナライズ機能自体は使い続けられる

## 使いどころ・使い分け

| 設定 | 目的 | オンにすべき場面 | 慎重になるべき場面 |
|---|---|---|---|
| カスタム指示 | 毎回同じ前提説明を省略する | 職種・業界・好みの回答形式が決まっている業務利用全般 | 複数の異なる立場（副業、私用、部署間で共有するアカウント等）で使い分けたい場合は内容が混線するので要注意 |
| メモリ（保存されたメモリ/チャット履歴の参照） | 過去のやり取りを踏まえたパーソナライズ | 継続的なプロジェクトで文脈を都度説明したくない場合 | 機密プロジェクト名・未公開の人事情報などを扱う会話では、メモリに残ってほしくない内容を都度「一時的なチャット」に切り替える |
| モデル学習のオプトアウト | 会話データがOpenAIの学習に使われないようにする | 顧客情報・非公開の社内資料・契約書など、社外秘情報を扱う可能性がある個人アカウントでの利用全般 | 法人としてガバナンスを効かせたいなら、個人アカウントのオプトアウト任せにせず、学習非利用が既定のBusiness/Enterpriseへの移行を検討する（[ChatGPTのプラン比較](chatgpt-plan-comparison.md)参照） |

なお、オプトアウトと「一時的なチャット（Temporary Chat）」は別物である。一時的なチャットは会話履歴に残らず、メモリも使わない・作らない、30日以内に自動削除される、モデル学習にも使われないという「その場限りの会話」用のモードで、通常のオプトアウト設定より保護が強い一方、過去のメモリやカスタム指示を踏まえた連続的な会話はできない。1回限り・記録を残したくない相談には一時的なチャット、日常的な業務利用にはオプトアウト設定、と使い分けるとよい。

## 実務での使い方

### 1. カスタム指示を設定する

**画面の場所**: 画面右上のアカウントアイコン →「設定（Settings）」→ 左メニュー「パーソナライズ（Personalization）」→「カスタム指示（Custom Instructions）」。「カスタマイズを有効にする」のトグルをオンにすると、2つの入力欄が表示される（各欄は最大約1,500文字）。

- 「ChatGPTにあなたについて知ってほしいこと」→ 自分・会社の背景情報
- 「ChatGPTにどう応答してほしいか」→ 出力形式・トーン・避けてほしい振る舞い

コピペで使える記入例（1つ目の欄用）:

```
## 私について
- 職種: 中堅メーカーのマーケティング担当（3年目）
- 業務でよく使う場面: 提案資料の要約、競合調査の下書き、社内向けメールの文面作成
- 前提知識: マーケティング用語は理解しているが、統計・データ分析の専門用語は初心者向けに説明してほしい

## 会社について
- 業種: 一般消費財メーカー
- 想定読者: 資料は社内の非専門部署（営業・経営層）に見せることが多い
- 表記ルール: 社名・製品名は「弊社」「当社製品」のように一般化して書く（固有名詞は自分で置き換える）
```

2つ目の欄（応答スタイル）の記入例:

```
## 回答の仕方
- 結論を最初の1〜2行で述べてから、詳細を箇条書きで展開する
- 断定できない情報は「要確認」と明記する
- 特に指定がない限り、日本語・である体で回答する
- 長すぎる前置きや免責事項は不要
```

### 2. メモリを管理する

同じく「設定 → パーソナライズ」内に「メモリ」の項目があり、「保存されたメモリを参照」「チャット履歴を参照」をそれぞれオン・オフできる（無料プランはメモリ全体のオン/オフのみ、有料プランはより細かく制御可能）。保存された個別の記憶項目は一覧から確認・削除でき、「保存されたメモリを参照」をオフにすると「チャット履歴を参照」も自動的にオフになる。記憶させたくない話題は、都度「一時的なチャット」で会話するか、該当のメモリ項目を手動で削除する。

### 3. モデル学習のオプトアウトを設定する

**画面の場所**: アカウントアイコン →「設定」→「データコントロール（Data Controls）」→「すべての人のためにモデルを改善する（Improve the model for everyone）」のトグルをオフにする。モバイルアプリ（iOS/Android）でも、プロフィールから開く設定内の同項目から同様に操作できる。この設定はデバイスではなくアカウント単位で適用される。

### ツール横断の対応関係

| 概念 | ChatGPT | Gemini | Claude | Microsoft Copilot |
|---|---|---|---|---|
| 自分について毎回教える指示 | 設定 → パーソナライズ → カスタム指示 | 設定 → パーソナルコンテキスト内の「保存された情報（Saved info）」 | 設定 → プロフィール（Custom instructionsに相当する項目） | Copilotのプロフィール設定、または法人向けはAgent Builder等でのシステムプロンプト相当設定 |
| 会話から自動学習する記憶 | 設定 → パーソナライズ →メモリ | 設定 → パーソナルコンテキスト（過去のチャットからの自動推論） | 現時点で同等のフル自動記憶機能は個人向けには限定的 | 法人向けMicrosoft 365 Copilotはグラフ（組織内データ）を参照する仕組みが中心 |
| モデル学習への利用を止めるオプトアウト | 設定 → データコントロール →「すべての人のためにモデルを改善する」をオフ | Geminiアプリのアクティビティ設定（Gemini Appsアクティビティ）をオフ | 設定 → プライバシー →「Help improve Claude」をオフ | Copilotのプライバシー設定でチャット履歴・トレーニングへの利用をオフ |

いずれのツールも呼び方や設置場所は異なるが、「①自分専用の前提を教える指示」「②会話から自動で溜まる記憶」「③学習利用のオプトアウト」という3層構造はほぼ共通している。ツールを乗り換える際は、この3つを対応付けて再設定すると迷わない。

## 注意点・よくある誤解

- **オプトアウトは「これから」の会話にしか効かない**: トグルをオフにしても、オフにする前の会話データが学習からさかのぼって除外されるわけではない。過去データの削除を求める場合は別途、OpenAIへのデータ削除依頼（プライバシーリクエスト）が必要になる
- **オプトアウトしても会話履歴自体は残る**: 「モデル学習に使われない」のと「自分のチャット履歴に表示されなくなる」のは別の設定。履歴からも消したい場合はチャット自体を削除する
- **一時的なチャットとの違いを混同しない**: オプトアウト設定は通常のチャット・メモリ・履歴を維持したまま学習だけを止める設定。記録自体を残したくない場合は一時的なチャットを使う
- **法人利用ならBusiness/Enterprise移行も検討する**: 個人向けプランのオプトアウトは利用者個人の設定に依存するため、組織として一律に統制したい場合は、学習非利用が既定のBusiness以上への移行やSSO・管理コンソールでのポリシー統制の方が確実（[ChatGPTのプラン比較](chatgpt-plan-comparison.md)）
- **地域による違いがある**: EEA（欧州経済領域）・英国・スイスの利用者はGDPR（EU一般データ保護規則）上の権利により、学習利用の停止を求める根拠がより明確になっているが、トグル自体はどの地域でも共通で用意されており、手動でオフにする操作が必要な点は変わらない
- **カスタム指示・メモリは「機密情報の入力を防ぐ機能ではない」**: これらはあくまで回答の質を上げるための個人設定であり、社外秘情報の取り扱いルールは別途、組織のガイドラインに従う必要がある（[生成AI利用における情報漏洩対策](../part03-risk-security/information-leakage-prevention.md)を参照）

## 最初の一歩

今すぐ「設定 → データコントロール」を開き、「すべての人のためにモデルを改善する」の状態を確認してオフにする。続けて「設定 → パーソナライズ → カスタム指示」で、上記のテンプレートを自分の状況に合わせて書き換えて保存する。
