# ChatGPTの初期設定とデータ学習オプトアウト

## これは何か

ChatGPTは初期状態のまま使い始めると、会話内容がモデルの学習に使われたり、機密情報を含む相談がそのまま履歴に残り続けたりする。「会社の非公開情報を貼って相談したら、それが将来のモデル改善に使われるのでは」という不安を持ったまま使うのは業務利用としてリスクが高い。アカウント作成後に確認すべき初期設定(カスタム指示・メモリ・データの学習利用オプトアウト・一時チャット)を一度きちんと設定しておけば、以後は安心して使い倒せる状態になる。

## 仕組み・背景

ChatGPTの設定は大きく4つに分かれる。

1. **パーソナライズ設定(カスタム指示)**: 「自分について」「ChatGPTにどう応答してほしいか」を事前に登録しておき、毎回同じ前提を書かずに済むようにする機能
2. **メモリ(記憶)機能**: 過去の会話から得た情報(職業・好み・進行中のプロジェクトなど)を自動的に記憶し、次回以降の回答に反映する機能。2026年6月からは「Dreaming」と呼ばれる新方式に切り替わっており、ユーザーが個別に確認・削除する保存メモリのリスト方式ではなく、過去の会話全体を背景で分析して記憶内容を継続的に更新する仕組みに変わっている
3. **データコントロール(学習利用オプトアウト)**: 会話をOpenAIのモデル改善に使わせるかどうかを制御する設定。オンのままだと、会話は今後のモデル学習の材料になり得る
4. **一時チャット(Temporary Chat)**: 履歴に残さず、メモリも参照・更新しない単発モードの会話

これらは独立した設定であり、「学習利用オプトアウトをオフにした」からといって履歴が消えるわけではなく、逆に「一時チャットを使った」からといって恒久的にオプトアウトされるわけでもない。それぞれ役割が違う点を最初に理解しておく。

なお、学習利用をオフにしても、不正利用の監視・法令対応・サービス提供のために、会話データは一定期間(目安30日、法的な保全命令が及ぶ範囲ではそれ以上)OpenAI側のシステムに残る場合がある。「オプトアウト=即時に何も残らない」ではない点に注意する。

## 使いどころ・使い分け

| やりたいこと | 使う機能 |
|---|---|
| 毎回「私は〇〇業界の企画職です」と書く手間を省きたい | カスタム指示(パーソナライズ設定) |
| 過去のやり取りを踏まえて会話を続けたい | メモリ機能をオン |
| 会話を今後のモデル学習に使われたくない | データコントロールの学習利用トグルをオフ |
| 特定の相談だけ履歴やメモリに残したくない(採用選考の下書き、他社の非公開情報の下調べなど) | その会話だけ一時チャットを使う |
| 会社としてデータ非学習を標準にしたい | 個人プランではなくBusiness/Enterpriseへの移行を検討 |

判断の起点は「この会話を後から見返す必要があるか」「この内容を学習に使われて困るか」の2軸。両方「NO」なら一時チャット、「履歴は残したいが学習には使われたくない」ならデータコントロールのオプトアウト、が基本の使い分けになる。

## 実務での使い方

### 1. カスタム指示(パーソナライズ設定)を最初に設定する

1. chatgpt.com にログインし、画面左下(PC版)のアカウントアイコンをクリック
2. メニューから「パーソナライズ」を選ぶ(スマホアプリでは、左上のメニューを開き右上のアカウントアイコン→「パーソナライズ」)
3. 「自分について」欄に、職種・業界・知識レベルなどを記入(1,500文字程度の上限あり)
4. 基本のスタイルとトーン(丁寧さ・熱量・見出しやリストの使い方・絵文字の量など)を調整
5. 設定はブラウザ版・デスクトップアプリ・iOS/Androidアプリ間で自動的に同期される

**コピペで使える記入例(「自分について」欄)**

```
## 私について
BtoB SaaS企業のマーケティング担当。社内向け資料作成と、
競合分析・レポート作成を主な業務としている。

## 会社について
従業員300名规模のIT企業。社外に出す文章は必ず「株式会社」を
正式名称で記載し、断定的な表現は避ける社風。

## 回答の希望
- 結論を先に、その後に理由を書く「PREP法」で回答してほしい
- 専門用語は使ってよいが初出時に一言説明を入れてほしい
- 特に指示がない限り、箇条書きよりも短い段落を優先してほしい
```

### 2. メモリ機能のオン・オフを確認する

1. 「設定」→「パーソナライズ」の中にある「メモリ」セクションを開く
2. 「保存されたメモリを参照する」をオフにすると、記憶した情報を回答に反映しなくなる(記憶自体は残る)
3. さらに「チャット履歴を参照する」もオフにすると、過去の会話全体を踏まえた応答も行わなくなる
4. 記憶内容を消したい場合は「パーソナライズ」→「メモリを管理」から個別削除、または「すべてのメモリを削除」を実行する

複数人でPCを共有している、あるいは部署異動などで前提が変わった場合は、記憶をリセットしてから使い直すと回答の精度が上がる。

### 3. データを学習に使わせない設定(オプトアウト)をする

1. アカウントアイコン→「設定」→「データコントロール」を開く
2. 「すべての人のためにモデルを改善する(Improve the model for everyone)」のトグルをオフにする
3. オフにした時点以降の新しい会話が学習対象から外れる(過去にすでに学習済みのデータは遡って取り消せない)
4. チャット履歴自体は消えない。履歴を残したまま学習だけ止める、という設定であることを確認する

### 4. 一時チャット(Temporary Chat)を使う

1. 新しいチャット画面を開き、右上にある点線の吹き出しアイコン(「一時チャットをオンにする」)をクリック、またはモバイルアプリでは同じ位置のアイコンをタップ
2. 一時チャット中は、通常のチャット履歴一覧に表示されず、メモリの参照・更新も行われない
3. 会話を閉じると再度開くことはできない。ただし不正利用対策として、最大30日間はコピーが内部的に保持される
4. 2026年1月のアップデートにより、一時チャットでもカスタム指示は引き続き反映されるようになった(メモリの参照・作成のみが対象外)。「個人的な記憶は使われたくないが、口調の指定などは効かせたい」場合に有効

### プランごとのオプトアウト可否・デフォルトの違い

| プラン | データ学習のデフォルト | オプトアウトの可否 |
|---|---|---|
| Free / Plus / Pro | オン(学習に使われる) | 「データコントロール」で個人が手動オフ可能 |
| Business(旧Team) | オフ(学習に使われない) | デフォルトが非学習。個人設定での変更は原則不要 |
| Enterprise | オフ(学習に使われない) | デフォルトが非学習。管理者がワークスペース単位でデータ保持期間(日数、または無期限保持なし)を設定可能 |

個人のPlus/Proアカウントで会社の機密情報を扱うと、この初期設定を各自が手動でオフにしない限り学習対象になり得る。全社的に非学習をデフォルトにしたいなら、個人プランへの手動オプトアウトの周知に頼るのではなく、Business/Enterpriseへの移行を検討するのが確実。

## 注意点・よくある誤解

- **オプトアウト=会話が即座に消えるわけではない**: 学習に使わせない設定と、履歴の保存・削除は別の話。学習をオフにしても履歴は残る。履歴ごと消したい場合は個別に会話を削除するか、一時チャットを使う。
- **オプトアウトは遡って効かない**: オフにする前に行った会話がすでに学習に使われていた場合、それを後から取り消すことはできない。機密性の高い相談をする前に、必ず先に設定を確認する。
- **削除した会話も一定期間残ることがある**: 不正利用監視や法令対応のため、削除後も内部的にはしばらく保持される場合がある。加えて、他社との訴訟に関連する裁判所命令により、一時的に一部データの長期保全が求められた経緯もある(該当範囲は既存データが中心で、新規チャット全般への適用は後に縮小されている)。「削除すれば完全に何も残らない」という前提では機密情報を扱わない方が安全。
- **一時チャットは組織的に強制できない**: Business/Enterpriseであっても、一時チャットの利用自体は各ユーザーが手動でオンにする必要があり、管理者が全社に一律強制する機能ではない(常時非学習にしたい場合はプラン側のデフォルト設定で対応する)。
- **メモリは2026年6月から仕組みが変わった**: 「Dreaming」と呼ばれる新方式により、個別のメモリ項目を一つずつ確認・削除する従来のUIから、背景合成型の仕組みに移行が進んでいる。記憶内容の透明性(何が記憶されているかの一覧性)が下がる可能性があるため、機密情報を扱う前提であればメモリ参照自体をオフにする運用が安全。

## 最初の一歩

今すぐ「設定→データコントロール」を開き、「すべての人のためにモデルを改善する」のトグルが自分の意図した状態(オン/オフ)になっているかを確認する。
