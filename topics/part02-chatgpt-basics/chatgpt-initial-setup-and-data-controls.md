# ChatGPTの初期設定とデータ利用のオプトアウト設定

## これは何か

ChatGPT(個人向けFree/Go/Plus/Pro)は初期設定のままだと、入力した会話が「モデルの改善(学習)」に使われる状態になっている。契約書のドラフトや顧客リストなど会社の機密情報を貼り付けて使うと、意図せずOpenAI側の学習データに取り込まれるリスクがある。この設定を最初に見直しておくかどうかで、ChatGPTを安心して業務利用できるかが決まる。あわせて「一時チャット」「メモリ」「カスタム指示」など、初期設定でセットで確認しておくべき項目も本ページでまとめる。

## 仕組み・背景

ChatGPTの「データ」に関する設定は、目的の異なる3つの仕組みに分かれている。混同しやすいので整理しておく。

- **データコントロール(学習利用のオプトアウト)**: 入力したチャット内容をOpenAIがモデルの追加学習に使ってよいかどうかのスイッチ。オンにしたまま使うと、会話が将来のモデルの学習材料になり得る。
- **一時チャット(Temporary Chat)**: 履歴に残らず、メモリにも記録されない「その場限り」のチャットモード。ブラウザのシークレットモードに近い感覚で使う機能。
- **メモリ(Memory)・カスタム指示(Custom Instructions)**: ChatGPTに自分の情報や好みの回答スタイルを覚えさせる「パーソナライズ」機能。学習利用のオプトアウトとは別軸の設定であり、オプトアウトしてもメモリは自動では消えない。

個人向けプラン(Free/Go/Plus/Pro)は「すべての人のためにモデルを改善する(Improve the model for everyone)」という設定がデフォルトでオンになっている。一方、法人向けプラン(Business/Enterprise/Edu、およびAPI)は、2023年3月以降のデータについて、契約者側が明示的にオプトインしない限りデフォルトで学習に使われない設計になっている。つまり「個人向けは自分でオフにする必要がある」「法人向けは元からオフになっている」という非対称な構造になっている点が最初に押さえるべきポイントである。

## 使いどころ・使い分け

| 状況 | 取るべき設定 |
|---|---|
| Free/Plus/Proで日常的に使うが、会社の情報は基本的に貼らない | データコントロールはお好みでよいが、機密情報は入力しない運用ルールを徹底 |
| Free/Plus/Proで顧客名・契約書・未公開の数値など機密情報を扱う可能性がある | 「すべての人のためにモデルを改善する」を必ずオフにする |
| 履歴にも残したくない一回限りの相談(人事相談、機微な壁打ちなど) | 都度「一時チャット」を使う(学習利用オプトアウトの設定に関係なく履歴・メモリに残らない) |
| 会社として複数人がChatGPTを業務利用する | 個人契約のPlus/Proではなく、学習非利用がデフォルトのBusiness/Enterpriseへの移行を検討 |
| 過去の会話をふまえて回答してほしい(継続的な業務での利用) | メモリ・カスタム指示をオンにする(データコントロールとは別に設定) |

判断基準はシンプルで、「その入力内容が外に出たら困るか」で考える。困る可能性が少しでもあるなら、個人向けプランでは学習オプトアウトを既定でオンにしておき、本当に一度きりで記録も残したくない内容は一時チャットを使う、という二段構えにするのが実務的な落としどころになる。

## 実務での使い方

### 1. 学習利用のオプトアウト(データコントロール)

**手順(PC・ブラウザ版)**

1. 画面左下(または右上)のアカウントアイコンをクリック
2. 「設定(Settings)」を選択
3. 「データコントロール(Data controls)」タブを開く
4. 「すべての人のためにモデルを改善する(Improve the model for everyone)」のトグルをオフにする

**手順(スマホアプリ版)**

1. メニュー(三本線または自分の名前)をタップ
2. 「設定」→「データコントロール」を開く
3. 同じトグルをオフにする

一度オフにすると、その後は新しい会話がモデル学習に使われなくなる。アカウント単位の設定なので、PC・スマホなど端末をまたいで一度設定すれば反映される。ただし、チャット履歴自体は消えるわけではない点に注意(履歴削除はデータコントロール内の別項目、または個別チャットの削除操作が必要)。

### 2. 一時チャットの使い方

新規チャット画面の右上にある、点線の吹き出しアイコン(「一時チャットをオンにする」)をクリック(スマホアプリでも同じ位置に表示)。一時チャットでは会話が履歴に表示されず、メモリへの読み書きも行われない。ただし不正利用の監視など安全確保の目的で、OpenAI側のシステムには最大30日間だけ内部的に保持され、その後完全に削除される。「学習に使われたくない」だけでなく「この相談自体を記録に残したくない」場合に使う。

### 3. メモリ・カスタム指示(パーソナライズ)

「設定」→「パーソナライズ(Personalization)」から、「カスタム指示(Custom Instructions)」と「メモリ(Memory)」をそれぞれ設定・オンオフできる。

- **カスタム指示**: 毎回変わらない前提条件を登録する欄。「あなたについての詳細」「カスタム指示」の2つの入力欄がある
- **メモリ**: 会話の中でChatGPTが自動的に覚えていく情報。オンオフの切り替えや、記憶済み内容の個別削除が可能

コピペで使えるカスタム指示の記入例:

```
## 私について
- 職業: 製造業の企画部門でマーケティングを担当
- 目的: 社内向け資料の下書き作成、市場調査の要約、メール文面の推敲

## 回答の指示
- 敬語だが硬すぎない、簡潔な日本語で回答してください
- 結論を先に述べ、根拠は箇条書きで示してください
- 専門用語を使う場合は一言説明を添えてください
- 特に指示がない限り、資料のたたき台として500字程度でまとめてください
```

これらはデータコントロールとは独立した設定であり、学習利用をオフにしても、メモリやカスタム指示の内容は自動的には消えない。不要になった場合は個別に削除する。

### ツール横断の対応表

| 概念 | ChatGPT | Claude | Gemini(個人向け) |
|---|---|---|---|
| 学習利用のオプトアウト | 設定→データコントロール→「すべての人のためにモデルを改善する」オフ | 設定→プライバシー(Privacy)→「Help improve Claude」オフ(claude.ai/settings/data-privacy-controls) | Googleアカウント→データとプライバシー→「Geminiアプリのアクティビティ」オフ |
| デフォルトの状態(個人向け) | オン(要オプトアウト) | オン(要オプトアウト、2025年秋の規約改定以降) | オン(18歳以上はデフォルトでアクティビティ保存がオン) |
| 法人向けプランのデフォルト | Business/Enterprise/Eduは学習非利用がデフォルト | Team/Enterpriseは学習非利用がデフォルト | Google WorkspaceのGeminiは学習非利用がデフォルト |
| 記録を残さない単発利用 | 一時チャット(Temporary Chat) | インシグニトモード相当の明確な単発機能は無し(チャットの削除で対応) | アクティビティ保存をオフにした状態での利用(オフでも安全確認のため最大72時間は保持) |
| パーソナライズ機能 | メモリ・カスタム指示(設定→パーソナライズ) | プロジェクトのカスタム指示・スタイル | Gemini拡張機能の設定、Geminiアプリのアクティビティに基づくパーソナライズ |

### 料金プランとの関係(2026年7月時点)

個人向け(Free/Go/Plus/Pro)は自分でデータコントロールをオフにする作業が必須になる。法人として複数人が使う場合は、Business(1ユーザーあたり月額$20〜25程度)以上への契約であれば、学習非利用がデフォルトになるためこの作業自体が不要になる。プランごとの料金・機能差の詳細は[ChatGPTのプラン比較](./chatgpt-plan-comparison.md)を参照。

## 注意点・よくある誤解

- **「オプトアウトすれば会話が即座に消える」わけではない**: あくまで「将来の学習に使われなくなる」だけで、履歴自体やサービス提供・安全確保・法令対応のための一定期間の保持は別に行われる。完全に記録を残したくない場合は一時チャットを使う。
- **メモリ・カスタム指示は自動では消えない**: 学習利用をオフにしても、メモリに保存された「あなたについての情報」は別途手動で削除しない限り残り続ける。定期的に「設定→パーソナライズ→メモリ」で棚卸しするとよい。
- **法人向けプランでも「オプトインすれば学習に使われる」ことがある**: Business/Enterprise/Eduはデフォルトで学習非利用だが、フィードバック機能などで組織が明示的にオプトインした場合はその共有データが学習に使われ得る。管理者は自組織の設定を確認しておく。
- **個人契約のPlus/Proを複数人で使い回すのは危険**: ガバナンス機能(SSO、監査ログ、学習非利用の既定設定)が無いため、会社の情報を扱うなら早めにBusiness以上への移行を検討する。
- **一時チャットも「無制限に安全」ではない**: 不正利用対策のため最大30日間はOpenAI側に一時保持される。機密情報を書いてよいという意味ではなく、あくまで「履歴に残したくない・メモリに反映したくない」ときの機能と理解する。

## 最初の一歩

自分のChatGPTで「設定→データコントロール」を開き、「すべての人のためにモデルを改善する」がオンになっていないか今すぐ確認し、業務で機密情報を扱う可能性があるならオフにする。
