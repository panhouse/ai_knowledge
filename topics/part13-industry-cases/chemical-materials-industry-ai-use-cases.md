# 化学・素材業界における生成AI活用事例

## これは何か

化学・素材業界は、新素材の開発に長年の試行錯誤(トライ&エラー)を要する一方、化学構造式・実験データ・特許文献という専門性の高い情報を大量に扱う業種であり、AIによる材料設計の高速化と、生成AIによる専門文書処理の両面で活用が進んでいる。本ページは、[製造業における生成AI活用事例](manufacturing-ai-use-cases.md)が設計・生産計画・品質管理・保守という工程別の一般的な製造業活用を扱うのに対し、化学構造・材料開発という化学・素材業界固有の研究開発プロセスに絞って事例を整理する。

## 仕組み・背景

化学・素材業界のAI活用は、性格の異なる2つの技術が組み合わさっている。

1. **マテリアルズインフォマティクス(MI、Materials Informatics、材料科学に情報科学・機械学習を組み合わせて新素材の候補を効率的に探索する手法)**: 過去の実験データや物性データベースを機械学習で解析し、目的の性能を持つ材料の組成・配合を予測する技術。旭化成はMIを全社で推進し、「熟練者が試行錯誤で求めたのとほぼ同じレシピを、MIでは1回で求められた」という成果を報告している。横浜ゴムのタイヤゴム材料開発や東レの炭素繊維強化プラスチックの開発期間短縮にもMIが活用されている([AI革命株式会社メディア](https://ai-revolution.co.jp/media/ai-in-chemical/))。Google DeepMindの「GNoME」は、エネルギー貯蔵・半導体・触媒に応用可能な220万件の新規結晶構造(うち38万件が安定材料)を発見したと報告されている([PatSnap](https://www.patsnap.com/resources/blog/rd-blog/ai-generative-chemistry-for-materials-discovery-2026/))。
2. **生成AI(LLM)による専門文書処理・新規用途探索**: 化学構造式の理解や実験結果の表の読み取りなど、化学分野特有の専門性に対応した生成AIの活用が進む。三井化学は日本IBMと協業し、生成AI(GPT)とIBM Watsonを組み合わせて自社製品の新規用途探索を行い、新規用途の発見数を約2倍に増加させた。さらに独自開発の生成AIチャットプラットフォームを2025年度から社内本格運用し、特許検索にかかる時間の80%削減を目指している([日経クロステック](https://xtech.nikkei.com/atcl/nxt/news/24/02031/)、[三井化学公式](https://jp.mitsuichemicals.com/jp/release/2024/2024_1225/index.htm))。

MIが「実験データから最適な材料組成を予測する」ことに強い一方、生成AI(LLM)は「化学構造式や実験報告書を読み解き、新規用途のアイデアを言語化する」ことに強いという役割分担がある。

## 使いどころ・使い分け

| 業務 | MI(機械学習ベースの材料探索) | 生成AI(LLM、汎用チャットAI・専用文書処理AI) |
|---|---|---|
| 新素材の組成・配合の最適化 | 向く(過去の実験データからの予測) | 向かない(化学的な予測モデルではない) |
| 実験レポート・特許文献の要約・検索 | 向かない | 向く(専用生成AIチャット、汎用チャットAI) |
| 新規用途のアイデア出し | 一部対応(既存データとの類似性分析) | 向く(化学構造・特性データを渡してのブレインストーミング) |
| 安全データシート(SDS)・技術資料のドラフト作成 | 向かない | 向く(定型フォーマットの下書き高速化) |
| プラントの異常検知・予知保全 | 向く(時系列データの機械学習モデル) | 限定的(異常の説明文生成の補助) |

判断基準は「実験データに基づく数値予測が必要か」「文書の読解・要約・下書き作成が必要か」で、前者はMI・専用の機械学習基盤、後者は生成AI(LLM)の得意領域である。

## 実務での使い方

### プロンプト例1: 実験データからの新規用途アイデア出し

```
以下は自社が保有する樹脂材料の物性データです。この材料の特性を踏まえ、
現在想定していない業界・用途での応用可能性を5つ提案してください。
各提案について、想定される競合材料と、自社材料が優位性を持ちそうな理由を1行で添えてください。

[物性データ(耐熱性・強度・柔軟性など)を記載]
```

出力はあくまでアイデアの叩き台であり、実際の適用可否は追加の実験・評価で検証する。

### プロンプト例2: 特許文献の一次スクリーニング

```
以下の特許公報の要約を読み、自社が開発中の[技術領域]と抵触・類似する可能性が
「高い」「中」「低い」のいずれかに分類してください。「高い」の場合は、
具体的にどの請求項が関連しそうかを1行で指摘してください。

[特許公報の要約またはURLを貼り付け]
```

一次スクリーニングとしての活用にとどめ、実際の抵触判断・出願戦略は知的財産部門・弁理士が行う。

### プロンプト例3: SDS(安全データシート)の記載下書き

```
以下の製品の成分・危険有害性情報をもとに、SDSの「取扱い及び保管上の注意」セクションの
下書きを作成してください。GHS(化学品の分類および表示に関する世界調和システム)の
分類区分に基づいた標準的な表現を用いてください。

[製品の成分・GHS分類情報を記載]
```

SDSは法令に基づく記載義務があるため、下書きは必ず安全管理・法務担当者が最新の法令・分類基準と照合してから正式発行する。

### ツール横断の対応表

| 用途 | ツール例 |
|---|---|
| 材料組成・配合の最適化(MI) | 各社独自のMI基盤、Google DeepMind「GNoME」 |
| 特許検索・実験レポートの読解 | 三井化学の独自開発生成AIチャットプラットフォーム |
| 新規用途探索 | 汎用チャットAI(GPT)とIBM Watson等の組み合わせ |
| SDS・技術資料のドラフト作成 | ChatGPT/Gemini/Claude/Copilot(汎用チャットAI) |

## 注意点・よくある誤解

- **MIと生成AI(LLM)を混同しない**: MIは実験データに基づく機械学習の予測モデルであり、汎用チャットAIに「新素材のレシピを考えて」と聞いても、実験に基づかない「もっともらしい」回答が返ってくるだけである。材料組成の最適化は専用のMI基盤・実験データが前提。
- **未公開の発明情報を汎用チャットAIに入力しない**: 新規用途探索や特許調査で自社の未公開技術情報を入力すると、特許の新規性喪失につながるリスクがある。法人契約でデータ学習利用がオプトアウトされているかを必ず確認する([研究開発(R&D)職における生成AI活用事例](../part14-job-role-cases/rd-ai-use-cases.md)の注意点も参照)。
- **SDS・法定文書はAIの下書きをそのまま発行しない**: 化学物質の危険有害性情報は法令(化学物質排出把握管理促進法、労働安全衛生法等)に基づく正確な記載が求められる。AIの出力は下書きにとどめ、必ず専門部署が最新の法令・分類基準と照合する。
- **特許抵触判定の最終責任はAIに負わせない**: 生成AIによる特許文献の一次スクリーニングは調査の効率化に有効だが、抵触の有無や侵害リスクの最終判断は知的財産部門・弁理士が行う。

## 最初の一歩

保有する材料データや過去の特許文献を1件用意し、チャットAIに新規用途のアイデア出しや特許の一次スクリーニングを試させて、調査時間がどれだけ短縮できるかを確認してみる。
