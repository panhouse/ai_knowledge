# 製薬業界における生成AI活用事例

## これは何か

製薬業界は、新薬開発に平均10年以上・数百億円規模のコストを要する一方、治験関連文書・規制当局への提出資料・医療従事者向け資材といった膨大な文書作成業務を抱える業種であり、生成AIによる効率化の余地が大きい。本ページは、[医療・ヘルスケアにおける生成AI活用事例](healthcare-ai-use-cases.md)が病院・クリニックでの問診・診療記録作成支援やInsilico Medicineの創薬事例を1領域として扱うのに対し、創薬(候補化合物の探索・設計)・治験文書作成・MR(医薬情報担当者)/MSL(メディカルサイエンスリエゾン、KOLとの科学的対話を担う専門職)の実務という、医薬品を開発・提供する企業側の業務に焦点を当てて掘り下げる事例カタログである。

## 仕組み・背景

製薬業界における生成AI・AIの活用は、バリューチェーンに沿って大きく3つの段階に分かれる。

1. **創薬(候補化合物の探索・設計)**: AIが分子構造を生成し、標的探索から治験成功率の予測までを高速化する。第一三共はAmazon Web Servicesと協業し、複数の創薬AIエージェントを統合的に動かす「AIエージェント統合型創薬基盤」を構築中で、2026年の運用開始を公表している。中外製薬は独自の抗体配列最適化AI「MALEXA」を開発し、既存抗体と比較して結合強度が1,800倍以上に向上した配列を提案した実績がある([AI革命株式会社メディア](https://ai-revolution.co.jp/media/ai-in-pharmaceutical/))。2026年時点でAI由来の医薬品候補は173件以上が臨床開発段階にあり、第I相試験の成功率は80〜90%と、従来の平均(約52%)を大きく上回るという報告もある([axis-intelligence](https://axis-intelligence.com/ai-drug-discovery-2026-complete-analysis/))。
2. **治験・規制文書の作成支援**: 治験総括報告書・治験実施計画書など、規制当局(PMDA・FDA等)への提出が前提の文書は、フォーマットが厳格に決まっている一方で分量が膨大という特性を持つ。塩野義製薬と日立は生成AIを活用した規制関連文書作成支援ソリューションを提供開始し、治験総括報告書の作成時間を約50%、治験実施計画書の作成時間を約20%削減する効果を確認したと発表している([塩野義製薬公式](https://www.shionogi.com/jp/ja/news/2026/02/20260224.html))。米FDAも2025年1月、医薬品開発における AI活用の考え方を示すガイダンス草案を公表し、規制当局側もAI活用を前提とした枠組み整備を進めている([IntuitionLabs](https://intuitionlabs.ai/articles/ai-drug-discovery-pipeline))。
3. **MR・MSLの営業・学術活動支援**: MR(医薬情報担当者)は医療従事者への情報提供・資材作成、MSLはKOL(キーオピニオンリーダー、その領域で影響力の大きい専門家)との科学的対話を担う。生成AIは、面談相手の医師の経歴・注力領域・直近の筆頭著者論文・学会登壇履歴といった背景情報の収集、文献の翻訳・要約、医師との対話を模擬したロールプレイングなどに活用されている([Medinew](https://www.medinew.jp/articles/marketing/trend/genai-pharma-usecases))。

McKinseyは、生成AIが製薬バリューチェーン全体で年間600〜1,100億ドルのコスト削減効果を生む可能性があると試算している([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC13118854/))。

## 使いどころ・使い分け

| 業務 | 生成AI・AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| 候補化合物の分子構造生成・標的探索 | 向く(専用の創薬AI基盤による高速スクリーニング) | 最終的な有効性・安全性の証明は臨床試験でしか得られない |
| 治験総括報告書・実施計画書のドラフト作成 | 向く(定型フォーマットの下書き高速化) | 提出前の数値・記載内容は必ず専門部署が原本と照合する |
| MR向け医師背景リサーチ・資材の壁打ち | 向く(下調べ・想定問答の準備) | 医療従事者への最終的な情報提供内容は薬機法上の広告規制を踏まえ人が確認する |
| 文献の翻訳・要約 | 向く | 臨床判断に関わる要約は必ず原文と照合する |
| 副作用報告(ファーマコビジランス)の一次スクリーニング | 限定的(大量データの一次分類補助) | 重篤性判定・当局報告の要否は専門人材の最終判断が必須 |
| MR・MSLと医師との実際の面談内容 | 向かない | AIによる代替は薬機法・倫理上想定されていない |

## 実務での使い方

### プロンプト例1: MR向け医師面談前の背景リサーチ

```
以下の医師について、次回面談前の準備資料を作成してください。
- 専門領域・直近の学会発表テーマ
- 筆頭著者として発表した論文の要旨(直近2年分)
- 過去の面談記録で言及された関心事項(あれば要約)

[医師名・専門領域・入手済みの経歴情報を記載]

出力は箇条書きで、事実確認が必要な項目には「要確認」と明記してください。
```

生成された背景情報は必ず一次情報(論文・学会プログラム等)で裏取りを行う。医師の個人情報の取り扱いは社内規程に従う。

### プロンプト例2: 治験実施計画書のセクション下書き

```
以下の治験概要をもとに、治験実施計画書の「対象患者の選択基準・除外基準」セクションの
下書きを作成してください。規制当局への提出を前提とした、簡潔で明確な記載にしてください。

[治験の目的・対象疾患・投与方法などの概要を記載]

出力後、既存の類似治験の記載と表現の統一が必要な箇所があれば指摘してください。
```

下書きは必ず臨床開発部門・regulatory affairs(薬事)担当が内容を精査し、最終稿は原本のデータ・過去の承認事例と突合する。

### プロンプト例3: 医学論文の要約・翻訳

```
以下の英語論文のアブストラクトを、MR向けの社内資料として日本語に要約してください。
- 対象疾患、試験デザイン、主要評価項目、結果の要点を4行程度で
- 専門用語には初出で一言説明を付ける
- 数値(有効率・p値など)は原文の表記のまま正確に転記する

[論文アブストラクトを貼り付け]
```

医療従事者向けに配布する資料として使う場合は、必ず学術情報部門の確認を経る。

### ツール横断の対応表

| 用途 | ツール例 |
|---|---|
| 創薬(分子設計・標的探索) | 中外製薬「MALEXA」、Insilico Medicine、各社の創薬AIエージェント基盤 |
| 治験・規制文書の作成支援 | 塩野義製薬×日立の規制関連文書作成支援ソリューション |
| MR・MSLの背景リサーチ・文献要約・資材壁打ち | ChatGPT/Gemini/Claude/Copilot(汎用チャットAI、法人契約前提) |

## 注意点・よくある誤解

- **「AIが創薬した」と「承認された医薬品」は別物**: 2026年時点でAI由来の医薬品候補は臨床開発段階にある品目が多数を占め、完全なFDA承認第1号は2026〜2027年に見込まれる段階である([axis-intelligence](https://axis-intelligence.com/ai-drug-discovery-2026-complete-analysis/))。「AIが創薬した薬」という表現を過度に一般化して社内外に発信しない。
- **提出文書は必ず原本データと突合する**: 治験総括報告書等の作成時間短縮は「下書き作成」の効率化であり、記載された数値・結論の正しさを担保する仕組みではない。規制当局への提出前に専門部署による精査を必ず挟む。
- **医療従事者への情報提供は薬機法の広告規制を踏まえる**: AIが生成した文章表現が、未承認効能の示唆や誇大表現に該当しないか、資材化する前に確認する。
- **患者・治験参加者の個人情報を安易に入力しない**: 治験データや副作用報告には機微な個人情報が含まれるため、法人契約でデータ学習利用がオプトアウトされているツールを使う([生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md))。

## 最初の一歩

MR・MSL業務であれば次回の医師面談前の背景リサーチを、開発部門であれば治験文書の1セクションの下書き作成を、チャットAIに試させて、事実確認込みでどれだけ準備時間が短縮できるかを確認してみる。
