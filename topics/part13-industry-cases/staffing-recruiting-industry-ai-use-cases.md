# 人材紹介・人材サービス業における生成AI活用事例

## これは何か

人材紹介・人材サービス業とは、リクルート・パーソル・ビズリーチ・LinkedInのように、求職者と求人企業を仲介すること自体が事業(商品)である業種を指す。求人票の作成支援、候補者と求人の自動マッチング、スカウト文面の生成、面接日程の調整、応募書類の一次スクリーニングといった「仲介業務のコア工程」に生成AIを組み込むことで、扱える候補者・求人の母数を増やしながら1件あたりの処理時間を減らすことが競争力に直結する。本ページは[「人事(HR)職における生成AI活用事例」](../part14-job-role-cases/hr-ai-use-cases.md)(Part 11)とは対象が異なる点に注意したい。Part 11は「1社の内部で自社の採用・人事業務を行う人事担当者」の話であるのに対し、本ページ(Part 13)は「多数の求人企業と多数の求職者を同時に仲介する、人材サービス企業そのもののビジネス」を扱う。前者は自社1社分のデータを扱えばよいが、後者はAIの判断が一度に多数の候補者・多数の企業に影響するため、マッチングの公平性やアルゴリズムのバイアスがより大きな社会的リスクになる。

## 業務工程別の活用マップ

| 工程 | 課題 | AI・生成AIの役割 | 代表事例(本ページ内) |
|---|---|---|---|
| 求人票作成 | 求人企業ごとに表現・条件がバラバラで、担当者の作文負荷が高い | 職種・条件を入力すると求人票のたたき台を自動生成し、タイトル・給与表記・職務内容をAIが最適化 | ビズリーチ「求人自動作成機能」、パーソルキャリアの求人票自動作成アプリ、Indeed Talent Scout |
| 候補者マッチング | 数億件規模の求人・求職者データから最適な組み合わせを見つけるのは人力では不可能 | 自然言語での要件理解と大規模データベースの突合により、候補者・求人双方に合った相手を提示 | Indeed Career Scout / Indeed Talent Scout、LinkedIn Hiring Assistant |
| スカウト文面作成 | 大量の候補者に個別最適化した文面を送る時間がなく、定型文だと返信率が低い | 求人内容と候補者の職務経歴書を分析し、候補者ごとにパーソナライズしたスカウト文を自動生成 | ビズリーチ「スカウトメッセージAIカスタマイズ機能」、dodaダイレクトの検索条件自動生成機能 |
| 面接調整 | 複数の候補日・面接官の空き状況の突合に時間がかかり、採用リードタイムが伸びる | 面接官の予定を解析し、日程調整のやり取りそのものをAIエージェントが代行 | PKSHA「日程調整AI」、LinkedIn Hiring Assistantのスケジューリング支援 |
| 一次スクリーニング・書類作成支援 | 応募が集中する求人ほど書類確認の工数が膨らむ、求職者側も職務経歴書作成に時間がかかる | 職務経歴書の要約・整理をAIが支援し、要件との合致度を一次的に可視化 | dodaの職務経歴書作成支援、LinkedIn Hiring Assistantのプロフィールレビュー削減 |

**読み方のコツ**: 表の左3工程(求人票作成・マッチング・スカウト文面)は「AIに作らせて人が仕上げる」領域として定着しつつあるのに対し、右2工程(面接調整・一次スクリーニング)は「候補者本人の可否・評価に近づく」領域であるため、AIの自動化範囲を広げるほど公平性・説明責任の設計が重要になる。

## 代表事例の詳細

### 1. マッチング: リクルートホールディングス/Indeed「Indeed Career Scout」「Indeed Talent Scout」

- **企業**: 株式会社リクルートホールディングス(2012年に買収した米Indeedとの事業統合を推進中)
- **課題**: 従来の求人検索は「求人票に書かれたキーワード」と「求職者が入力した検索語」の一致度でマッチングしており、通勤条件・希望する働き方・スキルの背景といった履歴書に表れない情報を汲み取れなかった。企業側も応募が集中すると数百件の書類確認に忙殺されていた
- **導入したAI・仕組み**: 2025年5月9日の決算説明会で発表。「Indeed Career Scout」は求職者向けのAIキャリアコーチで、対話を通じてスキル・通勤条件・希望勤務時間・希望年収など履歴書に書かれない情報まで学習し、求職者本人の自己理解と求人紹介の精度を高める。「Indeed Talent Scout」は企業側のAI採用エージェントで、大量の応募書類を読み込んで一次確認する負担を減らし、自然言語での問い合わせに答えながら求人タイトル・勤務地表記・待遇条件などの掲載内容を最適化する
- **状況**: 2026年7月時点では米国で先行テスト中で、日本市場への投入時期は未定。国内では「Indeed PLUS」がAIによる求人解析で、タウンワーク・リクナビNEXTなど提携媒体へ自動配信し、最大約7割の求職者にリーチする仕組みを既に稼働させている
- **自社への応用ヒント**: 「検索語の一致」から「対話で候補者の背景を理解した上でのマッチング」へという流れは、社内の人材データベースを持つ企業の人事部門にとっても応用できる発想。求人票の一致度だけでなく、対話形式で候補者理解を深めるプロセスをどこに組み込めるかを考える材料になる

### 2. スカウト文面・求人票作成: ビズリーチ「ビズリーチAI」

- **企業**: 株式会社ビズリーチ(転職サイト「ビズリーチ」運営)
- **課題**: ダイレクトリクルーティング(企業がデータベースから候補者を探して直接スカウトする採用手法)は、候補者ごとにスカウト文面を個別に書く必要があり、採用担当者の作成負荷が高い一方、定型文の使い回しは返信率が下がりやすい
- **導入したAI・仕組み**: 16年分の転職市場データを学習した自社の生成AI「ビズリーチAI」を搭載。2025年4月23日に「求人自動作成機能」を正式提供開始し、募集条件を入力すると求人票のたたき台をAIが生成する。2025年10月22日には「スカウトメッセージAIカスタマイズ機能」を追加し、求人情報と候補者の職務経歴書を分析して候補者一人ひとりの志向を反映したスカウト文を自動作成できるようにした
- **効果**: 企業の発表によれば、候補者に合わせて個別最適化されたスカウト文により、即戦力人材からの返信率向上とマッチング機会の最大化を狙いとしている
- **自社への応用ヒント**: 「定型スカウト文の一斉配信」ではなく「候補者の職務経歴書を読んだ上でのパーソナライズ」を自動化した点が学びどころ。自社で候補者データベースを持つ企業(採用担当・アルムナイ採用など)でも、候補者ごとの経歴情報を読み込ませた上でスカウト文の下書きを作らせる運用に転用しやすい

### 3. 求人票作成・書類作成支援: パーソルキャリア「求人票自動作成アプリ」「dodaダイレクト」

- **企業**: パーソルキャリア株式会社(人材紹介・転職サービス「doda」運営)
- **課題**: 中途採用の人材紹介・採用コンサルティング領域では、求人企業ごとの募集要件を求人票に落とし込む作業に時間がかかり、公開までのリードタイムが長引くと機会損失につながる。またダイレクトリクルーティングの「dodaダイレクト」では、スカウト送信の前提となる検索条件の設計に手間がかかっていた
- **導入したAI・仕組み**: 2026年5月、中途採用の人材紹介・採用コンサルティング領域向けに生成AIを活用した「求人票自動作成アプリ」を発表。求人票公開までのリードタイムを平均0.85日短縮したと公表している。「dodaダイレクト」では2025年11月より大規模言語モデル(LLM)を活用した「検索条件の自動生成機能」を提供開始し、求人票から「卒業経過年数」「居住地」「年収」「職種」といった検索条件をAIが自動生成することで、ダイレクトリクルーティングの準備工数を削減している。加えて「doda」では生成AIによる職務経歴書作成支援機能により、求職者側の職務経歴書作成フローの所要時間を4分の1に短縮している
- **自社への応用ヒント**: 求人企業向け(求人票作成)と求職者向け(職務経歴書作成)の両方に生成AIを投入し、仲介の両サイドの入力コストを同時に下げている点が特徴。人材サービス業に限らず、「情報の出し手」と「受け手」の双方にAI支援を用意することで、マッチングの母数と速度を同時に増やせないかという発想は他業種にも転用できる
- **参考**: 面接日程調整の工程については、PKSHA Technologyが2026年3月にAI Suite for HR(1,000社超が利用)の対象領域を拡張する形で「日程調整AI」をベータリリースしており、面接官の予定を解析してAIが自律的に日程調整を行うことで、調整工数を約5割削減できるとしている。人材紹介会社自身が候補者・面接官双方の日程を仲介する場面でも応用しやすい工程である

### 4. マッチング・スクリーニング: LinkedIn「Hiring Assistant」

- **企業**: LinkedIn(Microsoft傘下)
- **課題**: リクルーター(採用担当者)は、求人の要件定義から候補者の絞り込み、メッセージ送付、面接日程調整まで一連の業務を人力でこなしており、応募が多い求人ほど候補者プロフィールの確認作業に忙殺されていた
- **導入したAI・仕組み**: LinkedIn初のAIエージェント「Hiring Assistant」が2025年9月に英語版で一般提供開始。採用担当者との対話を通じて役割・チーム構成・求める人物像を理解し、求人票と面談情報を候補者要件に変換した上で、LinkedInのプロフィールデータベースから適合候補者のパイプラインを自動構築する。基本的な候補者からの質問への返信や面接日程調整の支援も行う。2026年2月にはMicrosoft Teams連携、AIフォローアップ、AI応募者ターゲティングなどの機能が追加された
- **効果**: LinkedInの発表(2026年1月時点)では、プロフィール確認作業を81%削減、InMail(LinkedIn上のスカウトメッセージ)の承諾率を66%向上、1求人あたり適格な応募者の特定にかかる時間を平均1.5時間削減したとしている
- **自社への応用ヒント**: 「候補者を探す」だけでなく「要件のヒアリング→候補者探索→一次メッセージ→日程調整」という採用プロセス全体をエージェントに任せる設計思想が特徴。人材紹介会社が自社のコンサルタント業務のどこまでをAIエージェントに任せ、どこから人が引き継ぐかを線引きする際の参考になる

## 実務での使い方

### 1. 求人票ドラフトの生成(汎用チャットAIでの代替例)

専用ツールを持たない中小規模の人材紹介会社・エージェントでも、ChatGPT/Gemini/Claudeで同様の下書き作成ができる。

```
あなたは人材紹介会社のコンサルタントです。以下の求人企業からのヒアリング内容をもとに、
候補者に響く求人票のドラフトを作成してください。

【企業】従業員80名のBtoB SaaS企業(物流業界向けSaaS)
【募集職種】カスタマーサクセス
【必須要件】BtoB SaaSでのCS経験2年以上
【歓迎要件】物流・サプライチェーン業界の実務経験
【アピールポイント】離職率低い、リモート可、月1回の全社総会あり
【トーン】堅すぎず、転職検討中の若手にも読みやすい文体

出力構成: 仕事内容 / 必須要件 / 歓迎要件 / 働き方・制度 / 求人企業からの一言(3行)
性別・年齢・国籍など職業安定法上使用してはいけない表現が入っていないか
最後にセルフチェックして指摘してください。
```

### 2. 候補者ごとのスカウト文面の下書き

```
以下の求人内容と候補者の職務経歴書(要約)をもとに、
この候補者向けにパーソナライズしたスカウトメッセージを作成してください。

【求人内容】(貼り付け)
【候補者の職務経歴書要約】(貼り付け)

条件:
・候補者のこれまでの経験のうち、求人内容と特に合致する点を1〜2点具体的に引用する
・定型文らしさを避け、なぜこの候補者に声をかけたのかが伝わる文にする
・文字数は400字以内、返信のハードルを下げる一文を末尾に入れる
・年齢・性別・国籍など職業安定法上配慮すべき属性には触れない
```

### 3. 応募書類の一次整理(合否判定はさせない)

```
以下は求人企業の必須要件と、匿名化した応募者の職務経歴です。
評価や優劣の判定、合否の推奨はせず、
「求人要件に対して、経歴のどこが合致し、どこが情報不足か」を箇条書きで整理してください。

【求人要件】(貼り付け)
【応募者の職務経歴(氏名・性別・生年月日等を削除した匿名化済みテキスト)】(貼り付け)
```

### ツール横断の対応表

| やりたいこと | 主に使うツール |
|---|---|
| 求人票のたたき台作成 | ビズリーチAI「求人自動作成機能」、パーソルキャリア「求人票自動作成アプリ」、Indeed Talent Scout、汎用チャットAI(ChatGPT/Gemini/Claude) |
| 候補者ごとのスカウト文面生成 | ビズリーチ「スカウトメッセージAIカスタマイズ機能」、dodaダイレクト「検索条件の自動生成機能」、LinkedIn Hiring Assistant |
| 面接日程調整の自動化 | PKSHA「日程調整AI」、TimeRex・Spirなどの日程調整ツール(採用特化ではないが人材紹介実務でも利用) |
| 職務経歴書の作成支援(求職者向け) | dodaの職務経歴書作成支援、エン・ジャパン「ミドルの転職」のレジュメ自動作成 |
| 大規模候補者データベースからのマッチング | Indeed Career Scout / Indeed Talent Scout、LinkedIn Hiring Assistant |

## 注意点・よくある誤解

- **AIマッチング・レコメンドの結果が「差別的取扱い」に該当しないかの確認は法的義務に近い**: 職業安定法第3条および職業紹介事業等に係る指針は、申込みの受理・面接・指導・紹介などあらゆる業務における差別的取扱いを禁じている。厚生労働省は令和4年(2022年)の職業安定法改正の解説資料で、AI等を活用したレコメンドシステムが「多様かつ膨大な求人・求職情報を分析し適合する情報を提供するものであり適切に使えば有用」としつつ、AIによるレコメンド結果が差別的取扱いに該当しないよう留意が必要と明記している。人材紹介会社は自社1社の採用ではなく、多数の求人企業・求職者に同時に影響する立場であるため、偏りが生じた場合の影響範囲は事業会社の内部採用よりもはるかに大きい
- **求職者に関する情報の収集・利用は「特定募集情報等提供事業」の規制対象になりうる**: 2022年改正職業安定法により、求職者に関する情報(氏名等の個人情報だけでなく、メールアドレス・経歴・サイト閲覧履歴なども含む)を収集して行う募集情報等提供事業は「特定募集情報等提供事業」として事前届出や個人情報の利用目的の明示が義務付けられている。AIマッチングのために候補者データを学習・分析に使う場合、この規制の対象になっていないかを事業設計の段階で確認する必要がある
- **「最終的な合否・紹介判断はAIに一任しない」を明文化する**: 本ページの事例の多くは「マッチング候補の提示」「文面の下書き」「日程調整」など人の意思決定を支援する用途にとどまっており、合否そのものを機械的に確定させているわけではない。AIが提示した候補順位・スコアをそのまま採否に使うと、学習データに含まれる過去の偏り(特定の属性の採用実績が少ない等)がそのまま再生産されるリスクがある。海外では、過去10年分の応募データで学習した採用AIが女性応募者を系統的に低く評価し運用停止になった事例が知られており、日本の人材紹介事業でも同種のリスクは同じ理屈で当てはまる
- **候補者の職務経歴書・個人情報を学習目的で外部AIに入力しない**: スカウト文面生成や職務経歴書要約に汎用チャットAIを使う場合、法人契約でオプトアウト設定(入力データをモデル学習に使わない設定)が確認できているツールを使う。無料版・個人契約のAIに候補者の実データを入力するのは情報漏洩リスクが高い(詳細は[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md)を参照)
- **AI生成の応募書類が増えていることへの対応**: 2026年の採用トレンドとして、応募者側もAIで職務経歴書・自己PR・面接回答を作成するケースが増えており、AIで書かれた書類をAIでスクリーニングする状況が広がっている。文面の巧拙だけで一次評価をすると、AI活用度の差が評価に混入するおそれがあるため、経験の具体性・実績の裏付けなど内容面を見る運用が重要になる

## 最初の一歩

自社(または担当先)で直近扱った求人1件を選び、上記「スカウト文面の下書き」プロンプトに求人内容と候補者の職務経歴要約(匿名化したサンプルでよい)を貼り、AIが下書きした文面と自分で書いた場合の文面を比較してみる。
