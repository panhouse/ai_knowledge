# ChatGPTの初期設定とカスタム指示の書き方

## これは何か

カスタム指示(Custom Instructions)とは、「自分が何者か」「どう答えてほしいか」をあらかじめ登録しておくことで、毎回の会話で同じ前提説明を繰り返さずに済む機能である。これを設定しないままChatGPTを使っていると、「私はマーケティング担当なのですが」「です・ます調で」「結論から書いて」といった前置きを、質問のたびに手で入力し続けることになる。カスタム指示は無料プランを含む全プランで使え、設定内容は保存した瞬間からすべての会話に適用される。2025年11月の仕様変更以降、この反映は新規チャットだけでなく**進行中の既存の会話にも即座に及ぶ**ようになっており(それ以前は新規チャットにしか効かなかった)、「途中まで話していたチャットに設定変更を反映させたければ新しいチャットを開き直す」という以前の運用は不要になっている。

似た働きをする機能に「メモリ(Memory)」があるが、両者は仕組みが異なる。カスタム指示は自分で書いて明示的に登録する「固定の設定」、メモリは会話の中でChatGPTが自動的に学習していく「動的な記憶」である。この違いを理解していないと、「前に話した内容をなぜ覚えていないのか」「なぜ設定した通りに答えてくれないのか」といった誤解が生まれやすい。

## 仕組み・背景

カスタム指示に書いた内容は、ユーザーには見えない形で会話の裏側(システムメッセージ)に追加され、以後のすべてのやり取りの前提として扱われる。2023年7月に導入された当初は「自分について」「回答スタイル」の2つの入力欄だけだったが、2026年9月時点では次の3つの仕組みが「パーソナライズ」という1つの設定画面に統合されている。

| 仕組み | 何を設定するか | 更新のされ方 |
|---|---|---|
| カスタム指示(2つの自由記述欄) | 自分の属性・背景/回答してほしい形式やトーン | 自分で書いて手動更新。保存すると新規チャットだけでなく既存の会話にも即座に反映される(2025年11月以降) |
| 基本のスタイル(Base style and tone) | Default・Professional・Friendly・Candid・Quirky・Efficient・Nerdy・Cynicalなど口調のプリセットと、温かみ・熱量・見出しやリストの使用・絵文字量の強弱 | プルダウンとスライダーで選択。こちらも変更は既存の会話に即座に反映される。答えの「話し方」だけを変え、思考や機能そのものは変えない |
| メモリ(Memory) | 「保存されたメモリ」(会話の中でChatGPTが覚えた事実の一覧。編集・削除可能)と「チャット履歴を参照」(過去の会話全体から傾向を暗黙的に汲み取る機能) | 会話の中で自動的に蓄積される。ユーザーが明示的に「覚えておいて」と頼んだ場合も、話の流れから拾われる場合もある |

カスタム指示とメモリは併用され、両方の内容が回答生成時に加味される。優先順位としては、プロジェクト(特定の案件やテーマ専用のワークスペース)内で個別に指示を設定した場合、その指示がプロジェクト内ではグローバルなカスタム指示より優先される。

なお、2026年に投入されたモデル「GPT-6 Astra」は指示追従の精度が上がり、カスタム指示や会話中の指示に曖昧さが残る場面でも、文脈から妥当な解釈を補って作業を進めたり、結果を左右しそうな点だけ的を絞って聞き返したりする挙動が強化されている。カスタム指示の書き方自体を大きく変える必要はないが、「解釈の余地を残すとAIが自己判断で補ってしまう」ことを前提に、譲れない条件ほど明確に書くことの重要性は増している。

似て非なる新機能として、Pro向けの「ChatGPT Pulse」がある。これはGmail・カレンダーなどの連携アプリと保存済みメモリ・チャット履歴をもとに、ChatGPTが夜間にバックグラウンドで調べものをして翌朝トピックを提案してくる先回り型の機能で、カスタム指示のように自分で明示的に書き込む設定ではない。カスタム指示・メモリ・Pulseはいずれも「パーソナライズ」の傘の下にあるが、カスタム指示は自分で書く固定ルール、メモリは自動蓄積される事実、Pulseはそれらを使ってAI側から能動的に提案してくる機能、と役割が分かれている。

## 使いどころ・使い分け

| やりたいこと | 向いている機能 |
|---|---|
| 自分の役職・業界・文体の好みなど、常に一貫して適用したい前提がある | カスタム指示 |
| 会話の中で自然に出てきた情報(担当プロジェクト名、好みの言い回しなど)を、指示として書くほどではないが覚えておいてほしい | メモリ(保存されたメモリ/チャット履歴を参照) |
| 特定の案件・クライアントワークだけに閉じた設定にしたい。他の会話に情報が漏れると困る | プロジェクト機能内の指示欄(プロジェクト外のチャットには影響しない) |
| 特定の役割に特化した専用アシスタントを作り、社内の他メンバーとも共有したい | カスタムGPT(GPTs)の「指示」欄 |
| 機密情報を扱う一回限りの相談で、パーソナライズや記憶を一切残したくない | 一時的なチャット(Temporary Chat)。ただし有効化しているカスタム指示自体は一時チャットにも適用される点に注意 |
| 組織として統一したルール(表記ゆれの防止、社内用語集の遵守など)をメンバー全員に配布したい | Business/Enterpriseの管理者が共有できる指示セット。個人のカスタム指示より優先させるかはRBAC(ロールベースのアクセス制御)側の設定に従う |

判断に迷ったら、「守らせたい永続的なルール」はカスタム指示に、「会話の流れで覚えてほしい個別の事実」はメモリに任せる、という切り分けが基本になる。

## 実務での使い方

### 設定画面の場所(2026年9月時点)

**パソコン(ブラウザ版 chatgpt.com)**

1. 画面左下のアカウント(プロフィール)アイコンをクリック
2. メニューから「パーソナライズ」を選ぶ、または「設定」→「パーソナライズ」を開く
3. 「カスタム指示」の項目を開き、2つの入力欄に記入する

**スマートフォン版アプリ**

1. アプリ左上のメニューを開く
2. 右上のアカウントアイコンをタップ
3. 「パーソナライズ」を開き、「カスタム指示」を編集する

同じ「パーソナライズ」画面の中に、口調プリセット(Base style and tone)と、メモリのオン/オフ・「保存されたメモリを管理」への導線もまとまっている。

### カスタム指示の2つの入力欄

- **1つ目の欄「ChatGPTに何を知っておいてほしいですか?」**:自分の職業・業界・専門知識のレベル・よく頼む作業内容などを書く
- **2つ目の欄「ChatGPTにどのように応答してほしいですか?」**:文体・トーン・長さ・フォーマットなど、回答の「型」を書く

各欄の文字数上限は2026年7月15日頃、Plus・Pro・Enterprise・Business・Educationなどの有料プランで1,500文字から**5,000文字**へ引き上げられ、2026年9月時点でもこの上限が続いている。Free・Goプランは引き続き1,500文字が上限。プランによる差やその後の変更もあり得るため、実際の設定時は画面上の残り文字数表示を確認するのが確実。

### コピペで使える記入例

1つ目の欄(自分について)に貼る内容:

```
## 私について
- 職種:マーケティング部門のマネージャー(BtoB SaaS企業)
- ChatGPTを使う主な目的:市場調査の要約、社内向け資料のドラフト作成、英語メールの下書き
- 前提知識:マーケティング用語には詳しいが、統計・データ分析の専門用語は初心者向けに一言説明してほしい

## 会社について
- 業種:法人向けSaaS(会計クラウドサービス)
- 想定読者:社内の経営層・営業チーム・代理店パートナー
- 出力に含めてはいけない情報:顧客の個人情報・具体的な契約金額
```

2つ目の欄(回答スタイル)に貼る内容:

```
## 回答のトーン・形式
- 「である調」ではなく「です・ます調」の丁寧語で書く
- 結論を最初に一言でまとめてから、理由・詳細を箇条書きで続ける
- 資料のドラフトを頼まれたときは見出し付きのMarkdown形式で書く
- 断定できない情報は「推測です」「要確認です」と明示する
- 絵文字は使わない。専門用語には初出で一言説明を付ける
```

このように「## 私について」「## 会社について」「## 回答のトーン」のように見出しを付けて箇条書きにすると、後から見返して直しやすく、社内の他メンバーにテンプレートとして配布しやすい。

### 主要ツールでの対応関係

### 料金面

カスタム指示自体は無料プランを含む全プランで利用できる。メモリ機能(保存されたメモリ・チャット履歴を参照)は無料・Plus・Pro・Team個人アカウントではデフォルトで有効、Enterprise・Eduではデフォルト無効(管理者が組織全体でオン/オフを切り替える)という違いがある。会社アカウントで「前に話したことを覚えていない」場合は、まず管理者側の設定を確認するとよい。Business/Enterpriseではさらに、管理者がロール(役割)ごとにメモリの共有可否やエージェント機能の利用可否を細かく制御できるRBAC(ロールベースのアクセス制御)が用意されており、社外秘の前提情報は個人のカスタム指示や共有のメモリではなく、プロジェクト単位の指示や承認済みのワークスペース機能に載せることが推奨されている。

## 注意点・よくある誤解

- **カスタム指示を書いても、機密情報を書き込む場所ではない**:入力内容はモデルの追加学習に使われないよう設定できるが(データ利用のオプトアウト設定と併用が前提)、あくまで「毎回の会話に自動で挿入されるテキスト」であることに変わりはない。個人情報や社外秘の数値は書かない。
- **メモリをオフにしても、既に覚えた内容は自動削除されない**:メモリのトグルを切っても過去に保存された情報はそのまま残る。完全に消したい場合は「保存されたメモリを管理」から個別または一括で削除するか、ChatGPTに直接「〇〇を忘れて」と伝える。
- **チャットを削除しても、そのチャットから生成されたメモリは消えない**:チャット削除とメモリ削除は別の操作である。
- **一時的なチャット(Temporary Chat)は万能な「素の状態」ではない**:メモリは参照・生成されないが、有効にしているカスタム指示は一時チャットにも適用される。完全に指示なしで試したい場合はカスタム指示自体を一時的にオフにする必要がある。
- **プロジェクトの指示はカスタム指示より優先される**:グローバルなカスタム指示と矛盾する内容をプロジェクトの指示に書くと、そのプロジェクト内ではプロジェクト側が勝つ。挙動が想定と違う場合はプロジェクト設定を確認する。
- **「口調プリセット」は話し方だけを変える**:Professional・Friendlyなどのプリセットや温かみ・熱量のスライダーは、推論の質や機能を変えるものではなく、あくまで文体の調整である。回答の正確さを上げたい場合はモデル選択やプロンプトの書き方で対応する。
- **「ChatGPT Pulse」の提案とカスタム指示を混同しない**:Pulseは連携アプリやメモリをもとにAI側から先回りで話題を提示する機能であり、カスタム指示のように自分で書き込んで動作を固定するものではない。「なぜ聞いてもいないことを提案してくるのか」と感じたら、パーソナライズ設定内のPulse・メモリ参照のオン/オフを確認する。
- **指示が曖昧だと、モデルが独自解釈で補ってしまう**:2026年のGPT-6 Astra以降は指示追従力が上がった分、文言に解釈の余地があるとAIが自己判断で埋め合わせる場面が増える。「絶対に守ってほしい条件」ほど、カスタム指示には数値・NGワード・禁止事項など具体的に書く。
- **仕様は頻繁に変わる**:入力欄の文言や文字数上限、プリセットの種類は改定が多い項目のため、実際の設定時は画面表示を確認すること。

## 最初の一歩

「設定→パーソナライズ→カスタム指示」を開き、上記の記入例を自分の業務内容に置き換えて2つの欄に貼り付けてみる。次の新規チャットで、前置き説明なしにどれだけ意図通りの回答が返るかを試すのがよい確認方法になる。
