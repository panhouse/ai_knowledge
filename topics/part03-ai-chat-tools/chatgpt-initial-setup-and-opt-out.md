# ChatGPTの初期設定とデータ利用のオプトアウト

## これは何か

ChatGPTはアカウントを作った初期状態のままでも使えるが、「設定」画面をひと通り見ておかないと、入力した会話がモデルの学習に使われ続けたり、狙った通りの回答スタイルにならなかったりする。特に「入力データをモデルの学習に使わせない」設定(オプトアウト)は、個人向けプラン(Free・Go・Plus・Pro)ではデフォルトでオンになっており、放置すると社外秘の情報をうっかり学習データに提供してしまうリスクがある。初回に触るべき設定項目と、その意味を押さえておく。

## 仕組み・背景

ChatGPTの設定画面(プロフィールアイコン→「設定」)は、2026年7月時点でおおむね次のタブに分かれている(名称・並び順はアップデートで変わることがある)。

| タブ | 主な項目 |
|---|---|
| 一般 | テーマ(ライト/ダーク)、言語、フォントサイズなどの表示設定 |
| パーソナライズ | カスタム指示(Custom Instructions)、メモリ(過去の会話の記憶)、返答の雰囲気(トーン)のプリセット |
| データコントロール | 「すべての人のためにモデルを改善する」トグル(学習利用のオン/オフ)、チャット履歴のアーカイブ・削除、データのエクスポート |
| セキュリティ | 多要素認証(MFA)、ログイン中のデバイス一覧 |
| 通知 | ブラウザ・アプリのプッシュ通知 |
| 接続するアプリ | Google Drive、Slackなど外部サービス連携 |

これらのうち業務利用でまず押さえるべきは「データコントロール」と「パーソナライズ」の2つ。

**データ利用(学習)とデータ保持は別物**という点が理解のポイントになる。

- **学習利用**: 「すべての人のためにモデルを改善する」がオンだと、入力した会話が将来のモデルの訓練データとして使われる可能性がある。オフにすると、以後の会話は訓練に使われなくなる(過去にさかのぼって除外されるわけではない)。
- **データ保持**: 学習利用をオフにしても、不正利用の監視や法令対応のため、OpenAI側では会話のコピーが最大30日程度保持される。訴訟対応など法的な保全義務が生じた場合はさらに長く保持されることがある。
- **メモリ**: ChatGPTが会話の中で学んだ情報を次回以降の会話に活かす機能。学習利用のオン/オフとは別のスイッチで管理されており、メモリをオフにしても学習利用がオンなら会話は学習対象になり得る(逆もまた然り)。3つの設定は独立している。

## 使いどころ・使い分け

| 利用者像 | まず触るべき設定 |
|---|---|
| 個人でとりあえず試している | パーソナライズでカスタム指示を設定すると体感の使いやすさが大きく変わる |
| 業務で顧客情報や社外秘情報を扱う個人(Free/Plus/Pro) | データコントロールで学習利用を必ずオフにする。理想は法人契約への移行 |
| Business/Enterprise/Eduで働く従業員 | 会社側の既定でデフォルトが学習非利用になっていることが多いが、個人設定を勝手に変えていないか一度確認する |
| 情報システム部門・法人導入の管理者 | 個々のトグルより先に、管理コンソール(ワークスペース管理)でSSO・データ保持方針を組織全体に適用する |
| 一度きりの機密性の高い相談をしたい | 通常のチャットではなく「一時チャット(Temporary Chat)」を使う |

判断に迷ったら、「この会話の内容が学習データや監査ログに残っても困らないか」を基準にする。困る内容であれば、法人契約への一本化と学習利用オフを両方満たした上で使うのが安全。

## 実務での使い方

### 1. アカウント作成後にまずやること

1. 画面左下(モバイルでは右上)のアカウントアイコン→「設定」を開く
2. 「一般」でテーマ・言語を確認(日本語UIでは自動判定されるが、意図せず英語表示になっている場合はここで切り替える)
3. 「データコントロール」で「すべての人のためにモデルを改善する」の状態を確認する(次項で詳述)
4. 「パーソナライズ」でカスタム指示を設定する(業務効率が最も変わる項目)

### 2. データ利用のオプトアウト(最重要)

- **場所**: 設定 →「データコントロール」→「すべての人のためにモデルを改善する(Improve the model for everyone)」
- **意味**: オンのままだと、入力した会話やアップロードしたファイルの内容が、モデルの追加学習に使われる可能性がある
- **プランごとの既定値**:
  - Free / Go / Plus / Pro: 既定で**オン**。業務利用するなら手動でオフにする必要がある
  - Business(旧Team) / Enterprise / Edu: 既定で**学習に使用しない**。個人設定として切り替えるトグル自体が表示されない、または管理者権限でロックされていることが多く、組織のデータ保護方針は管理コンソール側で一括管理される
- **注意**: オフにしても、①過去にさかのぼって学習対象から除外されるわけではない、②不正利用監視・法令対応のための保持(最大30日程度、法的保全時はさらに長期)は別枠で行われる、という2点は必ず理解しておく
- **一時チャット(Temporary Chat)**: 新規チャット画面右上の「一時的」ボタンから開始できる会話モード。チャット履歴に残らず、メモリの読み書きも行われず、学習にも使われない。安全監視目的のコピーのみ最大30日保持される。一度きりの機密相談に向く。なお2026年1月のアップデートで、一時チャットでもカスタム指示は引き続き反映されるようになった(対象外になるのはメモリの参照・作成のみ)。「個人的な記憶は使われたくないが、口調の指定は効かせたい」場合に有効

### 3. カスタム指示(Custom Instructions)の書き方

- **場所**: 設定 →「パーソナライズ」→「カスタム指示」(プロフィールメニューから直接「ChatGPTをカスタマイズ」でも同じ画面に入れる)
- **入力欄は2つ**(各欄の目安上限は1,500文字程度):
  1. 「あなたについて教えてください」(職業・役割・専門知識レベルなどの背景情報)
  2. 「ChatGPTにどのように応答してほしいですか」(口調・出力形式・してほしくないことなど)
- 無料プランを含む全プランで利用可能

コピペで使える記入例:

```
## 私について
- 職業: 中堅BtoB SaaS企業のマーケティング担当(3年目)
- 業務: 週次レポート作成、競合調査、メルマガ文面のドラフト作成
- 知識レベル: マーケティング用語は理解できるが、統計・データ分析は初級者向けに噛み砕いて説明してほしい

## ChatGPTにどう応答してほしいか
- 結論を最初の1〜2行で述べてから詳細を説明する(結論ファースト)
- 断定できない情報は「推測ですが」と明示する
- 箇条書きを多用し、長文の段落は避ける
- 専門用語を使う場合は初出時に一言説明を添える
- 日本語の丁寧語(です・ます調)で回答する
- こちらが指示していない追加提案(「他にもこんな機能があります」等)は不要
```

さらに「パーソナライズ」画面には、あらかじめ用意された人格プリセット(几帳面・皮肉屋・聞き上手など)や、「温かみ」「熱量」「見出し・箇条書きの使用頻度」「絵文字の使用量」を個別に調整するスライダーが用意されている。カスタム指示と併用すると、毎回プロンプトで口調を指定する手間が減る。

### 4. メモリ(過去の会話の記憶)の設定

- **場所**: 設定 →「パーソナライズ」→「メモリ」
- **2つの独立したトグル**:
  - 「保存されたメモリを参照する(Reference saved memories)」: ユーザーが明示的に「覚えておいて」と伝えた事実(名前・好み・担当業務など)を参照する
  - 「チャット履歴を参照する(Reference chat history)」: 明示的に保存を指示していなくても、過去の会話全体から傾向を汲み取って応答に反映する
  - 「保存されたメモリを参照する」をオフにすると、「チャット履歴を参照する」も連動してオフになる
- **既定値**: Free / Plus / Pro / Business は既定でオン。Enterprise / Edu は既定でオフで、組織の管理者がオプトインで有効化する運用
- メモリは同一アカウント内でChatGPTの応答をパーソナライズする機能であり、「学習利用オプトアウト」(OpenAI側のモデル訓練に使うかどうか)とは別のスイッチである点に注意。過去の機密情報を含む会話をメモリに残したくない場合は、メモリ設定内の「マネージ」からメモリの中身を個別に確認・削除できる
- **2026年6月からメモリの仕組みが変わりつつある**: 「Dreaming」と呼ばれる新方式への移行が進んでおり、個別のメモリ項目を一つずつ確認・削除するリスト方式から、過去の会話全体を背景で分析して記憶を継続的に更新する方式に変わっている。何が記憶されているかの一覧性が下がる可能性があるため、機密情報を扱う前提ならメモリ参照自体をオフにする運用が安全

### 5. ツール横断の対応関係

| 概念 | ChatGPT | Gemini | Claude | Microsoft Copilot |
|---|---|---|---|---|
| 自分について毎回教える指示 | 設定 → パーソナライズ → カスタム指示 | 設定 → パーソナルコンテキスト内の「保存された情報(Saved info)」 | 設定 → プロフィール(Custom instructionsに相当する項目) | Copilotのプロフィール設定、または法人向けはAgent Builder等でのシステムプロンプト相当設定 |
| 会話から自動学習する記憶 | 設定 → パーソナライズ → メモリ | 設定 → パーソナルコンテキスト(過去のチャットからの自動推論) | 現時点で同等のフル自動記憶機能は個人向けには限定的 | 法人向けMicrosoft 365 Copilotはグラフ(組織内データ)を参照する仕組みが中心 |
| モデル学習への利用を止めるオプトアウト | 設定 → データコントロール →「すべての人のためにモデルを改善する」をオフ | Geminiアプリのアクティビティ設定(Gemini Appsアクティビティ)をオフ | 設定 → プライバシー →「Help improve Claude」をオフ | Copilotのプライバシー設定でチャット履歴・トレーニングへの利用をオフ |

いずれのツールも呼び方や設置場所は異なるが、「①自分専用の前提を教える指示」「②会話から自動で溜まる記憶」「③学習利用のオプトアウト」という3層構造はほぼ共通している。ツールを乗り換える際は、この3つを対応付けて再設定すると迷わない。また「個人向けプランは学習利用がデフォルトでオン(要オプトアウト)、法人向けプランは学習非利用がデフォルト」という非対称な構造も、ChatGPT(Business/Enterprise/Edu)・Claude(Team/Enterprise)・Gemini(Google Workspace)でほぼ共通している。

### 6. 法人・チーム利用時の管理者設定(概要)

Business・Enterpriseでは、個々のユーザー設定に加えて管理者側の設定が業務利用の実効性を左右する。

- **ワークスペース管理**: 管理コンソールでメンバーの招待・削除、ロールベースのアクセス制御(RBAC)、利用状況の可視化を行う
- **SSO(シングルサインオン)**: Businessはセルフサーブでのセルフ設定が可能だがSCIM(自動プロビジョニング)は非対応で、退職者アカウントの削除は手動対応が必要。Enterpriseは SAML SSO + SCIM に対応し、ID基盤と連動した自動プロビジョニング・デプロビジョニングができる
- **データレジデンシー・監査ログ**: Enterpriseでは保存地域の指定や詳細な監査ログの出力が可能
- **Global Admin Console**: 複数のワークスペース・API組織を横断してテナント単位で管理する統合管理コンソールが2026年に導入されている(大規模組織向け)

個人設定のオプトアウトに頼るのではなく、法人契約であれば管理者側でデータ保護方針を組織全体に強制できることが、Business/Enterpriseを選ぶ実務上の最大のメリットになる(プランごとの詳細比較は[ChatGPTのプラン比較](chatgpt-plan-comparison.md)を参照)。

## 注意点・よくある誤解

- **「オプトアウトすれば即座に何も残らない」わけではない**: 学習利用をオフにしても、不正利用監視や法令対応のための保持期間(目安30日、法的事由があればさらに長期)は別に存在する。機密性が極めて高い情報は、そもそも入力しないか、法人契約のZero Data Retention等の特別な保護オプションを検討する(詳細は[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md)を参照)
- **オプトアウトは遡及しない**: トグルをオフにした時点より前の会話が、既に学習済みのモデルから取り消されるわけではない。過去データの削除を求める場合は別途、OpenAIへのデータ削除依頼(プライバシーリクエスト)が必要になる
- **削除した会話も一定期間残ることがある**: 不正利用監視や法令対応のため、削除後も内部的にはしばらく保持される場合がある。加えて、他社との訴訟に関連する裁判所命令により、一時的に一部データの長期保全が求められた経緯もある(該当範囲は既存データが中心で、新規チャット全般への適用は後に縮小されている)。「削除すれば完全に何も残らない」という前提では機密情報を扱わない方が安全
- **メモリと学習利用オプトアウトは別物**: メモリをオフにしても学習利用がオンのままなら会話は学習対象になり得る。両方確認する必要がある。また学習利用をオフにしても、メモリやカスタム指示に登録済みの内容は自動では消えないため、不要になったら個別に削除する
- **一時チャットは組織的に強制できない**: Business/Enterpriseであっても、一時チャットの利用自体は各ユーザーが手動でオンにする必要があり、管理者が全社に一律強制する機能ではない(常時非学習にしたい場合はプラン側のデフォルト設定で対応する)
- **法人プランだから何もしなくて安全、とは限らない**: Business/Enterprise既定は学習非利用だが、個人アカウントでの野良利用が併存していると、その分は個人向けプランの既定(学習利用オン)のまま使われてしまう。組織として個人アカウント利用を禁止し、法人契約に一本化することが前提になる
- **画面名称・項目の並びは変更されやすい**: 本ページの手順は2026年7月時点の構成に基づく。OpenAIのヘルプセンター記事は認証環境によって直接アクセスできない場合があるため、契約前後に必ずアプリ内の実際の設定画面と[OpenAI公式ヘルプセンター](https://help.openai.com/)で名称を確認すること

## 最初の一歩

今すぐ設定画面を開き、「データコントロール」→「すべての人のためにモデルを改善する」の状態を確認し、業務でChatGPTを使っているならオフにする。
