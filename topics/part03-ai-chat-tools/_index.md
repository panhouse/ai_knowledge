# Part 3: AIチャットツールの基本

ChatGPT / Gemini / Claude / Copilot などの汎用AIチャットツールを、
特定ツールを本流とせず**横断比較**で扱う。機能の概念は章で束ね、
ツール固有の詳細は「◯◯の基本」ページ(第5章)に分離する。

## 章構成(分類の地図)

### 第1章 プラン・モデルの選び方
- 主要ツールのプラン比較、モデル一覧、料金対効果の判断

### 第2章 初期設定とデータ保護
- 初期設定、データ利用のオプトアウト、カスタム指示(各ツール対応表)

### 第3章 記憶・文脈の管理
- メモリ、プロジェクト系機能、会話の使い分け(各ツール対応表)

### 第4章 生成・分析の主要機能
- データ分析、Canvas、Web検索、画像生成、Agent/Tasks、音声

### 第5章 主要ツール各論
- ChatGPT、Gemini、Claude、Copilot、DeepSeek、Grok の個別ガイド
