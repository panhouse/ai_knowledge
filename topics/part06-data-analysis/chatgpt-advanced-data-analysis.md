# ChatGPTのデータ分析機能(Advanced Data Analysis)の使い方

## これは何か

売上データや顧客アンケートの集計・グラフ化を、Excelの関数やピボットテーブルを組まずに「このCSVの月別売上を折れ線グラフにして」と日本語で頼むだけでやってくれる機能が、ChatGPTの「Advanced Data Analysis(高度なデータ分析、旧称Code Interpreter)」である。裏側でChatGPTがPythonのコードを自動生成・実行しており、集計・グラフ作成・簡易的な統計処理・データの整形までをチャット画面だけで完結できる。分析スキルがなくても「表データを渡して聞くだけ」で一次分析ができる点が、通常のChatGPTとの対話との違いになる。

## 仕組み・背景

この機能はもともと2023年に「Code Interpreter」という名称のベータ機能として登場し、同年中に「Advanced Data Analysis」に改称された。名称は変わったが中身の仕組みは変わっておらず、現在もChatGPTの画面上では機能名を意識させず、ファイルを添付して質問するだけで自動的に起動する。

裏側の動作は次の通り。

1. ユーザーがCSV・Excel・JSONなどのファイルを添付し、自然文で依頼する
2. ChatGPTが依頼内容を解釈し、外部インターネットに接続できない**隔離されたサンドボックス環境**(他の利用者や社内システムから切り離された、使い捨てのPython実行環境)上でPythonコードを自動生成する
3. コードをその場で実行し、集計結果・グラフ・エラーの有無を確認する
4. エラーが出れば自動的にコードを修正して再実行し、最終的な結果と「実際に使ったコード」を両方チャット上に表示する

コードが画面に表示される点が重要で、数式や処理内容を検算できる透明性を確保している。ただしサンドボックスはセッションごとに使い捨てで、一定時間操作がないとファイルや実行状態は破棄される。翌日また同じファイルで分析したい場合は再アップロードが必要になる。

## 使いどころ・使い分け

| 業務シーン | 向いている | 向いていない |
|---|---|---|
| 売上データの月次・店舗別集計とグラフ化 | ◯ | |
| アンケート自由回答のカテゴリ分類・件数集計 | ◯ | |
| 重複データの検出、欠損値の確認などの簡易クレンジング | ◯ | |
| 2群の平均の違いなど簡易的な統計検定 | ◯(参考値として) | |
| 数十万行を超える大規模データの本格分析 | | ✕(行数制限・処理時間でエラーになりやすい) |
| 最新の為替レートなど外部情報を取り込んだ分析 | | ✕(サンドボックスはネット接続不可) |
| 毎週・毎月自動で更新される定例レポート | | ✕(BIツールやスプレッドシートの自動化機能が向く) |
| 意思決定に直結する重要な統計分析 | | △(必ず手元の数値やBIツールと突き合わせて検算する) |

「軽い一次分析・たたき台作り」には強いが、「継続運用する本番のレポーティング」や「厳密さが求められる統計分析」の代替にはならない、という線引きで使い分けるとよい。

## 実務での使い方

### 使い始め方(画面の場所)

1. ChatGPTのメッセージ入力欄にある「+」(ファイルを追加)アイコンをクリックし、CSV・Excel・PDFなどのファイルを選択する。ドラッグ&ドロップでも添付できる
2. ファイルを添付した状態で、やりたいことを日本語で入力して送信する。「データ分析」という機能名を明示的に選ぶ必要はなく、表データを添付して集計・グラフ化を頼むと自動的にPythonが実行される
3. 出力されたグラフは画像として画面に表示され、右クリック(またはダウンロードアイコン)で保存できる。集計結果をExcelファイルとして出力するよう頼めば、ダウンロードリンクも生成される

### コピペで使えるプロンプト例

```
添付のCSVについて、月別の売上推移を折れ線グラフにして。
X軸は月、Y軸は売上金額(円)にしてください。
```

```
このアンケートの自由記述列(「ご意見・ご要望」)を5つ程度のカテゴリに分類し、
カテゴリごとの件数を棒グラフにしてください。分類の基準も教えてください。
```

```
添付のExcelの顧客リストで、メールアドレス列に重複がないか確認してください。
重複があれば、重複している行だけを一覧で出してください。
```

```
A店とB店の月次売上データについて、平均に意味のある差がありそうか
簡単な統計検定(t検定)で確認してください。
専門用語は使わず、結果だけを日本語で分かりやすく説明してください。
```

```
このデータから極端に大きい・小さい値(外れ値)を検出し、
除外する前と後で平均がどう変わるか比較して見せてください。
```

```
ここまでの集計結果を、Excelファイル(.xlsx)としてダウンロードできる形で
出力してください。
```

### 向く業務の例

- **売上データの可視化**: 月別・店舗別・商品別の売上推移をグラフ化し、経営会議資料のたたき台にする
- **アンケート集計**: 自由記述回答をカテゴリ分けし、傾向をつかむ一次分析
- **データクレンジング**: 重複行の検出、表記ゆれ(全角/半角、日付形式の不統一など)の洗い出し
- **複数ファイルの突合**: 部署ごとに分かれたExcelを1つに結合し、差分や不一致を確認する

### プラン別の利用可否・上限(2026年7月時点)

| プラン | 利用可否 | 目安の制限 |
|---|---|---|
| Free | 利用可能(制限あり) | データ分析機能の利用回数・ファイルアップロードとも1日あたり少数回に制限される |
| Go | 利用可能 | Freeよりメッセージ数・アップロード枠が拡大(目安としてFreeの約10倍) |
| Plus | 利用可能 | 1メッセージあたり最大20ファイルまで添付可(2026年2月に10件から倍増) |
| Pro | 利用可能(実質無制限) | ファイルアップロード数は無制限 |
| Business・Enterprise | 利用可能 | 個人向けプランと同様の分析機能に加え、組織単位のデータ管理・ストレージ枠(ユーザーあたり25GB、組織あたり100GB目安)が適用される |

ファイル自体のサイズ上限は、1ファイルあたり512MB・約200万トークンが上限の目安で、CSV・スプレッドシート類は50MB程度、画像は1枚20MBが実務上の目安になる。数値は変更されやすいため、契約前後に[ChatGPT公式の料金ページ](https://chatgpt.com/pricing)や[ヘルプセンターのファイルアップロードFAQ](https://help.openai.com/en/articles/8555545-file-uploads-faq)で最新値を確認するとよい。プランごとの料金・全体像は[ChatGPTのプラン比較](../part02-chatgpt-basics/chatgpt-plan-comparison.md)を参照。

### ツール横断の対応付け

同じ「チャットにデータを渡して分析させる」機能は、ツールによって呼び名も強みも異なる。

| ツール | 名称・実装 | 特徴 |
|---|---|---|
| ChatGPT | Advanced Data Analysis(旧Code Interpreter) | Pythonサンドボックスをチャット内で自動実行。ファイル添付だけで起動 |
| Gemini | Google Colabとの連携・スプレッドシート連携 | Googleスプレッドシートと直接連携しやすく、生成したコードをColabノートブックとして開ける |
| Microsoft Copilot | Excel内の「Copilot」(数式・関数の提案、Python in Excel) | Excelアプリ内で完結し、既存の表・数式と地続きで使える |
| Claude | Analysisツール(claude.aiでのコード実行) | 同様にサンドボックスでJavaScript/Pythonを実行し、集計・グラフ化が可能 |

## 注意点・よくある誤解

- **結果を鵜呑みにしない**: 生成されたコードにエラーが出なくても、計算ロジックの解釈違いや集計対象の取り違えで、もっともらしい誤った結果を返すことがある。特に重要な数値は必ず一部を手元で検算する
- **セッションが切れるとファイルは消える**: サンドボックスは使い捨てのため、日をまたいで同じデータを分析し直す場合は再アップロードが必要。継続的な分析基盤としては使えない
- **外部データは取り込めない**: サンドボックスはインターネットに接続されていないため、「最新の為替レートを取得して」のような依頼は実行できない。あらかじめ必要な数値をファイルに含めておく必要がある
- **アップロードしたデータは学習利用設定の対象になる**: 個人向けプランで「モデルを改善する」設定がオンのままだと、分析のために渡したデータが学習に使われる可能性がある。顧客情報など機密データを扱う場合は、法人プラン(Business/Enterprise)の利用や学習オプトアウト設定を確認する。詳細は[生成AI利用における情報漏洩対策](../part03-risk-security/information-leakage-prevention.md)を参照
- **大規模データは苦手**: 数十万行を超えるような大規模ファイルは、処理途中でトークン上限やタイムアウトに達し、一部だけを読んで分析してしまうことがある。全体を分析したのか、一部サンプルだけを見て回答しているのか、必ず確認する
- **データの整え方次第で精度が変わる**: セル結合や複数行ヘッダーのExcelは誤読の原因になりやすい。事前の整形については[AIが扱いやすいデータ形式](ai-friendly-data-formats.md)のチェックリストを参照

## 最初の一歩

手元にある売上データやアンケート結果のCSV・Excelを1つ、ChatGPTのメッセージ欄に添付し、「月別の推移を折れ線グラフにして」と頼んでみる。
