# ChatGPTのデータアナリスト機能の使い方

## これは何か

ChatGPTにExcelやCSVファイルをアップロードして「集計して」「グラフにして」と頼むと、それらしい答えが返ってくる。しかしこれは単に文章として「読んで要約している」のではなく、ChatGPTが裏側でPython(データ分析やプログラムの記述に使われるプログラミング言語)のコードを実際に書いて実行し、その計算結果を返している。この仕組みを知らないと、「なんとなく雰囲気で答えている」と誤解して活用しきれなかったり、逆に検算せず数値を鵜呑みにしてしまったりする。

この機能は2023年の登場時は「Code Interpreter(コードインタープリター)」、その後「Advanced Data Analysis(高度なデータ分析)」と呼ばれ、現在ではChatGPTの通常のチャット画面にファイルを添付するだけで自動的に呼び出される標準機能の一部になっている。呼び方は変遷してきたが、「実際にコードを実行して計算する」という中身は一貫している。

## 仕組み・背景

ファイルを添付して分析系の質問をすると、ChatGPTは裏側でサンドボックス(外部から隔離された安全な実行専用の仮想環境)を起動し、その中でPythonコードを自動生成・実行する。pandas(表データの集計・加工)、matplotlib・seaborn(グラフ描画)、numpy・scipy(数値計算・統計)、scikit-learn(機械学習)といった、データ分析で定番のライブラリ(あらかじめ用意された機能部品群)があらかじめ使える状態になっている。

このサンドボックスは「ステートフル」、つまり同じ会話の中では計算結果や読み込んだデータを覚えたまま、追加の指示(「今度は地域別に分けて」など)を積み重ねられる。Jupyter Notebook(データサイエンティストが使う対話型のコード実行環境)に近いイメージだ。

現在(2026年時点)のUI上の呼び出し方に関する重要な変化は、かつてのように「Advanced Data Analysisというツールを明示的に有効化する」操作が原則不要になっている点にある。ChatGPT Plus以上のプランでは、通常のチャット画面にCSV・Excel・PDFなどのファイルを添付し、集計・グラフ化・統計処理を求める質問をするだけで、モデルが必要に応じて自動的にコード実行に切り替える。「Advanced Data Analysis」という名称は今も一部のヘルプ記事やGPT(カスタムChatGPT)名として残っているが、機能自体は標準チャットに溶け込んでいる状態と理解しておくとよい。

## 使いどころ・使い分け

| やりたいこと | ChatGPTのデータ分析機能 | Excelピボットテーブル / BIツール(Looker、Tableau等) |
|---|---|---|
| 手元の1〜数枚のCSV・Excelを素早く集計・可視化したい | 向いている。自然言語で指示するだけで集計・グラフが得られる | セットアップに時間がかかり、単発の分析には過剰 |
| 列の意味が曖昧なデータをざっと探索したい(仮説出し) | 向いている。試行錯誤のスピードが速い | 向いていない(定型的な集計向け) |
| 数百万行規模の大量データ、または複数テーブルの結合が必要 | 不向き(ファイルサイズ・処理時間の制約に当たりやすい) | 向いている |
| 社内の複数人が継続的に見るダッシュボードが欲しい | 不向き(その場限りの結果で、自動更新・共有の仕組みがない) | 向いている(本来の用途) |
| 外部に出す確定数値・経営報告の最終チェック | 参考値としては有用だが、最終数値の根拠には単独で使わない | 向いている(検算済みの数値基盤として) |
| 基幹システム・APIから最新データを都度取得したい | 不向き(後述の通りサンドボックスにインターネット接続がない) | 向いている(データ連携が前提) |

要するに、「その場で・単発で・素早く」データの見通しを立てたいときはChatGPT、「継続的に・複数人で・正確性を担保して」使うならExcelの正式なピボットやBIツールという住み分けになる。

## 実務での使い方

### 基本の使い方(ファイルをアップロードして質問するだけ)

1. ChatGPTのチャット入力欄にある「+」または クリップ(添付)アイコンをクリックし、パソコン内のファイルを選択してアップロードする。CSV・Excel(.xlsx/.xls)・JSON・PDF・画像などに対応している。
2. 「このファイルの月別売上を集計して、棒グラフにしてください」のように、日本語の自然な文章で依頼する。列名や計算方法を具体的に指定するほど精度が上がる。
3. ChatGPTは自動的にPythonコードを書いて実行し、結果の表やグラフをチャット内に表示する。生成されたコードは「コードを見せて」と頼めば表示され、計算ロジックを確認できる。
4. 同じ会話内であれば、「今度は地域別に分けて」「前年同月比も追加して」のように条件を変えて追い込んでいける(直前までの分析結果を覚えている)。

### コピペで使える実例プロンプト

売上データのCSV(`customer_id`、`order_date`、`product_category`、`sales_amount`などの列を想定)をアップロードした直後に、次のように依頼する。

```
添付した売上データを分析してください。

1. まず列名と各列のデータ型、欠損値の有無を確認し、
   あなたがどう解釈したかを箇条書きで教えてください。
2. 月別・商品カテゴリ別の売上合計を集計し、表で出してください。
3. 月別の売上推移を折れ線グラフにしてください(日本語ラベルで)。
4. 前月比で売上が20%以上落ちている商品カテゴリがあれば指摘してください。

金額の単位は円です。日付は yyyy-mm-dd 形式です。
```

ポイントは、いきなり集計を頼むのではなく「1. 解釈の確認」を最初に入れることだ。これによりChatGPTがどの列を何だと理解したかを事前に確認でき、誤読による誤集計を防ぎやすくなる。

### もう少し踏み込んだ使い方(明示的にコード実行を依頼する)

相関分析や簡単な統計検定など、やや高度な処理をさせたいときは、遠慮せず「Pythonコードを書いて実行し、結果を出してください」と明示すると意図が伝わりやすい。例えば「広告費と売上の相関係数を計算し、散布図を描いてください。相関係数が0.5以上なら関係ありと判断してください」のように、判断基準まで数値で指定すると解釈のブレが減る。

### 生成物の受け取り方

グラフや加工後のExcel・CSVファイルは、チャット内の出力に表示されるリンクからダウンロードできる。会話が長くなったり日をまたいだりすると生成ファイルへのアクセスができなくなることがあるため、必要なファイルはその場でダウンロードしておく。

## 注意点・よくある誤解

- **サンドボックスにインターネット接続はない**: この実行環境はセキュリティ上の理由で外部ネットワークから完全に遮断されている。最新の株価をAPIで取得する、社内データベースに直接クエリする、Webサイトをスクレイピングする、といった「今アップロードしていないデータを外から取ってくる」処理はできない。分析対象は必ず事前にアップロードしたファイルの中身に限られる。
- **列の意味を取り違えることがある**: 列名が曖昧だったり(例:「区分」「金額」だけ)、同じ列に複数の意味が混在していたりすると、ChatGPTが誤った前提で集計してしまうことがある。エラーは出ないまま結果だけがもっともらしく表示されるため、必ず「どう解釈したか」を確認させ、代表的な数値は自分の手元(元のExcelでの目視確認や簡単な検算)で突き合わせる。
- **ファイルサイズ・行数に上限がある**: CSVやExcelはおおむね50MB程度が実務上の目安とされ、ファイル全体では512MBが上限、テキスト系ファイルはトークン数(AIが処理する文字の単位)で上限が設定されている。数百MB・数百万行級のデータは、そのままではエラーになったり、一部だけ読み込まれて集計が不正確になったりするため、事前に必要な列・行に絞り込んでから渡すとよい。
- **グラフの日本語が文字化けすることがある**: matplotlibなど内部で使われる描画ライブラリが日本語フォントを標準で持たないため、グラフのタイトルや軸ラベルの日本語が四角(豆腐文字)になることがある。文字化けした場合は「グラフのラベルは英語にしてください」と頼むか、フォント指定をやり直すよう依頼する。
- **大規模・継続利用の代替にはならない**: その場限りの分析には強いが、自動更新されるダッシュボードや、複数人で同じ数値を継続的に参照する用途には向かない。経営会議などで使う確定数値は、最終的にExcelやBIツール側で検算・管理する運用にする。
- **元データが汚いと結果も崩れる**: セル結合や複数行の見出し、日付フォーマットの不統一があると、集計の土台からズレる。渡す前にデータを整える具体的なコツは「[AIが扱いやすいデータ形式](ai-friendly-data-formats.md)」を参照。

## 最初の一歩

手元にあるExcelやCSVのファイルを1つ、ChatGPTのチャット欄にドラッグ&ドロップし、「このデータの列の意味をどう理解したか教えてから、月別に集計してグラフにしてください」と頼んでみる。出てきた数値のうち1つだけ、元のファイルで手計算して合っているか確認する。
