# ChatGPTのデータ分析機能(Advanced Data Analysis)

## これは何か

CSVやExcelをChatGPTにアップロードすると、ChatGPTが裏側でPythonコードを自動的に書いて実行し、集計・グラフ作成・統計分析まで行ってくれる機能。Excelで関数を組んだりピボットテーブルを作ったりする手間をかけずに、「月別の売上を集計してグラフにして」と日本語で頼むだけで結果が返ってくる。旧称「Code Interpreter」→「Advanced Data Analysis」で、現在はChatGPT本体に統合された標準機能として提供されている。

## 仕組み・背景

ファイルをアップロードして分析を頼むと、ChatGPTは裏側の「ステートフルなJupyterノートブック環境」(会話の間、変数やデータの状態を保持し続けるPython実行環境)でPythonコードを自動生成・実行する。集計結果やエラーを見ながらChatGPTが自分でコードを書き直すこともあるため、複雑な指示でも複数ステップの処理を1回のやり取りでこなせる。

名称の変遷は以下の通り。

- 2023年7月: 「Code Interpreter」としてベータ公開(Pythonコード実行が主眼)
- 2023年8月: 「Advanced Data Analysis」に改称(データ分析用途を前面に押し出す)
- 現在: 明示的な機能選択(旧バージョンにあった「プラグイン/ツールを選ぶ」操作)は不要になり、ファイルをアップロードするだけで自動的にデータ分析モードが起動する、ChatGPT本体の標準機能になっている。OpenAIのヘルプセンターでは単に「データ分析(Data analysis with ChatGPT)」として案内されている。「Advanced Data Analysis」「Data Analyst」という名前の入力欄下部の候補やカスタムGPTが表示されることもあるが、通常の会話でファイルを添付するだけで同じ分析機能が働く。

ファイルをアップロードすると、行・列をスクロールして確認できる「インタラクティブテーブル」が自動生成される。生成するグラフは基本的に画像として出力されるが、棒グラフ・線グラフ・円グラフ・散布図の一部はクリックで並べ替えや拡大ができるインタラクティブチャートとしても表示される。

## 使いどころ・使い分け

同じ「集計・グラフ化」でも、Excel関数・BIツール(Looker Studioなど)・ChatGPTのデータ分析ではコストと向き不向きが異なる。

| 目的・状況 | 向いている手段 | 理由 |
|---|---|---|
| 毎月・毎週同じ形式で繰り返す定型集計 | Excel関数・ピボットテーブル | 一度作れば再利用でき、動作も高速。ChatGPTに毎回頼むより効率的 |
| 「とりあえずこのデータ、傾向を教えて」という非定型・探索的な分析 | ChatGPTデータ分析 | 集計軸や見せ方を自然言語で試行錯誤しながら決められる。統計知識が浅くても t検定やANOVAなどの手法をChatGPTが選んでくれる |
| 複数人・複数部署に継続的にダッシュボードとして共有したい | BIツール(Looker Studio、Tableauなど) | データソースを自動更新・接続でき、権限管理やアクセス制御もできる。ChatGPTは会話ごとに使い切りで共有・自動更新に向かない |
| 数百万行規模の大規模データ、複数テーブルの結合が常態化している分析 | BIツール、またはSQL/BigQueryなどの前処理を経てからChatGPTに渡す | ChatGPTのデータ分析はファイルサイズ・行数に実務的な上限があり、大規模データは処理が遅くなったり不完全になったりする |
| 「このコードが正しいか」「なぜこの結果になったか」を人に説明する必要がある分析 | ChatGPTデータ分析(ただし検算必須) | 実行したPythonコードをそのまま確認・再利用できるのが利点。ただし最終結果は必ず検算する |

判断基準を一言でまとめると、**「毎回同じ手順を繰り返すなら自動化(Excel関数・BIツール)、毎回違う質問を投げるなら対話型(ChatGPT)」**。

## 実務での使い方

### アップロードの手順(画面の場所)

1. ChatGPTの画面下部、プロンプト入力欄の左側にある「+」(ファイルを追加)アイコンをクリックする
2. 「このデバイスからアップロード」、または「Google ドライブから追加」「Microsoft OneDriveから追加」を選ぶ(Google Sheets・Excel・Wordなどをファイルに変換せず直接読み込める)
3. CSV・Excel(xlsx)・TSV・JSON・PDFなど対象のファイルを選択する
4. アップロードが完了すると自動でインタラクティブテーブルが表示されるので、列名や行数がイメージ通り読み込まれているか確認する
5. プロンプト欄に「何を集計したいか」を書いて送信する

なお、この機能を安定して使うにはChatGPT Plus以上(Plus / Pro / Business (Team) / Enterprise)のプランが必要。無料プランはファイル添付そのものは1日3件程度まで可能だが、Pythonコードを実行するデータ分析機能はPlus以上でのみフル対応する。

### コピペで使えるプロンプト例

**基本の集計とグラフ化**
```
このCSVを読み込んで、月別の売上合計を集計し、折れ線グラフにしてください。
グラフのタイトルは「月別売上推移」、横軸は月、縦軸は売上金額(円)にしてください。
```

**クロス集計**
```
この顧客データについて、地域別・商品カテゴリ別の売上をクロス集計してください。
売上が多い上位5つの組み合わせを表で示し、簡単な傾向のコメントを付けてください。
```

**複数ファイルの結合・データクリーニング**
```
アップロードした2つのExcelファイルを「顧客ID」列で結合してください。
結合後、値が欠損している行、重複している行があれば件数と内容を教えてください。
```

**比較・異常値の発見**
```
先月と今月の売上データを比較して、前月比の変化率が大きい上位10商品を教えてください。
集計に使ったPythonコードも見せてください。
```

**分析結果のアウトプット化**
```
これまでの分析結果を、社内報告用にスライド構成の骨子(章立てと各章の要点)としてまとめてください。
グラフはどのスライドに使うと効果的かも提案してください。
```

### 実務のコツ: 日本語グラフの文字化け対策

ChatGPTのグラフ生成環境には標準で日本語フォントが入っていないため、グラフの日本語ラベルが「豆腐(□□□)」化けすることがある。対策は、Google Fontsなどで配布されている「Noto Sans JP」のフォントファイル(.ttf)を事前にダウンロードしてChatGPTにアップロードし、「アップロードした日本語フォントを使ってグラフを描画してください」と明示的に指示すること。カスタムGPTを作る場合は、フォントファイルを「知識」に登録し、システムプロンプトに「グラフは常にこのフォントを使うこと」と書いておくと毎回のアップロードが不要になる。

## 注意点・よくある誤解

- **ファイルサイズ・行数には実務的な上限がある**: 添付ファイル自体の上限は1ファイルあたり最大512MBだが、CSV・Excelなど表形式データはセルの複雑さや列数によって実質50MB程度が目安になる場合が多い。1つの会話で添付できるファイル数は最大20件程度。数十万行を超えるような大規模データは、読み込みでエラーになったり、処理が途中で止まったりすることがある。大きいデータは事前にSQL/BigQueryなどで集計・絞り込みをしてから渡すか、必要な列・期間だけに分割してから渡す。
- **機密データのアップロードにはリスクがある**: 顧客の個人情報や未公開の財務データなど機密性の高い生データをそのまま渡すのは避ける。ChatGPTの設定(左下のアカウントアイコン→設定→データコントロール)で「モデルの改善に会話データを使用する」をオフにできるが、それでも第三者のサービスに機微情報を送ること自体のリスクは残る。個人名や取引先名は匿名化・マスキングしてから渡す、または社内で許可されたEnterprise/Team環境(会話データが学習に使われない設定になっているプラン)を使うのが基本。
- **集計結果は必ず検算する**: Pythonコードを実際に実行しているとはいえ、生成AIが集計軸やフィルタ条件を勝手な解釈で設定してしまうことがある。エラーメッセージが出ないまま、意図と違う条件で集計した結果を「正しい答え」として返してくることもある。「実行したPythonコードを見せてください」と頼んでロジックを確認し、重要な数値は一部を手元のExcelやSQLの結果と突き合わせて検算する習慣をつける。
- **グラフの見栄えは簡素になりがち**: デフォルトの配色・フォント・レイアウトはシンプルなため、社外向け資料にそのまま使うと見劣りする場合がある。色や凡例、タイトルの体裁は追加で指示するか、出力後に他のツールで整える。

## 最初の一歩

手元にあるCSVかExcelファイルを1つ、ChatGPT Plus以上の画面でプロンプト入力欄の「+」からアップロードし、「このデータの列構成を説明して、月別の合計を集計し、グラフにしてください」と送ってみる。
