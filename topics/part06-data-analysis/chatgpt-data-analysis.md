# ChatGPTのデータ分析機能(Advanced Data Analysis)の使い方

## これは何か

ChatGPTには、アップロードしたExcelやCSVファイルを実際にプログラムで処理して、集計・グラフ作成・簡易的な統計分析までこなす「Advanced Data Analysis(アドバンスド・データ・アナリシス)」という機能がある。関数や集計を自分で組まなくても、「月別の売上推移をグラフにして」と日本語で頼むだけで、表とグラフ入りの回答が返ってくる。旧称はCode Interpreter(コードインタープリター)。この機能を知らないと、ChatGPTを「文章を書くだけのツール」だと誤解し、日々のExcel集計を手作業のまま続けてしまうことになる。

## 仕組み・背景

- **名称の変遷**: 2023年にCode Interpreterという名前でβ提供が始まり、同年後半にAdvanced Data Analysisへ改称された。現在のChatGPTの画面では機能名がUI上に大きく表示されることは少なく、入力欄の「+」(ツール)メニューの「データを分析する(Analyze data)」といった選択肢、またはExcel/CSVを添付した時点で自動的に使われる裏方の機能として存在している。技術的な呼称としては今もAdvanced Data Analysis(旧Code Interpreter)が使われる。
- **仕組み**: ファイルを渡すと、ChatGPTは裏側で隔離されたPython実行環境(サンドボックス。他の利用者や外部ネットワークから遮断された使い捨ての作業スペース)を起動し、依頼内容に応じてPythonコード(pandas・matplotlibなどのライブラリを使用)を自動生成して実際に実行し、その結果を返す。単に「文章として計算しているふり」をしているのではなく、コードが本当に走って数値を出している点が通常のチャット応答と異なる。
- **制約のある環境**: このサンドボックスはインターネットに接続されておらず、外部サイトから最新の為替レートや競合情報を取得することはできない。また無操作のまま一定時間(目安15〜30分)経過するとセッションがタイムアウトし、アップロード済みファイルへのアクセスが失われるため再アップロードが必要になる。1回のコード実行にはおよそ120秒程度のタイムアウトがあり、大規模データの重い処理には向かない構造になっている。

## 使いどころ・使い分け

| 用途 | 向いている/向いていない | 理由・補足 |
|---|---|---|
| 月次推移・構成比などの単純集計とグラフ化 | 向いている | 得意領域。日本語の指示だけでPythonコードが生成・実行される |
| 数千行規模のデータクリーニング(欠損値補完、重複削除、型変換) | 向いている | pandasによる前処理を自動化できる |
| 平均・中央値・相関・回帰の傾向などの簡易統計 | 向いている(要検算) | 傾向把握には十分だが、経営判断に使う数値は必ず元データと突き合わせる |
| 数十万行を超える大規模データやリアルタイム分析 | 向いていない | 実行タイムアウト(約120秒)やファイルサイズ上限に抵触しやすい |
| 機密性の高い顧客データ・個人情報を含む分析 | 慎重に判断 | プランによって学習利用の既定設定が異なる(後述) |
| 最新の外部情報と突き合わせた分析(為替・株価・競合の最新動向) | 向いていない | サンドボックスはネット接続なし。Web検索機能と組み合わせて数値を手動で渡す必要がある |

判断の目安: 「Excel関数やピボットテーブルで数分でできる集計」はAdvanced Data Analysisの得意領域。「BIツールでないと重くて開けない量のデータ」や「監査レベルの厳密な統計処理」は専用ツール(Excel、BIツール、統計ソフト)に任せる方がよい。

## 実務での使い方

### 使い方の手順

1. [chatgpt.com](https://chatgpt.com) を開く(スマホアプリでも同様の手順)
2. メッセージ入力欄の左側にある「+」アイコン(ファイル添付/ツールメニュー)をクリック
3. 「ファイルを追加」を選び、分析したいExcel(.xlsx)やCSVファイルを選択してアップロードする(ドラッグ&ドロップでも可)
4. ツール一覧に「データを分析する」のような項目があれば明示的に選ぶと、Pythonでの分析モードが確実に起動する。明示しなくても、集計・グラフ作成を頼む文言を送れば自動的にこのモードが使われることが多い
5. 分析してほしい内容を日本語のプロンプトで具体的に入力する(下記の実例を参照)
6. ChatGPTが生成したPythonコードと実行結果(表・グラフ)が返ってくる。コード部分は折りたたみ表示され、クリックすると中身を確認できる
7. 出力されたグラフ画像や、クリーニング後のCSV/Excelファイルは、回答内のダウンロードアイコンから保存できる
8. 「地域別にも分けて」「直近3か月だけで見せて」のように、同じチャット内で続けて深掘りの指示を出せる。ただし放置時間が長いとセッションがタイムアウトするため、時間が空いた場合はファイルを再アップロードする

### コピペで使える実例プロンプト

月次売上データ(CSV)をアップロードした後に送るプロンプトの例。

```
以下は当社の月次売上データ(sales_2026.csv)です。
このデータを使って次の3つを行ってください。

1. 月別の売上合計の推移を折れ線グラフにする(横軸:月、縦軸:売上金額)
2. 上位5商品の売上構成比を円グラフにする(6位以下は「その他」としてまとめる)
3. 前月比の増減率が最も大きかった月と、その要因になりそうな商品を1つ挙げる

グラフの軸ラベル・凡例は文字化け防止のため英語で表示してください。
金額は千円単位に丸めて表示してください。
最後に、集計に使った計算方法(合計・構成比の算出方法)を3行以内で説明してください。
```

「文字化け防止のため英語で表示」の一文は、日本語の軸ラベルがグラフ内で文字化けする不具合を避けるための実務上の定石。

### ツール横断の対応付け

| 機能 | ツール | 呼び方・起動場所 |
|---|---|---|
| コード実行によるデータ分析 | ChatGPT | Advanced Data Analysis(旧Code Interpreter)。入力欄「+」→ファイル添付、または「データを分析する」 |
| コード実行によるデータ分析 | Claude | コード実行ツール(2025年11月に「Analysis」から改称)。ファイルを添付して分析を依頼すると自動的に発動し、結果はArtifactとして表示 |
| コード実行によるデータ分析 | Gemini | Code executionツール(Gemini Appでファイル添付時に利用)、またはGoogleスプレッドシート内の `=AI()` 関数によるセル単位の処理 |
| コード実行によるデータ分析 | Microsoft Copilot | Excelの「数式」タブにある「Python in Excel」、またはMicrosoft 365 Copilotのデータ分析エージェント |

### プラン別の利用可否・上限(2026年7月時点)

| プラン | 月額目安 | データ分析機能 | ファイルアップロードの目安 | 備考 |
|---|---|---|---|---|
| Free | 無料 | 利用可だが1日あたりごく少数回に制限(正確な回数は非公表) | 1日数件程度 | 業務用途では制限に達しやすい |
| Go | $8(2026年1月提供開始) | 利用可、Freeよりも大幅に拡張(目安10倍) | Freeの約10倍 | 低価格帯だが実務利用に耐える枠 |
| Plus | $20 | 利用可、実務利用に十分な回数 | 3時間で最大80ファイル程度(全有料プラン共通のレート制限) | 個人利用の主力プラン |
| Pro | $200 | 利用可、優先実行・上限に到達しにくい | 同上 | 大量データを頻繁に扱う個人向け |
| Business(旧Team、2025年8月に名称変更) | 1ユーザー月20〜25ドル程度(年払い/月払い、最低2席) | 利用可、Plus相当+管理機能 | 同上 | 会話データは既定でモデル学習に使われない、SSO等の管理機能あり |
| Enterprise | 個別見積もり | 利用可、組織内で優先度最高 | 組織全体でストレージ100GBなど個別設定 | データレジデンシー・監査ログなど大企業向け要件に対応 |

ファイル自体の制限はプラン共通でおおむね以下の通り。

- 1ファイルの絶対上限は512MB程度だが、CSVやExcelなどの表形式ファイルは行の複雑さにより実質50MB前後が目安
- テキスト・文書ファイルは1ファイルあたり最大200万トークンまで
- 画像は1枚20MBまで
- 1メッセージに添付できるファイル数は最大20件程度(2026年2月のアップデートで10件から拡張)
- ストレージ上限は1ユーザーあたり25GB、組織全体で100GB

金額・上限は改定が多い領域なので、契約前には[ChatGPTの料金ページ](https://chatgpt.com/pricing/)で最新値を確認するとよい。

## 注意点・よくある誤解

- **結果は必ず実データと突き合わせて検算する**: ChatGPTは裏でPythonコードを実行して正確な数値を出すのが基本だが、集計条件の指示があいまいだと「除外すべき行を含めたまま合計する」など意図しない集計をすることがある。重要な数値は元データの一部を手計算で照合する
- **グラフの日本語ラベルは文字化けしやすい**: 軸ラベル・凡例は英語で出力させ、必要ならタイトルだけ後から日本語に書き換えるのが実務上の定石
- **サンドボックスはネットにつながっていない**: 最新の為替レートや外部サイトの情報を取り込んだ分析はできない。必要な数値は別途Web検索させてから手動でプロンプトに含める
- **セッションのタイムアウトでファイルが消える**: 無操作のまま15〜30分程度放置するとセッションが切れ、アップロード済みファイルへのアクセスが失われることがある。長時間の分析作業は区切って進め、必要に応じて再アップロードする
- **機密データの扱いはプランで既定が異なる**: Free/Go/Plusでは会話データが既定でモデル学習に利用される場合があり、オプトアウト設定の確認が必要。顧客データや個人情報を扱うなら、学習利用が既定オフのBusiness/Enterpriseへの切り替えを検討する
- **大規模データや厳密な統計モデリングには不向き**: 1回のコード実行が約120秒でタイムアウトするため、数十万行を超えるデータや複雑な統計処理はBIツールや統計ソフトと併用する

## 最初の一歩

手元にある売上データや経費データのCSV/Excelを1つ選び、ChatGPTの入力欄「+」からアップロードして「月別の推移を折れ線グラフにして」と頼んでみる。
