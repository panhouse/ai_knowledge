# ChatGPTによるデータ分析(Advanced Data Analysis)

## これは何か

ExcelやCSVファイルをChatGPTにアップロードするだけで、集計・グラフ化・異常値の検出・重複データの洗い出しまでを自動でやってくれる機能が「Advanced Data Analysis(アドバンスド・データ分析、旧称Code Interpreter)」である。関数やピボットテーブルを自分で組む必要も、分析用のプログラミングを覚える必要もなく、「売上の月別推移をグラフにして」と日本語で頼むだけで、裏側でChatGPTがPythonコードを書いて実際に実行し、結果を返してくれる。Excel作業の下準備や一次分析を任せられるため、日々の集計・レポート作成の時間を大きく圧縮できる。

## 仕組み・背景

この機能の核心は、ChatGPTが「サンドボックス」と呼ばれる隔離されたクラウド上の実行環境を持っている点にある。サンドボックスとは、外部のシステムに影響を与えないよう隔離された使い捨ての作業スペースのことで、ここでPythonのコードを実際に走らせてから結果を返す。

これが重要なのは、通常の文章生成が「それらしい答えを言語モデルが予測して書く」のに対し、データ分析機能では「実際にコードを実行して得た計算結果」を返している点である。例えば「売上合計はいくらか」と聞かれたとき、ChatGPTは`df['sales'].sum()`のようなコードを書いて実行し、その戻り値を回答として提示する。単なる推測ではなく計算結果であるため、四則演算や集計の精度は本来高いはずである(ただし後述のとおり、コードの前提=どの列をどう集計するかの解釈ミスは起こり得るため、検算は必須)。

名称の変遷も押さえておくとよい。2023年3月に「Code Interpreter」として登場した際はプログラマー向けの機能という印象が強かったが、2023年8月にOpenAIが「Advanced Data Analysis」に改称し、プログラミング知識のないビジネスユーザーにも使える分析機能であることを打ち出した。現在のChatGPTの画面上には「データ分析」という専用ボタンは存在せず、ファイルをアップロードした時点で自動的にこの機能が有効になる(裏側の処理名として今も両方の呼び方が使われている)。

## 使いどころ・使い分け

| 状況 | 向いている選択肢 |
|---|---|
| 数百〜数万行程度の売上データ・アンケート結果を、その場でサクッと集計・可視化したい | ChatGPTのデータ分析機能で十分 |
| 「毎週この数字を見たい」など継続的に更新されるダッシュボードが欲しい | Power BI・Tableau・Looker Studioなど専用BIツールを使う(ChatGPTは対話1回ごとに使い捨ての分析であり、自動更新の仕組みを持たない) |
| 数百万行を超える大規模データ、複雑な結合を伴う分析 | サンドボックスのCPU・メモリ・実行時間(目安として1回の処理が数分でタイムアウトする)に制約があるため、専用の分析基盤やデータウェアハウス(BigQueryなど)を使う |
| 顧客の個人情報・契約情報など機密性の高い基幹データ | 社内のBIツールや、社内データが外部AIの学習に使われない契約形態(ChatGPT Enterprise/Business等)を使う。安易に汎用のChatGPTへアップロードしない |
| 定型フォーマットのレポートを毎回同じロジックで自動生成したい | GPTs(カスタムGPT)やAPI連携で分析ロジックを固定化する方が再現性が高い |

## 実務での使い方

### 手順: アップロードから分析結果のダウンロードまで

1. ChatGPTの入力欄左側にある「+」(ファイル追加)アイコンをクリックし、「パソコンからアップロード」を選んでExcel/CSVファイルを選択する(ドラッグ&ドロップでも可)。
2. アップロード後、そのファイルに対して分析したい内容をチャットで指示する(下記プロンプト例を参照)。
3. ChatGPTが自動でPythonコードを生成・実行し、表やグラフを返す。処理内容を確認したい場合は、生成されたコードブロックの「コードを表示」的な表示をクリックすると、実際に実行されたコードを見られる。
4. グラフが出力されたら、グラフ右上に表示されるダウンロードアイコンから画像(.png)として保存できる。
5. 加工済みのデータそのものが欲しい場合は「集計結果をExcelファイルでダウンロードできるようにして」のように依頼すると、ダウンロード用リンクが会話中に生成される。

### コピペで使えるプロンプト例

```
添付のExcelは過去1年分の店舗別・月別売上データです。以下を行ってください。

1. 列の意味を最初に確認し、想定と違う場合は質問してください
2. 店舗別の月次売上推移を折れ線グラフにしてください
3. 前年同月と比べて売上が20%以上落ちている店舗と月を一覧にしてください
4. 全体の傾向について、営業会議で報告できる形で3行に要約してください

グラフの軸ラベルは日本語ではなく英語で出力してください。
```

```
添付のCSVは先月実施した顧客アンケートの回答データです。以下を行ってください。

1. 自由記述欄以外の選択式回答を設問ごとに集計し、割合(%)を表にしてください
2. 満足度スコア(1〜5点の列)のヒストグラムを作成してください
3. 回答内容が完全に重複している行があれば教えてください
```

### ツール横断の対応付け

同じ「ファイルをアップロードして分析させる」機能は、主要ツールでは次のように呼ばれる。

| ツール | 名称・機能 | 呼び出し方 |
|---|---|---|
| ChatGPT | Advanced Data Analysis(旧Code Interpreter) | 入力欄の「+」からファイルを添付するだけで自動的に有効化 |
| Gemini(アプリ版) | ファイルアップロードによるデータ分析 | 入力欄のクリップ(ファイル追加)アイコンからアップロード |
| Google スプレッドシート | Gemini in スプレッドシート | 画面右側のGeminiサイドパネルを開き、自然言語で集計・グラフ化を指示 |
| Microsoft Copilot(Excel) | Copilot in Excel(Pythonによる高度な分析) | Excel上部の「Copilot」ボタン→編集依頼時にPythonの利用を指示、またはCopilotが自動判断してPythonを使用 |

### 業務での活用シーン例

- **売上データの傾向分析**: 店舗別・商品別の売上推移を可視化し、季節性や異常値(急な落ち込み・急騰)を洗い出す。
- **アンケート集計**: 選択式回答の単純集計・クロス集計、自由記述のテキストからのキーワード抽出。
- **重複データのクレンジング**: 顧客リストや在庫リストに含まれる表記ゆれ(全角/半角、大文字/小文字)や完全重複行の検出・除去。

### 料金プラン(2026年7月時点)

データ分析機能自体は無料プランでも回数制限付きで利用できる。継続的に使うなら以下が目安。

| プラン | 目安月額 | データ分析機能の扱い |
|---|---|---|
| Free | 無料 | 利用可能だが、アップロード回数・処理量の上限が厳しい |
| Go | 月1,400〜1,500円程度 | Freeより利用上限が緩和される |
| Plus | 月20ドル程度 | 実務利用に十分な上限。個人利用の主力プラン |
| Business/Team・Enterprise | 要問い合わせ | 上限がさらに緩和され、組織のデータをモデル学習に使わない設定が標準 |

ファイルサイズの上限は1ファイルあたり512MBが上限だが、CSVやスプレッドシートは行数次第でおおむね50MB程度までを目安にするとよい(行数が多いほどサンドボックスの処理が重くなり、タイムアウトしやすくなる)。

## 注意点・よくある誤解

- **「実際に計算している」から常に正しいわけではない**: コードの実行結果自体は正確でも、ChatGPTが列の意味や集計単位を取り違えたまま計算していることがある。重要な数値は必ず自分でも一部を検算し、鵜呑みにしない。
- **大きすぎるデータ・重い処理はタイムアウトする**: サンドボックスにはCPU・メモリ・実行時間の制約があり、数百万行を超えるデータや複雑な処理は途中で止まることがある。エラーが出た場合はデータを分割してアップロードし直す。
- **グラフの日本語ラベルが文字化けすることがある**: サンドボックス内のフォント環境の都合で、軸ラベルや凡例の日本語が四角(豆腐文字)になることがある。文字化けしたら「英語で出力し直して」と頼み、必要なら手元で日本語に置き換える。
- **機密データのアップロードは情報漏洩リスクを伴う**: 顧客の個人情報や未公開の経営数値をアップロードする前に、契約しているプランでデータがモデルの学習に使われない設定になっているかを必ず確認する。詳細は[生成AI利用における情報漏洩対策](../part03-risk-security/information-leakage-prevention.md)を参照。
- **セル結合・複雑な見出しのExcelは誤集計のもと**: そもそもAIが読みにくいデータ形式だと分析結果自体が崩れる。渡す前にデータを整えるコツは[AIが扱いやすいデータ形式](ai-friendly-data-formats.md)を参照。
- **1回の会話はダッシュボードではない**: チャットのたびに一からファイルを読み込み直す使い捨ての分析であり、自動更新やスケジュール実行はできない。継続運用が必要な数字はBIツール側に移す。

## 最初の一歩

手元にある売上データやアンケート結果のExcel/CSVファイルを1つ、ChatGPTの入力欄にドラッグ&ドロップし、「このデータの傾向を3つ挙げて、それぞれグラフにして」と頼んでみる。出てきた数値のうち1つだけでよいので、自分の手元(元のExcelの合計や件数)と突き合わせて検算してみる。
