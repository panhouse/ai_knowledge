# 造船業における生成AI活用事例

## これは何か

造船業は「1隻ごとに設計が異なる一品生産」「熟練工の技(溶接・板曲げ)への依存」
「深刻な人手不足」という3つの構造課題を抱えており、これらに対応するために
設計エージェント・技能伝承AI・生産現場のデジタルツインといった形で生成AIの導入が
急速に進んでいる業界である。[海運・港湾業界における生成AI活用事例](maritime-shipping-ai-use-cases.md)
が「船を運航する側」の話であるのに対し、このページは「船を建造する側」の
生成AI活用に絞って整理する。

## 仕組み・背景

船は1隻あたり部品点数が約100万点にのぼり、量産品と異なりほぼ毎回設計が異なる。
そのため設計工程がボトルネックになりやすく、これを短縮する目的でLLMを使った
「設計エージェント」の導入が進んでいる。また、板を曲げて船体の曲面を作る
「線状加熱」や高精度な溶接は長年の経験が必要な匠の技とされ、若手への技能伝承と
AIによる自動化・再現の両輪で人手不足への対応が図られている。生成AIはこれらに加えて、
外国人労働者向けの多言語マニュアル生成や、設計図面と実際の建造物のズレを
すり合わせるシミュレーション基盤の構築にも使われ始めている。

## 使いどころ・使い分け

| 課題 | 向いている打ち手 | 主な効果 |
|---|---|---|
| 設計の手戻り・工数増大 | 設計図面の自動チェック・発注書自動作成を行うAIエージェント | 従来1年規模の設計サイクルの短縮 |
| 熟練工の技能伝承(溶接・線状加熱) | AI+ロボットによる技能の再現、AR/AIでの作業支援 | 誤差1cm未満など熟練工と同等の精度の実現 |
| 生産現場の設計と実物のズレ | AIによる生産工程シミュレーション基盤 | 手戻り工数の削減 |
| 外国人労働者への技能伝承・教育 | 現場作業の動画から多言語マニュアルを生成する生成AI | 教育コンテンツ作成の高速化 |
| 溶接部の欠陥検出 | 画像認識AI(生成AIではなく従来型のコンピュータービジョン) | 検査時間の短縮 |

**注意**: 溶接部のX線検査・外観検査によるキズ・空洞の自動判定は、生成AIではなく
従来型の画像認識AI(異常検知)が中心である。生成AIが担うのは、検査結果の
自然言語での要約・レポート生成や、設計・発注業務など「言葉を扱う」領域が主。
両者を混同しないこと。

## 実務での使い方

- **設計エージェントの活用例**: 東京大学発スタートアップNoahlogyは造船・海事特化の
  AIエージェント基盤を開発し、2025年8月から今治造船などが、設計図面のチェックから
  見積書の作成・発注までをAIエージェントに任せるPoC(実証実験)を開始した(詳細は下の導入事例カタログ)。
  船は部品点数が多く1隻ごとに仕様が異なるため設計が長期化しやすく、
  従来1年規模とされる設計サイクルの短縮を狙う
- **生産現場のデジタルツイン化**: 川崎重工業とNVIDIAは2026年、坂出工場(香川県)で
  「次世代デジタル造船所」プロジェクトを発表。設計・調達・製造・品質管理の各プロセスに
  デジタルツイン技術とエージェント型AI(現実世界で動くロボットと連携する「フィジカルAI」)
  を組み込む計画を進めている
- **技能伝承の自動化**: ジャパン マリンユナイテッド(JMU)は、鋼板を曲げて船体の
  曲面を作る「線状加熱」という熟練工の技をAI・ロボットで自動化し、誤差1cm未満という
  熟練工と同等の精度を実現。今治造船・川崎重工業・名村造船所などは、経済産業省・国土交通省の
  「AI造船ロボット」関連プロジェクトにも選定され、曲げ加工・溶接の自動化技術開発を進めている
- **外国人労働者向け多言語マニュアル生成**: ビースポークは、スマートフォンで撮影した
  作業動画から多言語の教育用マニュアルを生成AIで自動作成するツールを、外国人労働者の
  採用が急増する造船・舶用工業向けに提供している
- **業界横断のデータ基盤整備**: 船級協会のClassNKは、造船所・設計会社・ソフトウェアベンダーを
  つなぎ、3Dモデルや設計データを検索・比較できるデジタルマーケットプレイスを開始した

## 導入事例カタログ

2026年11月時点で、造船会社が生成AI・LLM・AIエージェントを業務に組み込んだ実名事例を、国内外から1事例=1カードで整理する(溶接・曲げ加工ロボットなど生成AI以外の自動化は「実務での使い方」の節に譲る)。国内は設計チェックの実証段階が中心で、効果の数値を公表した例はまだない。韓国の大手造船所では、設計文書の検索や外国人作業者向けの翻訳など、業務に入った例が出始めている。

### 今治造船(国内建造量首位の造船グループ) — 対象業務: 設計図面チェックから見積・発注まで
- **導入形態**: 専用SaaS導入(東大発スタートアップNoahlogyの造船特化AIエージェント)
- **段階**: PoC(2025年8月に実証実験を開始)
- **やったこと**: 船舶の設計図面チェックから見積書の作成・発注までを、AIエージェントが自分で判断しながら処理する実証実験を始めた。船は部品点数が多く1隻ごとに仕様が違うため、設計・調達部門の負担を減らすことが狙い
- **効果**: 数値公表なし。Noahlogyは「設計リードタイムを最大10分の1に短縮」を目標に掲げているが、これはベンダーの目標値(2026年6月、ベンダー公表)で、実証の結果でも本番展開後の数値でもない
- **学べること**: 一品生産の業界でも、「図面を確認し、見積・発注までつなぐ」定型の確認作業ならエージェントの実証対象にできる
- **出典**: [日本経済新聞(2025年8月2日)](https://www.nikkei.com/article/DGKKZO90430320S5A800C2BZ0000/) / [LOGISTICS TODAY(2026年6月)](https://www.logi-today.com/969748) / 最終確認日: 2026-11-25

### HD現代三湖(HD Hyundai Samho。韓国HD現代グループの大手造船所・海外事例) — 対象業務: 設計文書の管理・検索、船体支持配置の検討
- **導入形態**: 内製(船級協会のKorean Register〈KR〉と共同開発)
- **段階**: 部門展開(1年間の共同プロジェクトが2026年6月に完了)
- **やったこと**: KRとの共同プロジェクトで2つを作った。1つは、造船所の複雑な設計文書を管理・検索する造船特化のLLMサービス。造船所のセキュリティ要件に合わせてオンプレミス(社内設置)で構築し、熟練者の知見に多くの社員がアクセスできるようにした。もう1つは、船体を支える支持材の数と配置を決めるAIモデル
- **効果**: 数値公表なし
- **学べること**: 図面・設計情報の機密性が高い造船業では、外部クラウドではなく社内ネットワーク内に置いたLLMで文書検索を作る選択肢が現実的
- **出典**: [Marine Link(2026年6月4日)](https://www.marinelink.com/news/kr-hd-hyundai-samho-complete-aipowered-539972) / 最終確認日: 2026-11-25

### HD韓国造船海洋(HD KSOE。HD現代グループの造船中間持株会社・海外事例) — 対象業務: 外国人作業者への作業指示の翻訳
- **導入形態**: 内製
- **段階**: 部門展開(2024年7月時点でHD現代三湖の造船所に導入。グループの造船子会社への展開を計画)
- **やったこと**: 生成AIを使った翻訳サービス「AI Agent」を開発し、社内メッセンジャー「Team Up」と連携させた。韓国語の作業指示を、各作業者が設定した言語に自動翻訳する。造船用語1万3,000語と作業指示文4,200文を集めて翻訳の精度を高めた
- **効果**: 数値公表なし。対応言語はベトナム語・ウズベク語・ネパール語・タイ語の4言語で、11言語への拡大を予定(2024年7月時点、Korea Herald報道=第三者取材。その後の拡大状況は未確認)
- **学べること**: 業界の専門用語集と定型の指示文を先に整えると、汎用の翻訳より現場で通じる多言語化ができる
- **出典**: [Hellenic Shipping News(Korea Herald転載、2024年7月10日)](https://www.hellenicshippingnews.com/hd-korea-shipbuilding-launches-translation-service-for-foreign-workers/) / 最終確認日: 2026-11-25

### ハンファオーシャン(Hanwha Ocean。韓国大手造船3社の一角・海外事例) — 対象業務: 購買仕様書(POS)の作成・検証
- **導入形態**: 専用SaaS導入(カナダのCohereと協業)
- **段階**: PoC(2026年3月31日に合意)
- **やったこと**: 船の設計・調達で使う購買仕様書(POS: Purchase Order Specification。機器メーカーに発注する際の技術仕様をまとめた文書)を、生成AIで作成・検証するPoCを始めた。最初の対象は主機関(メインエンジン)の仕様書で、うまくいけば船体構造・配管・電気計装へ広げる構想
- **効果**: 数値公表なし
- **学べること**: 複数チームの手作業で表記揺れが出やすい調達仕様書は、範囲の狭い1機器分から生成AIを試すのに向いている
- **出典**: [Vanguard Defence(2026年4月29日)](https://www.vanguarddefence.ca/p/designing-the-future-fleet-cohere-and-hanwha-ocean-bring-generative-ai-into-shipbuilding-s-core) / 最終確認日: 2026-11-25

### 事例から見える傾向

造船会社の生成AI活用は、溶接や曲げ加工といった「手の技能」よりも、設計図面・仕様書・作業指示といった「文書」の領域から始まっている。韓国大手は、社内に置く造船特化LLMや外国人作業者向けの翻訳など、業務に入った段階に進んでいる。国内は今治造船の設計エージェント実証のようなPoCが中心。どの事例も本番運用での効果数値をまだ公表していないため、ベンダーの目標値と実績を分けて読む必要がある。

## 注意点・よくある誤解

- **「自律的にできる」を鵜呑みにしない**: ClassNKは、AIが航行支援・機械管理・造船所の
  ロボット制御・自律運航船の判断にまで関わる場合、判断ロジックのブラックボックス化や
  責任の所在の不明確化が課題になると指摘しており、船級協会がAIシステムの妥当性検証を
  求められる場面が増えている。安全に直結する判断は必ず人が最終確認する体制を維持する
- **人手不足対策としての側面が強い**: 造船業でAI導入が急がれる最大の動機は、
  効率化そのものよりも「線状加熱・溶接といった匠の技を継承する人材の不足」である。
  導入を検討する際は、単なる自動化ではなく技能継承の仕組みとして設計する視点が要る
- **国内一次情報が薄い会社もある**: 三菱造船固有の生成AI活用事例や、規制対応文書の
  自動作成といった領域は、2026年8月時点で確認できる一次情報が少ない。導入事例を
  調べる際は親会社(三菱重工業グループなど)全体の取り組みも合わせて確認する

## 最初の一歩

自社の設計・生産現場で「毎回作り直している文書」(発注書・作業手順書・多言語マニュアルなど)
を1つ洗い出し、その作成にどれだけ工数がかかっているかを見積もることから始めるとよい。
