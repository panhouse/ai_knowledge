# 自動車ディーラー(新車販売・アフターサービス)業界における生成AI活用事例

## これは何か

自動車ディーラー(新車正規販売店・中古車販売チェーンの店舗運営)は、「Webで見込み客を捕まえて来店・試乗につなげる」「下取り・買取査定を素早く出す」「ローン・保険(F&I: Finance & Insurance)の与信を回す」「車検・点検の予約とサービスフロントでの提案を回す」という、来店前から購入後のアフターサービスまで一連の顧客接点を、限られた営業・サービス要員でさばくビジネスである。ここに生成AI・AIチャットボット・画像認識AIが入り込み、(1)Webサイト・LINE等での見込み客対応と来店予約を担う「AIチャットボット・AIエージェント」、(2)下取り・買取価格を写真や車両情報から即時算出する「セルフ査定AI」、(3)車検・点検の予約受付とサービスフロントでの提案を支援する「サービス受付AI」、(4)蓄積した顧客データをもとにフォローアップを自動化する「CRM・BDC(Business Development Center)向けAI」、(5)ローン審査を自動判定する「F&I向け与信AI」、(6)外国人顧客向けの「多言語対応AI」という6領域で実用化が進んでいる。

本ページは「新車・中古車を店舗で売り、車検・点検で顧客と長く付き合う」**ディーラー運営そのもの**に焦点を当てる。自動車メーカー・OEM側の車載AIアシスタントや、ディーラーの商談音声要約AI・ホンダ「My Honda」のような顧客向けAIエージェントの詳細は[自動車業界における生成AI活用事例](automotive-industry-ai-use-cases.md)で扱っており、本ページでは重複を避けて簡潔な言及にとどめる。また車両の**損傷画像からの修理見積もり・故障診断・技術伝承**は[自動車整備・鈑金業界における生成AI活用事例](auto-repair-bodyshop-industry-ai-use-cases.md)、業者間**オークション・輸出**の画像査定・相場予測は[中古車販売・オークション業界における生成AI活用事例](used-car-sales-auction-industry-ai-use-cases.md)で扱っているため、本ページは「Web集客→来店→査定→契約→アフターサービス」という**店舗の顧客対応フロー**の観点に絞って整理する。

## 仕組み・背景

ディーラー業界でのAI活用を支えるのは、大きく3つの技術要素である。

1. **生成AI・LLMによる自然な対話**: 従来の決まった選択肢しか選べないシナリオ型チャットボットに代わり、LLMが顧客の自由な言い回しの質問に答え、車種提案・見積もり案内・試乗予約までを対話形式で完結できるようになった。米国では自動車小売業界向けにImpel AIの「Chat AI」のような専用の対話AIが、CDK Global・Reynolds and Reynolds・Cox Automotive「Dealertrack」・Tekionといった主要DMS(Dealer Management System、販売店基幹システム)と連携する形で提供されている([Impel AI公式ブログ](https://impel.ai/blog/7-ways-ai-is-revolutionizing-customer-service-in-auto-dealerships/))
2. **画像認識AI+生成AIによる査定・撮影の自動化**: スマートフォンで撮った車両写真から傷・状態を判定し、相場データと突き合わせて査定額を算出する。査定額の説明文や車両紹介文の生成には生成AIが使われることが多い
3. **CDP(Customer Data Platform)・DMSに蓄積されたデータをAIエージェントが横断活用**: 来店履歴・商談履歴・サービス履歴・SNS上の行動データを一つの顧客プロファイルに統合し、フォローアップメールの自動生成や次回車検の提案タイミングをAIが判断する。米Fullpathのようなディーラー特化CDPは200以上の外部システム連携を備え、行動データにもとづくメール・広告配信の最適化にAIを使っている([Fullpath公式](https://www.fullpath.com/))

背景には、新車・中古車ディーラー業界共通の**人手不足**(営業・サービスフロント要員の採用難)と、**問い合わせ手段の多様化**(電話だけでなくWebチャット・LINE・SNS経由の問い合わせが増え、営業時間外の機会損失が経営課題化している)がある。米Cox Automotiveの2026年の調査では、ディーラーの60%がAIツールの試験導入段階、約15%が業務フローにAIを組み込み済みとされ、パーソナライズしたメッセージ配信によって来店予約への転換率が26%向上したという結果も報告されている([Cox Automotive公式](https://www.coxautoinc.com/insights/how-ai-agents-will-reshape-every-dealership-workflow/))。日本国内でも、トヨタ系列ディーラーの商談支援AI導入([自動車業界における生成AI活用事例](automotive-industry-ai-use-cases.md)参照)に加え、下取り査定・F&I与信・多言語対応といった周辺業務でのAI活用が広がりつつある。

| 下取り・買取のセルフ査定AI | 査定は店頭でしか出せず、来店前に金額感がわからないと商談化しにくい | ラグザス「カーネクスト」AI車売却、WECARS(伊藤忠が旧ビッグモーターから承継)、エーエヌラボ「かいとりロボ」 | 車両情報・写真からAIが査定価格を自動算出、スマホ完結の売却フロー |
| サービス予約・サービスフロントでの提案 | 車検・点検の予約管理と、点検結果をもとにした追加整備の提案に時間がかかる | Tekion「AI Agent for Service」(米国)、オートバックスの接客AIアシスタント実証(あえて非生成AIを採用) | 対話AI・生成AIによる予約受付とパーソナライズした整備提案 |
| CRM・BDC(顧客データ活用)の自動化 | 来店・商談・サービス履歴が分断され、フォローアップの機会を逃す | Fullpath(顧客データプラットフォーム)、Salesforce「Agentforce」自動車向けCRM | 顧客データを統合しAIがフォローアップメール・広告配信を最適化 |
| F&I(ローン・保険)の与信審査 | 与信判断が審査担当者の経験に依存し、回答までに時間がかかる | 三菱総研×三菱自動車ファイナンス「審査AIサービス」、MS&AD×セカンドサイトアナリティカ | 審査官の判断を学習したAIモデルによる自動承認判定 |
| 多言語対応・外国人顧客対応 | 訪日外国人・在留外国人の来店増に対し多言語対応できるスタッフが限られる | ポケトーク・VoiceBiz等の汎用AI翻訳ツール、多言語対応をうたう販売店(カーマッチ等) | 音声・チャットのリアルタイム翻訳AIによる接客支援 |

## 使いどころ・使い分け

| 業務 | 生成AI・AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| Web上の一次問い合わせ対応・試乗予約 | 向く(営業時間外の対応、定型的な車種案内・予約受付の自動化) | 値引き額・下取り交渉など契約条件に関わる回答は人にエスカレーションする設計が必要 |
| 下取り・買取のセルフ査定額提示 | 向く(来店前の金額感の提示による商談化率の向上) | 「AIが出した額=確定額」ではない。最終額は現車確認を経る旨を明示する必要がある |
| 車検・点検の予約受付 | 向く(定型的な日程調整、リマインド送付の自動化) | サービスフロントでの追加整備提案は、AIの参考情報をもとに人が最終説明する運用が安全(オートバックスがあえて非生成AIを選んだ判断も参考になる) |
| 顧客データにもとづくフォローアップ | 向く(次回車検・買い替えタイミングの提案、休眠顧客の掘り起こし) | 顧客データを外部AIサービスに渡す場合はプライバシーポリシー・データ保存先の確認が前提 |
| F&Iの与信判断 | 向く(定型的な信用情報にもとづく一次判定の自動化、審査時間の短縮) | 与信の最終責任は金融機関・販売会社側にあり、AIの判定はあくまで補助。特殊事情のある案件は人による審査に回す設計が必須 |
| 多言語での契約説明・重要事項説明 | 慎重に(一次対応・簡単な案内はAI翻訳で十分だが) | 契約書・保証内容など法的拘束力のある説明は誤訳のリスクが大きく、必要に応じて有資格の通訳・多言語スタッフを介する |

## 実務での使い方

### 1. Web集客・来店予約チャットボット

- **AITOLIE**: 自動車ディーラー向けに、試乗予約・見積もり案内をチャット上で24時間受け付けるチャットボットを提供。予約完了後の確認メッセージ自動送信や前日リマインドにより無断キャンセルの防止も狙う([AITOLIEコラム](https://aitolie-chat.com/column/chatbot-for-car-dealer))
- **SELF TALK(スズキ四輪サイト)**: SELF株式会社の「コミュニケーションAI」をスズキの四輪車メーカーサイトに導入し、車選びが初めての訪問者にも接客員のように個別の好みや状況をヒアリングして案内する仕組みを提供している([SELF株式会社公式](https://self.systems/ai-selftalk-dounyu-suzukicar/))
- **Impel AI「Chat AI」(米国)**: 1億件超の自動車業界の会話データと消費者行動データを学習させた生成AIが、CDK Global・Reynolds and Reynolds・Cox Automotive「Dealertrack」・Tekionなど主要DMSと連携して顧客対応を行う。従来のシナリオ型チャットボットに代わり、自然な会話で商談化までつなげる設計になっている([Impel AI公式ブログ](https://impel.ai/blog/7-ways-ai-is-revolutionizing-customer-service-in-auto-dealerships/))
- **Spyne**: 車両写真・360度撮影・動画のAI生成/編集を中心に、自動車ディーラー向けのAIコールボット機能も展開している([Spyne公式](https://www.spyne.ai/ja))

### 2. 下取り・買取のセルフ査定AI

- **ラグザス「カーネクスト」AI車売却**(2026年4月24日提供開始): スマートフォンで車両情報を入力すると、AIが査定価格を自動算出し、査定から売却手続き・自宅への車両引き取りまでをスマホとLINE公式アカウントだけで完結できるサービス。中古車市場の拡大とオンライン完結ニーズの高まりを背景に投入された([カーネクスト、「AI車売却」開始…スマホで査定から売却まで完結 - レスポンス](https://response.jp/article/2026/04/24/410527.html))
- **WECARS(ウィーカーズ)**: 伊藤忠商事・伊藤忠エネクス・JWPの3社が旧ビッグモーターの事業を承継して設立した中古車販売チェーン。査定業務でのAI活用を進めているとされ、伊藤忠は2026年4月に360度画像生成技術を手がけるスタートアップAGENCIA(アジェンシア、[中古車販売・オークション業界における生成AI活用事例](used-car-sales-auction-industry-ai-use-cases.md)で紹介した360°Auction®/360°Car®の開発元)へ出資しており、AI査定・画像活用の強化を進めている([中古車ウィーカーズ、伊藤忠がAIで再建挑む 27年度黒字化へ課題なお - 日本経済新聞](https://www.nikkei.com/article/DGXZQOUC149SQ0U6A510C2000000/))
- **エーエヌラボ「かいとりロボ」**: AI画像査定サービスを運営するエーエヌラボが、車検・板金を手がける八幡自動車商会(山形県)の車検専門店「コバック」店頭で、カメラの前を通過した車両をAIが自動撮影・画像解析し、中古車データベースと即座にマッチングして査定する実証実験を2021年9月から開始した([AI画像査定サービス「かいとりロボ」を運営するエーエヌラボ、中古車販売の八幡自動車商会と実証実験開始 - PR TIMES](https://prtimes.jp/main/html/rd/p/000000001.000087119.html))
- 個人が使うスマホ完結型の自己査定アプリとしては、IDOM「Gulliver AUTO」が代表例。詳細は[中古車販売・オークション業界における生成AI活用事例](used-car-sales-auction-industry-ai-use-cases.md)を参照

### 3. サービス予約・サービスフロントでの提案

- **Tekion「AI Agent for Service」(米国)**: 2026年2月のNADA(全米自動車ディーラー協会)ショーでTekionが発表したAgentic AI Suiteの一部で、サービスアドバイザーがAIの提案する整備・修理内容をもとにタイムリーで個別化した提案を顧客に行えるようにする機能を含む。あわせて生成AIによる顧客とのコミュニケーション機能「Tekion Smart Communication」も提供し、Tekionは自動車小売業界向けプラットフォームとして初めてISO/IEC 42001(AIマネジメントシステムの国際規格)認証を取得したと発表している([Tekion, the AI-Native Platform, Sets a New Standard for Agentic AI in Automotive Retail at NADA 2026 - Morningstar/Business Wire](https://www.morningstar.com/news/business-wire/20260205479848/tekion-the-ai-native-platform-sets-a-new-standard-for-agentic-ai-in-automotive-retail-at-nada-2026))
- **オートバックスの接客AIアシスタント実証**: オートバックスセブン子会社のオートバックスデジタルイニシアチブが、Ridgelinez・クーガーの2社と共同で2024年8月1日から東京都内の「デジタルラボ」に模擬環境を構築し、フランチャイズオーナー等向けに接客AIアシスタントの実証を行った。従来タッチパネル端末で分かれていたインターフェースを対話型に統合する狙いだが、**あえて生成AIではなく非生成AIを選んだ**点が特徴で、回答の一貫性・予測可能性を重視した判断とされる([オートバックスが接客AIアシスタントを実証、あえて「非生成AI」を選ぶ - 日経クロステック](https://xtech.nikkei.com/atcl/nxt/news/24/01297/))
- 定型的な日常整備・車検の見積もり自動生成については、トヨタモビリティパーツ×ギックス「AI整備見積りシステム」が詳しい。[自動車整備・鈑金業界における生成AI活用事例](auto-repair-bodyshop-industry-ai-use-cases.md)を参照

### 4. CRM・BDC(顧客データ活用)の自動化

- **Fullpath(米国)**: DMS・CRM・Webサイトのデータを統合してひとつの顧客プロファイルを作る顧客データプラットフォーム(CDP)。200以上の外部システムとの連携実績を持ち、行動データ・下取り可能性・サービス履歴等にもとづくセグメント配信をAIが最適化する([Fullpath公式](https://www.fullpath.com/))
- **Salesforce「Agentforce」自動車向けCRM**: ホンダの「My Honda」AIカーライフアドバイザーが採用していることで知られる自動車業界向けAIエージェント基盤。ディーラーCRMとしても提供されており、詳細は[自動車業界における生成AI活用事例](automotive-industry-ai-use-cases.md)を参照
- Cox Automotiveの調査では、パーソナライズしたメッセージ配信により来店予約への転換率が26%向上したと報告されている(前掲、[Cox Automotive公式](https://www.coxautoinc.com/insights/how-ai-agents-will-reshape-every-dealership-workflow/))

### 5. F&I(ローン・保険)の与信審査AI

- **三菱総合研究所×三菱自動車ファイナンス「審査AIサービス」**: 三菱総合研究所が2021年7月1日から、三菱自動車ファイナンスに対してAIによるオートクレジット審査業務の提供を開始。審査官の融資可否判断を学習したAIモデルを金融機関の審査業務システムに連携させ、案件の50〜70%程度について人手を介さない自動承認判定を可能にした。回答スピード・効率性・客観性の向上を狙いとしている([三菱総合研究所、三菱自動車ファイナンスに審査AIサービスを提供開始 - MRI公式](https://www.mri.co.jp/news/press/20210712.html)、[AIが自動車ローンの与信判断…7割無人化 三菱自動車ファイナンス - レスポンス](https://response.jp/article/2021/07/17/347768.html))
- **MS&AD(三井住友海上)×セカンドサイトアナリティカ**: 保険データを機械学習で分析し、個人向け自動車ローン・リースの与信力を評価する信用力スコアリングサービス「個人向け自動車ローン等の審査モデル」を2022年5月に構築。Global Mobility Serviceや自動車販売会社と連携した検証も行われている([信用力 スコアリングサービス「個人向け自動車ローン等の審査モデル」構築 - セカンドサイトアナリティカ プレスリリース](https://prtimes.jp/main/html/rd/p/000000037.000034194.html))

### 6. 多言語対応・外国人顧客対応

訪日外国人・在留外国人の中古車購入や車検・点検の需要が増える一方、多言語対応できるスタッフを常時揃えるのは中小規模のディーラーには負担が大きい。名古屋の中古車販売チェーン「カーマッチ」の一部店舗のように、多言語対応(英語・中国語・ベトナム語)を掲げて外国人顧客の免許取得から購入後の緊急対応までを一貫サポートする例もあるが、これは人員配置による対応が中心である([カーマッチ岐阜羽島店 店舗ブログ](https://car-match.jp/shopblog/posts13513/))。AIを使った現実的な選択肢としては、ポケトーク・VoiceBiz(TOPPAN)のような音声リアルタイム翻訳端末や、ChatGPT・Geminiの音声対話機能を使った簡易通訳を、一次案内・簡単な質疑応答に限定して併用する形が現実的である。契約内容や保証条件など法的拘束力のある説明は、AI翻訳だけに頼らず、有資格の通訳や多言語対応の書式・重要事項説明書を用意しておくことが望ましい。

### 汎用生成AIで来店予約チャットのFAQ回答・車種案内スクリプトを下書きするプロンプト例

```
あなたは新車販売店の来店予約チャットボットの応答設計者です。以下の条件から、
Webサイト・LINE公式アカウントに設置するチャットボット用の応答スクリプトを
Q&A形式で10問分作成してください。

## 前提条件
- 取扱ブランド・車種: (例: トヨタ・レクサスの新車、対象車種はヤリス、カローラ、RAV4)
- よくある質問カテゴリ: (例: 試乗予約、見積もり相談、下取りの有無、営業時間、支払い方法)
```

### ツール横断の対応付け

| 用途 | 主に使われるツール・基盤 | 導入のハードル |
|---|---|---|
| Web上の来店予約・一次対応チャットボット | AITOLIE、Spyneのようなディーラー特化チャットボット、汎用チャットボットSaaS(Zendesk、LINE公式アカウントのAI応答機能等) | 自社サイト・LINE公式アカウントへの組み込み設定が必要。既存DMS/CRMとの連携有無で機能差が出る |
| セルフ査定・下取り査定 | カーネクスト「AI車売却」、Gulliver AUTOのような自己査定アプリ | 自社で開発するより、既存の買取・査定アプリへの送客連携やホワイトラベル利用が現実的 |
| サービス予約・整備提案 | Tekion「AI Agent for Service」等の海外DMS一体型AI、国内では既存の予約管理システムへのチャットボット追加 | 国内はDMSと一体化した専用AIより、予約受付だけを切り出したチャットボット導入が先行しやすい |
| 顧客データ活用・フォローアップ | Fullpath、Salesforce Agentforce | DMS・CRMのデータ連携基盤が前提。データ量が少ない小規模店舗はまず既存CRMのリマインド機能の活用から |
| F&I与信審査 | 三菱総研「審査AIサービス」、セカンドサイトアナリティカのスコアリングサービス | 自社直接契約ではなく、提携する信販会社・保険会社経由で導入されるのが基本形 |
| 多言語対応 | ポケトーク、TOPPAN「VoiceBiz」、ChatGPT/Geminiの音声翻訳機能 | 端末購入・月額利用料は数千円程度からで、小規模店舗でも今日から試せる |
| 車両紹介文・広告文の下書き | ChatGPT、Gemini、Copilot等の汎用チャットAI | プロンプトに車両情報・ターゲット層を具体的に書き込むと精度が上がる(詳細は[自動車業界における生成AI活用事例](automotive-industry-ai-use-cases.md)参照) |

## 注意点・よくある誤解

- **AI査定額・チャットボットの回答はあくまで一次情報**: カーネクストの「AI車売却」のような自動査定も、最終的な買取額は車両状態の確認を経て確定する。「AIの提示額=確定額」という誤解を顧客に与えない案内文言を用意しておく
- **「生成AI導入=正解」ではない**: オートバックスの接客AIアシスタント実証では、あえて非生成AIを選択している。回答の一貫性・予測可能性が重視される場面(価格提示・法令に関わる案内等)では、生成AIより従来型のルールベースAIのほうが適する場合もあり、用途ごとに向き不向きを見極める必要がある
- **F&Iの与信AIは最終責任を代替しない**: 三菱総研のようなAI審査は案件の50〜70%程度を自動承認するにとどまり、残りは人による審査に回っている。特殊事情のある与信案件・法令上の説明義務(割賦販売法等)は、AIの判定結果を鵜呑みにせず、最終的に金融機関・販売会社側が責任を持って確認する
- **顧客データを扱うAIサービスは個人情報保護法の順守が前提**: Fullpathのような顧客データプラットフォームや、来店予約チャットボットに蓄積される個人情報・車両情報は、個人情報保護法・利用目的の明示、外部AIサービスへのデータ送信に関する社内規程の整備が前提になる
- **多言語対応AIは契約・重要事項説明の代替にはならない**: 音声翻訳AIは日常会話・簡易な案内には有効だが、契約書・保証内容の説明など法的拘束力のある場面での誤訳はトラブルに直結する。必要に応じて多言語の書面や有資格通訳を併用する
- **チャットボットの値引き・キャンペーン回答は要検証**: 車種案内や試乗予約はAIに任せやすい一方、値引き額やキャンペーン条件をAIが誤って案内すると「言った通りにしてほしい」というトラブルに発展しうる。価格・契約条件に関わる回答は人にエスカレーションする設計にしておく([自動車業界における生成AI活用事例](automotive-industry-ai-use-cases.md)でも同様の注意点を指摘)

## 最初の一歩

自社が新車・中古車ディーラーであれば、まずは投資額の大きいDMS一体型AIの導入よりも、コストの低い「Web来店予約チャットボットの試験導入」または「汎用生成AIでの来店予約チャットのFAQスクリプト・車種紹介文の下書き」から着手し、効果(問い合わせ対応時間の短縮、来店予約数の変化)を小さく検証してから、下取り査定AI・F&I与信AI・多言語対応ツールへと対象を広げていくのが現実的である。
