# 農業における生成AI活用事例

## これは何か

農業は「担い手の高齢化・減少」「熟練農家の経験・勘への依存」「繁忙期の事務作業の負担」という課題を抱える一方、栽培記録・気象データ・出荷実績といったデータのデジタル化が急速に進んでいる業種である。
農林水産省は2024年2月に「農業DX構想2.0」を公表し、生成AIを用いたサービスの開発・普及を推進する方針を示しており([農林水産省](https://www.maff.go.jp/j/kanbo/dx/attach/pdf/nougyou_dxkousou-167.pdf))、農機メーカー・JA・スタートアップが相次いで生成AIを組み込んだサービスを投入している段階にある。
本ページは、営農相談チャットボット(生産者向け・JA職員向けの双方を含む)・画像診断の説明文生成・補助金申請書類のドラフト作成・需要予測レポート・EC商品説明文という5つの業務領域について、実在する取り組みを整理した事例カタログである。

## 仕組み・背景

農業のAI活用を理解するうえで押さえておきたいのが、**「認識系AI」と「生成AI」の役割の違い**である([認識系AIの応用](../part01-ai-basics/recognition-ai-applications.md)も参照)。

- 病害虫の検出や生育診断そのものは、本来は特定の作物・病害に特化して学習させた画像認識モデル(専用の分類・検出モデル)が最も精度・速度に優れる
- 一方、近年広がっているのは、GPT-4やAzure OpenAI Serviceのような**画像を扱える汎用の生成AI(マルチモーダルLLM)**に葉や果実の写真をそのまま送り、診断結果や対処法を自然な日本語で説明させるという使い方
- この方式は専用モデルほどの検出精度は保証されないが、開発コストをかけずに「診断+わかりやすい説明+次の一手の提案」までを一気通貫でこなせる手軽さが利点になる

この「専用モデルの精度」対「生成AIの手軽さ・説明力」のトレードオフを理解しておくと、自社がどちらの仕組みを求めているかを判断しやすい。

もう一つの背景は、農研機構(国立研究開発法人農業・食品産業技術総合研究機構)が2024年10月に三重県で試験運用を開始した**国内初の農業特化型生成AI**の存在である。
全国の公設試験研究機関・農業法人などの知見を学習させており、汎用の生成AIに比べて農業関連の質問への正答率が40%高いという結果が示されている([農研機構プレスリリース](https://www.naro.go.jp/publicity_report/press/laboratory/rcait/166108.html))。
「生成AIに農業を聞けば何でも正しく答えてくれる」わけではなく、**汎用モデルか農業特化モデルか**によって回答の信頼性が変わる点は業務での使い分けに直結する。

もう一つ押さえておきたいのが、**衛星データ×AIのような「認識系AI」への投資も並行して加速している**ことである。衛星データを解析して耕作放棄地の検出や作付け調査を行うサグリ株式会社は2026年8月8日、シリーズAラウンドで約10億円を調達したと発表した([宙畑](https://sorabatake.jp/37848/))。こうした衛星×AIサービスも、検出・診断そのものは専用に学習させたモデルが担っており、生成AIが関わるとすれば「検出結果を人向けの説明・レポートに変換する」工程に限られる点は変わらない。「AIで農地を見える化する」取り組みの多くは生成AI単体の技術ではないことに注意する。

## 使いどころ・使い分け

| 業務 | 課題 | 生成AIの役割 | 向いているツールの型 |
|---|---|---|---|
| 営農相談・栽培Q&A | 普及指導員・ベテラン農家への相談が属人化し、繁忙期は回答が滞る | チャット形式で栽培方法・農機の使い方・制度情報に24時間回答 | 農業特化型生成AI(FarmChatなど)、農機メーカーのAIチャット |
| JA職員の文書作成・業務効率化 | 議事録・提案書・研修資料の作成に時間がかかり、生成AI活用のノウハウが組合ごとにばらつく | 議事録の要約、提案書・資料のたたき台作成、組合員対応の想定問答生成 | JA向け生成AI基盤(報徳Hub、日農AI金次郎など) |
| 病害虫・生育診断の説明生成 | 診断の経験・技量に個人差があり、判断根拠を言葉で説明しにくい | 画像から異常を検知し、診断結果と対処法を自然文で説明 | マルチモーダル対応の農業向けAIチャットボット |
| 補助金・助成金申請書類のドラフト作成 | 公募要領の読み込みと書類作成に数十時間かかり、事務負担が大きい | 事業者情報・事業計画を入力すると申請書のたたき台を自動生成 | 補助金申請支援SaaS(生成AI搭載型) |
| 需要予測・出荷計画のレポート作成 | 出荷量のブレによる価格乱高下・食品ロス、レポート作成の手間 | 予測モデルの結果を人向けにわかりやすく要約・文書化 | 専用の需要予測AI(数値モデル)+生成AIによる要約 |
| 農産物のPR・EC販売用の文章生成 | 出品点数が多く、商品説明文・SNS投稿文の作成が追いつかない | 産地・栽培方法・味の特徴からキャッチコピー・説明文を生成 | 汎用チャットAI、ECモールのAIアシスタント機能 |

判断基準:
- **診断・検出の「精度」が経営に直結する**(出荷可否判定、農薬の使用量決定など)→ 専用の認識系AIを軸にし、生成AIは説明・提案の補助に留める
- **相談・文書作成のように「対話」「要約」「たたき台作成」が主目的**→ 生成AI(汎用または農業特化型)が向く
- **数字の予測精度がそのまま経営インパクトになる**(出荷量・価格)→ 需要予測は専用の時系列モデルに任せ、生成AIは結果の解釈・レポート化を担当する

## 実務での使い方

### 事例1: 営農相談チャットボット

- **クボタ「KSAS AIチャット」**: 営農支援システム「KSAS(Kubota Smart Agri System)」に生成AIを活用したチャット機能を搭載。2025年1月に試用版を公開して検証を行い、2025年6月からサービスを開始、同年7月3日に正式機能として追加した。KSASの使い方、新規就農に役立つ情報、農作物の栽培方法についての質問にチャット形式で回答し、正式版では過去の質問履歴を確認できる「対話履歴機能」や、回答の根拠となるマニュアルのページをPDFで表示する機能も備える([クボタ ニュースリリース](https://www.kubota.co.jp/news/2025/management-20250703.html)、[日本経済新聞](https://www.nikkei.com/article/DGXZQOUF155CY0V10C25A1000000/))
- **農研機構「農業特化型生成AI」(FarmChat)**: 農業情報ポータルアプリ「FarmChat」から利用できる、国内初の農業特化型生成AI。全国の公設試験研究機関・農業法人などが蓄積してきた知見・データを学習させており、汎用生成AIと比べて農業関連の質問への正答率が40%高いという結果が出ている。2024年10月21日から三重県で試験運用を開始し、普及指導員の負担軽減と農業生産者への回答の質向上を狙う。今後はFarmChatを導入している都道府県・農業団体と連携し、地域や品目に特化した営農相談の自動化を目指す方針が示されている([農研機構プレスリリース](https://www.naro.go.jp/publicity_report/press/laboratory/rcait/166108.html))
- **IPPUKU(株式会社cv digital)**: ChatGPTを活用し、LINEで使える農業特化のAIチャットサービス。2023年6月にサービス開始。相談内容を「生産」「販売」「経営」「業務効率化」の4カテゴリに分けることでChatGPTの回答精度を高める工夫をしており、家庭菜園の初心者から事業拡大を目指すプロ農家まで対象にしている。料金は無料お試し(月2回まで)、BASICプラン月額980円(生産カテゴリのみ無制限)、PREMIUMプラン月額1,980円(全カテゴリ無制限、税別)の3段階([SMART AGRI](https://smartagri-jp.com/news/6912))
- **報徳Hub × 日農AI金次郎(JA職員向け)**: 上記3つが生産者向けなのに対し、JA(農業協同組合)の職員自身の業務を支援する生成AIの整備も進んでいる。イマジエイト株式会社は2025年7月23日、JAグループ向けの生成AIプラットフォーム「報徳Hub」をリリース。ChatGPT・Claude・GeminiなどをWeb検索と組み合わせて利用でき、議事録作成・渉外(営業)ロールプレイ・組合員との雑談ネタ提案・財務諸表分析といったJA業務向けアプリを揃える([イマジエイト](https://www.imageight.co.jp/2025/09/09/ja%E5%90%91%E3%81%91%E7%94%9F%E6%88%90ai%E3%83%97%E3%83%A9%E3%83%83%E3%83%88%E3%83%95%E3%82%A9%E3%83%BC%E3%83%A0%E3%80%8C%E5%A0%B1%E5%BE%B3hub%E3%80%8D%E3%82%92%E3%83%AA%E3%83%AA%E3%83%BC%E3%82%B9/))。同年12月5日には日本農業新聞とリセールパートナー契約を締結し、同社のJA会員制サービス「Jパートナーズ」が提供する生成AI「日農AI金次郎」(通常モード・農業モード・議事録モード・検索モードを備え、入力内容をAIの学習に使わない情報管理環境で運用)と合わせて全国のJAへの導入拡大を進めている。2026年に入ってからもパワーポイント生成・ファイル分析機能、文字起こし機能などが追加され続けており、機能拡張のペースが速い([Innovatopia](https://innovatopia.jp/ai/ai-news/73517/)、[日本農業新聞](https://www.agrinews.co.jp/ja/index/259251))

**コピペで使える営農相談プロンプト例**(汎用チャットAIに新規就農者が投げる想定):

```
あなたはベテランの野菜農家兼普及指導員として、新規就農者からの
栽培相談にアドバイスします。以下の条件で回答してください。

# 前提条件
- 作物: (例: 玉ねぎ)
- 栽培地域・気候: (例: 関東地方、露地栽培)
- 栽培経験: (例: 就農1年目、この作物は初めて)
- 圃場の状況: (例: 前作は水稲、粘土質の土壌)

# 相談内容
(例: 定植から収穫までの作業スケジュールと、各時期の注意点を
一般的な目安として教えてください)

# 出力形式
- 月ごと・作業ごとに箇条書きで
- 病害虫や天候不順が起きやすい時期には「要注意」の目印を付ける
- 最後に「地域・年によって最適な時期は変わるため、必ずJAや
  普及指導センターの最新情報で確認してください」と明記する
```

汎用の生成AIは学習データが平均的・一般論に寄りやすいため、最後の「要最新確認」の一文は必須。JAや普及指導センターへの確認を促す注記を外さないことが実務上のコツになる。

### 事例2: 病害虫・生育診断の説明生成

AGRIST株式会社が提供するAIチャットボット「食と農のあぐりすたんと」は、Microsoft の Azure OpenAI Service を活用し、LINE で友だち登録するだけで利用できる。作物の写真を送ると生育状況や病害虫の被害を判定し、対処法をチャットで提案する。機能追加のペースが速く、2025年4月には画像1枚から生育状態を診断する「生育調査」機能と、料理の写真から品目を判別してレシピを提案する「レシピ提案」機能を追加([SMART AGRI](https://smartagri-jp.com/smartagri/11061)、[jacom.or.jp](https://www.jacom.or.jp/shizai/news/2025/04/250410-80848.php))、続く同年6月には画像チャット機能を改良し、従来は画像を送ると会話がリセットされていた仕様を改め、画像送信後も文脈を保ったまま追加質問できるようにした。経験や技量によって差が出やすい病害虫の早期発見や、農薬散布の適切なタイミング・方法の判断を、誰でも一定水準で行えるようにすることを狙いとしている([jacom.or.jp](https://www.jacom.or.jp/saibai/news/2025/06/250613-82447.php)、[AGRIST](https://agrist.com/archives/12165))。同社は2026年に入って農林水産省の「開発供給実施計画」認定も取得しており、ロボティクスと生成AIを組み合わせたスマート農業DXへの投資を継続している([AGRIST](https://agrist.com/archives/15254))。

この事例は「仕組み・背景」で述べた境界線の典型例で、専用に学習させた病害虫検出モデルではなく、汎用のマルチモーダルLLMに写真を送って解釈させている。導入・改修のスピードは速いが、まれに誤診断や過度に断定的な回答をする可能性があるため、農薬の使用可否など経営上重要な判断は生産者自身や専門家の最終確認を挟む運用が前提になる。

### 事例3: 補助金・助成金申請書類のドラフト作成

補助金クラウド(株式会社Stayway)は、GPT-4を活用し、事業者情報・事業内容・実績・雇用状況などを入力すると申請書類のたたき台を自動生成するサービス。担当者いわく、通常20時間程度かかる書類作成が12分程度で完了するようになったという([日本経済新聞](https://www.nikkei.com/article/DGXZQOUC063AI0W3A900C2000000/)、[MUGENLABO Magazine](https://mugenlabo-magazine.kddi.com/list/mcafe_stayway/))。長野県信用農業協同組合連合会(長野県信連)とは補助金活用支援で業務提携しており、農業者・地域事業者がそれぞれの経営課題・事業計画に合った補助金情報とあわせて、申請書類の作成支援を受けられる体制を整えている([Stayway](https://stayway.co.jp/news/2282/))。

農業向けの補助金(経営継続補助金、強い農業づくり総合支援交付金、ものづくり補助金の農業活用など)は公募要領が複雑で、事業計画書に「導入の必要性」「効果の見込み」といった定型的だが作り込みが必要な項目が多い。生成AIはこうした定型記述のたたき台作成に向くが、**採択の可否を左右する数値の裏付け・独自性のある記述は担当者自身が仕上げる**必要がある。

なお、農業のAI・IT導入を後押しする公的支援制度は名称・要件が年度で変わりやすい点にも注意したい。中小企業庁の「IT導入補助金」は令和7年度補正予算事業から「デジタル化・AI導入補助金2026」に改称されており、小規模事業者は補助率最大4/5・補助額上限450万円程度でAIを含むITツール導入を支援する制度になっている([中小企業庁](https://www.chusho.meti.go.jp/koukai/hojyokin/kobo/2026/260310001.html))。生成AIに申請書のたたき台を作らせる場合も、対象となる制度名・公募要領は必ず最新版を都度確認する。

### 事例4: 需要予測・出荷計画のレポート作成支援

- 静岡県のJAふじ伊豆と矢崎総業は、AIを活用したミニトマトの出荷予測システムを共同開発し、誤差25%以内での予測を実現している([日本農業新聞](https://www.agrinews.co.jp/farming/index/387758))
- NTTデータ関西の直売所向けAI需要予測サービス「アグリアスエ」は、需要予測により「機会損失」と「食品ロス」を減らし、直売所の流通総額と生産者の所得向上を狙う([NTTデータ関西](https://www.nttdata-kansai.co.jp/agriase/))

これらの出荷量・需要の予測自体は、[認識系AIの応用](../part01-ai-basics/recognition-ai-applications.md)で扱う時系列予測(従来型の機械学習)が担っており、生成AI単体の技術ではない。生成AIが活きるのはその先の工程で、予測結果や乖離の理由を「なぜこの出荷量を見込むのか」「なぜ計画と実績がズレたのか」という会議・関係者向けの説明文・日報に自動で要約する役割である。農業法人・JAの営農指導部門が日々作成している出荷会議資料・営農日誌のドラフト作成に、生成AIを組み合わせて時間を短縮できるかを検討する価値がある。

### 事例5: 農産物のPR・EC販売用の商品説明文生成

産直EC・ふるさと納税サイトでは、産地・栽培方法・味の特徴・おすすめの食べ方をもとに、生成AIで商品説明文やレシピ提案を作成する動きが広がっている。EC全般での商品説明文自動生成の仕組み(楽天市場「RMS AIアシスタント」、メルカリ「AIアシスト」など)は[小売・流通・ECにおける生成AI活用事例](retail-ai-use-cases.md)で詳しく扱っているため、ここでは農産物特有の切り口だけ補足する。

**コピペで使える農産物EC商品説明文プロンプト例**:

```
以下の情報をもとに、産直ECサイトに掲載する商品説明文を作成してください。

# 商品情報
- 品目・品種: (例: シャインマスカット)
- 産地: (例: 長野県〇〇市)
- 栽培方法: (例: 減農薬栽培、朝採り直送)
- 味・食感の特徴: (例: 皮ごと食べられる、糖度18度以上)
- おすすめの食べ方: (例: 冷やしてそのまま、白ワインと合わせて)

# 出力条件
- 200〜300文字程度
- 誇大表現(「日本一」「絶対に」等の断定・最上級表現)は避ける
- 品種名・産地・栽培方法など事実情報は入力された内容のみを使い、
  入力にない情報(受賞歴・収穫時期など)は書き加えない
- 出力の最後に「価格・数量限定の有無は必ず最新の販売ページで確認」の一文を付ける
```

「入力にない情報を書き加えない」という制約は、生成AIが受賞歴や産地の由来などを"それらしく"補完してしまう(ハルシネーション)のを防ぐための実務上のコツである。

## 注意点・よくある誤解

- **病害虫診断は「参考情報」であって最終判断ではない**: 汎用の生成AIによる画像診断は手軽だが、専用に学習させた検出モデルほどの精度は保証されない。農薬の使用判断や出荷可否など経営に直結する意思決定は、生産者自身や専門家(JA営農指導員など)の確認を挟む運用にする
- **汎用生成AIと農業特化型生成AIで回答の信頼性が違う**: 農研機構の農業特化型生成AIは汎用モデルより正答率が高いという結果が出ている。栽培方法や制度情報など「間違うと実害が出る」相談ほど、農業特化型のツールや一次情報(JA・自治体・農研機構)での裏取りを優先する
- **補助金申請はAIのドラフトをそのまま提出しない**: 生成AIは定型的な記述のたたき台作成に向くが、採択の可否を左右する数値の根拠や独自性のある記述は担当者・専門家(中小企業診断士・行政書士など)の確認が必須。公募要領の要件(対象経費、加点項目など)は必ず原文を確認する
- **需要予測・出荷予測は生成AI単体の技術ではない**: 出荷量・価格の予測精度を左右するのは時系列予測などの専用モデルであり、生成AIの役割は結果の説明・要約に限られる。「生成AIを導入すれば需要予測ができる」という誤解に注意する
- **EC・PR文章は事実情報の水増しに注意**: 産地・栽培方法・受賞歴などをAIに"それらしく"補完させると、景品表示法上の優良誤認表示につながるリスクがある。入力していない情報を書き加えない指示を徹底する
- **国内の農業×生成AIの検証事例はまだ発展途上**: 大規模な効果測定を伴う事例は農機メーカーや農研機構など一部に限られ、中小規模の農業法人・個人農家レベルでの定量的な導入効果の報告は現時点では限定的である。本ページで紹介した各サービスの効果は提供企業の発表ベースであり、自社での効果は規模・作物・地域によって変わる点を踏まえて評価する
- **JA向けの生成AI基盤は乱立気味**: 「報徳Hub」「日農AI金次郎」のようなJA職員向けの専用基盤が2025年後半から急速に広がっているが、組合ごとに導入状況・利用ルールが異なる段階にある。個人が独断でChatGPTなど汎用の外部生成AIに組合員情報・議事録などを入力すると情報漏洩リスクが生じるため、所属JA・部署が正式に契約している基盤の利用ルールを確認したうえで使うことが前提になる

## 最初の一歩

自分や自社が繰り返し受けている「同じような栽培相談」「同じような書類作成」を1つ思い浮かべ、上記の営農相談プロンプト例か商品説明文プロンプト例をそのまま汎用チャットAIに貼り付けて、たたき台がどの程度使えるかを試してみるとよい。JA職員であれば、まず自組合が「報徳Hub」や「日農AI金次郎」のようなJA向け生成AI基盤を導入済みかを確認するところから始めるとよい。
