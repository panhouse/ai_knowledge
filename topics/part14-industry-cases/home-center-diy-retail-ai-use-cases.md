# ホームセンター(DIY小売)業界における生成AI活用事例

## これは何か

ホームセンターは、1店舗で数万点(大型店では10万点規模)のSKU(商品の最小管理単位)を
扱いながら、木材のカットや塗料の選び方、リフォーム相談、園芸のアドバイスといった
「専門知識を要する接客」を同時にこなさなければならない、小売の中でも特殊な業態。
[小売・流通・ECにおける生成AI活用事例](retail-ai-use-cases.md)で扱う一般的な小売AI
(商品説明文生成・需要予測・接客チャットボット)がそのまま当てはまる部分と、
「膨大な品目数の発注業務」「専門性の高い相談対応」「大型店舗特有の売り場提案」
というホームセンター特有の課題に向けたAI活用の両方が存在する。
本ページは、カインズ・DCMホールディングスなど実在企業の事例を軸に、
ホームセンター特有の活用パターンを整理する。

## 仕組み・背景

ホームセンターの生成AI活用が集中しているのは、主に次の3つの業務領域。

1. **発注・在庫管理の自動化**: 商品点数が多すぎて表計算ソフトでの管理が限界に
   達しており、AIエージェント(自然言語で指示すると裏側のデータベースを操作する
   仕組み)と数理最適化(トラック積載量など複数の制約条件を満たす最適解を計算する
   手法)を組み合わせて自動化する動きが先行している
2. **接客ナレッジの生成AI化**: 資材・工具・園芸・リフォームなど専門性の高い
   質問にベテラン社員でなくても答えられるよう、社内マニュアルやFAQを
   RAG(検索拡張生成。社内文書を検索してからAIに回答させる仕組み。詳細は
   [RAGの基本](../part07-data-analysis/rag-basics.md))の形でスマートフォン端末に
   持たせる事例が増えている
3. **画像生成AIによる売り場・EC体験の強化**: 「この家具を部屋に置いたらどう見えるか」
   「この写真の商品と似たものが欲しい」といった、大型店舗ならではの「実物を
   想像しにくい」という悩みに、画像生成AI(詳細は
   [画像生成AIの基本](../part08-specialized-ai-tools/image-generation-ai-basics.md))で応える取り組み

## 使いどころ・使い分け

| 業務領域 | 課題 | 代表企業・サービス | 使ったAI・仕組み |
|---|---|---|---|
| 発注・在庫管理の自動化 | 190万行規模のSQL処理結果を表計算ソフトで手作業管理しており、出力だけで2日、車建て発注の最適化計算にさらに1日かかっていた | カインズ(Google Cloud基盤) | Vertex AI Agent Builder(自然言語指示でBigQueryを操作)＋数理最適化アルゴリズム |
| 店舗スタッフ向け商品知識アシスタント | 資材・工具・修理方法など専門知識の習得に時間がかかり、入社間もないスタッフは接客で顧客を待たせてしまう | DCMホールディングス「Dアドバイザー」 | 生成AIによる商品知識の即時検索(スマートフォン端末) |
| コールセンターの応答支援 | オペレーターが回答のための情報検索に時間を要し、通話時間や事後入力の負担が大きい | カインズ×AI Shift「AI Messenger Chatbot」「AI Messenger Summary」 | ChatGPT連携のFAQ自動応答・通話要約 |
| 画像生成AIによるインテリア提案 | 家具・ラグ・カーテンなど「置いてみないと分からない」商品は、大型店の売り場でも購入判断がつきにくい | カインズ「CAINZ Fitting Room」 | Amazon Nova Canvas(画像生成AI)による部屋画像の商品差し替え(店頭サイネージ) |
| 口コミ・UGC生成支援 | 自社ECサイト「くらシェア」で顧客投稿を増やしたいが、AIが書いた文面だとすぐに分かってしまうと逆効果になる | カインズ | 生成AIによる投稿文の下書き支援(「AIが書いた感」を抑える工夫込み) |
| 店舗DXの下支え(情報共有・問い合わせ) | 紙とデジタルの二重入力、ツールの点在で現場が疲弊している | カインズ(Slack×AI) | Slack上でのAI要約・ワークフロー活用 |

判断の目安として、「発注・在庫管理の自動化」はデータ基盤への投資が前提になるため
着手までのリードタイムが長い。一方「店舗スタッフ向け商品知識アシスタント」は
既存のFAQ・マニュアルをRAG化するだけで始められるため、ホームセンターが
最初に着手する対象として現実的。画像生成AIによる売り場体験の強化は、
カインズの事例でも「精度と処理効率の両立」が課題として明言されており、
効果検証にまだ時間がかかる領域と捉えておくとよい。

なお、コメリ・コーナン商事についても、コーナン商事はAWSを用いた基幹システムの
クラウド移行、コメリは中期経営計画でのDX投資を進めていることが確認できるが、
2026年8月時点で両社が生成AIを使った具体的な取り組みを公表した一次情報は
確認できなかった。データ基盤の整備は生成AI活用の前提条件になるため、
「データ基盤の整備→生成AI活用」という順序で投資が進む業界であることの
傍証として捉えておきたい。

## 実務での使い方

### 1. 発注・在庫管理の自動化(カインズ)

- **課題**: 需要予測モデル自体の精度は上がっていたが、その後工程である
  棚割りデータ・在庫データ・売上実績の紐付けや、車建て発注(トラック1台分の
  積載量を最大化しつつ在庫回転日数もコントロールする発注方式)の計算を
  表計算ソフトで手作業処理しており、190万行のSQL処理結果を出力するだけで
  2日、20万行ごとに6〜7ファイルに分割して管理する必要があった
- **使ったAI**: BigQueryにデータソースを一本化した上で、Vertex AI Agent Builder
  (自然言語の指示でデータ抽出・加工を実行できるAIエージェントの構築ツール)を
  導入。車建て発注の最適化計算には数理最適化アルゴリズムを組み込み、
  Cloud Run JobsとWorkflowsで自動実行する基盤を構築した
- **効果**: 2〜3日かかっていた発注点メンテナンスのデータ抽出・表計算作業を
  大幅に効率化し、点在していた業務プロセスをGoogle Cloud上に統合。
  今後はローカル環境で行っていた数理最適化計算もAIエージェント上へ移行し、
  季節商品・棚割りの最適化など、より複雑な領域への拡張を計画している
- **出典**: [膨大な表計算作業から脱却。AIと数理最適化で実現する、需要予測の先の「発注・在庫管理の自動化」 - Google Cloud 公式ブログ](https://cloud.google.com/blog/ja/topics/customers/cainz-breaks-free-from-the-burden-of-massive-spreadsheet-work?hl=ja)

### 2. 店舗スタッフ向け商品知識アシスタント(DCMホールディングス「Dアドバイザー」)

- **課題**: ホームセンターの接客は、資材の選び方や修理方法など幅広い専門知識を
  必要とするが、習得には経験と時間がかかり、入社間もないスタッフが
  お客様を待たせてしまう場面が発生していた
- **使ったAI**: 生成AIを使った店舗向け接客支援システム「Dアドバイザー」を開発。
  店舗スタッフがスマートフォン端末で質問を入力すると、商品知識を即座に
  検索・回答する。ホームセンター向けの接客支援システムとして先駆的な位置づけで、
  全店への導入を完了している
- **効果**: 顧客を待たせる時間の削減と、経験の浅いスタッフでも安心して
  接客対応できる体制づくりにつながっている。DCMは人口減少に対応した
  業務効率化を重要方針に掲げており、Dアドバイザーはその中核施策の一つ
- **出典**: [デジタル化の推進 - DCM株式会社新卒採用サイト](https://www.dcm-hc.co.jp/recruit/interview/interview03.html)

### 3. コールセンターの応答支援(カインズ×AI Shift)

- **課題**: コールセンターのオペレーターが顧客からの問い合わせに回答するための
  情報検索に時間がかかり通話時間が伸びる一方、通話終了後も顧客管理システムへの
  問い合わせ内容の入力に時間を要していた
- **使ったAI**: AI Shift(サイバーエージェント子会社)の生成AIプロダクトを用い、
  (1)ChatGPTと連携しFAQ・社内マニュアルから自動応答する「AI Messenger Chatbot」、
  (2)オペレーターと顧客の会話を自動要約する「AI Messenger Summary」の
  2つを組み合わせた実証実験を開始。将来的には在庫情報を持つ外部データベースとも
  連携し、商品の在庫有無への即時回答も見込む設計
- **効果**: 2023年11月の実証実験開始時点の発表であり、具体的な数値効果は
  2026年8月時点で公表されていない。ただし「オペレーターの自己解決」と
  「事後入力の自動化」という2段構えの設計は、コールセンターにAIを
  導入する際の型として参考になる
- **出典**: [AI Shift、株式会社カインズと生成AIを活用した「AI Messenger Chatbot」「AI Messenger Summary」を用いたコールセンターの業務効率化に向けた実証実験を開始 - 株式会社AI Shift](https://www.ai-shift.co.jp/3809)

### 4. 画像生成AIによるインテリア提案(カインズ「CAINZ Fitting Room」)

- **課題**: 家具・ラグ・カーテンなどは「実際に部屋に置いてみないと分からない」
  商品の代表格で、大型店舗であっても購入前の意思決定を後押しする手段が
  限られていた
- **使ったAI**: 店頭サイネージ「CAINZ Fitting Room」で、部屋の写真に写る
  家具・ラグ・カーテンを別のカインズ製品に画像生成AIで差し替えて表示する。
  Amazon Bedrockの画像生成モデル「Nova Canvas」(2026年にvirtual try-on
  機能が一般提供開始)を採用し、埼玉県の「カインズ 吉川美南店」など
  次世代型の大型店舗でテストを開始した。生成にはリアルタイム性よりも
  正確性を優先し、あらかじめ生成した画像を管理画面に登録してから
  店頭で表示する運用とし、生成結果と実物のズレ(ハルシネーション)を防いでいる。
  精度向上のため、Nova Canvasより高精度とされる新モデル「Pruna」の
  検証も進めている
- **効果**: 2026年8月時点ではテスト段階で、正確性(生成画像と実商品の一致度)と
  処理効率の両立が課題として明言されている。将来的には顧客自身が撮影した
  自室の写真を使った生成を目指す
- **出典**: [カインズが画像AIで売上UP模索、店頭でのインテリア"試着"をテスト 立ちはだかる「正確性と効率」の壁 - ITmedia NEWS](https://www.itmedia.co.jp/news/articles/2606/26/news114.html) / [カインズ、大型店舗でのインテリア商品選びを生成AIによる画像生成で解消へ - Impress dcross](https://dcross.impress.co.jp/docs/usecase/004679.html)

### 5. 口コミ・UGC(ユーザー生成コンテンツ)生成支援(カインズ「くらシェア」)

- **課題**: カインズが運営する、顧客が商品を使ったDIY・工作アイデアを
  共有するコミュニティサービス「くらシェア(みんなのくらしシェア)」で
  投稿数を増やしたいが、生成AIで投稿文を作りやすくしすぎると
  「AIが書いた感」の強い定型文ばかりが増え、コミュニティの熱量が下がる
  リスクがあった
- **使ったAI**: 生成AIで投稿の下書きを支援する機能を開発する際に、
  あえてAIらしさを抑えたトーンにチューニングする工夫を重ねた
  (2026年7月開催のGoogle Cloud Next Tokyoで「生成AIで実現するtoCサイトの
  リッチ化」として事例発表)
- **効果**: 投稿のハードルを下げつつ、コミュニティらしい"人の言葉"を保つ
  バランス設計の事例として紹介されている
- **出典**: [口コミ増やしたい、でも"AIが書いた感"は抑えめに……カインズ、「自社商品の投稿」促すAI機能どう開発した？ - ITmedia ビジネスオンライン](https://www.itmedia.co.jp/business/articles/2608/24/news059.html)

### ツール横断の対応付け(接客ナレッジAIの呼び方)

同じ「店舗スタッフ向け商品知識アシスタント」という機能でも、企業やツールによって
呼び名や設置場所が異なる。自社で検討する際は下記の対応で読み替えるとよい。

| 概念 | DCMホールディングス | カインズ | 一般的な仕組み |
|---|---|---|---|
| スタッフ向け商品知識検索 | 「Dアドバイザー」(スマートフォン端末) | (社内向けは非公開だが、コールセンターでは「AI Messenger Chatbot」) | RAG(社内マニュアル・FAQを検索してAIが回答) |
| 顧客対応の自動要約 | ー | 「AI Messenger Summary」(コールセンター) | 通話・チャットログの生成AI要約 |
| 画像生成による商品体験 | ー | 「CAINZ Fitting Room」(店頭サイネージ) | 画像生成AI(Amazon Nova Canvas等)によるインペインティング(画像の一部差し替え) |

### コピペで使える実例: 店舗スタッフ向け商品知識アシスタントのプロンプト設計例

社内マニュアル・FAQをRAGで検索させる際、次のようなシステムプロンプトの骨格が
参考になる(実装はDify・ChatGPTのカスタムGPT・Copilot Studioなど、
社内で使えるRAG基盤に合わせて読み替える)。

```
## 役割
あなたはホームセンターの店舗スタッフ向け商品知識アシスタントです。
接客中のスタッフが、その場でお客様に正確な情報を伝えられるよう支援します。

## 回答のルール
- 必ず検索された社内マニュアル・商品情報の範囲内で回答し、憶測で答えない
- 该当する情報が見つからない場合は「担当者に確認してください」と案内する
- 塗料・薬剤・電動工具など安全に関わる質問は、必ず注意書き・使用上の注意も併記する
- 回答は3行以内で簡潔にまとめ、詳細は箇条書きで補足する

## 出力形式
【回答】(結論を1〜2文)
【補足】(使い方・注意点を箇条書き)
【関連商品】(あれば型番・売り場)
```

## 注意点・よくある誤解

- **発注・在庫管理の自動化は、データ基盤の統合が先**: カインズの事例でも、
  AIエージェント導入そのものより「190万行のデータを単一のBigQueryソースに
  一本化したこと」が土台になっている。表計算ソフトでの分散管理を残したまま
  AIエージェントだけ導入しても効果は出にくい
- **画像生成AIは「リアルタイム生成」を急がない**: CAINZ Fitting Roomのように、
  精度優先であらかじめ生成した画像を使う設計は、生成AIが不得意とする
  「実物との細部の不一致」を回避する実務的な工夫。インテリア・商品外観のように
  ユーザーが後で実物と見比べる用途では、この「事前生成・差し替え表示」の
  発想が参考になる
- **UGC生成支援は「AIらしさを消す」チューニングが要る**: くらシェアの事例が
  示す通り、生成AIによる投稿支援は便利さと引き換えに文面が均質化しやすい。
  口コミ・レビューのように「人が書いた実感」が価値になるコンテンツでは、
  定型文になりすぎないプロンプト設計・出力後のランダム性の確保が必要
- **数値は各社発表ベースであることに留意**: 本ページに記載した効果は
  各社のプレスリリース・企業サイト・報道に基づくものであり、算出方法や
  検証段階(実証実験か本番導入か)が事例ごとに異なる。実証実験段階の事例
  (AI Shiftとの取り組みなど)は「効果」ではなく「狙い」として読むこと
- **コメリ・コーナン商事の事例は「基盤整備」段階**: 両社とも生成AI特有の
  取り組みとして公表された一次情報は本ページ執筆時点で確認できていない。
  同業他社の動きを引き合いに出す際は、事例が実在するか出典を必ず確認する

## 最初の一歩

自社の店舗マニュアル・FAQのうち「よく聞かれる質問トップ10」だけを
ChatGPTやCopilotのカスタムGPT・Gemに読み込ませ、上記のプロンプト例を使って
「その場で接客に使えるか」を1人のスタッフに試してもらうところから始める。
