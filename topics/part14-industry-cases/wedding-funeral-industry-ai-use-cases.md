# 冠婚葬祭業(結婚式・葬儀)における生成AI活用事例

## これは何か

冠婚葬祭業(結婚式場・ブライダル企業、葬儀社、冠婚葬祭互助会)は、**一生に一度・
一度きりのイベントを、限られた打ち合わせ期間と人手で仕上げなければならない**という
共通の構造を抱えている。ブライダルでは提案書・招待状・ムービーといった「一組ごとに
作り直す成果物」が大量にあり、葬儀では「深夜・早朝を問わない問い合わせ」「短時間で
仕上げる遺影・弔辞・見積り」への対応が求められる。どちらも少子高齢化による市場縮小と
人手不足が同時に進んでおり、生成AIを「プランナー・葬祭ディレクターの下書き係」として
使う動きが2024〜2026年にかけて実証段階から商用サービス段階へ進んだ。

本ページは、ブライダル業界(プランニング提案、招待状・席次表デザイン、プロフィール
ムービーの自動編集)と葬儀業界(生前相談チャットボット、見積り・提案文書生成、遺影・
エンディングノート作成支援)の両方について、確認できた国内事例と料金感を整理する。
結婚式場・葬儀社の経営者、プランナー・葬祭ディレクター、互助会の企画担当者が、
自社で何から始めるかを判断するための材料集として使う。

## 仕組み・背景

冠婚葬祭業で生成AI活用が広がっている背景は主に3つ。

1. **市場縮小と人手不足の同時進行**: 婚姻件数・死亡件数(死亡数自体は当面増加するが
   葬儀単価は縮小傾向)双方で、単価下落と人材確保難が同時に起きており、
   「限られた人数で、一組・一件ごとに質を落とさず対応する」ことが経営課題になっている
2. **「一組・一件ごとに作り直す」定型フォーマット業務が多い**: ブライダルの提案書・
   招待状・プロフィールムービー、葬儀の会葬礼状・弔辞・見積書は、いずれも
   「変数(氏名・エピソード・予算)を差し替えれば一定の型に収まる」性質が強く、
   生成AIの「型に沿って大量に個別化する」得意分野と相性がよい
3. **緊急性・24時間対応へのニーズ**: 葬儀は深夜・早朝・土日祝を問わず発生するため、
   問い合わせ対応の24時間化ニーズが強い。ブライダルも来館前の問い合わせ対応・
   SNS運用に人手が割けない中小式場が多く、AIチャットボット・自動応答への期待が
   共通して高い

技術的には、ChatGPT・Gemini・Canvaなどの**汎用AIツールをプランナー・スタッフが
個人で使うケース**と、葬儀業界特化の「AIみかえる」「いとわAI」「アイアイちゃん」、
ブライダル特化の「Speria AI」のような**業界特化SaaSを導入するケース**の二本立てで
普及している。2026年に入り、葬儀業界では特に大手互助会・上場葬儀社を含む導入が
進み、ブライダル業界では中小式場・フォトスタジオでのSNS・ブログ運用効率化から
着手する例が目立つ。

## 使いどころ・使い分け

| 業務 | 業界 | 主な用途 | 向いているツールの型 |
|---|---|---|---|
| プランニング提案・演出アイデア出し | ブライダル | 顧客のヒアリング情報(出会い・趣味・予算・テーマ)から演出案・提案書のたたき台を作る | 汎用チャットAI |
| 招待状・席次表・ペーパーアイテムのデザイン生成 | ブライダル | テンプレートを土台に、招待状・席次表・メニュー表のデザインを作る | Canva等のデザイン生成AI |
| プロフィールムービー・エンドロールの自動編集 | ブライダル | 写真・動画素材からムービーの土台を自動生成し、仕上げだけ人が調整 | 動画編集AIアプリ(スマホ完結型) |
| 打ち合わせ準備・議事録・メール文面 | ブライダル | 打ち合わせ前の準備資料、打ち合わせ後の議事録、カップルへのメール下書き | 汎用チャットAI |
| SNS投稿・ブログ・広告文の作成 | ブライダル | 式場のInstagram投稿文、ブログ記事、キャンペーン告知文 | 汎用チャットAI、SNS運用支援SaaS |
| 生前相談・問い合わせ対応チャットボット | 葬儀 | 葬儀の流れ・マナー・費用・互助会に関する質問への24時間対応 | 葬儀特化AIチャットボットSaaS |
| 見積り・プラン説明文書の生成 | 葬儀 | プラン内容・価格内訳を遺族にわかりやすく説明する文書のたたき台作成 | 汎用チャットAI + テンプレート化 |
| 会葬礼状・弔辞・ナレーション原稿の生成 | 葬儀 | 故人のエピソード・宗教形式を入力し、礼状・ナレーション原稿を自動作成 | 葬儀特化の文章生成AIサービス |
| 遺影写真のAI加工・複数案生成 | 葬儀 | 手持ちの写真1枚から背景・服装を変えた複数案を短時間で生成 | 葬儀特化の画像生成AIサービス |
| デジタル供養・AI故人対話・生前の想い継承 | 葬儀 | 故人の生前の言葉・LINEのやり取りをAIに学習させ、遺族が対話できるようにする | AI故人対話特化サービス |
| エンディングノート・終活相談 | 葬儀(生前) | 資産整理・葬儀の希望など終活の悩みをAIに気軽に相談する | LINE等のチャットAI相談サービス |

判断基準:

- **「型に個別情報を流し込む」性質の業務**(会葬礼状・提案書・招待状の下書き)→
  生成AIに任せてよい。人の役割は「素材(エピソード・エピソード写真)の質」と
  「最終チェック」に集中させる
- **心情・宗教・法規が絡む業務**(弔辞の最終確認、遺影の加工可否、成婚・香典に
  関わる金額表現)→ AIは下書きまで、最終判断・確認は必ず有資格者・ベテランスタッフが行う
- **24時間対応が必要で、誤答の被害が比較的小さい定型質問**(空き状況、一般的な
  葬儀の流れ、互助会の仕組み)→ チャットボットに任せてよいが、**緊急の一次対応
  (ご逝去の連絡など)は必ず人につながる導線を残す**
- **自社で完結できるか/業界特化SaaSが要るか**→ 個人店・小規模式場・葬儀社は
  まずChatGPT・Gemini・Canvaなど汎用ツール(月0〜3,000円程度)で試し、
  遺影・礼状・チャットボットまで自動化したい場合に業界特化SaaSを検討する

## 実務での使い方

### 1. ブライダル: プランニング提案・演出アイデア出し

プランナーの仕事は打ち合わせそのものより「準備」に多くの時間がかかる。
ヒアリング済みの情報をもとに、演出アイデアや提案書の構成をAIに下書きさせ、
プランナーはカップルとの対話に時間を使う運用が広がっている
([taian-inc「生成AIを活用した、結婚式の打ち合わせ準備のポイント」](https://www.blog.taian-inc.com/archives/2347))。

**コピペで使える演出提案プロンプト**(ChatGPT・Geminiなど汎用チャットAIに投げる想定):

```
あなたは結婚式場のベテランウェディングプランナーです。
以下のヒアリング内容をもとに、この新郎新婦に合った演出アイデアを
3パターン提案してください。

# ヒアリング内容
- 出会いのきっかけ: (例: 大学のサークル)
- お二人の趣味・好きなもの: (例: 海外旅行、映画鑑賞)
- 会場の雰囲気: (例: ガーデン付きのゲストハウス)
- 予算感: (例: 挙式・披露宴合わせて300万円程度)
- ゲストの特徴: (例: 遠方からの参列者が多い、子連れゲストがいる)

# 出力条件
- 各案に「コンセプト」「具体的な演出内容」「概算追加費用感」を含める
- 奇抜すぎず、この会場・予算で実現可能な範囲に収める
- 最後に「この提案はたたき台であり、実際の演出内容・費用は
  打ち合わせで正式に確定する」旨を明記する
```

### 2. ブライダル: 招待状・席次表・ペーパーアイテムのデザイン生成

招待状・席次表・メニュー表などの「ペーパーアイテム」は、AI搭載のデザインツール
Canvaで無料〜低価格に作成できる。テンプレートを選び、AIの画像生成・レイアウト
提案機能で写真や文字を差し替えるだけで統一感のあるデザインに仕上がる
([Canva「結婚式ペーパーアイテム」](https://www.canva.com/ja_jp/wedding/))。
自作する花嫁・花婿本人向けの需要と、式場・プランナーが提案時のサンプルを
素早く作る需要の両方で使われている。Canva Pro(有料プラン)ではブランドキット
機能でフォント・ロゴ・カラーを事前設定でき、招待状から席次表・席札まで
デザインの統一が容易になる。

### 3. ブライダル: プロフィールムービー・エンドロールのAI自動編集

プロフィールムービーは業者への外注相場が3万〜8万円程度(簡易プランで2万円前後)
とされる一方、AI搭載の動画編集アプリを使えば自作でも高い完成度に近づけられる
ようになった([wara-wedding.com「プロフィールムービーの料金・値段」](https://wara-wedding.com/column/profile/souba/))。
2026年8月時点で使われている代表的なツールは以下の通り。

| ツール | 特徴 | 料金感(2026年8月時点) |
|---|---|---|
| NONNOFILM | スマートフォンで撮影から編集まで完結。結婚式特化テンプレートを土台に、写真とタイトルを入れ替えるだけで一定の完成度になる | アプリ内課金あり |
| Canva | ドラッグ&ドロップでムービーを編集。AIによる音楽・トランジション提案機能あり | 無料プランあり、Pro版は有料 |
| CapCut | 余興・手持ち動画の編集に強い | 無料〜 |
| PowerDirector / Filmora | PCでの詳細な編集向け。AI機能でカット・BGM同期を自動化 | 買い切り8,980円程度〜、年額プランもあり |
| ChatGPT / Gemini | ムービーの構成案・ナレーション原稿・字幕コメントの文章生成に使う(動画そのものは生成しない) | ChatGPT Plus月3,000円程度、Gemini無料枠あり |

実務でのコツは「AIに8割任せ、残り2割を人が仕上げる」という感覚で使うこと。
AIが生成したトランジション(切り替え効果)が派手すぎて写真が見づらくなることが
あるため、テンプレートの土台部分はAI・人手作業どちらでもよいが、**「この夫婦
らしいエピソードの選び方・言葉選び」という「心」の部分は人が最終調整する**、
という役割分担が実務のコツとして共有されている
([NONNOFILM.app「結婚式プロフィールムービーをAIで楽に作るコツ」](https://app.nonnofilm.jp/profile/profile-movie-app/wedding-profile-movie-ai/))。

### 4. 葬儀: 生前相談・問い合わせ対応チャットボット

葬儀は深夜・早朝・土日祝を問わず発生するため、問い合わせ対応の24時間化が
長年の課題だった。2024年以降、葬儀・互助会特化のAIチャットボットが複数
商用化されている。

- 株式会社セレモニーは2024年4月1日から、葬儀・互助会に特化したAIチャット
  サービス「アイアイちゃん」の提供を開始。葬儀に関するマナーや互助会の
  仕組みについての質問に24時間対応する
  ([セレモニー公式お知らせ](https://www.sougi.info/news_show?id=718))
- 株式会社itowaは2026年2月25日、葬儀業界に特化した生成AI基盤「いとわAI」を
  発表。第一弾機能として、Web訃報サイト上で弔意メッセージの収集や
  故人との対話を支援するチャットAI「いとわトーク」を2026年春から提供予定。
  発表時点で累計利用実績は葬儀15,000件、上場企業3社を含む約40社の葬儀社が
  導入し、月間約2,000件の葬儀で活用されている
  ([itowa PR TIMES](https://prtimes.jp/main/html/rd/p/000000014.000106238.html))
- 株式会社ファミトラは、資産整理・身辺整理・病気やけがへの備えなどについて
  LINEで気軽に相談できる「終活相談AI」を無料で提供。ChatGPTの技術をベースに
  したチャットボットで、会員登録不要ですぐに使える
  ([crownmedia](https://crownmedia.jp/aidx/1096/))
- SAMURAI Securityは、法人(葬儀社・士業事務所向け)にChatGPT連携の相続・
  終活支援AIチャットボット「わたしのAIコンシェルジュPRO」を提供している
  ([葬研](https://souken.info/ai-concierge-pro/))

**コピペで使える生前相談チャットボット用の応答方針プロンプト**(自社サイト・
LINE向けにチャットAIを設定する際のシステムプロンプト例):

```
あなたは葬儀社「(社名)」の生前相談・お問い合わせ窓口AIです。

# 対応方針
- 葬儀の流れ、費用の目安、互助会の仕組み、宗教・宗派ごとのマナーなど、
  一般的な質問には丁寧にわかりやすく回答する
- 個別の見積り金額や契約内容は断定せず、「詳細はスタッフが個別にご案内する」
  旨を伝えて連絡先に誘導する
- 「今まさにご逝去された」「危篤である」など緊急性の高い内容を検知した場合は、
  一般的な案内をせず、直ちに24時間対応の電話窓口(◯◯-◯◯◯◯-◯◯◯◯)へ
  つなぐ案内のみを行う
- 悲しみの感情を示す発言には、事務的な回答の前に一言寄り添う言葉を添える
- 医療・法律・税務に関する専門的判断が必要な質問には、専門家への相談を促す

# 入力
「(ここにお客様からの質問を貼り付け)」
```

### 5. 葬儀: 見積り・提案文書、会葬礼状・弔辞ナレーションの生成

葬儀のプラン説明・見積り内訳は専門用語が多く、遺族にわかりやすく説明する
文書を都度作るのは負担が大きい。生成AIでプラン内容・価格内訳をかみ砕いた
説明文のたたき台を作り、スタッフが個別事情に合わせて調整する運用が
実務で広がっている
([campnet.co.jp「葬儀社・葬祭業のDX／AI活用」](https://campnet.co.jp/blog/funeral-ai-usecase.html))。

会葬礼状・弔辞・ナレーション原稿は、「故人の氏名・続柄・エピソード・宗教形式」
を変数として差し替えれば一定の型に収まる業務で、生成AIと特に相性がよい。

- 株式会社ビアンフェの「IKIRU」は、3つの質問に答えるだけで葬儀のナレーション
  原稿を自動生成するクラウドAIシステム。25年分・約1万本の原稿データを
  基盤に、約8万通りの文型を組み合わせて作成し、宗派ごとの忌み言葉
  (葬儀の場でタブーとされる言葉)リストや、施主の挨拶・お礼状の作成にも対応する
  ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000004.000073462.html))

**コピペで使える会葬礼状の下書きプロンプト**:

```
以下の情報をもとに、会葬礼状の文面を作成してください。

# 故人の情報
- 続柄・お名前: (例: 祖父 ◯◯ ◯◯)
- 宗教・宗派: (例: 仏式・浄土真宗)
- 人柄・エピソード: (例: 庭の手入れが好きで、近所の子供たちにも慕われていた)

# 条件
- 一般的な会葬礼状の形式(時候の挨拶、生前のご厚誼への感謝、
  今後の変わらぬお付き合いのお願い)に沿う
- 「忌み言葉」(重ね言葉、直接的な死の表現の繰り返しなど)を避ける
- 文面は300字程度
- 最後に、宗派特有の言い回しに誤りがないか、必ず担当者が確認する旨を注記する
```

### 6. 葬儀: 遺影写真のAI加工・複数案生成

従来、遺影写真の背景差し替え・服装の着せ替えは外部の写真加工業者に発注し、
1件あたり2時間程度・数千円〜1万円程度のコストがかかっていた。生成AIによる
画像加工サービスの登場で、この工程を内製化・大幅短縮できるようになっている。

| サービス | 提供元 | 機能 | 料金感(2026年8月時点) |
|---|---|---|---|
| 「AIみかえる」 | 木村情報技術株式会社 | 遺影写真の背景・服装をAIで加工。会葬礼状・メモリアルムービーの作成も内製化できる。2025年11月に正式リリース | 1斎場あたり月額2万円〜([PR TIMES](https://prtimes.jp/main/html/rd/p/000000187.000006034.html)) |
| 「WearStudio.AI」遺影写真機能 | 株式会社ニュウジア | 故人の写真1枚から背景のAI生成・正装への着せ替え・最大3案の同時比較提案を数分で生成。2026年2月に正式公開 | 1枚あたり約40〜50円〜、初期費用・月額固定費ゼロのポイント制([ニュウジア PR TIMES](https://prtimes.jp/main/html/rd/p/000000058.000127837.html)) |

「AIみかえる」は遺影写真の作成時間を外注時の約2時間から最短約5分に短縮でき、
約95%の作業時間削減になるとベンダーが公表している。「WearStudio.AI」は
外注費(1枚3,000〜10,000円)と比較して最大97%のコスト削減になるとしている。
いずれもベンダー公表値であり、自社の実際の削減率は運用してみないとわからない
点に留意する。

### 7. 葬儀: デジタル供養・AI故人対話・生前の想い継承

故人の生前の言葉・写真・LINEのトーク履歴などをAIに学習させ、遺族が対話
できるようにする「AI故人」サービスが登場し、葬儀社・寺院・自治体・
介護施設向けの法人パートナー展開が始まっている。

- 株式会社ニュウジアの「TalkMemorial.AI」は、故人の記憶・言葉・価値観を
  学んだAIと対話できるグリーフケア(悲嘆へのケア)サービス。料金は片方向
  メッセージ型が2万円〜、双方向対話型が年額5万円(税込)から。2026年の
  大幅リニューアルでAIによる自動インタビュー機能、LINEトーク履歴の
  ナレッジ活用、家族全員が故人AIの育成に参加できる家族招待機能を追加した。
  「利用者がいつか卒業を選べること」を重視し、依存を防ぐ卒業スコア・
  危機介入の仕組みを組み込んでいる点が特徴
  ([東京新聞×PR TIMES](https://adv.tokyo-np.co.jp/prtimes/article134034/))。
  2026年3月には葬儀社・寺院等を対象にした法人パートナープログラムを
  本格スタートし、リセラーとしてサービス提供できるモデルを展開している

このジャンルは技術的には実現できても、遺族の心情・グリーフケアの観点から
賛否が分かれる分野であるため、次節の注意点も踏まえて慎重に検討する。

## 注意点・よくある誤解

- **AI加工した遺影・写真は「本人らしさ」との乖離に注意する**: 遺影写真の
  背景・服装をAIで変更する行為は、遺族にとって「故人らしい」表現かどうかが
  極めて重要であり、加工の程度・提案する案の数について、必ず遺族の同意と
  確認を挟むプロセスを設計する
- **緊急の一次対応をチャットボットだけに任せない**: 生前相談・問い合わせ
  チャットボットは、空き状況やマナーなど一般的な質問には有効だが、
  「ご逝去の連絡」のような緊急対応が必要な問い合わせを誤って定型応答して
  しまうと重大なクレームになる。**緊急性の高い内容を検知したら即座に人に
  つなぐ設計**を必須にする
- **弔辞・ナレーションの「忌み言葉」チェックはAI任せにしない**: 宗派・地域に
  よって避けるべき言い回しは細かく異なる。生成AIはあくまで下書きであり、
  最終的な言葉選びの確認はベテランの葬祭ディレクターが行う
- **AI故人・デジタル供養サービスはグリーフケアの専門性が問われる**:
  故人とのAI対話は依存や悲嘆のこじれにつながるリスクが指摘されており、
  サービス提供側が「卒業」を前提とした設計(依存を防ぐ仕組み)を組み込んでいるかを、
  導入前に確認する。単なる技術デモとしてではなく、遺族のケアという観点で
  サービスを選定する
- **ブライダルのAI生成コンテンツも著作権・肖像権チェックが必要**: プロフィール
  ムービーで使うBGM・素材、SNS投稿で使う画像は、AIが生成したものであっても
  著作権侵害がないか、また新郎新婦・ゲストの肖像権に配慮した使い方かを
  プランナーが必ず確認してから対外的に公開する
- **数値は各社・各ツールベンダーの発表ベースであることに留意**: 本ページの
  作業時間削減率・コスト削減率・利用実績数は、導入企業やSaaSベンダーが
  公表した事例であり、算出方法や比較対象は企業ごとに異なる。自社の目標
  設定にそのまま流用せず、あくまで「桁感」の参考とする

## 最初の一歩

葬儀社であれば、まず会葬礼状や見積り説明文のような「変数を差し替えれば
一定の型に収まる」定型文書1件を、汎用チャットAI(ChatGPT・Gemini等)に
下書きさせてみて、スタッフの手直し時間がどれだけ短縮できるかを確認する
ところから始めるとよい。ブライダルであれば、Canvaの無料プランで招待状か
席次表のデザインを1件作ってみて、テンプレートからの差し替えでどこまで
提案品質を出せるかを試すのがよい第一歩になる。
