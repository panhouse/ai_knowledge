# 警備業界における生成AI活用事例

## これは何か

警備業界(施設警備・機械警備・雑踏警備・交通誘導警備など)は、深刻な人手不足と高齢化が進む一方で、監視すべき対象(施設・イベント・工事現場)は減っていないという板挟みの状態にある。警備員総数は令和6年末時点で58万7,848人、市場規模は約3.4兆円に達するが、平均年齢は55歳を超え、2025年前後には警備員の約3分の1が65歳以上になるとの見立てもある([keibinext.jp](https://keibinext.jp/news250805/)、[guardaxis.net](https://guardaxis.net/2025/02/19/%E3%80%902025%E5%B9%B4%E5%95%8F%E9%A1%8C%E3%80%91%E8%AD%A6%E5%82%99%E6%A5%AD%E7%95%8C%E3%81%AE%E4%BA%BA%E6%89%8B%E4%B8%8D%E8%B6%B3%E3%81%8C%E6%B7%B1%E5%88%BB%E5%8C%96%EF%BC%81%E7%8F%BE%E7%8A%B6/))。この状況を背景に、SECOM・ALSOK(綜合警備保障)といった大手警備会社や、asilla・VOLLMONTホールディングスなどの専業ベンダーが、画像認識AI・自律走行ロボット・生成AIを組み合わせて「限られた人数で警備品質を落とさない」体制づくりを進めている。本ページは、警備業界という業種そのものにおけるAI・生成AI活用の全体像を、識別系AI(検知・監視)と生成AI(文章生成・対話・教育資料作成)の役割分担として整理する。

## 仕組み・背景

警備業界のAI活用は、性質の異なる2種類のAIが役割分担する構造になっている。

1. **識別系AI(画像認識・異常検知)**: 防犯カメラやロボットに搭載され、「侵入者がいるか」「転倒者がいるか」「不審な挙動か」を判定する。生成AIのように文章や画像を新しく作るのではなく、既知のパターンから逸脱がないかを見分ける役割で、警備業界のAI活用の中核はこちらが占める。
   - **ALSOK AIカメラシステム**: 200億枚以上の人物画像を学習したAIをカメラ内蔵チップ(エッジAI)で処理し、夜間・逆光・雨天でも侵入禁止エリアへの侵入やフェンスの乗り越え、ほふく前進・かがみ歩きといった姿勢まで検知してリアルタイム通知する。映像はクラウド上に3日〜3年保存できる([ascii.jp](https://ascii.jp/elem/000/004/070/4070679/)、[ALSOK](https://www.alsok.co.jp/corporate/ai-camera/))。
   - **AI Security asilla(株式会社アジラ)**: 既存のIPカメラ映像をAIが自ら学習して「平常」を定義し、そこからの逸脱を「違和感」として数秒で検知する仕組み。商業施設・複合施設・オフィスビルなど約200施設に導入され、日立システムズ経由でも提供されている。2026年5月のVer.4.4では車両の侵入・長時間駐車、自転車の放置検知機能も追加された([日立システムズ](https://www.hitachi-systems.com/solution/s0312/sec_asilla/)、[PR TIMES](https://prtimes.jp/main/html/rd/p/000000232.000043312.html)、[ASCII](https://ascii.jp/elem/000/004/404/4404264/))。
2. **警備ロボット(識別系AI+自律走行)**: 巡回・受付・交通誘導といった現場業務そのものを代替・補助する。
   - **SECOM cocobo**: AIと5G通信を活用した自律走行の警備ロボットで、2022年1月に発売。転倒者・不審物・混雑状況をカメラ映像のAI解析で検知し、警備員へアラートを送るほか、煙で不審者を威嚇する機能も持つ。日本で初めて夜間の公道走行が認められたロボットで、成田国際空港では既存の「セコムロボットX2」(2019年6月〜稼働、レーザーセンサーで自律走行)に続く5号機として稼働している([Impress Watch](https://www.watch.impress.co.jp/docs/news/1330650.html)、[日経クロステック](https://xtech.nikkei.com/atcl/nxt/news/18/13012/)、[知財図鑑](https://chizaizukan.com/news/VsSGGxHfpCeRvgCR7MJa0/)、[SECOM](https://www.secom.co.jp/business/cocobo/))。
   - **ALSOK Reborg-X / REBORG-Z**: 2015年発売の自律走行警備ロボット。顔認証で不審者・特定人物を識別し、ショッピングセンターや空港・スタジアムなどの人混みを避けながら巡回する。案内特化の「REBORG-Z」は多言語での道案内にも対応する([ウレぴあ総研](https://ure.pia.co.jp/articles/-/32564)、[ALSOK](https://www.alsok.co.jp/corporate/robot/reborg-x/))。
   - **VOLLMONTホールディングス「Comune+」シリーズ**: 道路工事現場の片側交互通行を誘導するAIロボット。画像認識で車両・自転車・歩行者の位置と速度を検知し、信号の有無や道路形状を認識して渋滞を回避する誘導を行う。緊急車両のサイレン音を認識すると全車両を停止させる機能もあり、2025年12月にはヒューマノイド型ロボットと連携した自動誘導システムの開発も報じられている([Merkmal](https://merkmal-biz.jp/post/6756)、[j-cast](https://www.j-cast.com/trend/2022/03/04432392.html?p=all)、[ごぐいねっと](https://ome-hamura.goguynet.jp/2025/12/28/vollmont/))。
   - **セコム バーチャル警備システム**: 現実空間を映すディスプレイ一体型ミラーに3Dの「バーチャル警備員」を表示し、警戒監視・受付業務をAIが担う。2022年1月に発売され、AGC・DeNA・NTTドコモと共同開発。実際の対処・緊急対応は常駐警備員が担う設計で、経済産業大臣賞を受賞した([ITmedia NEWS](https://www.itmedia.co.jp/news/article/2201/13/1220113143/)、[SECOM](https://www.secom.co.jp/business/vks/)、[知財図鑑](https://chizaizukan.com/news/7wzJ6FStXNe2sUPRLCQRhJ/))。
3. **生成AI(文章生成・対話)**: ここが本来の「生成AI」の出番で、現場ではなく本部・管理側の事務業務を代替する。巡回報告書のドラフト作成、シフト表のたたき台作成、新人教育用の研修資料作成などに使われ始めている(詳細は次章)。

こうした識別系AIの現場導入を後押しする形で、警備業法施行規則も2024年6月27日に改正され、機械警備業務管理者を拠点ごとに専任配置する原則が緩和された。合計5,000施設以下であれば複数拠点を1人の管理者が兼務できるようになり、AIによる遠隔・集約監視の余地が広がっている([兵庫県警](https://www.police.pref.hyogo.lg.jp/news/kyoninka/data/kaisei_20240627.pdf)、[全国警備業協会](https://www.ajssa.or.jp/wp/wp-content/themes/ajssa/img/security/laws-data/kisoku-kaisei.pdf))。

## 使いどころ・使い分け

| 業務 | 向いているAIの種類 | 使い分けの理由 |
|---|---|---|
| 施設・敷地の常時監視、不審者・異常行動の検知 | 識別系AI(AIカメラ、asilla等) | 24時間365日の疲れない監視が可能。人間より反応が早く、見落としを減らせる |
| 空港・商業施設の巡回、転倒者・放置物の発見 | 警備ロボット(cocobo、Reborg-X等) | 定型ルートの巡回はロボットに任せ、警備員は判断・実対応に集中できる |
| 道路工事現場の交通誘導 | 誘導AIロボット(Comune+等) | 単純作業・長時間の反復作業を代替し、熟練誘導員の技術不足を補える |
| 巡回・パトロール報告書のドラフト作成 | 生成AI(ChatGPT・Gemini等) | 音声入力から整形済みの文章を作れ、報告書作成の時間を大幅に圧縮できる |
| シフト表・配置計画のたたき台作成 | 生成AI | 希望シフトや制約条件を渡せば下書きを瞬時に作れる。ただし最終確定は人が行う |
| 新人研修資料・マニュアルの要約作成 | 生成AI | 既存マニュアルを要約・平易化でき、教育の標準化に役立つ |
| 施設受付・一次対応(道案内・入館案内) | AI音声対話+バーチャルキャラクター | 定型的な案内は自動化できるが、緊急時は有人対応へのエスカレーションが必須 |
| 不審者への声かけ・実力行使・緊急時対応 | 人(警備員)が担う | AIはあくまで検知・情報提供までで、現場対応の最終判断・実行は法的にも実務的にも人が担う |

## 実務での使い方

### ツール横断の対応表

| 用途 | 提供元・ツール例 |
|---|---|
| 画像認識による異常検知(AIカメラ) | ALSOK AIカメラシステム、AI Security asilla(株式会社アジラ/日立システムズ) |
| 巡回・受付を担う警備ロボット | SECOM cocobo・セコムロボットX2、ALSOK Reborg-X・REBORG-Z |
| バーチャル受付・警戒監視 | セコム バーチャル警備システム(AGC・DeNA・NTTドコモ共同開発) |
| 交通誘導ロボット | VOLLMONTホールディングス「Comune+」シリーズ |
| 巡回報告書・日報のドラフト作成 | ChatGPT(GPTs)、Google Gemini、Claude等の汎用生成AI |
| シフト作成・新人研修資料の生成 | Google Workspace(Gemini)を使った社内活用事例([here-now.jp](https://here-now.jp/blog/2025-12-18_gws_gemini_ai/)) |

山口県のある警備会社では、Google Workspaceに搭載されたGemini機能を使い、シフト作成の複雑な調整をたたき台として自動生成させたり、既存マニュアルをもとに新人向けの不審者対応研修資料の要約を作らせたりする取り組みが報告されている([here-now.jp](https://here-now.jp/blog/2025-12-18_gws_gemini_ai/))。自社資料をベースにした生成であるため、内容の信頼性を保ちながら教育の標準化につなげやすいという特徴がある。

### プロンプト例1: 巡回パトロール報告書のドラフト作成

現場での音声メモ・箇条書きメモを、報告書の体裁に整形させる使い方。ChatGPTのGPTsやカスタムプロジェクト機能を使えば、フォーマットを固定した専用アシスタントとして繰り返し利用できる([menext.jp](https://menext.jp/recipes/automated-safety-patrol-reporting)を参考に警備向けへ改変)。

```
あなたは警備会社の巡回報告書作成を支援するアシスタントです。
以下の箇条書きメモ(現場の音声入力を文字起こししたもの)をもとに、
社内フォーマットに沿った巡回報告書を作成してください。

# 出力フォーマット
- 巡回日時:
- 巡回担当:
- 巡回ルート:
- 異常の有無: (あり/なし)
- 発見事項の詳細:
- 対応内容:
- 引き継ぎ事項:

# 現場メモ
[音声入力の文字起こしテキストを貼り付け]

※事実と異なる推測は書き加えず、メモにない情報は「記載なし」としてください。
```

出力後は必ず巡回担当者本人が内容を確認し、時刻・場所・固有名詞などの事実関係を照合してから正式な報告書として提出する。

### プロンプト例2: シフト表のたたき台作成

```
以下の条件をもとに、来月のシフト表のたたき台を作成してください。

# 前提条件
- 対象拠点: [拠点名]
- 勤務体系: 日勤(8:00-17:00)/夜勤(20:00-翌8:00)
- 必要人数: 日勤2名、夜勤1名(毎日)
- スタッフ一覧と希望・制約:
  [氏名・希望休・夜勤可否などを記載]
- 労働基準法上、連続勤務は最大[  ]日までとする

# 出力してほしいもの
- 1ヶ月分の日別シフト表(表形式)
- 希望が満たせなかった箇所への注記
```

生成された案はあくまで「たたき台」であり、法定労働時間・36協定の範囲内かの最終確認は必ず人事担当者が行う。

### プロンプト例3: 新人向け研修資料の要約作成

```
以下は当社の「不審者対応マニュアル」の抜粋です。
新人警備員向けに、覚えるべきポイントを5項目以内に要約し、
現場でとっさに思い出せるようなチェックリスト形式にしてください。
専門用語には一言の補足説明を付けてください。

[マニュアルの抜粋を貼り付け]
```

要約後は、必ず教育担当者がマニュアルの原本と照合し、抜け・誤りがないかを確認する。

### 導入コストの目安

警備ロボットは数百万円〜1,500万円規模の投資、あるいは月額十数万円〜のリース契約が一般的で(ALSOK Reborg-Xは購入約150万円/月額リース約25万円という価格帯で発売された実績がある、[ウレぴあ総研](https://ure.pia.co.jp/articles/-/32564))、中堅・中小の警備会社にはハードルが高い。一方、ChatGPTやGeminiといった汎用生成AIを使った報告書作成・シフト作成の効率化は、月額数千円のプランからでも着手でき、投資対効果を確認しながら段階的に広げやすい。

## 注意点・よくある誤解

- **生成AIは「実力行使」や「最終判断」を代替しない**: 識別系AIやロボットが検知・通報を担っても、不審者への声かけ・拘束・緊急対応といった実際の対処は法律上も実務上も人の警備員が担う。AI・ロボットはあくまで「気づく」役割であり、「対処する」役割ではないという線引きを社内で明確にしておく。
- **監視カメラ映像・AI検知データはプライバシー・個人情報保護法の対象になりうる**: 映像から個人が識別できる場合、その映像は個人情報として扱われる。撮影範囲への掲示、保存期間・閲覧権限・削除ルールの明文化、クラウド保管先の暗号化方式の確認など、「プライバシー・バイ・デザイン」を意識した運用が必要になる([アイスマイリー](https://aismiley.co.jp/ai_news/examples-of-ai-introduced-in-the-crime-prevention-security-industry/))。詳細は[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md)も参照。
- **機械警備業務管理者などの法定資格・体制は、AI導入後も要件が残る**: 2024年の施行規則改正で拠点間の兼務要件は緩和されたが、資格者の配置義務そのものがなくなったわけではない。AI・ロボットの導入と警備業法上の体制整備は別問題として管理する。
- **生成AIが作った報告書・シフト表はハルシネーション(もっともらしい誤り)を含みうる**: 現場になかった情報を補完してしまうことがあるため、時刻・場所・固有名詞・法定労働時間などの事実関係は必ず人が照合してから確定させる。
- **高額な警備ロボット導入だけが「AI活用」ではない**: 大手が数百万円規模のロボットを導入する一方、中小の警備会社でも汎用生成AIによる報告書作成・研修資料作成の効率化は低コストで始められる。自社の規模に合った入り口を選ぶことが重要。

## 最初の一歩

自社の巡回報告書のフォーマットを1つ用意し、ChatGPTやGeminiに音声入力またはメモの文字起こしを渡して、報告書のドラフトを作らせてみる。出力内容を担当者が事実確認する運用まで含めて、まず1件試すことから始める。
