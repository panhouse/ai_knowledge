# 自動車業界における生成AI活用事例

## これは何か

自動車業界は「設計・生産」だけでなく、車を売る・使う・直すという顧客接点の
すべてに生成AIが入り込み始めている業種である。本ページは、そのうち
**ディーラーの販売・接客、アフターサービス・整備、車載AIアシスタント、
マーケティング・スペックシート作成**という、自動車「業界」ならではの
生成AI活用事例を整理する事例カタログである。

なお、車両そのものの設計・製造工程での生成AI活用(トヨタ・リサーチ・
インスティテュートの生成AI車両設計ツールなど)は
[製造業における生成AI活用事例](manufacturing-ai-use-cases.md)で扱っており、
本ページでは重複を避けて詳しく触れない。本ページは「工場の外」、
すなわち販売店・顧客・運転席で起きている活用に焦点を当てる。

## 業務工程別の活用マップ

| 工程 | 課題 | AI・生成AIの役割 | 代表事例(本ページ内) |
|---|---|---|---|
| 販売・接客(ディーラー) | 商談内容が営業担当者の記憶・メモに依存し、要望の聞き漏らしや「言った言わない」が発生 | 商談の音声をリアルタイムで文字起こし・要約し、顧客の要望をデータ化 | トヨタ系列ディーラー(青森トヨタ自動車ほか)のAI商談支援ツール |
| 販売・接客(問い合わせ対応) | 営業時間外や繁忙期に問い合わせ対応が追いつかず、機会損失が発生 | AIエージェントが24時間365日、車種案内から試乗予約までを自動応対 | ホンダ「My Honda」AIエージェント |
| アフターサービス・整備 | 車種・年式ごとに異なる整備手順や技術サービスブレティン(TSB、メーカーが出す修理上の注意喚起文書)を探すのに時間がかかる | 自然言語の質問でOEM整備データ・TSBを横断検索し、診断の当たりをつける | Mastertech.aiのAI整備支援プラットフォーム |
| 車載AIアシスタント | 従来のカーナビ音声操作は決まった言い回しでしか反応せず、複雑な質問に答えられない | 車載音声アシスタントに大規模言語モデル(LLM)を組み込み、自由な言い回しでの対話・知識質問への回答を実現 | Mercedes-Benz「MBUX」×ChatGPT、BMWインテリジェント・パーソナル・アシスタント×Amazon Alexa+、GM×Google Gemini、Rivian「Hey Rivian」 |
| マーケティング・スペックシート作成 | 中古車販売店が扱う掲載車両数が多く、1台ずつ魅力的な紹介文を書く時間が取れない | アクセスデータや車両情報をもとに、掲載効果の高い車種紹介コメントを自動生成 | プロトコーポレーション「MOTOR GATE AI」(グーネット) |

**読み方のコツ**: 「販売・接客」「アフターサービス」は**人手不足と対応スピード**が
課題の中心であり、生成AIは人の代わりに一次対応・一次検索を担う形で導入されている。
一方「車載AIアシスタント」は**インターフェースの高度化**が主眼で、
自動車メーカーは自社でLLMを一から開発するのではなく、OpenAI(Microsoft Azure経由)・
Google・Amazonといった既存の生成AI基盤に接続する形で提供している点が共通する。

## 代表事例の詳細

### 1. 販売・接客: トヨタ系列ディーラーのAI商談支援ツール

- **企業**: 青森トヨタ自動車株式会社などトヨタ系列の販売会社
- **課題**: 新車商談の内容は営業担当者のメモや記憶に依存しており、
  顧客の細かな要望が聞き漏れたり、「言った・言わない」のトラブルが起きたりしていた。
  また商談内容が個人の頭の中にとどまり、上司による接客状況の把握や、
  会社としての顧客ニーズの分析に活用しにくかった
- **導入したAI・仕組み**: 商談中の会話を音声認識でリアルタイムに記録し、
  生成AIが内容を要約してデータ化するAI商談支援ツール。2026年1月に青森トヨタ自動車が
  導入を発表したほか、トヨタ系列の複数の販売会社で同様の取り組みが進んでいる
- **効果・示唆**: 要望の聞き漏らし防止やトラブル防止に加え、記録作業の自動化により
  接客・手続きにかかる時間を短縮。蓄積した商談データは接客品質向上の分析だけでなく、
  将来的には顧客の潜在ニーズを商品開発に活かす狙いもあるとされる
- **自社への応用ヒント**: 「営業トークをAIに置き換える」のではなく、
  「営業担当者の後ろでAIが記録・要約する」形にした点がポイント。
  対人接客の価値を残しつつ、記録という定型作業だけをAIに渡すことで
  導入への抵抗感を下げられる。導入時は顧客への録音・AI利用の告知と同意取得を
  忘れないようにしたい

### 2. 販売・接客: ホンダ「My Honda」AIエージェント

- **企業**: 本田技研工業(ホンダセールスオペレーションジャパン)
- **課題**: ディーラーの営業時間外は顧客からの問い合わせに即応できず、
  試乗予約や車種相談の機会を逃していた
- **導入したAI・仕組み**: モバイルアプリ「My Honda」にAIエージェントを組み込み、
  24時間365日、顧客データに基づいた車種・オプションの提案から試乗予約の受付までを
  対話形式で完結できるようにした。2026年6月に発表
- **効果・示唆**: 営業時間に縛られず顧客対応を継続できるようになり、
  問い合わせから試乗予約までの導線を短縮した。ホンダファイナンスでも
  以前からチャットボットによる問い合わせ対応を導入しており、
  ホンダグループ全体で顧客接点のAI化が段階的に進んでいる
- **自社への応用ヒント**: 「AIチャットボットで質問に答える」だけでなく、
  「試乗予約という具体的な行動(コンバージョン)まで一気通貫でつなげる」設計に
  すると、問い合わせ対応の効率化だけでなく営業機会の創出にも直結しやすい

### 3. アフターサービス・整備: Mastertech.aiのAI整備支援プラットフォーム

- **企業**: Mastertech.ai(米国コロラド州、ASE認定整備士出身者らが2023年設立)
- **課題**: 整備士が車種・年式ごとの整備手順やTSB(技術サービスブレティン、
  メーカーが「この症状にはこの対処」と現場向けに出す注意喚起文書)を探すには、
  OBD-II診断機でエラーコードを読み取ったあと、紙・PDFのサービスマニュアルや
  社内ナレッジを手作業で探す必要があり、原因特定に時間がかかっていた。
  TSBの中には文字情報が画像として保存され、通常の検索では引っかからないものも多い
- **導入したAI・仕組み**: 自然言語の質問でOEM(自動車メーカー)純正の整備データ・
  部品図・配線図・TSB・整備士向けの労務時間ガイドを横断検索できるAIプラットフォーム。
  画像内のTSB本文もOCR(文字認識)で抽出し検索対象に含めることで、
  従来検索から漏れていた情報も拾えるようにしている
- **効果・示唆**: 業界全体では、2025年初頭に約25%だった整備工場のAI活用率が
  2026年末までに60%超に達すると見込まれており、AIによる故障診断の時間短縮効果は
  最大90%程度との報告もある
- **自社への応用ヒント**: 整備現場のAI活用は「異常を検知する」ことより
  「過去の紙・PDFの知見を自然言語で検索できるようにする」ことに価値がある。
  自社に眠っている整備マニュアル・修理記録が電子化されているかをまず確認するとよい

### 4. 車載AIアシスタント: Mercedes-Benz「MBUX」× ChatGPT

- **企業**: メルセデス・ベンツ(Microsoft Azure OpenAI Serviceを活用)
- **課題**: 従来の車載音声アシスタントは「エアコンを22度にして」のような
  定型コマンドにしか反応できず、複雑な質問や雑談的なやり取りができなかった
- **導入したAI・仕組み**: 車載インフォテインメントシステム「MBUX」の音声アシスタントに
  Azure OpenAI Service経由でChatGPTを統合。知識を要する質問にはMicrosoft Bingで検索した
  最新情報をもとにChatGPTが自然な文章で回答する。会話履歴は最大1時間保持され、
  文脈をふまえた聞き返しにも対応する。ドイツ語・英語(英国・米国)で提供され、
  対象車種は300万台規模に拡大した。2026年に投入予定の次世代インターフェースでは、
  利用者の習慣や気分を踏まえた提案機能も予告されている
- **効果・示唆**: 「ナビ操作の音声認識」から「知識質問に答えられる対話エージェント」への
  質的な転換を、自社でLLMを開発せずクラウド大手のAI基盤を組み込む形で実現した点が特徴
- **自社への応用ヒント**: 自動車メーカー各社は車載AIを自前開発ではなく、
  OpenAI(Microsoft経由)・Google・Amazonの生成AI基盤を組み込む方式で提供している
  (BMWインテリジェント・パーソナル・アシスタントはAmazon Alexa+を採用し2026年後半に
  BMW iX3から展開、GMは2026年からGoogle Geminiを採用、新興EVメーカーRivianも
  「Hey Rivian」で音声アシスタントを展開しGoogle Geminiとの連携をテストしている)。
  自社に生成AIの研究開発体制がない場合でも、既存の生成AI基盤への接続という形で
  顧客接点を高度化できることを示す事例群である

## 実務での使い方

### 中古車・新車の紹介文(スペックシート・広告文)をAIで下書きする

中古車販売店が扱う掲載車両数は多く、1台ずつ紹介文を書く時間が取れないという
課題は業界共通である。実際にプロトコーポレーションが運営する中古車情報サイト
「グーネット」向けの経営支援システムでは、AIがアクセスデータをもとに
車種紹介コメントを自動生成する機能「MOTOR GATE AI」を提供しており、
掲載車両の見積依頼・電話問い合わせ等の反応が約180%向上したと報告されている
(2020年提供開始。生成AI/LLMが普及する前からの取り組みだが、
「掲載文をAIに作らせる」発想自体は現在のChatGPT・Geminiでもそのまま応用できる)。

現在ChatGPTやGeminiで同様のことを行う場合のプロンプト例:

```
あなたは中古車販売店の広告担当です。以下の車両情報から、
グーネット・カーセンサーなどの中古車ポータルサイトに掲載する
紹介文を300字程度で作成してください。

## 車両情報
- 車種・グレード: (例: トヨタ ハリアー Z 4WD)
- 年式・走行距離: (例: 2023年式・8,000km)
- 装備・特長: (例: 純正ナビ、パノラミックビュー、ワンオーナー)
- 価格: (例: 328万円)

## 条件
- ターゲット: (例: 30〜40代のファミリー層)
- 強調したいポイント: (例: 低走行・ワンオーナーの安心感)
- 誇張表現・断定的な効果を避け、事実にもとづいて書くこと
- 最後に「お問い合わせ・ご来店をお待ちしております」等の一言を添える
```

### ツール横断の対応付け

| 用途 | 主に使われるツール・基盤 | 備考 |
|---|---|---|
| 商談の文字起こし・要約 | ディーラー独自のAI商談支援ツール、Web会議ツールのAI議事録機能 | 汎用チャットAIの音声入力機能でも代替検討は可能だが、通話録音には別途アプリ・同意取得が必要 |
| 車種紹介文・広告文の下書き | ChatGPT、Gemini、Copilot等の汎用チャットAI | プロンプトに車両情報・ターゲット層を具体的に書き込むと精度が上がる |
| 整備マニュアル・TSB検索 | Mastertech.aiのような整備特化AI、社内RAG(検索拡張生成)システム | 汎用チャットAIに直接聞くと存在しない手順を答える(ハルシネーション)リスクが高く、自社データに接続した検索の仕組みが前提になる |
| 車載音声アシスタント | 各メーカー独自のアシスタント(MBUX、BMW IPA等)+ ChatGPT/Gemini/Alexa+基盤 | 一般ユーザーが個別に設定できるものではなく、購入した車種・年式・地域で対応状況が異なる |

## 注意点・よくある誤解

- **AI商談記録は「録音・AI利用への同意」が前提**: 顧客との会話を生成AIが要約する
  仕組みは、個人情報を含む音声を録音・AI処理する行為でもある。
  導入時は顧客への告知・同意取得のプロセスを事前に整えておく必要がある
- **AIチャットボットの価格・キャンペーン回答は要検証**: 車種案内や試乗予約は
  AIチャットボットに任せやすい一方、値引き額やキャンペーン条件をAIが誤って
  案内すると、顧客との間で「言った通りにしてほしい」というトラブルに発展しうる。
  価格・契約条件に関わる回答は人による確認や、回答自体を人にエスカレーションする
  設計にしておくと安全である
- **整備・診断AIの提案はあくまで「当たりをつける」ためのもの**: TSB検索や
  故障診断支援AIは、過去の類似事例から可能性の高い原因を提示するツールであり、
  最終的な修理判断・作業はメーカーの正規手順に沿って整備士が行う必要がある。
  AIの提案をそのまま作業指示として使うと、誤診断による事故・クレームの
  責任の所在が曖昧になりかねない
- **車載AIアシスタントは運転中の操作に配慮した設計になっているか確認する**:
  対話が長く複雑になるほど運転への注意がそがれるリスクがあるため、
  各社は「手放しで完結できる操作」に留めるなど安全設計に配慮しているが、
  利用者側も長い雑談的なやり取りは停車中に行うなどの使い分けが望ましい
- **「AI」と「生成AI」を混同しない**: 中古車の車種画像判別のような分類系AIと、
  文章を作る生成AI(LLM)は技術的に別物である。同じ「AI活用事例」として
  紹介されていても、何を自動化しているのかを区別して評価するとよい

## 最初の一歩

自社(ディーラー・整備工場)で「営業担当者の記憶」「紙のマニュアル」に
とどまっている情報を1つ選び、それを商談要約AIや整備マニュアル検索AIのような形で
デジタル化・検索可能にできないかを検討することから始めるとよい。
