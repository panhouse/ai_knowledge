# アニメ・映像制作業界における生成AI活用事例

## これは何か

アニメ・映像制作業界は、[メディア・広告・エンタメにおける生成AI活用事例](media-entertainment-ai-use-cases.md)の中でも特に「効率化への切実なニーズ」と「創作の核心・雇用への強い危機感」がぶつかり合う特殊な業種である。原画と原画の間を埋める中割り(動画)や彩色は人手不足が慢性化した労働集約型の工程で自動化の恩恵が大きい一方、まさにその中割り・動画は新人アニメーターの登竜門であり、声優の声はキャラクターそのものであるため、「効率化ツール」の一言では済まない反発が起きやすい。本ページは、Part8で扱う動画生成AIツール自体の使い方や、[ゲーム業界における生成AI活用事例](game-industry-ai-use-cases.md)とは別に、日本のアニメスタジオ・制作委員会・配信事業者が実際にどこまで生成AIを導入し、どこで公式に線引きをしているかを実名事例で整理する事例カタログである。

## 仕組み・背景

アニメ制作は大まかに「企画・脚本→絵コンテ→原画(キーとなる動きを描く)→動画/中割り(原画の間を補完する)→彩色→背景美術→撮影(合成)→編集→アフレコ・音響→納品」という工程を経る。生成AIが実際に手を伸ばしている工程は主に次の3つに集約される。

1. **中割り(インビトウィーン)の自動生成**: 原画と原画の間の動きをAIが補完し、動画工程の作業量を圧縮する。NTTドコモの社内起業制度から2025年8月にスピンアウトしたスタートアップ「CrestLab」の中割りAI「ANICRA(アニクラ)」は、複数のアニメスタジオでの実証実験で対象工程の作業時間を約7割削減したと報告されている。利用料金は企業ごとの個別交渉制で、公開の定価は設定されていない([日本経済新聞](https://www.nikkei.com/article/DGXZQOUC0135G0R00C25A8000000/)、[NTTドコモ プレスリリース](https://www.docomo.ne.jp/info/news_release/2025/08/01_00.html))。
2. **背景美術の自動生成**: 東映アニメーションとPreferred Networks(PFN)は2021年3月、風景写真をアニメ調に変換する背景美術支援ツール「Scenify」を共同開発したと発表した。実験映像『URVAN』では全背景美術の約2/3にScenifyを活用し、画像変換・セグメンテーション(領域分割)技術で下地を自動生成することで、美術スタッフの前処理時間を従来の約1/6に短縮したとしている([Preferred Networks](https://www.preferred.jp/ja/news/pr20210312)、[ASCII](https://ascii.jp/elem/000/004/047/4047371/))。両社の協業はその後も続いており、2025年4月30日にはPFNの50億円規模の第三者割当増資に東映アニメーション・講談社・TBSが揃って出資し、東映アニメーションは合弁会社設立の検討にも言及している([東映アニメーション プレスリリース](https://corp.toei-anim.co.jp/ja/press/press3820827490487697471.html))。
3. **音声合成による多言語吹替**: [メディア・広告・エンタメにおける生成AI活用事例](media-entertainment-ai-use-cases.md)で扱ったTBS×ElevenLabsやTitan Intelligence「mimidub」のような放送局主導の事例に加え、配信プラットフォーム側でもAI吹替の実験が進んでいる。ただし後述の通り、声優本人の声を使う吹替という工程は業界内の反発が最も強く出る領域でもある。

このほか、絵コンテのラフ案生成・制作進行(スケジュール管理)や社内問い合わせ対応のDX・古い作品のアップスケール(高解像度化)にも生成AI・AI技術の活用が広がっているが、いずれも「創作の中核ではない周辺業務」として位置づけられていることが共通点になっている。

## 使いどころ・使い分け

| 工程 | 生成AIの活用状況(2026年9月時点) | 代表例・理由 |
|---|---|---|
| 中割り・動画(原画間の補完) | 実証実験〜一部実用化 | ANICRA(CrestLab)で複数スタジオが実証、工数7割減の報告。ただし新人アニメーターの登竜門である工程のため、置き換え方には慎重な声もある |
| 背景美術の下地生成 | 実用段階(公式協業として継続中) | 東映アニメーション×PFN「Scenify」。最終的な色調・ディテール調整は美術スタッフが担当する設計 |
| 彩色(仕上げ) | 実証・部分導入段階 | 線画への自動着色ツールは複数存在するが、キャラクターごとの色指定・陰影表現の精度確保が課題として残る |
| 絵コンテ・ストーリーボードのラフ案 | 実証段階・個人/小規模開発が中心 | 脚本からシーン構成案を自動生成するツールが登場しているが、大手スタジオの公式導入事例は限定的 |
| 制作進行・社内DX(スケジュール管理、問い合わせ対応) | 実用段階 | トムス・エンタテインメントがAllganize Japan「Alli LLM App Market」を導入し、社内問い合わせ・議事録作成・素材の類似画像検索を効率化(2025年4月) |
| 音声合成によるセリフ・吹替 | 公式には慎重・一部で炎上 | Amazon Prime Videoが2025年11月にBanana Fish等へAI吹替(「English [AI beta]」)を追加したが批判を受け12月1日までに撤回。音声業界3団体はアニメ・洋画吹替でのAI音声不使用を要求(2024年11月) |
| 字幕・ローカライズ翻訳 | 公式方針は「使わない」、実態は下請け経由で混入 | Crunchyrollは方針としてAI不使用を掲げるが、2025年7月に第三者ベンダー経由のChatGPT生成字幕(ドイツ語版)が発覚し謝罪 |
| 旧作のアップスケール・修復 | 個人・非公式ツールが中心、公式スタジオの採用例は未確認 | Waifu2x・Aiarty Video Enhancer等の汎用AI高画質化ツールがファン・動画配信の周辺で広く使われているが、大手スタジオが自社の4Kリマスターで特定AIツールを採用したと公表した一次情報は確認できていない |
| キャラクターデザイン・キービジュアルなど最終成果物 | 公式には控える方向 | 著作権・作家性への懸念から、完成品への直接適用は多くのスタジオが慎重姿勢 |

**読み方のコツ**: 「工数がかかるが創造性への要求度が相対的に低い工程」(背景の下地、社内DX、制作進行)ほど公式導入が進み、「声・キャラクター・絵柄そのもの」に直結する工程(声優の声、キービジュアル)ほど公式には慎重、または導入後に撤回されている。この線引きを理解せずに「アニメ業界はAIに積極的/消極的」と一括りにすると実態を見誤る。

## 実務での使い方

### プロンプト例: 絵コンテ・ラフ案作成の下書き支援

絵コンテそのものをAIに丸投げするのではなく、「箇条書きの構成案」を作らせて演出家・絵コンテマンが取捨選択する使い方が実務的な落としどころになる。

```
以下のシーン設定をもとに、絵コンテのカット割り案を8カット、
簡潔な箇条書きで提案してください。

## シーン設定
[舞台・時間帯・登場キャラクターと感情の動きを記載]

## 出力条件
- 各カットは「カット番号／画角(俯瞰・寄り等)／カメラの動き／画面内の要素」の順で1〜2行
- 尺は合計約[◯]秒を想定
- 演出上の見せ場となるカットには★を付ける
```

出力はあくまで演出家・絵コンテマンが選ぶための「叩き台」であり、最終的なカット割り・間の取り方は人が決める前提で使う。

### 導入前チェックリスト: 外部AIツール・ベンダーを評価する際の確認項目

Crunchyrollの字幕騒動のように、下請けベンダーが無断でAIツールを使っていたケースは「発注側が気づかないうちにAIが混入する」リスクを示している。外部ツール・ベンダーを検討する際は次を確認する。

- 生成物にAIをどの工程で使うか(下書きか、最終成果物か)を契約書・仕様書に明記しているか
- 学習データの出所(自社IP以外の著作物を無断学習していないか)を開示できるか
- 声優の声・キャラクターデザインなど「本人性」に関わる素材を扱う場合、本人・権利者の同意取得プロセスがあるか
- AIが生成した部分をどの範囲まで人が確認・修正するかの体制(最終承認者)が明確か
- 発注先(特に翻訳・字幕のような多段階の下請け構造がある工程)が独自にAIツールを使っていないかを契約・成果物レビューで確認できるか

### ツール横断の対応表

| 用途 | 提供企業・ツール例 | 導入状況 |
|---|---|---|
| 中割り自動生成 | CrestLab「ANICRA」 | 複数スタジオで実証、事業化(2025年8月〜) |
| 背景美術の下地生成 | Preferred Networks「Scenify」(東映アニメーションと共同開発) | 実用段階(2021年〜継続協業) |
| 汎用の動画生成AI(CM・映像素材の下書き) | Runway、Google Veo、Kling AI等 | [メディア・広告・エンタメにおける生成AI活用事例](media-entertainment-ai-use-cases.md)参照 |

## 注意点・よくある誤解

- **「アニメ業界はAIに反対」と一括りにしない**: NAFCA(日本アニメフィルム文化連盟)が2023年6〜7月に実施した調査(有効回答3,854件)では73.7%が生成AIの規制を求める一方、アニメ業界従事者は非従事者よりAI技術への期待も高いという結果が出ている。「AI利用禁止」と明記されたデータの無断学習については87.4%が規制すべきと回答しており、反発の中心は「AIそのもの」ではなく「無断学習・無断利用」に向いている([NAFCA](https://nafca.jp/survey01/)、[Branc](https://branc.jp/article/2023/09/13/738.html))。
- **声優の声は特に強い保護意識の対象**: 日本俳優連合・日本芸能マネージメント事業者協会・日本声優事業社協議会の音声業界3団体は2024年11月13日、(1)アニメ・洋画吹替で生成AI音声を使用しないこと、(2)声の学習・利用には本人の許諾を得ること、(3)AI生成物であることを明記すること、の3点を求める共同声明を発表した([日本俳優連合](https://www.nippairen.com/wp-content/uploads/2024/11/25d2c1a91dc0a1c23acc1f17ee068af4.pdf))。実際にAmazon Prime Videoは2025年11月、Banana Fish・No Game No Life Zero等にAI吹替(「English [AI beta]」)を追加したが、感情の乗らない棒読みとの批判が殺到し、12月1日までに撤回した。Crunchyroll社長も「AIを声優の演技や創作プロセスには使わない」と繰り返し表明している。
- **「公式の実証実験」と「下請け経由の無断混入」を混同しない**: 東映アニメーション×PFNのScenifyのように、権利者が主体的に契約・出資して進める協業と、Crunchyrollが2025年7月に発覚させたベンダー経由のChatGPT生成字幕(ドイツ語版に「ChatGPT said:」が誤って残っていた)のように、発注側の方針に反して下請けが無断でAIを使っていたケースは全く性質が異なる。後者は「AI活用」というより管理体制の不備であり、外部委託先の管理を強化する材料として扱うべき事例である。
- **著作権・学習データを巡る問題は継続中**: 2025年3月にOpenAIのGPT-4oで「ジブリ風」画像生成が世界的に流行した際は、既存作品の画風を無断で模倣しているとの批判が起き、宮崎駿監督のAI生成表現に対する過去の発言(「生命への冒涜」)が改めて注目を集めた。2025年10月31日には日本動画協会・出版社17社・日本漫画家協会など19団体が、権利者の事前同意なく学習・生成する運用は日本の著作権法の原則に反するとする共同声明を発表し(詳細は[メディア・広告・エンタメにおける生成AI活用事例](media-entertainment-ai-use-cases.md)を参照)、2026年5月27日にはCODA(コンテンツ海外流通促進機構、スタジオジブリ等が加盟)も、既存著作物と酷似する生成物が確認されているとしてAI事業者に権利保護を求める声明を発表している([CODA](https://coda-cj.jp/news/2770/)、[ITmedia](https://www.itmedia.co.jp/aiplus/article/2605/27/2000000026/))。
- **中割り自動化は「新人の仕事を奪う」議論と表裏一体**: 中割り・動画は伝統的に新人アニメーターが経験を積む入り口の工程であり、この工程の自動化は単純な効率化として歓迎されにくい面がある。JAniCA(日本アニメーター・演出協会)の「アニメーション制作者実態調査2023」ではアニメーターの平均年収は455.5万円(2019年調査から+15万円)と改善傾向にはあるが、依然として労働環境改善が課題とされる中での自動化論議であることを踏まえる必要がある([JAniCA](https://www.janica.jp/survey/survey2023_report.html)、[東洋経済](https://toyokeizai.net/articles/-/673453))。

## 最初の一歩

自社・自スタジオの業務のうち「制作の中核(絵柄・声・脚本の創造性)」ではない周辺工程を1つ選び(社内問い合わせ対応、素材の検索、絵コンテのラフ案出しなど)、上記の「導入前チェックリスト」を使って外部ベンダー・AIツールの学習データの出所と最終確認体制を確認したうえで試験導入することから始めるとよい。
