# 保育・幼児教育における生成AI活用事例

## これは何か

保育所・認定こども園・幼稚園といった保育・幼児教育の現場は、「保育士の慢性的な
人手不足」に加えて、午睡(お昼寝)・食事・排泄などの記録、連絡帳やおたよりの作成、
シフト作成といった事務作業に時間を取られ、子どもと向き合う時間が削られるという
課題を抱えている。一方でこうした記録・連絡業務は毎日同じフォーマットで発生する
定型業務でもあり、生成AIによる効率化の効果が出やすい領域である。

[教育における生成AI活用事例](education-ai-use-cases.md)が小中高・大学を対象に
「教材作成・個別指導・採点・入試事務」を扱うのに対し、本ページが対象とする
保育・幼児教育は0〜6歳の未就学児が中心で、成績評価や入試対策は存在せず、
**日々の生活記録(午睡・食事・排泄など)と保護者への連絡・報告**が業務の中心と
なる点で性格が異なる。また、自治体が保育所の入所選考(希望順位や兄弟の条件を
踏まえた入所振分)にAIを使う取り組みは[公共・自治体における生成AI活用事例](public-sector-ai-use-cases.md)で
扱う「行政側」の業務であり、本ページが扱う「保育施設側が保育士の日常業務を
支援するAI」とは主体・用途が異なるため区別して整理する。

本ページは、実在する保育ICT(情報通信技術)企業・保育施設の導入事例を業務領域別に
整理し、自園に応用する際の着眼点を示す事例カタログである。

## 業務領域別の活用マップ

| 業務領域 | 課題 | AI・生成AIの役割 | 代表事例(本ページ内) |
|---|---|---|---|
| 保育記録の要約・児童票/要録作成 | 日々の記録は蓄積されるが、年度末の児童票・要録(就学先へ引き継ぐ法定の育ちの記録)作成に時間がかかる | 日々の保育記録(保育ドキュメンテーション)をAIが解析・要約し、育ちの振り返り文のたたき台を生成 | CoDMON(コドモン)×ベネッセ「こどもストーリープロジェクト」 |
| 連絡帳・おたよりの作成支援 | 個々の子どもの様子を毎日文章にする負担、園だより・クラスだよりの執筆に時間がかかる | 箇条書きのメモを自然な文章に整形、誤字脱字チェック、多言語翻訳 | ルクミー(ユニファ)「保育AI」・AIアシスト「たよれるくん」、hinary(エイチテクノロジーズ) |
| 保育計画案・指導案の下書き | 週案・月案・年間指導計画の作成が保育士個人の力量・時間に依存 | 質問に答える・箇条書きを入力するだけで週案・月案のたたき台を自動生成 | こぴぺたくん(ちょきぺたファクトリー)、hinary「保育AIエージェント」 |
| シフト作成 | 有資格者の配置基準・希望シフト・パート比率を踏まえた勤務表作成が属人化し時間がかかる | 配置基準・希望を踏まえて勤務表を自動生成し、担当者の偏りによる不公平感も軽減 | しふとっと(PROTECA IT Lab) |
| 写真管理・確認業務 | 日々大量に撮影される園児の写真の仕分け・配信作業に時間がかかる | 画像解析AIが写っている子どもを判別し、配信用アルバムの仕分けを補助 | ルクミー「ルクミーフォトAI」 |
| 現場発の活用検討・自治体実証 | 現場が個別にAIを試すだけでは知見が共有されず、ガイドライン整備も追いつかない | 現場の保育士がAIと一緒に活用法を検討する場や、自治体・国による実証事業で効果・課題を整理 | 信州子育てみらいネット「みらいくAIラボ」、こども家庭庁の生成AI利用実証事業 |

**読み方のコツ**: 「保育記録・連絡帳・指導案」は保育士本人が毎日書く**文章生成**の
領域で、生成AI(LLM)がそのまま効果を発揮しやすい。一方「シフト作成」は
配置基準・希望条件を満たす組み合わせを探す**最適化問題**の性格が強く、
必ずしも生成AI(LLM)ではなくルールベースの自動化アルゴリズムが中心になっている
点は、[物流・運輸の配送最適化](logistics-transportation-ai-use-cases.md)と同様の
切り分けが当てはまる。

## 使いどころ・使い分け

| 判断基準 | 考え方 |
|---|---|
| 保護者に直接届く文章(連絡帳・おたより) | AIはドラフト作成まで、送信前に保育士が内容(誤情報・園児名の取り違えなど)を必ず確認する |
| 児童票・要録など就学先に引き継ぐ法定書類 | AIは要約・たたき台作成の補助に留め、最終的な記載内容の責任は保育士・園が負う |
| 午睡チェック・写真の仕分けなどセンサー/画像系AI | 見守りの補助であり、目視確認や紙・アプリでの実記録の代替にはしない |
| シフト作成 | AIが機械的に作成することで「不公平では」という人間関係の摩擦を減らせる半面、個々の事情(体調・家庭の都合)は最終的に人が調整する |
| 汎用チャットAI(ChatGPT等)で自作する vs 保育特化AI・保育ICT大手のAI機能を使う | 小規模園・まず試したい場合は汎用チャットAI+定型プロンプトから、記録データとの連携や園の理念の学習まで求めるなら保育特化AI(hinary等)や導入済みICTシステムのAI機能を検討する |

## 実務での使い方

### 1. 保育記録の要約・児童票作成支援: CoDMON(コドモン)×ベネッセ「こどもストーリープロジェクト」

- **企業**: 株式会社コドモン(保育・教育施設向けICTシステム「CoDMON」提供、業界シェアNo.1を謳う)、株式会社ベネッセスタイルケア
- **課題**: 保育士は日々の保育の様子を「保育ドキュメンテーション」として記録しているが、年度末に作成する児童票・要録(就学先へ子どもの育ちを引き継ぐ書類)は、蓄積された記録を読み返して要約する作業に時間がかかっていた
- **導入したAI・仕組み**: 2024年夏から全国の協力施設で実証実験を重ね、2025年4月に「こどもストーリープロジェクト」として本格始動。CoDMONの「保育ドキュメンテーション」に蓄積された一定期間の記録をAIが解析・要約し、児童票・要録にそのまま使える振り返り文章の下書きを作成する「こどもストーリー」機能を開発。500施設限定の「こどもストーリーおためし版(無料)」の利用申込も開始した
- **効果・位置づけ**: 保育者が「子どもについて考えること」に時間を割けるよう、振り返り文章の「作業時間」を圧縮することが狙い。日々の記録や保育者の想いをそのまま残しつつ、要約作業だけをAIに任せる設計になっている
- **自園への応用ヒント**: 児童票・要録のような法定書類にAIを使う場合、いきなり全文をAI任せにするのではなく、まず「その期間の記録を要約したたたき台」を作らせ、保育士が事実確認・加筆修正する運用から始めるのが現実的である

### 2. 連絡帳・おたよりの作成支援: ルクミー(ユニファ)「保育AI」/ルクミーAIアシスト「たよれるくん」

- **企業**: ユニファ株式会社(保育ICTサービス「ルクミー」を導入数2万件以上・約70自治体に提供)
- **課題**: 連絡帳やおたよりの作成は、箇条書きのメモを自然な文章に整えたり、誤字脱字を確認したりする手間がかかるうえ、保育中は入力作業自体が行いにくい。外国人児童・保護者の増加による多言語対応の負担も増えていた
- **導入したAI・仕組み**: ChatGPTと連携した生成AI機能「ルクミーAIアシスト(たよれるくん)」が、箇条書きで入力した子どもの様子を自然な文章に変換し、誤字脱字チェックやおたよりの多言語翻訳までを支援する。あわせて画像解析AIの「ルクミーフォトAI」が、配信用アルバムに写っている子どもの仕分けなど写真確認業務を補助する
- **実証実験と効果**: 岩手県北上市・神奈川県横須賀市・東京都狛江市の3自治体と2024年10月〜2025年2月にかけて、保育施設での生成AI実証実験を実施。ルクミーフォトAIによる業務時間・精度の変化と、AIアシストによる文書作成時間・生成文書の精度を検証した結果、利用した保育者の64%が「業務負担が軽減した/やや軽減した」、68%が「満足度が高い/やや高い」と回答した
- **自園への応用ヒント**: 「文章化」と「写真確認」という性質の異なる2つの負担を、それぞれ別のAI機能(文章生成AI・画像解析AI)で個別に解決している点が参考になる。導入時は自園の負担が大きい業務(文章作成か、写真整理か)を切り分けて優先順位をつけるとよい

### 3. 保育特化の生成AIチャット・エージェント: hinary(ヒナリー)

- **企業**: エイチテクノロジーズ株式会社
- **課題**: 汎用チャットAIは便利だが、保育に関する専門知識や園ごとの理念・方針、関連法令・ガイドラインを踏まえた回答にはならず、連絡帳・おたよりの文面が保護者に響かない/ワンパターンになりがちという声があった
- **導入したAI・仕組み**: 保育に特化した生成AI「hinary」を2025年8月1日に正式リリース。保育士試験に合格する水準の保育専門知識を学習させたうえで、園ごとの理念・ルールも反映できるようにした「保育AIチャット」と、指導計画・おたより・連絡帳・要録などの書類作成を自動化する「保育AIエージェント」の2本柱で構成される。2026年には東京都の実証事業「PoC Ground Tokyo」に採択され、保育AIエージェントの開発・検証を進めている
- **周辺の取り組み**: 提供元のエイチテクノロジーズは、おたより・指導計画・遊びのアイデアなど保育業務11カテゴリーを網羅した「保育現場で使える生成AIプロンプト集100選」を無料公開しており、hinaryのような専用サービスを使わず汎用チャットAIで試したい園でも活用できる
- **自園への応用ヒント**: 保育特化型のサービスは「園の理念・方針を学習させられる」点が汎用チャットAIとの違いになる。まずは無料のプロンプト集で自園に合うプロンプトの型を試し、業務量が多ければ専用AIの導入を検討する、という段階的な進め方ができる

### 4. シフト作成の自動化: 「しふとっと」

- **企業**: 株式会社PROTECA IT Lab(保育士自身が開発に関わったサービス)
- **課題**: 保育士のシフトは有資格者の配置基準・個々の勤務希望・パート/フルタイム比率など考慮事項が多く、担当者が手作業で組むと時間がかかるうえ「配置に偏りがあるのでは」という不公平感にもつながりやすい
- **導入したAI・仕組み**: 2023年4月にリリース。職員はスマホから勤務希望を送信し、園児数に応じた必要配置数をシステムが自動で調整したうえで、ボタン一つでシフトを自動作成する。提供元によれば、シフト作成のボタン操作から約10秒で作成が完了し、シフト業務全体の作業量を60%程度削減できるとしている
- **効果・位置づけ**: 機械が機械的な基準に基づいて作成するため、「特定の人に有利/不利なシフトを組んでいるのでは」という人間関係の摩擦を減らせる点も導入効果として挙げられている
- **自園への応用ヒント**: シフト作成は生成AI(文章生成)というより、配置基準を満たす組み合わせを探す最適化・自動化の領域である。「AIで文章を作る」以外にも、こうしたルールベースの自動化ツールで削減できる事務作業がないか棚卸しする価値がある

### 5. 現場発の活用検討・自治体/国による実証: 信州子育てみらいネット「みらいくAIラボ」とこども家庭庁の生成AI利用実証事業

- **団体**: 一般社団法人信州子育てみらいネット(長野県内で保育施設9施設を運営)、こども家庭庁
- **課題**: 現場の保育士が個別にAIを試しても知見が園内・法人内にとどまり、業界全体に広がりにくい。国としても、保育・子育て分野で生成AIを使う際の効果・課題・注意点を整理したガイドラインが必要とされていた
- **取り組み**: 信州子育てみらいネットは、連絡帳や引き継ぎ資料など日々作成する書類の作成支援を中心に、現場の保育士が生成AIと一緒に活用法を考えるオンラインの場「みらいくAIラボ」を立ち上げた。削減できた時間を子ども・保護者と向き合う時間に充てることを目的としている。国レベルでは、こども家庭庁が2024年度に「こども・子育て分野における生成AI利用実証団体」を公募し、地方公共団体や保育施設等を対象に生成AI活用の効果・課題を整理する実証事業を実施。2025年7月には実証結果を踏まえた「生成AIの導入・活用に向けた実践ハンドブック」を公開している
- **自園への応用ヒント**: 「園内でAIの使い方を試す・共有する場」を小さくでも作ることが、個人任せの利用を組織的な知見に変える第一歩になる。国や自治体の実証事業・ハンドブックが公開されている場合は、自園でゼロから試行錯誤するより先にそれらを参照すると導入のハードルを下げられる

**コピペで使える連絡帳・おたより文面プロンプト例**(汎用チャットAIに投げる想定):

```
あなたは保育士として、保護者向けの連絡帳の文章を作成します。
以下の条件を守ってください。

# 園の方針・トーン
- 丁寧だが堅すぎない、温かみのある言葉遣い
- 子どもの成長・頑張りをポジティブに伝える

# 入力するメモ(箇条書き)
「(ここに今日の様子を箇条書きで貼り付け。例: 給食完食/お昼寝スムーズ/
制作活動でクレヨンを上手に使えた/お友達に「どうぞ」ができた)」

# 出力条件
- 3〜4文程度の自然な文章にする
- 個人名は「(なまえ)ちゃん/くん」の形でそのまま使う
- 誤字脱字がないか確認したうえで出力する
- 最後に「本日の一言」として保護者への一言を添える

# 出力形式
連絡帳の本文のみを出力してください。前置きや解説は不要です。
```

外国語対応が必要な園では、末尾に「上記の文章を英語/中国語でも作成してください」と
追加すれば多言語版のたたき台も同時に得られる。

## 注意点・よくある誤解

- **子どもの記録・写真は特に慎重に扱う個人情報である**: 園児の氏名・発達状況・
  健康状態・写真は、漏洩した場合の影響が大きい機微な情報である。無料版の汎用
  チャットAIに実名や顔写真をそのまま入力しない、入力データが学習に使われない
  設定の法人向けサービスを使う、といった基本的な情報管理を先に整えることが前提になる
- **児童票・要録などの法定書類は保育士・園による最終確認が前提**: コドモン×
  ベネッセの事例のように、AIが作るのはあくまで「振り返り文章のたたき台」であり、
  最終的な記載内容の正確性・妥当性を確認する責任は保育士・園に残る。AIの出力を
  無確認でそのまま提出・保管しない
- **午睡チェック・写真解析などのセンサー/画像系AIは「見守りの補助」であり代替ではない**:
  午睡センサーや画像解析AIは体位・写っている子どもの判別を助けるものであり、
  実際の呼吸確認や安全確認そのものを代替する目的では設計されていない。導入後も
  目視確認や既存の安全管理ルールを継続することが前提となる
- **「保育施設のAI」と「自治体のAI」を混同しない**: 保育所の入所選考(希望順位・
  兄弟条件などを踏まえた振り分け)にAIを使う取り組みは自治体側の業務であり、
  本ページで扱った連絡帳・記録・シフト作成のAIとは主体も目的も異なる。導入を
  検討する際は「誰の・どの業務を効率化するAIか」を区別して整理する
- **効果は「業務負担の軽減」であって「保育士の代替」ではない**: ユニファの実証実験でも
  「業務負担が軽減した」利用者は64%にとどまり、満足度も「高い/やや高い」で68%と、
  導入すれば必ず劇的な効果が出るとは限らない。まずは小規模に試し、自園の業務に
  合うかを見極めてから本格導入するのが失敗の少ない進め方である

## 最初の一歩

自園で毎日発生している連絡帳・おたよりの下書きを1件用意し、上記の
「連絡帳・おたより文面プロンプト例」にそのまま貼り付けて、AIに文章を作らせて
みるとよい。出てきた文章を保育士が1〜2分で確認・修正できるか、個人名や
事実関係に誤りがないかを確かめるところから始めるのが安全である。
