# 外国人材紹介・技能実習/特定技能支援業界における生成AI活用事例

## これは何か

外国人材紹介・技能実習/特定技能支援業界とは、技能実習制度・特定技能制度のもとで来日する外国人労働者の**募集(送出機関との連携)・在留手続き・受入企業とのマッチング・来日後の生活支援**を仲介する業種を指す。具体的には、技能実習生の受入れを仲介・監督する**監理団体**、特定技能外国人の受入企業を支援する**登録支援機関**、そして両者と連携する人材紹介会社・送出機関が担い手になる。人手不足を背景に市場が急拡大している分野で、特定技能の在留外国人数は2025年12月末時点で390,296人(前年末比約37%増)に達しており、母語も在留資格制度も異なる労働者を大量かつ迅速に受け入れる実務負荷が、生成AIによる多言語対応・書類作成支援・マッチング効率化のニーズを押し上げている。

本ページは[「人材紹介・人材サービス業における生成AI活用事例」](staffing-recruiting-industry-ai-use-cases.md)(Part 14、日本人向け一般求人・転職市場が対象)や[「人事(HR)職における生成AI活用事例」](../part15-job-role-cases/hr-ai-use-cases.md)(Part 15、自社の人事担当者視点)とは対象が異なる。本ページが扱うのは、在留資格制度に紐づく手続き(在留資格申請、母国語での契約内容説明、定期監査・報告)と、言語・文化の壁を前提にした支援(多言語チャット、来日前後の日本語教育、生活相談)という**この業界に固有の業務**である。

さらに2026年9月時点、この業界は制度そのものの大転換期にある。技能実習制度は2027年4月1日に廃止され、新設の**育成就労制度**に置き換わる。監理団体は「監理支援機関」への衣替えが必要で、その許可申請(移行認定申請)は2026年4月15日から、受入企業側の育成就労計画の認定申請は2026年9月1日から、それぞれ本格施行に先立つ形で受付が始まったばかりである。つまり本ページで扱う内容は、旧制度(技能実習)と新制度(育成就労)が並走する過渡期の業務実態であることに留意されたい。

## 仕組み・背景

この業界の実務フローは、大きく次の関係者の連携で成り立つ。

1. **送出機関**(候補者の母国側で募集・事前教育を行う機関、技能実習では相手国政府認定が必要)
2. **監理団体/監理支援機関**(技能実習生の受入れを監理し、定期監査・技能実習日誌の確認などを行う非営利団体。育成就労制度では「監理支援機関」に再編される)
3. **登録支援機関**(特定技能外国人の生活オリエンテーション・相談対応・定期面談などの支援業務を受入企業から委託され代行する機関)
4. **受入企業**(実際に外国人材を雇用する事業者)

このどの結節点にも「言語の壁」と「書類作成の負荷」が存在する。候補者の母国語での募集・面接、雇用契約書・雇用条件書の母国語(または本人が理解できる言語)での説明、来日前後の日本語教育、生活オリエンテーション、そして監理団体・登録支援機関が四半期ごとに行う定期監査・定期面談の記録・報告書作成——これらすべてに通訳・翻訳・書類作成の人的コストがかかってきた。生成AIは主に次の4つの形でこの負荷を下げている。

- **多言語マッチング**: 求職者データベースと求人条件をAIで突き合わせ、候補者の絞り込みにかかる時間を圧縮する
- **多言語コミュニケーション支援**: チャットボット・翻訳AIで、母国語での質問対応や社内知識の説明を24時間体制で行う
- **書類・記録作成支援**: 在留資格関連書類のたたき台作成、定期報告書の管理、面談内容の文字起こし
- **状態把握の補助**: 表情・会話内容の分析により、外国人材本人が言葉にしにくい不安・不満の兆候を早期に検知する

## 使いどころ・使い分け

| 業務工程 | AI活用が進んでいる領域 | 人の判断が必須の領域 |
|---|---|---|
| 募集・候補者マッチング | 求人条件と候補者データベースの照合、候補者への一次案内文の多言語生成 | 最終的な採否判断、労働条件の適法性チェック |
| 雇用契約書・雇用条件書の説明 | 下書き翻訳・やさしい日本語への言い換え、本人の理解度確認用の平易な要約作成 | 法的拘束力を持つ正式書面の確定(出入国在留管理庁の公式母国語様式との照合)、本人への説明そのもの |
| 来日前後の日本語教育 | AIによる発音・会話練習の補助、学習進捗の可視化 | 技能実習・特定技能の各試験(日本語能力試験・技能評価試験等)の合否認定 |
| 来日後の生活支援・相談対応 | 定型的な生活情報(ゴミ出し・行政手続き等)への多言語チャット回答、FAQ自動生成 | 労務トラブル・ハラスメント相談などデリケートな内容の一次対応と最終的な解決 |
| 定期監査・定期面談・行政報告 | 面談内容の多言語文字起こし、モチベーション状態の一次スクリーニング、報告書のたたき台作成 | 監査結果の最終判断、行政機関への正式な届出・報告書の提出 |
| 在留資格申請書類の作成 | 記載事項のたたき台生成、必要書類チェックリストの整理 | 書類の作成・提出そのもの(行政書士または弁護士の独占業務) |

**読み方のコツ**: 表の左列(下書き・一次対応・可視化)はAIが実務を助ける領域として定着しつつあるが、右列(最終判断・正式書面の確定・法的手続きの実行)は資格・責任が明確に人に紐づいている工程であり、AIに代替させてはならない。特に在留資格申請書類の作成は行政書士法・弁護士法により有資格者の独占業務と定められており、AIで下書きを作った場合でも提出前に必ず有資格者が確認・作成する体制が前提になる。

### 1. 求人・研修案内の多言語下書き作成(汎用チャットAIでの代替例)

専用ツールを導入していない中小規模の監理団体・登録支援機関でも、ChatGPT/Gemini/Claudeで同様の下書き作成ができる。

```
あなたは技能実習生・特定技能外国人向けの生活オリエンテーション資料を作成する担当者です。
以下の内容を、日本語の原文をもとに、指定した2つの言語で作成してください。

【対象】ベトナム語・インドネシア語を母語とする候補者(日本語レベル:JLPT N4程度)
【原文(日本語)】(ここに社内規則・生活ルールなどの原文を貼り付け)

出力の条件:
1. まず「やさしい日本語」(小学校中学年程度の語彙・短文)に言い換えたバージョンを作成
2. 次に、そのやさしい日本語版をもとにベトナム語・インドネシア語へ翻訳
3. 専門用語・制度名(在留資格、技能実習、特定技能 等)は翻訳せず日本語表記のままローマ字読みを併記
4. 誤解が生じやすい表現(禁止事項・罰則・費用負担)には下線相当の強調(**太字**)を付ける
5. 最後に「この翻訳は下書きであり、法的な説明義務を伴う書面には公式の翻訳様式との照合が必要」という注記を出力の末尾に付ける
```

### 2. 雇用契約書の翻訳精度チェック(バックトランスレーション)

契約書のように誤訳が労働条件トラブルに直結する文書は、AIに翻訳させて終わりにせず、逆翻訳(バックトランスレーション)で意味のズレを確認する運用が有効。

```
以下は、日本語の雇用条件書の一部を(担当者が)ベトナム語に翻訳した文章です。
このベトナム語文を、独立した視点で日本語に逆翻訳してください。
その上で、逆翻訳結果と元の日本語原文を1文ずつ突き合わせ、
・意味が変わってしまっている箇所
・数値(賃金・労働時間・手当)の表記が原文と一致しない箇所
・法律用語や制度名の訳が不自然、または誤解を招く箇所
を指摘してください(評価や書き直しの提案は不要、指摘のみ)。

【元の日本語原文】(貼り付け)
【ベトナム語訳】(貼り付け)
```

### 画面の場所・導入のステップ(汎用ツールを使う場合)

1. ChatGPT/Claude/Geminiの法人プラン(データをモデル学習に使わないオプトアウト設定が可能なプラン)を契約する
2. 上記のようなプロンプトを「カスタム指示」または社内テンプレートとして保存し、担当者間で使い回せるようにする(ChatGPTなら「マイGPT」の指示欄、Claudeなら「プロジェクト」のカスタム指示欄に保存すると再利用しやすい)
3. 出力された翻訳・下書きは、必ず母語話者のスタッフまたは提携する通訳・翻訳会社が最終確認してから配布・提出する
4. 法的な説明義務を伴う書面(雇用契約書・雇用条件書など)は、出入国在留管理庁が公開している母国語対訳の公式様式をベースにし、AI翻訳はそれ以外の補足資料(生活案内・社内規則など)の下書きに限定して使う

## 注意点・よくある誤解

- **法的拘束力のある書面の翻訳をAI任せにしない**: 特定技能の雇用契約書・雇用条件書は、外国人本人が理解できる言語での説明が義務付けられており、出入国在留管理庁が英語を含む多言語の公式様式を提供している。生成AI翻訳はあくまで社内資料・生活案内などの下書き作成に使い、法的な説明義務を伴う書面は必ず公式様式または有資格の翻訳者による訳文を使う。AIの誤訳が労働条件の誤解・トラブルにつながった場合、監理団体・登録支援機関側の説明義務違反として行政指導の対象になりうる
- **制度移行期の情報は「いつ時点か」を必ず確認する**: 技能実習制度は2027年4月1日に廃止され育成就労制度に移行するが、2026年9月時点では監理支援機関の許可申請(移行認定申請、2026年4月15日受付開始)と育成就労計画の認定申請(2026年9月1日受付開始)がようやく始まったばかりの過渡期にある。運用要領も頻繁に改正されており(2026年4月6日改正版が公表されるなど)、AIチャットに制度の説明をさせる場合も、回答が最新の運用要領を反映しているとは限らない点に注意し、必ず出入国在留管理庁の公式情報で裏取りする
- **外国人材本人の個人情報・在留関連情報の取扱いに注意する**: 技能実習生・特定技能外国人の氏名・パスポート情報・健康状態・在留資格の詳細などは、送出機関・監理団体(監理支援機関)・登録支援機関・受入企業の間で共有される機会が多く、個人情報保護法および厚生労働省の「雇用管理に関する個人情報の適正な取扱い」指針の対象になる。無料版・個人契約の生成AIツールにこうした実データを入力するのは情報漏洩リスクが高く、法人契約でオプトアウト設定が確認できているツールに限定する(詳細は[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md)を参照)
- **在留資格申請書類の「作成」は有資格者の独占業務であることを忘れない**: 特定技能の在留資格に関する申請書類の作成を反復継続して行えるのは行政書士(または弁護士)に限られる。登録支援機関や監理団体がAIで書類のたたき台を作ること自体は問題にならないが、それを「作成」として提供・代行する業務範囲には資格制度上の一線があることを理解しておく
- **AIによる表情判定・モチベーション推定は「参考情報」にとどめる**: さくらJOBのような表情分析AIは、面談担当者が気づきにくい変化を早期に検知する補助としては有用だが、文化的背景によって感情表現の出方は異なる。AIのスコアだけで「問題あり/なし」を機械的に判定せず、必ず人による面談・ヒアリングと組み合わせて解釈する

## 最初の一歩

自社(または担当先)が最近作成した生活オリエンテーション資料や研修案内文を1つ選び、上記「求人・研修案内の多言語下書き作成」のプロンプトを使って「やさしい日本語」版と外国語版の下書きをAIに作らせ、実際に配布している資料と比べてどこが分かりやすくなるか(または誤訳・不自然な表現がないか)を確認してみる。
