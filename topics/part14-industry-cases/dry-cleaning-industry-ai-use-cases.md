# クリーニング業界における生成AI活用事例

## これは何か

クリーニング業界(白洋舎・ポニークリーニングのような店舗チェーン、リネット・せんたく便のような
宅配クリーニング、ホテル・病院向けの繊維製品を扱うリネンサプライ業者)は、**店舗数の継続的な
減少と人手不足が同時進行する縮小市場**という共通の経営課題を抱えている。厚生労働省の調査では
2025年3月末時点のクリーニング施設数(無店舗取次店を含む)は69,855カ所で前年同期比4.2%減、
取次所を除いたクリーニング所は19,939カ所で5.4%減となっており、7万カ所を割り込む減少傾向が
続いている([厚生労働省「クリーニング業 結果の概要」](https://www.mhlw.go.jp/bunya/kenkou/seikatsu-eisei22/15-02.html))。
限られた人員で「シミ・汚れの判定」「季節による繁閑差への対応」「店舗と宅配双方の顧客対応」
「集配ルートの効率化」を回さなければならない構造が、生成AI・AI活用のニーズを生んでいる。

本ページは、店舗型クリーニング・宅配クリーニング・リネンサプライという業態ごとに、
確認できた実例(画像認識によるシミ・汚れ判定、AIチャットボット・電話応対、需要予測、
配送ルート最適化)を整理する。ただし先に断っておくと、**クリーニング業界に特化した生成AI
活用の公開事例は、飲食・小売・医療など他業種と比べてまだ数が少ない**。本ページでは
確認できた具体例と、業界の構造上「応用が効くはず」の汎用AI手法を分けて示すので、
自社に当てはめる際の参考にしてほしい。

## 仕組み・背景

クリーニング業界でのAI・生成AI活用は、大きく4つの領域に整理できる。

1. **画像認識AIによる衣類識別・シミ判定**: クリーニング業界でのAI画像認識活用の
   先駆例として知られるのが、福岡県田川市で「クリーニングハウスレモン」を8店舗展開する
   株式会社エルアンドエーの事例である。同社の副社長が独学でGoogleの機械学習フレームワーク
   「TensorFlow」を使い、事前に撮影した衣類画像 約2万5,000枚を学習させて、受付カウンターの
   カメラに衣類を置くだけでワイシャツ・ズボン・スーツなどの品目を自動識別するシステムを
   投資額30万円程度で開発した(識別精度はワイシャツ・ズボンで99%)。2018年5月から
   店舗での実証実験を始め、将来的な無人受付を目指す取り組みとして日本経済新聞・
   日経クロステック・ITmediaなど複数メディアで報じられた
   ([日経クロステック](https://xtech.nikkei.com/atcl/nxt/column/18/00001/00337/)、
   [ITmedia](https://www.itmedia.co.jp/news/articles/1804/04/news118.html)、
   [日本経済新聞](https://www.nikkei.com/article/DGXMZO29024970V00C18A4000000/))。
   衣類の「品目識別」の次の段階として、シミ・汚れの種類や範囲を画像から判定し、
   シミ抜きの要否や追加料金の見積もりにつなげる仕組みも技術的には同じ画像認識AIの
   延長線上にあるが、2026年8月時点で確認できる限り、この「シミ判定→自動見積もり」まで
   一般化した商用サービスの公開事例は限定的で、大手チェーンの一部工場での検品工程への
   AIカメラ導入(搬入時に衣類を撮影・分析し、シミ・汚れの位置や種類を検出する仕組み)が
   紹介されている程度にとどまる([おうちプロ「ポニークリーニングの料金や評判」](https://ouchipro.jp/cleaning/pony-cleaning-price-review/))。
2. **AIチャットボット・AI電話応対による問い合わせ一次対応**: 店舗・宅配クリーニング
   双方で、営業時間・預かり期間・シミ抜き可否・保管サービスといった定型的な問い合わせに
   AIチャットボットやAIボイスボット(電話の自動応答)が一次対応する動きが広がっている。
   汎用の対話型AIサービス「AIさくらさん」(ティファナ・ドットコム)は、クリーニング業界向けに
   複数の活用記事を公開しており、LINE連携のチャットボットで電話問い合わせをLINE経由に
   誘導することでフロント担当者の負荷を減らし、その分をプレス・仕上げ作業に充てる運用や、
   AI電話対応による24時間受付を紹介している
   ([AIさくらさん「クリーニング店の電話対応をゼロにする」](https://www.tifana.ai/article/aifaqsystem-article-382)、
   [AIさくらさん「AIとChatGPTでハウスクリーニング業界に革命」](https://www.tifana.ai/article/reception-article-1134))。
   これらはベンダー自身が公開する事例記事であり、効果の数値は自社に当てはまるかを
   割り引いて見る必要がある(注意点の節で後述)。
3. **需要予測(季節繁閑対応)・配送ルート最適化**: クリーニング業は衣替えシーズン
   (春・秋)に依頼が集中し、閑散期との差が大きい典型的な季節変動型ビジネスである。
   経済産業省の「AI導入ガイドブック(需要予測)」で示されているような、販売実績に加えて
   気温・天候・地域イベントなどの外部データを組み合わせて需要を予測し、人員配置や
   資材発注を最適化する手法は、業種を問わず応用できる汎用AI手法であり、クリーニング業の
   繁閑差対策にも原理的に当てはめられる
   ([経済産業省「AI導入ガイドブック 需要予測」](https://www.meti.go.jp/policy/it_policy/jinzai/AIguidebook_DemandForecasts_FIX.pdf))。
   同様に、宅配クリーニングの集荷・配達ルートも、AIによる組み合わせ最適化(条件・制約を
   もとにルートをスコアリングして最短ルートを導く技術)で効率化できる余地があり、
   物流業界向けのAI配送ルート最適化ツールがそのまま応用可能である
   ([物流・運輸における生成AI活用事例](logistics-transportation-ai-use-cases.md)参照)。
   ただし、これらは「クリーニング業界専用」の商用サービスとしてではなく、汎用の需要予測・
   配送最適化SaaSを導入する形になるのが実情である。
4. **公的補助金を使ったIT・AI導入**: 中小クリーニング事業者の場合、単独でAIシステムを
   開発するのではなく、国の「IT導入補助金」(2026年時点で「デジタル化・AI導入補助金」に
   改称)を使ってソフトウェアを導入するケースが典型的である。滋賀県大津市のクリーニング
   会社が、需要が伸びている宅配クリーニングに対応するため訪問型受付に特化したソフトウェアを
   同補助金を使って導入し、注文・請求業務を効率化した例が中小企業庁の広報サイトで
   紹介されている([中小企業庁「事例から学ぶIT導入補助金」](https://mirasapo-plus.go.jp/hint/20874/))。

## 使いどころ・使い分け

| 業務 | 生成AI・AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| 衣類の品目自動識別(受付の効率化) | 向く(定型的な分類作業、実績あり) | 特殊な形状・重ね着・汚損が激しい衣類は誤識別が起きやすく、最終確認は人が行う |
| シミ・汚れの種類判定と追加料金の見積もり | 部分的に向く(一次スクリーニング) | 素材・染料・シミの原因(油性/水性/血液等)の見極めは経験豊富な職人の判断が依然として必要。誤った薬剤選定は衣類を傷める可能性があり、AIの判定だけで処理方法を決めない |
| 営業時間・預かり期間・保管サービス等の定型問い合わせ対応 | 向く(FAQ回答、24時間対応) | シミ抜きの成否や損害賠償が絡む相談はAIで完結させず、必ず有人窓口に引き継ぐ |
| 季節繁閑を踏まえた人員配置・シフト調整の判断材料作り | 向く(過去データ+天候・イベント情報の統合) | 最終的な人員配置の決定は店舗責任者が行う。AIの予測はあくまで参考値として使う |
| 宅配クリーニングの集荷・配達ルート効率化 | 向く(配送先が多い場合に効果が出やすい) | 配送件数が少ない小規模事業者では、専用ツール導入のコストに見合わない場合がある |
| 店舗の口コミ・レビューへの返信文・改善点の整理 | 向く(下書き作成、傾向の要約) | 個別クレームへの謝罪文はテンプレート化しすぎると誠意が伝わらないため、最終的な文面は人が調整する |
| 衣類の損傷・紛失トラブル時の一次説明・過失判断 | 向かない | 法的責任や賠償額に関わる判断をAIに任せると顧客とのトラブルが深刻化するリスクが高い。事実確認と判断は必ず人が行う |

判断の軸は明快で、**「定型化できる受付・問い合わせ・需要予測」はAIに任せてよいが、
「衣類そのものの状態判断・薬剤選定・トラブル対応」は職人・スタッフの経験に委ねる**、
という業界特有の切り分けになる。

## 実務での使い方

### 1. 宅配クリーニングのチャットボット受付(システムプロンプト例)

自社サイトやLINE公式アカウントに汎用チャットAI(ChatGPT・Gemini等のAPI、または
AIさくらさんのような対話型AIサービス)を組み込む際のシステムプロンプト例。

```
あなたは宅配クリーニングサービス「(サービス名)」のお問い合わせ窓口AIです。

# 対応方針
- 集荷・配達の申し込み方法、対応可能な品目、預かり期間、保管サービスの
  料金など、一般的な質問には丁寧にわかりやすく回答する
- 個別の衣類のシミ・汚れが「落ちるかどうか」を断定しない。
  「素材やシミの種類によって仕上がりが異なるため、実際の判定は職人が
  現物を確認したうえでご案内する」旨を必ず伝える
- 集荷予定日・配達予定日に関する質問には、システム上の予約状況を
  確認した上で回答し、確約できない場合は「目安」であることを明記する
- 衣類の損傷・紛失に関するクレームや、高額品(礼服・毛皮・着物等)の
  特殊素材に関する相談は、AIで回答を完結させず、直ちにカスタマー
  サポート窓口(受付時間: ◯時〜◯時、電話: ◯◯◯-◯◯◯◯-◯◯◯◯)へ
  引き継ぐ
- 個人情報(氏名・住所・電話番号)を聞く際は、利用目的(集荷・配達のため)を
  明示する

# 入力
「(ここにお客様からの質問を貼り付け)」
```

緊急性・トラブル性の高い相談(紛失・損傷・高額品)をAIで抱え込まず、
必ず人につなぐ設計にしておくことが、クレーム対応の観点で特に重要になる。

### 2. 店頭スタッフ向け「シミ・汚れの聞き取りスクリプト」下書き作成

シミ抜きの成否は職人が最終判断するとしても、**受付時にお客様から聞き取るべき情報を
漏れなく確認するための問診スクリプト**は生成AIで下書きできる。

```
クリーニング店の受付スタッフが、シミ・汚れのある衣類を預かる際に
お客様へ確認すべき項目を、聞き取りスクリプトの形でまとめてください。

# 条件
- 「シミが付いた時期」「シミの原因(思い当たるもの)」「これまでに
  自分で処置したか(水で濡らした、他の洗剤を使った等)」「素材表示タグの内容」
  の4項目を必ず含める
- お客様に安心してもらえるよう、「必ず落とせるとは限らない」旨を
  丁寧に伝える一言を含める
- 敬語・接客用語で、そのまま読み上げられる自然な文章にする
```

### 3. 需要予測を踏まえたシフト・発注の判断材料作成(データ分析AI活用)

過去の受付件数データ(曜日・天候・衣替え時期などの外部情報を含む)をチャットAIの
データ分析機能(ChatGPTのCode Interpreter、GeminiのデータAnalysis等)に読み込ませ、
繁閑パターンを可視化・要約させることができる。

```
添付した過去2年分の「日別受付件数・気温・降水量・曜日」のデータを分析し、
以下を出力してください。
- 受付件数が特に増える条件(気温帯・曜日・月)の傾向
- 来月の受付件数の目安レンジ(過去データからの単純な傾向値でよい)
- 上記を踏まえた人員配置の見直し案(何曜日に何人体制が妥当か)

※これは参考値であり、最終的なシフト決定は店舗責任者が行うことを前提とする
```

生成AIによる需要予測は、専用の需要予測AIツールほどの精度は期待できないが、
中小規模の店舗が「まず傾向をつかむ」目的では十分実用的である。

### ツール横断の対応表

| やりたいこと | 代表的なツール・手法 | 料金感・特徴(2026年8月時点) |
|---|---|---|
| 衣類の品目自動識別 | 独自開発(TensorFlow等の機械学習フレームワーク) | エルアンドエーの事例では開発投資額30万円程度。自社開発には一定のエンジニアリングリソースが必要 |
| チャットボット・AI電話応対 | AIさくらさん(ティファナ・ドットコム)、LINE公式アカウント+ChatGPT/Gemini API連携 | 要問い合わせ〜。汎用チャットAI連携なら月数千円〜のAPI利用料で構築可能 |
| 需要予測・繁閑分析 | ChatGPT/GeminiのデータAnalysis機能、専用の需要予測AI SaaS | 汎用AIなら月0〜3,000円程度、専用SaaSは要問い合わせ |
| 配送ルート最適化 | 配送ルート最適化アプリ・AIサービス各種 | 無料プランのあるものから、件数に応じた従量課金まで幅広い |
| IT・AI導入の資金調達 | デジタル化・AI導入補助金(旧IT導入補助金) | 対象経費の一部を補助。申請には事前のIT導入支援事業者との相談が必要 |

## 注意点・よくある誤解

- **「クリーニング業界特化の生成AI」はまだ少ない**: 本ページで紹介した事例のうち、
  衣類の品目識別は2018年の先行事例、チャットボット活用はベンダーの一般的な対話型AI
  サービスの応用であり、業界特化で高度に最適化された生成AIサービスが多数登場している
  他業種(医療・小売等)と比べると、公開事例の絶対数は少ない。導入検討時は「業界専用の
  魔法のツール」を探すのではなく、汎用のチャットAI・需要予測AI・配送最適化ツールを
  自社の業務フローに当てはめる発想で進めるほうが現実的である。
- **AIの品質保証はできない**: シミ・汚れの判定や衣類識別の精度(たとえば前述の
  エルアンドエーの事例でも品目識別精度は99%であり、100%ではない)を過信しない。
  誤った薬剤選定・処理方法の判断は衣類を傷める・変色させるといった不可逆的な
  トラブルにつながるため、AIの判定はあくまで一次スクリーニングにとどめ、
  最終判断は経験を積んだ職人が行う。
- **ベンダー公表の効果数値は自社にそのまま当てはまらない**: チャットボット導入による
  「電話件数◯割減」といった数値は、各ベンダーの事例記事で公表されているものであり、
  算出方法や比較条件は非公開のことが多い。自社での効果は業態・地域・既存の
  問い合わせ量によって変わるため、導入前に小規模なトライアルで効果を確認する。
- **個人情報・住所情報の取り扱い**: 宅配クリーニングは集荷・配達のために顧客の住所・
  連絡先を扱う。チャットボットや生成AIに顧客情報を入力する際は、データの保存先・
  学習利用の有無を契約前に確認する([生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md))。
- **紛失・損傷トラブルの一次対応をAIに任せない**: 衣類の紛失・損傷は法的責任や
  賠償額の交渉に発展しうる。AIチャットボットが安易に「弁償します」等の確約をしてしまうと
  トラブルが深刻化するため、こうした相談は検知した時点で必ず人の窓口につなぐ設計にする。

## 最初の一歩

自社で発生している定型業務(営業時間・預かり期間・保管サービスに関する問い合わせ対応、
または過去の受付件数データの繁閑分析)を1つ選び、まずは汎用チャットAI(ChatGPT・Gemini等)
に下書き作成やデータ分析を試させてみて、スタッフの作業時間がどれだけ短縮できるかを
確認するところから始めるとよい。
