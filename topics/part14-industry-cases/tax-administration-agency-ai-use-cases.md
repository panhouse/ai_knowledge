# 税務署・国税庁など税務行政における生成AI活用事例

## これは何か

国税庁・税務署をはじめとする税務当局は、「毎年数千万件におよぶ確定申告書の処理」
「限られた調査官で膨大な申告データから不正・申告漏れを見つける税務調査」
「税に関する定型的な問い合わせへの一次対応」という業務を抱える一方、
扱うデータが所得・資産という機微な個人情報そのものであり、AIの判断が
更正処分・追徴課税という納税者の権利義務に直結するため、民間企業以上に
説明責任と公平性が問われる特殊な行政分野である。本ページは、国税庁・税務署が
「行政の担い手」として生成AI・AIをどう使っているか(住民対応チャットボット、
申告書のAI-OCR読み取り、税務調査対象の異常検知・リスクスコアリング、
「税務行政の将来像」に基づくDX方針)を、海外の税務当局の事例と合わせて整理する。

**Part 15の「[税理士における生成AI活用事例](../part15-job-role-cases/tax-accountant-ai-use-cases.md)」との違い**:
本ページは**税務当局(国税庁・税務署・地方税務当局)側**が納税者に対して
AIをどう使うかを扱う。一方 Part 15 のページは**税理士(民間の実務家)**が
クライアントの確定申告・税務相談を代行する際にAIをどう使うかを扱う。
同じ「確定申告」というキーワードでも、「行政がAIでどう処理・審査するか」と
「納税者側の代理人がAIでどう申告書を作るか」は視点が逆であり、本ページは前者、
税理士ページは後者が主役になる。

## 仕組み・背景

税務行政における現在のAI活用は、2017年に国税庁が公表した
「税務行政の将来像 〜スマート化を目指して〜」を起点とする一連のDX方針の延長線上にある。
2021年6月に「税務行政のデジタル・トランスフォーメーション−税務行政の将来像2.0−」へ改訂され、
「①納税者の利便性の向上」「②課税・徴収事務の効率化・高度化」の2本柱で
ICT・AI活用を進める方針が示された。2023年6月の「税務行政の将来像2023」では、
これに「③申告手続の電子化を含む事業者のデジタル化促進」を加えた3本柱に再整理されている。
この方針のもとで、現在は大きく3つの領域でAI・生成AIの実装が進んでいる。

1. **住民(納税者)対応の自動化**: 国税庁は税務相談チャットボット「税務職員ふたば」を
   運用し、確定申告書等作成コーナーやタックスアンサーのページから、
   所得税・消費税・贈与税・インボイス制度・年末調整など、時期に応じた
   定型的な税務相談にAIが24時間対応している。2025年分(2026年提出)の
   確定申告シーズンには、年末調整(2025年9月〜)、所得税(2026年1月〜)、
   消費税(2026年2月〜)の順に相談対象を順次拡大する運用がとられた。
2. **申告書処理のAI-OCR化**: 源泉徴収票のOCR読み取りは2021年から
   「確定申告書等作成コーナー」に導入済みで、マイナポータル連携により
   給与所得の源泉徴収票・医療費控除・ふるさと納税などのデータを自動入力する
   「書かない確定申告」が進んでいる。さらに国税庁は2026年9月24日稼働予定の
   次世代基幹システム「KSK2」(国税総合管理システムの刷新版)にあわせて、
   書面提出される申告書・申請書・届出書・法定調書など約1,800種類の様式を
   AI-OCRでの読み取りを前提としたレイアウトに順次改訂している。
3. **税務調査対象の選定・不正申告リスクの分析**: 国税庁は従来から
   KSK(国税総合管理)システムに蓄積された申告・調査実績データを分析して
   調査対象を絞り込んできたが、KSK2稼働後は法人税・所得税・相続税・贈与税・
   消費税など税目横断でデータが統合され、AIによる異常値検知(売上と経費の
   不自然な乖離、業種平均からの利益率の乖離、消費税還付パターンなど)を
   もとに、追徴課税につながりやすい先を優先的に抽出する仕組みが強化される
   見通しである。税務大学校(国税庁の職員研修機関)の論叢でも、
   AI・ICT技術の税務行政活用について、予測の理由・根拠が不明瞭だと
   公平性・透明性・説明責任の確保が難しくなるため、AIの「説明性・解釈性」が
   重要になるという課題が指摘されている。

地方税務当局(都道府県・市区町村)側でも同様の動きがあり、住民対応は
公共・自治体全般の章で扱うチャットボット活用と重なる一方、固定資産税のように
税務固有の活用も出てきている。例えば香川県善通寺市は、衛星画像から
固定資産税の課税対象となる土地の用途(地目)を判別する画像解析プログラムを、
生成AIに書かせたソースコードをもとに内製した。

海外に目を向けると、米国の内国歳入庁(IRS)は2025年6月時点で126件、
その後129件のAIユースケースを運用しており、2022年8月時点のわずか10件から
急拡大した。特に大口パートナーシップ(組合形態の事業体)や超高所得者層の
監査選定にAIモデルを活用しており、2024年末までに大口パートナーシップ76件を
AIモデルで選定して調査、2025年には対象を3,600件超に拡大する計画としている。
英国の歳入関税庁(HMRC)も、納税者向けAIチャットボット「Ask HMRC」が
2025〜2026年度に630万件超のやり取りに対応したほか、滞納・不払いリスクを
予測する分析ツール、文書分析による不正検知の仕組み(データ分析基盤「Connect」)を
運用し、2025年度は約54万件の税務照会をこのデータ分析が支えたとしている。

## 使いどころ・使い分け

税務行政のAI活用は「納税者向けの一次対応・入力支援」と
「当局側の内部判断(調査選定・処分)」で、AIに任せてよい範囲が大きく異なる。

| 業務領域 | AIの役割 | 最終判断者 | 向き不向き |
|---|---|---|---|
| 定型的な税務相談への一次回答(チャットボット) | よくある質問への自動応答、24時間対応 | 個別事案は税務署・税理士へ誘導 | 向く(定型的な制度説明にとどめる前提) |
| 確定申告書・法定調書のOCR読み取り・自動入力 | 手書き・書面データのデジタル化、マイナポータル連携での自動転記 | 最終的な申告内容は納税者(または代理人)が確認・提出 | 向く(入力の手間削減、読み取り誤りは要確認) |
| 税務調査対象の絞り込み・異常値検知 | 大量データからの異常検知・優先順位付け(スクリーニング) | 調査の実施可否・更正処分は国税専門官(職員)が判断 | 向く(あくまで一次選定。処分の法的根拠づけには使わない) |
| 更正・決定処分そのものの決定 | (現時点では実用化されていない) | 必ず職員が法令に基づき判断 | 向かない(行政処分は説明責任・不服申立て制度が前提の職員判断事項) |
| 職員向け内部文書・研修資料の下書き作成 | 議事録要約、通達・法令の一次整理、研修資料のたたき台 | 職員が内容を確認して確定 | 向く(公共・自治体全般と同様、内部の下書き用途) |
| 個別の税務相談・税務代理そのもの(有償で顧客に回答) | 該当しない(当局は納税者に対し行政サービスとして無償で相談に応じる) | - | 民間のAI税務相談サービスの提供可否は税理士法上の論点になる(詳細は[税理士における生成AI活用事例](../part15-job-role-cases/tax-accountant-ai-use-cases.md)を参照) |

判断に迷う場合の目安は「その出力が納税者の権利義務(税額の確定・処分)に
直接影響するか」。影響する領域(調査選定の一次スクリーニングを除く実際の
処分決定)には現時点でAIを直接使わず、影響しない領域(定型相談・入力支援・
内部文書のたたき台)から優先的に広げるのが、国税庁・海外当局とも共通する順序になっている。

## 実務での使い方

### 1. 税務相談チャットボット「税務職員ふたば」(国税庁)

- **どこで使えるか**: 国税庁ホームページ・「確定申告書等作成コーナー」の
  各ページに設置されたチャットアイコンから起動できる。メニュー選択方式と
  自由文入力方式の両方に対応する。
- **対応領域(2026年時点)**: 年末調整、所得税の確定申告(令和7年分)、
  消費税の確定申告(令和7年分)、贈与税の申告(令和7年分)、インボイス制度に
  関する相談などを、それぞれの申告時期の前後にあわせて順次対応開始している。
- **位置づけ**: あくまで「よくある質問」への自動応答であり、個別の事情に
  踏み込んだ相談は電話相談センターや税務署の窓口、税理士への相談に
  誘導する設計になっている。

### 2. AI-OCRによる申告書処理と「書かない確定申告」

- **マイナポータル連携**: マイナンバーカードを使いe-Taxで申告する際、
  マイナポータル経由で給与所得の源泉徴収票・医療費控除・ふるさと納税等の
  データを取得し、確定申告書の該当項目へ自動入力できる(2024年2月分の
  申告から本格提供)。デジタル庁はこれを「書かない確定申告」と呼んでいる。
- **KSK2稼働にあわせた様式改訂**: 2026年9月24日稼働予定の次世代基幹システム
  「KSK2」にあわせ、書面提出される申告書・届出書・法定調書など約1,800種類の
  様式がAI-OCRでの読み取りを前提としたレイアウトへ改訂されつつある。
  書面提出が多い事業者・経理担当者は、様式変更の告知が出た際に
  記入欄のレイアウト変更に注意する必要がある。

### 3. 税務調査対象の選定・不正申告リスクのスクリーニング(KSK2)

- KSK2稼働後は、法人税・所得税・消費税・相続税・贈与税といった税目横断で
  データが統合され、AIが売上と経費の乖離・業種平均からの利益率の乖離・
  消費税還付のパターンなどを分析し、「調査の優先度が高い先」を機械的に
  抽出する仕組みが強化される見通しである。事業者側の実務対応としては、
  「経費と私的支出の混同」「同業種平均から大きく外れた利益率」など、
  AIが異常値として拾いやすいポイントを普段の経理から意識しておくことが
  実質的な備えになる。

### 4. 職員が使う生成AIプロンプトの例(納税者向けFAQ回答の下書き)

税務署・国税庁の広報・相談担当者が、よくある質問への回答案を
下書きする場面を想定したプロンプト例(コピペして使える形):

```
あなたは税務署の広報担当者です。以下の「よくある質問」について、
納税者向けのFAQ回答案を作成してください。

# 質問
[ここに納税者からよくある質問を貼り付け]

# 参照してよい情報
[国税庁タックスアンサーの該当ページのURLまたは抜粋を貼り付け。
 この情報の範囲を超えて、条文番号・通達番号・適用要件を
 推測で補わないこと]

# 出力条件
1. 一般的な制度の説明にとどめ、個別の税額計算や当てはめは行わない
2. 「個別の事情によって扱いが異なる場合があります。詳しくは
   最寄りの税務署または税理士にご相談ください」という一文で必ず締める
3. 専門用語には一言説明を付ける
4. 断定的な表現を避け、確認が取れていない数値・期日は書かない

# 注意
この回答案は担当職員が国税庁タックスアンサー・法令の原文と
突き合わせて確認したうえで公開する前提の下書きであり、
このまま最終回答として公開しない。
```

### 5. ツール横断の対応付け

| 用途 | 使われる仕組み | 位置づけ |
|---|---|---|
| 納税者向け定型相談 | 国税庁「税務職員ふたば」、英国HMRCの「Ask HMRC」 | 専用のAIチャットボット(汎用チャットAIではなく行政専用に構築) |
| 申告書のデータ化・自動入力 | AI-OCR(確定申告書等作成コーナー)、マイナポータル連携 | 光学文字認識(OCR)にAIを組み合わせた専用システム |
| 税務調査対象の絞り込み | KSK2(国税総合管理システムの刷新版)、IRSの監査選定AIモデル | 当局内部の異常検知・スコアリングモデル(非公開) |
| 職員の内部文書作成支援 | Azure OpenAI Service等の閉域環境(公共・自治体全般と共通) | 汎用生成AIを閉域環境で利用(詳細は[公共・自治体における生成AI活用事例](public-sector-ai-use-cases.md)を参照) |

## 注意点・よくある誤解

- **納税者データはとりわけ機微な個人情報である**: 所得・資産・家族構成に
  関する情報が税務当局に集中するうえ、KSK2では法人税・所得税・相続税等の
  データが税目横断で統合される。国税通則法上の守秘義務に加え、AI活用に
  あたっても学習データへの流用防止・アクセス権限の限定など、民間企業以上に
  厳格なデータ隔離が前提になる。
- **調査対象選定AIの「公平性・恣意性」は継続的な論点**: 大量データによる
  スクリーニングは効率的である一方、「なぜその納税者が選ばれたのか」の
  説明が不十分だと、特定の業種・所得層への機械的な偏り(バイアス)が
  生じているのではという不安・批判につながりやすい。税務大学校の論叢でも、
  AIの予測理由が不明瞭だと公平性・透明性・説明責任の確保が困難になるため、
  AIの説明性・解釈性の確保が課題として指摘されている。調査対象の
  「候補への格上げ」と「実際の着手・処分」を分け、後者は必ず職員の
  法的判断を経る運用が、この懸念への現実的な答えになっている。
- **AIの選定結果はそのまま処分の法的根拠にできない**: 更正・決定処分には
  国税通則法上の理由附記等の要件があり、「AIがそう判定したから」という
  説明では法的な説明責任を果たせない。AIは調査対象の優先順位付け
  (スクリーニング)にとどめ、処分の理由づけは職員が法令・事実関係に
  基づいて別途構成する必要がある。
- **チャットボットの回答を個別事案の最終回答と誤解しない**: 「税務職員ふたば」
  のような相談チャットボットは、あくまで一般的な制度説明にとどまる設計に
  なっている。納税者がチャットボットの回答を根拠に申告内容を確定させ、
  後から税務署の見解と食い違うケースも起こりうるため、個別性の強い論点は
  必ず税務署・税理士への相談に誘導する案内文をセットにしておく。
- **AI-OCRの読み取り誤りは「自動入力=正しい」とは限らない**: マイナポータル
  連携やAI-OCRによる自動入力は入力の手間を省くものであり、転記元データの
  誤りやOCRの読み取り誤りがそのまま申告書に反映されるリスクは残る。
  提出前に自動入力された内容を確認する工程は省略できない。

## 最初の一歩

自分(または自社)が確定申告・法人税申告で提出している書類のうち、
書面提出のままになっているものがあれば、国税庁「確定申告書等作成コーナー」の
e-Tax・マイナポータル連携への切り替えと、税務相談チャットボット
「税務職員ふたば」の対応範囲(所得税・消費税・贈与税・インボイス制度など)を
一度確認してみるとよい。
