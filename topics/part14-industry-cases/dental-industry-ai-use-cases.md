# 歯科業界における生成AI活用事例

## これは何か

歯科医院は全国に約6万7,000施設(コンビニより多いとされる)あり、その大半が院長1人・スタッフ数名の小規模経営という特徴を持つ。限られた人員で「予約受付」「カルテ・SOAP記録」「レセプト(診療報酬明細書)請求」「患者説明」「画像診断」までを回す必要があり、生成AI・AIによる業務効率化の効果が特に出やすい業種である。一方で、口腔内写真やレントゲン画像は患者の身体に関する機微な情報であり、診断・治療方針の最終判断は歯科医師法により歯科医師が担うという制約も強い。本ページは、[医療・ヘルスケアにおける生成AI活用事例](healthcare-ai-use-cases.md)が病院・診療所全般を扱うのに対し、歯科医院に固有の受付・診療・経営ワークフロー(電子カルテ記録、予約・リコール、レセプト、患者説明、口腔内画像診断、多言語対応、歯科技工所との連携)に焦点を絞った事例カタログである。

## 仕組み・背景

歯科医院における生成AI・AIの活用は、次の7つの業務領域に整理できる。

1. **電子カルテ記録・SOAP作成支援**: 診察室での医師・患者の会話を音声認識エンジンがリアルタイムでテキスト化し、生成AI(LLM)がSOAP形式(主観的情報・客観的情報・評価・計画の4項目で整理するカルテ記載方式)に自動整形する仕組みが医科・歯科を問わず広がっている。エムスリーが提供する電子カルテ「デジカル」は2026年、AIエージェント機能により「通常モード」「整形モード」に加え、AIが自動でSOAP形式に構造化する「SOAPモード」を実装し、導入から6か月時点でカルテ記載時間が平均2.5時間から1.2時間に削減された事例が報告されている([エムスリーデジカル公式](https://digikar.m3.com/articles/medical-dx/article108))。歯科向けにもSOAP対応のレセコン一体型電子カルテ(例: Avanti)が存在し、同様の音声入力・自動整形の流れが波及しつつある。
2. **予約受付・リコール(定期検診案内)の自動化**: 月間予約数が数百件規模の医院では、電話対応の負荷が受付スタッフの大きな負担になっている。LINE公式アカウント(Messaging API)とChatGPTを連携させたAIチャットボットを導入し、予約確認・リマインド・キャンセル受付を24時間自動化した医院では、受付電話が1日40件から15件に減少(約62%減)したという事例が報告されている([note: しおどめ氏の歯科医院AI活用事例](https://note.com/shiodome_098/n/n434521643edb))。AI電話応対サービス「SmartCall for Dental」のように、電話そのものをAIが受ける専用サービスも2026年に入って複数の歯科医院で導入が進んでいる([SmartCall for Dental公式](https://smartcall.jp/dental/))。
3. **レセプト・保険請求書類支援**: レセプト(診療報酬明細書)は歯科特有の点数表に基づく複雑な算定ルールがあり、記載ミスによる「返戻(差し戻し)」は医院の収益を直接圧迫する。生成AI・AIによるレセプト点検サービスは、提出前に算定漏れ・記載矛盾を自動検出する「提出前エラー検出」に活用が進んでおり、AIチェックの導入でレセプト返戻率を最大42%削減したとする報告もある([歯科AIナビ](https://dental-ai-navi.com/articles/dental-receipt-ai-automation-denial-reduction))。
4. **患者向け説明資料の生成**: 治療方法のメリット・デメリット、費用、治療期間など、患者が知りたい情報を平易な言葉でまとめた説明資料の下書きを生成AIが作成できる。口腔内スキャナーで取得したデータや口腔内写真を見せながら説明する「視覚的なインフォームドコンセント」と組み合わせる使い方が広がっている([AMI: 歯科医院の生成AI活用6つの具体例](https://ami-h.com/2025/05/02/dental-generative-ai-6-use-cases/))。
5. **口腔内画像・レントゲンのAI診断支援**: 米国ではOverjet・Pearlの2社が代表的なレントゲンAI診断支援ツールで、Overjetは10、Pearlは7のFDA(米食品医薬品局)承認モジュールを保有し、う蝕(虫歯)・歯石・根尖病変などを検出する。臨床検証では検出精度94〜95%、解析時間は1枚あたり30秒未満と報告されている([Overjet: Overjet vs Pearl比較記事](https://www.overjet.com/blog/overjet-vs-pearl-dental-ai-software)、[Overjet: う蝕検出におけるAI活用](https://www.overjet.com/blog/how-ai-improves-caries-detection-in-dentistry))。異常の検出自体は画像分類・検出モデル(従来型の認識系AI)が担い、生成AIは所見の文章化・要約を担う分業構造は、病院向け画像診断支援AIと同じ構図である。
6. **多言語対応(インバウンド患者)**: 訪日外国人・在留外国人患者の増加を受け、タブレット型のAI通訳サービスを受付・診療に導入する歯科医院が増えている。ニチイ学館の「グローバルトーク」は24時間365日・17言語に対応し、AI通訳で対応しきれない専門的な会話は多言語オペレーターへエスカレーションできる仕組みを持つ([ニチイ学館公式](https://medi.nichiigakkan.co.jp/service/medical/global-talk/))。
7. **歯科技工所とのコミュニケーション**: 補綴物(被せ物・入れ歯等)の製作を担う歯科技工所との連携では、デジタル印象データ(口腔内スキャナーで取得した3Dデータ)をクラウド経由で数秒で送信する仕組みが普及している(例: デンツプライシロナ「DS Core」)。AIによる咬合(かみ合わせ)解析・色調判定の支援機能も登場しているが、最終的な補綴設計の判断は歯科医師・歯科技工士の専門性に委ねられている([デンツプライシロナ公式](https://www.dentsplysirona.com/ja-jp/discover/discover-by-topic/by-category/dental-laboratory/digital-impression-for-dental-lab.html))。

船井総合研究所の2025年レポートも、歯科医院業界における生成AI活用がマーケティング・採用・診療・事務全般に広がっていると総括している([船井総合研究所](https://www.funaisoken.co.jp/dl-contents/industry-ai2-dentist_S031))。

## 使いどころ・使い分け

| 業務 | 生成AI・AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| SOAP形式のカルテ下書き作成 | 向く(音声入力→自動整形で記載時間を大幅短縮) | 最終的な記載内容の正確性は歯科医師本人が確認・修正する |
| リコール案内・予約リマインドのメッセージ生成 | 向く(定型文の量産・多チャネル配信に強い) | キャンセル待ち調整など複雑な例外対応は人が判断する |
| レセプトの提出前チェック(算定漏れ・記載矛盾の検出) | 向く(ルールベース+AIによる自動検出で返戻率を削減) | 最終的な提出責任・診療内容と算定の整合性判断は歯科医師・レセプト担当者が負う |
| 患者向け説明資料・治療計画資料の下書き | 向く(専門用語の平易化・パターン量産) | ビフォーアフター画像を使う場合は医療広告ガイドラインの注記義務を満たす必要がある |
| う蝕・歯周病・根尖病変のレントゲン画像診断 | 認識系AI(画像分類・検出モデル)が向く。生成AIは所見文の下書きまで | 確定診断・治療方針の決定は歯科医師法により歯科医師が行う |
| 外国人患者への通訳・多言語案内 | 向く(定型的な問診・案内の即時多言語化) | 専門的・込み入った説明はAI通訳から人間オペレーターへのエスカレーションを前提にする |
| 技工所への発注・咬合解析の下支え | 向く(デジタル印象データの即時送信、色調・咬合の一次判定補助) | 最終的な補綴設計判断は歯科医師・歯科技工士の専門性に委ねる |

## 実務での使い方

### プロンプト例1: リコール(定期検診)案内のLINEメッセージ生成

```
以下の条件で、歯科医院からのリコール(定期検診)案内メッセージを3パターン作成してください。
- 送付先: 前回の定期検診から6か月以上来院がない患者
- トーンは丁寧かつ親しみやすく、押し付けがましくならないようにする
- 予約はLINEのメニューから直接取れる旨を案内する
- 文字数は120字以内、絵文字は最小限に

[医院名・診療時間・予約用リンクなどの情報を記載]
```

生成した文面は、送信前に医療広告ガイドライン(誇大な表現・不安を過度に煽る表現の禁止)に抵触しないか確認する。

### プロンプト例2: 口腔内写真をもとにした患者向け説明文の下書き

```
以下の治療内容について、患者向けの説明資料の下書きを作成してください。
- 対象: [例: 前歯部のセラミッククラウン]
- 含める項目: 治療の概要/メリット・デメリット/費用の目安/治療期間/よくある質問
- 中学生でも理解できる平易な言葉を使い、専門用語には一言説明を付ける
- 医学的な誇大表現(「必ず治る」等)は使わない

[治療内容・費用・期間などの情報を記載]
```

ビフォーアフター画像を資料に使う場合は、治療内容・主なリスク・費用・治療期間の注記を医療広告ガイドラインに沿って必ず併記する。

### プロンプト例3: レセプト摘要欄コメントの下書き

```
以下の診療内容について、レセプトの摘要欄に記載するコメント文の下書きを作成してください。
- 算定した処置・材料と、それを裏付ける診療内容の対応関係が分かるように書く
- 保険点数表の記載ルールに沿った簡潔な表現にする
- 記載内容と実施した診療内容に矛盾がないか、確認すべき箇所があれば指摘する

[診療内容・算定項目を記載]
```

出力はあくまで下書きであり、提出前に歯科医師・レセプト担当者が診療録の原本と突合して最終確認する。

### ツール横断の対応表

| 用途 | ツール例 |
|---|---|
| SOAP形式カルテの音声入力・自動整形 | エムスリー「デジカル」AIエージェント機能、ヘンリー「文書生成支援機能」、歯科向けSOAP対応電子カルテ(例: Avanti) |
| 予約・リコール自動化 | LINE公式アカウント+ChatGPT連携のAIチャットボット、SmartCall for Dental(AI電話応対) |
| レセプトの提出前AIチェック | 歯科向けレセプトチェックAIサービス(歯科AIナビ等で紹介される各社ツール) |
| 患者向け説明資料の生成 | ChatGPT/Gemini/Claude/Copilot(汎用チャットAI)+口腔内スキャナーの3Dデータ表示 |
| レントゲン画像のAI診断支援 | Overjet、Pearl(いずれも米国、複数FDA承認モジュールを保有) |
| 多言語対応(インバウンド) | ニチイ学館「グローバルトーク」(タブレット型AI通訳、24時間365日・17言語) |
| 歯科技工所とのデジタル連携 | デンツプライシロナ「DS Core」(デジタル印象データのクラウド送信)、エミウム クラウド技工 |

## 注意点・よくある誤解

- **口腔内写真・レントゲンは機微な医療情報**: 患者の身体状況を直接示す画像データであるため、生成AIに入力・保存する場合は個人情報保護法の要配慮個人情報に準じた厳重な取り扱いが必要になる。院内で完結する構成(オンプレミス)か、入力データを学習に使わない設定になっているクラウドサービスかを必ず確認する。
- **「AIが虫歯を見つける」は正確な理解ではない**: う蝕・歯周病・根尖病変などの異常検出は画像分類・検出モデル(従来型の認識系AI)が担い、生成AI(LLM)は検出結果を患者向け・カルテ向けの文章に変換する役割にとどまることが多い。最終的な確定診断・治療方針の決定は歯科医師法により歯科医師が行う。
- **医療広告ガイドラインはAI生成コンテンツにも適用される**: 患者向け説明資料やビフォーアフター画像をAIで生成した場合でも、治療内容・主なリスク・費用・治療期間の明示義務や、誇大・虚偽表現の禁止は通常のコンテンツと同様に適用される。
- **レセプトAIは「下書き・チェック支援」であり最終責任は医院側**: AIによる提出前チェックで返戻率を下げられても、算定内容と診療内容の整合性を最終的に担保するのは歯科医師・レセプト担当者である。AIの指摘を鵜呑みにせず、必ず診療録の原本と突合する。
- **多言語AI通訳は万能ではない**: 定型的な問診・案内はAI通訳で十分対応できるが、治療方針や同意取得など込み入った説明は誤訳のリスクがあるため、人間の医療通訳者へのエスカレーション経路をあらかじめ用意しておく。
- **小規模医院ほど「導入効果の測り方」を誤りやすい**: 予約対応の電話件数削減やレセプト返戻率の低下など、定量的な効果が出やすい業務から着手し、院長・スタッフの体感的な負荷軽減(残業時間・精神的負担の軽減)も合わせて評価するとよい。

## 最初の一歩

自院の業務のうち「電話対応(予約・リコール)」「レセプトの返戻対応」「カルテ記載」のいずれか最も負担の大きい1つを選び、まずは患者の個人情報を直接扱わない範囲(定型的なリコール文面のドラフト作成など)から生成AIを試してみることから始めるとよい。
