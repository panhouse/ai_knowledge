# 廃棄物処理・リサイクル業界における生成AI活用事例

## これは何か

廃棄物処理・リサイクル業界は、人手不足(業界の約65%が人手不足を実感しているという調査もある)と、廃棄物処理法をはじめとする複雑な法規制対応という2つの構造的な課題を抱える([AI革命株式会社メディア](https://ai-revolution.co.jp/media/ai-in-waste/))。この業界特有のAI活用は大きく分けて、(1)ベルトコンベア上のゴミをカメラで認識し異物・不適物を判定する「画像認識AI」、(2)収集車両の走行ルートを最適化する「配車・ルート最適化AI」、(3)産業廃棄物のマニフェスト(処理の流れを記録する管理票)作成や法令遵守チェックを支援する「生成AI」、(4)住民からのごみ分別に関する問い合わせに答える「自治体向けチャットボット」の4領域に整理できる。本ページは、物流・運輸一般(配送最適化)や自治体業務一般とは異なる、選別・法令遵守・資源循環という廃棄物処理・リサイクル業界固有の論点に絞って整理する。

## 仕組み・背景

### 1. 選別現場における画像認識AI

従来のリサイクル選別は、ベルトコンベアを流れてくる廃棄物を熟練作業員が目視で見分け、手作業で仕分ける労働集約的な工程だった。近年は、カメラで撮影した画像をAI(機械学習によるコンピュータービジョン)が判定し、ロボットアームが対象物をピックする「AI選別ロボット」の実用化が進んでいる。

- 米国AMP Roboticsの「Cortex」は、コンピュータービジョンとロボットアームを組み合わせ、1分間に最大80アイテムを99%前後の精度で選別し、単一種類のプラスチック(PETの透明・色付きの分離など)まで100種類以上のカテゴリーを識別できるとされる([Ellen MacArthur Foundation](https://www.ellenmacarthurfoundation.org/circular-examples/artificial-intelligence-for-recycling-amp-robotics)、[Waste Management World](https://waste-management-world.com/resource-use/lets-talk-about-artificial-intelligence-for-recycling-with-amp-robotics/))。
- 国内では、タイチマシナリー株式会社がAI画像認識でビンだけを自動選別するロボットを開発し、1分間最大60ピック(作業員2〜3名分の省人化)を実現、2025年7月から受注を開始し、2026年5月開催の「2026NEW環境展」でリチウムイオン電池除去システムとあわせて発表している([ATPRESS](https://www.atpress.ne.jp/news/598321))。リチウムイオン電池の混入は選別施設での火災事故の主要因であり、AIによる電池検知・除去は安全対策としても重要視されている。
- 横浜市は早稲田大学・株式会社イーアイアイ・伊藤忠マシンテクノス株式会社と共同で、AIを活用した資源ごみ選別ロボットの自動化実証実験を2025年7月から開始している([横浜市](https://www.city.yokohama.lg.jp/city-info/koho-kocho/press/shigen/2025/senbeturobo20250718.html))。

### 2. 収集ルート最適化

収集車両の走行ルートは、これまで熟練ドライバーの経験に頼ってきた領域だが、AIによる配車最適化サービスが実用段階に入っている。

- エコスタッフ・ジャパン株式会社は、産業廃棄物処分業者向けにAIでごみ収集ルートを最適化するサービスを2020年6月に開始し、全国56社の廃棄物運搬関係企業ネットワークの情報をもとに最適ルートを算出、収集車両台数の削減や作業負荷軽減につなげている([ロボスタ関連情報](https://robotstart.info/article/2025/06/27/376018.html)、業界動向記事)。
- Borzoi AI株式会社は電気通信大学と連携し、東京都調布市と共同で「AI収集ナビ」の実証実験を2025年7月から開始した。ごみ収集車両にAI収集ナビを搭載し、燃料消費・作業負担の削減を狙う([ICT総研](https://ictr.co.jp/report/%E3%80%90%E6%A5%AD%E7%95%8C%E3%83%88%E3%83%94%E3%83%83%E3%82%AF%E3%82%B9%E3%80%91ai%E3%81%A7%E5%9C%B0%E5%9F%9F%E8%AA%B2%E9%A1%8C%E3%82%92%E8%A7%A3%E6%B1%BA%E3%80%82%E8%AA%BF%E5%B8%83%E5%B8%82%E3%81%A7.html/))。

### 3. マニフェスト作成・法令遵守チェックへの生成AI活用

産業廃棄物を排出する事業者は、廃棄物処理法にもとづき「マニフェスト(産業廃棄物管理票)」を発行し、収集運搬・処分の各段階で処理が適正に行われたことを確認する義務を負う。紙マニフェストに加え、環境省が普及を進める電子マニフェスト(JWNET)があるが、2024年度時点の捕捉率(産業廃棄物委託処理量に対する電子マニフェスト利用割合)は約64.5%にとどまり、2030年度に75%とする目標が「第五次循環型社会推進基本計画」(2024年8月閣議決定)で掲げられている。現場では紙・FAX・メールでのやり取りも根強く残っている([JWNET 捕捉率・登録件数](https://www.jwnet.or.jp/jwnet/about/regist/))。

こうした背景から、生成AIの活用は次のような領域で進んでいる。

- **運行日報・マニフェスト記載の下書き自動生成**: 収集運搬ドライバーがスマートフォンで音声入力(廃棄物の種類・数量など)や写真(計量伝票、廃棄物の状態など)を記録すると、生成AIが運行日報やマニフェストの記載内容の下書きを自動生成し、日報作成にかかる時間を1日2時間から30分程度に短縮したという報告がある。ただし、マニフェストは法定帳票であるため、AIの出力はあくまで下書きとして扱い、最終的な記載内容は人が事実確認・承認する運用が前提となる([生成AI研修ラボ](https://note.com/genai_labo/n/n88741e69fc0e))。
- **契約書・法令チェック**: 2026年1月からは廃棄物処理法にもとづく委託契約書の記載事項に追加項目が生じるなど、規制は頻繁に改正される。配車・マニフェストAIを設計する際は、廃棄物処理法・JWNETの仕様変更を継続的に反映する体制が必要になる(株式会社renue、産業廃棄物収集運搬業の配車AI実装に関する解説記事)。
- **社内問い合わせ・マニュアル検索**: 品目ごとの処理基準・許可品目の確認など、ベテラン担当者の経験に依存しがちな判断業務を、生成AIとRAG(検索拡張生成、社内文書を参照させて回答させる仕組み)で支援する取り組みも紹介されている([ArcHack](https://www.arc-hack.com/blog/waste-recycling-generative-ai/))。

### 4. リサイクル資源の需給・市況把握

古紙・金属スクラップなど有価物(リサイクル資源として売却できる廃棄物)の価格は、為替・海外需要・国内発生量に応じて変動する市況商品であり、古紙の国内価格は2022年11月に約2年9か月ぶりの高値をつけるなど変動が大きい。仕入れ・売却のタイミングを判断するため、市況予測AIサービス(古紙卸市場の市場規模推移予測など)が提供され始めている([プリント資源循環センター 古紙ハンドブック](http://www.prpc.or.jp/wp-content/uploads/handbook2023.pdf))。ただし、価格予測AIは市況変動の目安を得る参考情報であり、実際の売買判断は担当者が市況情報と併せて行うのが現状である。

### 5. 不法投棄検知・住民対応

- パスコと茨城県は、衛星画像の時期違い比較にAIモデルを追加学習させ、産業廃棄物の不法投棄が疑われる箇所を抽出する実証実験を行っている([UchuBiz](https://uchubiz.com/article/new38090/))。
- 自治体では、住民からの「これは何ゴミか」という問い合わせに答えるAIチャットボットの導入が広がっている。横浜市の「イーオのごみ分別案内」、大分県別府市のLINE公式アカウントでの日英対応AIチャットボット(711品目・2,344語のキーワードに対応、日英対応は全国初と紹介される)、佐賀市の「AIスタッフ総合案内サービス」(2025年2月から生成AIとRAGを組み合わせた新システムに移行、行政手続き・ごみ分別に24時間対応)などが代表例である([モビルス株式会社](https://mobilus.co.jp/press-release/23966))。

## 使いどころ・使い分け

| 業務 | 生成AI・AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| 選別ラインでの異物・不適物検知 | 向く(コンピュータービジョンによる高速・高精度判定、24時間稼働) | 初期導入コストが高く、少量多品種の施設では投資回収に時間がかかる |
| 収集ルート・配車の最適化 | 向く(過去の収集データ・地図情報をもとにした計算) | 道路工事・イベント等の突発的な変化への追従は人の調整が必要 |
| マニフェスト・運行日報の下書き作成 | 向く(音声入力・写真からの下書き生成で時間短縮) | 法定帳票のため、記載内容の正確性は必ず人が最終確認・承認する |
| 廃棄物処理法など法令の解釈・契約書チェック | 一次確認には向く(条文の要約・過去事例の検索) | 最終的な法解釈・許可要件の判断は専門家(行政書士・弁護士・所轄自治体)に確認する |
| リサイクル資源(古紙・金属スクラップ等)の需給予測 | 参考情報としては向く(市況変動の傾向把握) | 予測は目安であり、実際の売買判断は市況情報と担当者の経験を併用する |
| 住民向けごみ分別案内(自治体チャットボット) | 向く(定型的な品目照会、24時間対応、多言語対応) | 特殊・大型ごみの持ち込み可否や自治体独自ルールの例外対応は人の窓口に誘導する設計にする |
| 不法投棄の疑いがある事案の最終判断・行政処分 | 向かない(検知の一次スクリーニングまで) | 現地確認・証拠保全・行政処分の判断は職員が行う |

## 実務での使い方

### プロンプト例1: マニフェスト・運行日報の下書き作成(生成AIによる整形)

収集運搬ドライバーの音声入力・写真記録から生成AIで下書きを作る場合、次のような指示を組み合わせる。

```
以下はドライバーが音声入力した本日の収集内容のメモです。この内容を、当社の運行日報フォーマットに
整形してください。

- 項目は「収集日時」「排出事業者名」「廃棄物の種類」「数量(重量)」「運搬先」「特記事項」に分ける
- メモに記載のない項目は空欄にし、絶対に数値を推測で埋めない
- マニフェスト番号など法定記載事項に関わる部分は「要確認」と明記する

## 音声入力メモ
[ドライバーの音声入力テキストを貼り付け]
```

出力はあくまで下書きであり、マニフェストへの正式な記載前に必ず担当者が数量・排出事業者名・廃棄物の種類を伝票と突き合わせて確認する。

### プロンプト例2: 品目の分別区分に関する社内マニュアル検索(RAG想定)

```
以下は当社が受け入れ可能な産業廃棄物の品目一覧と処理基準です。
この情報だけをもとに、次の品目が「安定型」「管理型」のどちらの処分場に搬入すべきか、
根拠となる基準名とともに回答してください。分からない場合は「資料内に記載なし」と答えてください。

## 品目一覧・処理基準
[社内マニュアル・処理基準の抜粋を貼り付け]

## 確認したい品目
[品目名]
```

自治体・処分場ごとに独自の受け入れ基準がある場合が多いため、社内マニュアルを最新の状態に保ち、AIが古い基準を参照しないよう定期的に更新する。

### プロンプト例3: 住民向けごみ分別案内チャットボットの回答テンプレート設計

```
あなたは自治体のごみ分別案内チャットボットです。以下のルールに従って回答してください。
- 住民が入力した品目名から、正式な分別区分(可燃/不燃/資源/粗大ごみ等)と収集日の目安を回答する
- 品目一覧に該当がない場合は、憶測で分別区分を答えず「窓口(電話番号)にご確認ください」と案内する
- 粗大ごみ・危険物(電池・スプレー缶等)は必ず個別の出し方の注意を添える

## 品目一覧(自治体の分別区分表)
[分別区分表を貼り付け]

## 住民からの質問
[品目名]
```

品目一覧に無い問い合わせを断定的に答えさせないガードレールが、誤情報による誤った排出(回収不能・事故)を防ぐ上で重要である。

### ツール横断の対応表

| 用途 | ツール・サービス例 |
|---|---|
| 選別ラインの画像認識・ロボット選別 | AMP Robotics「Cortex」(海外)、タイチマシナリーのAI選別ロボット、イーアイアイ×早稲田大学×伊藤忠マシンテクノスの実証機(国内) |
| 収集ルート・配車最適化 | エコスタッフ・ジャパンのAI配車サービス、Borzoi AI「AI収集ナビ」、HARVEYの廃棄物総合管理システム |
| マニフェスト・運行日報の下書き生成 | 汎用生成AI(ChatGPT/Gemini/Claude等)+音声入力アプリ、現場DX向け日報生成サービス |
| 住民向けごみ分別案内チャットボット | モビルス(別府市 LINE公式アカウント)、佐賀市「AIスタッフ総合案内サービス」、横浜市「イーオのごみ分別案内」 |
| 不法投棄の兆候検知 | 衛星画像×AI(パスコ×茨城県の実証実験)、監視カメラ×画像解析 |

まずは自社・自団体の課題が「選別現場の省人化」「配車の効率化」「法令遵守文書の作成負荷」「住民対応の一次窓口」のどれに当たるかを切り分け、投資額の大きい選別ロボット導入よりも、汎用生成AIによる日報下書き・マニュアル検索・住民向けチャットボットのようなスモールスタートから着手するのが費用対効果の高い順序である([ArcHack](https://www.arc-hack.com/blog/waste-recycling-generative-ai/))。

## 注意点・よくある誤解

- **マニフェストの最終記載は必ず人が確認する**: マニフェストは廃棄物処理法上の法定帳票であり、虚偽記載や記載漏れには罰則がある。生成AIによる下書き作成は時間短縮に有効だが、数量・廃棄物の種類・排出事業者名などの記載内容は担当者が伝票・現物と突き合わせて確認する運用を必ず組み込む。
- **選別ロボットは万能ではない**: AI選別ロボットは特定の材質・形状のピッキングには強いが、施設全体の完全自動化にはまだ至っておらず、リチウムイオン電池などの危険物除去や、想定外の混入物への対応は人・専用システムとの組み合わせが前提となる。
- **住民向けチャットボットは「分からない」と言わせる設計が重要**: 品目一覧に無い問い合わせに対してAIが誤った分別区分を断定的に回答すると、住民の誤った排出(収集不可・事故)につながる。該当がない場合は窓口へ誘導するガードレールを必ず設ける([ハルシネーションとその対策](../part04-risk-security/hallucination-and-countermeasures.md)も参照)。
- **法改正への追従が必須**: 廃棄物処理法・JWNETの仕様や委託契約書の記載事項は改正が続く(2026年1月からの契約書記載事項追加など)。AIに参照させる社内マニュアル・プロンプトの前提知識は、法改正のたびに更新する運用ルールを決めておく。
- **電子マニフェストの普及はまだ発展途上**: 2024年度時点の捕捉率は約64.5%であり、紙・FAX・メールでのやり取りが現場に残っている。AI活用を検討する際は、自社の運用がどの段階(紙中心/電子マニフェスト中心/併用)にあるかを踏まえてツールを選ぶ。
- **画像認識モデルの精度は学習データ次第**: 選別AIの精度は、自社施設で実際に流れる廃棄物の種類・混入パターンを学習データに反映できるかに左右される。他社事例の数値(例: 1分間60〜80ピック)はあくまで参考値であり、自社施設での実証・PoC(概念実証)を経てから本導入を判断する。

## 最初の一歩

まずは選別ロボットのような大規模投資ではなく、収集運搬ドライバーの運行日報・マニフェスト下書き作成、または住民向けごみ分別案内の一次対応に、既存の生成AIチャットツールや音声入力アプリを試験導入し、時間削減効果を確認するところから始める。
