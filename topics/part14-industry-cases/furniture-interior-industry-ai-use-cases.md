# 家具・インテリア業界における生成AI活用事例

## これは何か

家具・インテリア業界は、「置いてみないとサイズ・見た目が合うかわからない」
「自分の部屋に何が似合うか言葉で説明できない」という、ECでも実店舗でも
共通して起きる課題を抱えている。本ページは、この業界に**固有**の生成AI・AI活用――
自室の写真をもとにした家具の試し置きシミュレーション、AIによるコーディネート提案・
レコメンド、生成AIで部屋の画像をリスタイリングするツール、住宅営業でのAI提案画像
生成――を実在企業の事例で整理する。

なお、商品説明文の自動生成・チャットボット接客・POSデータに基づく一般的な需要予測など、
業種を問わないEC・小売共通の生成AI活用は
[小売・流通・ECにおける生成AI活用事例](retail-ai-use-cases.md)で扱っているため、
本ページでは扱わない(重複を避けるため、そちらを参照)。

## 業務工程別の活用マップ

| 工程 | 課題 | 代表事例(本ページ内) |
|---|---|---|
| 部屋シミュレーション・試し置き | ECでは家具のサイズ・雰囲気が自分の部屋に合うか試せない | IKEA「Kreativ」、ニトリ×燈「お部屋の写真deシミュレーション」 |
| コーディネート提案・レコメンド | 商品点数が多すぎて「自分の部屋に合う組み合わせ」を選べない | ニトリ×シルバーエッグ「アイジェント・レコメンダー」 |
| 生成AIによる部屋画像のリスタイリング | 好みのテイストを言葉で説明しにくい、完成イメージが湧かない | Wayfair「Decorify」 |
| 住宅営業でのAI提案画像生成・スタイル診断 | リフォーム営業で顧客の潜在的な好みを言語化・可視化できない | ミサワホーム「Interior Maker」「インテリアチェッカー」 |
| 事業者向け3D提案・レンダリング(BtoB) | 店舗・営業担当が顧客ごとに提案資料を作る負担が大きい | Coohom、Homestyler(実務での使い方で紹介) |

**読み方のコツ**: アパレル業界の「試着」に相当するのが家具・インテリア業界の
「試し置き」であり、いずれも「見た目の合致」を写真1枚から予測する技術が核になっている。
一方で、コーディネート提案やスタイル診断は生成AIというより従来型の推薦AI・分類AIで
実現されているケースが多い点が、アパレルとの違いとして押さえておきたい。

## 代表事例の詳細

### 1. 部屋シミュレーション・試し置き: IKEA「Kreativ」

- **企業**: イケア・ジャパン(Ingka Group)
- **課題**: 家具は「実際に置いてみないと部屋に合うかわからない」商材の代表格だが、
  店舗のショールームでは自宅の広さ・採光・既存家具との組み合わせまでは再現できず、
  ECでの購入後に「思っていたのと違う」という失敗が起きやすかった
- **導入したAI・仕組み**: 2020年4月にイケアの親会社Ingka Groupが買収した
  シリコンバレーのAI企業Geomagical Labsの3D・画像認識技術をもとに開発した
  「IKEA Kreativ」を、2024年2月27日から日本でも提供開始。スマートフォンで
  自室を撮影するだけで寸法まで再現した3Dモデルを自動生成し、既存の家具を
  AIで画像から取り除いた上で、イケアの実商品を実寸スケールで自由に配置・
  入れ替えできる。IKEAアプリとWebサイトの両方から利用可能
- **効果**: 「まず部屋を丸ごとスキャンし、そこに実寸の商品を試しに置く」という
  体験を無料で提供することで、購入前の失敗を減らす設計になっている。日本語版
  リリース時点でiOS 14以降・Android 9.0以降に対応
- **自社への応用ヒント**: 「AIで商品画像を作る」ではなく「AIで顧客の部屋を
  再現し、そこに実物を試しに置かせる」という発想が転用しやすい。自社に3D
  スキャン技術がなくても、まず店舗での接客時に既存の3D CADツール(後述の
  Coohom等)で同じ体験を提供することから始められる

### 2. 部屋シミュレーション・試し置き: ニトリ×燈「お部屋の写真deシミュレーション」

- **企業**: 株式会社ニトリ、AI技術提供元は東京大学発AIスタートアップの燈(あかり)株式会社
- **課題**: ニトリは店舗数・商品数(家具・家電・インテリア雑貨まで数万点規模)が
  非常に多く、来店せずに「自分の部屋にこの商品を置いたらどう見えるか」を
  確認する手段がなかった
- **導入したAI・仕組み**: 2026年8月5日、スマートフォンで撮影した部屋の写真
  1枚から、AIの物体検出・サイズ推定技術によって数十秒で3Dの部屋モデルを
  再現し、既存の家具を写真上で削除・置き換えたうえで、約2,500点の商品を
  3Dで自由に配置・移動・回転できる新サービスを「ニトリアプリ」と
  「ニトリネット」で無料提供開始。PC・スマホのブラウザからも別アプリの
  ダウンロード不要で利用できる
- **効果**: 配置を確認したまま「ニトリネット」でそのまま購入できる導線まで
  一体化されている。IKEA Kreativと同様の「自室スキャン+実寸配置」という
  体験を、国内スタートアップとの協業で自社ECに組み込んだ事例
- **自社への応用ヒント**: 大手企業が独自に3D AI技術を開発する以外に、
  スタートアップとの協業でこの種の体験を短期間で実装する選択肢がある
  ことを示す事例。商品数が多い業態ほど、コーディネート単位ではなく
  「自室に1点ずつ試し置きできる」体験の価値が高い

### 3. コーディネート提案・レコメンド: ニトリ×シルバーエッグ「アイジェント・レコメンダー」

- **企業**: 株式会社ニトリ、AI提供元はシルバーエッグ・テクノロジー株式会社、
  スタッフ投稿基盤は株式会社バニッシュ・スタンダード「STAFF START」
- **課題**: ニトリネットには販売スタッフが投稿した多様なコーディネート画像
  (商品の組み合わせ例)が蓄積されていたが、閲覧者一人ひとりの好みに
  合わせて表示を切り替える仕組みがなく、埋もれてしまっていた
- **導入したAI・仕組み**: 2022年1月17日、店舗スタッフのSNS風投稿ツール
  「STAFF START」と、シルバーエッグの推薦AI「アイジェント・レコメンダー」
  (すでにニトリネットの商品レコメンドで滞在時間・CVR改善に使われていた
  エンジン)を連携。顧客ごとの閲覧・購買傾向に合わせて、スタッフが投稿した
  コーディネート画像の中から合うものをAIが選んで表示する
- **効果**: 「商品単位のレコメンド」に加えて「コーディネート単位のレコメンド」
  を提供することで、顧客が自分に合うライフスタイルそのものに出会う体験を
  目指している。スタッフの投稿がより評価されやすくなる効果も期待されている
- **自社への応用ヒント**: 生成AIで新しい画像を作るのではなく、「すでに社内
  (スタッフ・過去の提案資料)にある良質なコーディネート画像・提案例を、
  推薦AIで適切な人に届け直す」という発想は、コンテンツ制作コストをかけずに
  始められる

### 4. 生成AIによる部屋画像のリスタイリング: Wayfair「Decorify」

- **企業**: Wayfair(米国最大級の家具・インテリアEC)
- **課題**: 顧客が「北欧テイスト」「インダストリアル」のように好みのスタイルを
  言葉で説明できても、それが自分の部屋にどう反映されるかを想像するのは難しく、
  カタログ画像だけでは購買の決め手にならなかった
- **導入したAI・仕組み**: 2023年7月25日提供開始。生成AIモデルにより、
  顧客が自分の部屋の写真をアップロードし「Traditional」「Modern」
  「Farmhouse」「Bohemian」「Rustic」「Industrial」「Glam」
  「Perfectly Pink」など好みのスタイルを選ぶと、フォトリアルな
  リスタイリング画像を生成する。生成された画像内の商品はそのまま
  Wayfairで購入できる。当初はリビングルームのみ対応。2026年時点でも
  Webのほか、Apple Vision Pro版でも提供が継続している
- **効果**: 「言葉で好みを伝える」負担を、生成画像を見て選ぶ体験に置き換え、
  ビジュアルからそのまま購買導線につなげる設計になっている
- **自社への応用ヒント**: 汎用の画像生成AI(Gemini・ChatGPT・Adobe Firefly等)
  でも同様の体験を簡易に模倣できる。まずは自社の人気商品カテゴリ1つに絞り、
  「スタイル選択→生成→購入」の一連の流れを試作してみるとよい

### 5. 住宅営業でのAI提案画像生成: ミサワホーム「Interior Maker」

- **企業**: ミサワホーム株式会社(リフォーム営業向け)
- **課題**: リフォーム営業では、顧客自身が「理想の暮らし」を言語化できていない
  ことが多く、営業担当が言葉だけで提案してもイメージが合わず商談が停滞しやすい。
  一方で提案用のイメージ画像を都度デザイナーに発注するのは時間がかかる
- **導入したAI・仕組み**: 2026年5月25日発表、全国の販売店向けにiPad専用
  アプリ「Interior Maker」を開発し本格運用を開始。営業担当が顧客の自宅写真を
  アップロードし、部屋の種類・広さ・床や壁の色などをボタンでタップして
  選択するだけで、生成AI向けの指示文(プロンプト)が自動で組み立てられ、
  リフォーム後の高品質なインテリアパース画像をその場で生成する。
  「北欧テイストにしたい」といった抽象的な要望や具体的な家具指定も
  自由テキストで反映できる
- **効果**: その場で「暮らしのイメージ」を顧客と共有できることで、
  顧客自身が気づいていなかった潜在的な要望を掘り起こし、想像を超える
  提案を共創できる場を作ることを狙っている。あわせて同社は2022年1月に、
  Google CloudのVertex AI(AutoML)を使って撮影した空間の写真を14種類の
  インテリアスタイルに自動分類する「インテリアチェッカー」も提供しており、
  「診断(好みの分類)→提案(生成AIでのビジュアル化)」の二段構えで
  営業現場のAI活用を進めている
- **自社への応用ヒント**: 「生成AIに直接プロンプトを書かせる」のではなく、
  「ボタン選択で属性を組み合わせ、裏側でプロンプトを自動生成する」UIに
  すると、AIの扱いに不慣れな営業担当でも安定した提案画像を作れる。
  この設計は住宅・リフォーム業に限らず、非エンジニアが生成AIを使う
  現場全般に応用できる

## 実務での使い方

### 自社商品の設置イメージをたたき台として作るプロンプト例(汎用画像生成AI)

自社のEC商品画像を、汎用の画像生成AI(Gemini・ChatGPT・Adobe Firefly等)で
簡易的に試す場合、実写の商品画像をアップロードした上で以下のような指示を出すと
たたき台を作りやすい。

```
以下は当社のダイニングテーブル(実写・単体)の画像です。この商品の色・素材感・
サイズ感を変えずに、北欧テイストのリビングダイニングに設置されているイメージ
画像を生成してください。
- 部屋の広さは10畳程度、窓からの自然光が入る昼間の設定
- 床は明るい色のフローリング、壁は白系
- 他の家具(椅子・照明等)は写実的で、テーブルの存在感を邪魔しないこと
- 商品の脚のデザイン・質感は実写と一致させること
- 生成AIで作成した画像である旨を、社内資料・顧客向け提案書には必ず明記すること
```

**ツール横断の対応付け**:

| やりたいこと | 代表的なツール | 特徴 |
|---|---|---|
| 消費者が自室の写真に実寸の商品を試し置き | IKEA「Kreativ」、ニトリ×燈「お部屋の写真deシミュレーション」 | スマホ撮影→3D化→既存家具の削除・商品配置までを無料アプリ・Webで提供。事業者側は自社での技術開発かスタートアップ協業のいずれかで実装している |
| 消費者が部屋の写真を好みのテイストに一括リスタイリング | Wayfair「Decorify」、RoomGPTのような汎用アプリ | 生成AIで部屋全体の雰囲気を変換し、写った商品をそのまま購入できる導線を持つ |
| 事業者(営業・コーディネーター)が提案資料を3Dで作成 | Coohom、Homestyler | 数万〜数千万点規模の3DモデルライブラリとAI自動レイアウト機能を持つ業務用SaaS。住宅メーカーのショールームVRや接客タブレットへの組み込みで使われる |
| 住宅・リフォーム営業でその場に生成AI提案画像を作る | ミサワホーム「Interior Maker」のような自社構築アプリ | ボタン選択でプロンプトを自動生成する設計にすることで、非エンジニアの営業担当でも扱える |
| 顧客の好みのインテリアスタイルを分類・診断する | 画像分類AI(Google Cloud Vertex AI AutoML等)を用いた自社構築 | 生成AIではなく分類AIだが、提案の前段(好みの把握)として組み合わせると効果的 |

## 注意点・よくある誤解

- **部屋スキャンの精度には限界がある**: スマートフォン1枚の撮影による3D化・
  サイズ推定は、照明条件や奥行きの読み取り誤差によって実際の家具サイズと
  数cm単位でずれることがある。IKEA Kreativやニトリの「お部屋deシミュレーション」
  のような機能を導入・活用する際も、「あくまで目安」であることを利用者に
  明示しておく必要がある
- **生成AI画像は「見た目」しか伝えない**: 生成AIで作ったリスタイリング画像や
  提案パースは、色・レイアウトの雰囲気は伝えられても、生地の質感・座り心地・
  耐久性、実際の重さや組み立てやすさまでは表現できない。「画像と実物が違う」
  という不満・返品理由につながりうるため、生成AI画像であることの明示と、
  実物の質感情報(素材表・サンプル送付等)を必ず併用すること
- **コーディネート提案の「元ネタ」の質と多様性に依存する**: ニトリの事例のように
  推薦AIでスタッフ投稿を選び出す仕組みは、元となる投稿コンテンツの量・鮮度・
  多様性が乏しいと効果が出ない。生成AIで画像を量産する場合も、ワンパターンな
  提案にならないよう、テイストのバリエーションを意図的に確保する必要がある
- **顧客の自宅写真を扱う以上、プライバシー・データ管理への配慮が欠かせない**:
  部屋のシミュレーション・診断系のサービスは顧客自身の生活空間の写真を
  クラウドに送信する。利用規約での用途明示、保存期間、第三者提供の有無を
  導入前に必ず確認・説明すること
- **効果数値は各社発表ベースであることに留意**: 本ページで紹介した効果
  (滞在時間・CVR改善など)は各社のプレスリリース・報道に基づくものであり、
  算出方法や比較対象は企業ごとに異なる。自社導入時の目標設定にそのまま
  流用せず、あくまで「桁感」の参考とする

## 最初の一歩

自宅の家具を1点買い替えると仮定して、IKEA「Kreativ」またはニトリアプリの
「お部屋の写真deシミュレーション」で自室の写真から試し置きしてみて、
サイズ感・雰囲気の再現度がどこまで実用的かを体感することから始めるとよい。
