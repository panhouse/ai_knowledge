# 調剤薬局・ドラッグストア業界における生成AI活用事例

## これは何か

調剤薬局・ドラッグストアは、薬剤師・登録販売者(一般用医薬品の販売を担う専門資格者)の人手不足が深刻な一方、薬歴(薬剤服用歴、患者ごとの服薬記録)の記載や在庫発注といった定型業務の負荷が大きい業種である。厚生労働省が2015年に示した「患者のための薬局ビジョン」以来、薬局の役割は「対物業務(調剤・ピッキングなど物を扱う業務)」から「対人業務(服薬指導・健康相談など人に向き合う業務)」へ移行することが政策的に求められており、生成AIはこの対物業務を効率化して対人業務に人手を回すための手段として、2024〜2026年に大手チェーンで急速に導入が進んだ。本ページは、[医療・ヘルスケアにおける生成AI活用事例](healthcare-ai-use-cases.md)が病院・クリニックを、[製薬業界における生成AI活用事例](pharmaceutical-industry-ai-use-cases.md)が創薬・治験を扱うのに対し、患者・生活者と直接接する**薬局・ドラッグストアの店舗運営**に焦点を当て、薬歴記録支援・OTC医薬品(一般用医薬品)の接客・在庫発注最適化・電子処方箋連携という業務領域別に実在事例を整理した事例カタログである。

## 仕組み・背景

調剤薬局・ドラッグストアにおける生成AI・AIの活用は、次の6つの業務領域に整理できる。

| 業務領域 | 課題 | AI・生成AIの役割 | 代表企業・サービス(本ページ内) |
|---|---|---|---|
| 薬歴記録・服薬指導支援 | 服薬指導後の薬歴記載(SOAP形式が標準)に時間がかかり、対人業務を圧迫する | 服薬指導中の会話を音声認識し、生成AIが薬歴の下書きを自動生成する | カケハシ「Musubi」/ 日本調剤「corte」/ ウィーメックス(メディコム)「生成AI薬歴入力支援サービス」/ 三菱電機デジタルイノベーション「AnyCOMPASS」/ アインHD・ウエルシア薬局・ツルハHDの自社導入 |
| OTC医薬品の接客・登録販売者育成 | 登録販売者の不足、薬機法(医薬品等の広告・説明表現を規制する法律)を踏まえた接客の難しさ | 生成AIとのロールプレイで接客スキルを自主学習し、症状相談への一次案内やQA対応を支援する | ネットパイロティング「トー☆ハンくん」「ホクロヤッコ」/ MG-DX「AI薬師®」 |
| 在庫・発注最適化 | 医薬品の廃棄・欠品と、発注業務そのものの負荷 | AIが需要を予測し、自動発注や店舗間の在庫確認を担う | クオール薬局×Liaro/ 中部薬品×日立システムズ/ スギ薬局×エクサウィザーズ(品揃え最適化) |
| 店舗運営・バックオフィス支援 | 大量の業務マニュアル、クレーム対応文案、社内問い合わせ対応など定型文書業務の負荷 | 店舗業態特化の生成AIチャットが要約・文案作成・問い合わせ対応を行う | 日本調剤「exaBase 生成AI for 店舗」/ スギ薬局(Amazon Bedrock活用の年末調整QAボット) |
| 電子処方箋・オンライン服薬指導との連携 | 処方箋のデジタル化に伴う重複投薬チェックの重要性向上、対面が難しい患者への対応 | AI受付とオンライン服薬指導を組み合わせたハイブリッド運用、店頭受付の自動化 | MG-DX「薬局受付AIエージェント」(クオール薬局) |
| 調剤ロボット・調剤監査 | 計数調剤・分包など対物業務そのものの人手不足、取り間違いリスク | ロボットが調剤を自動実行し、AIが画像判定・バーコード判定で取り間違いを検知、最終監査は薬剤師が行う | 各種調剤ロボット・調剤監査システム(業界一般の取り組み) |

**読み方のコツ**: 「薬歴記録」と「OTC接客」は自然言語の要約・対話が中心のため生成AI(LLM)がそのまま活躍しやすい領域である。一方「調剤ロボット」は物理的な自動化(従来型のロボティクス・画像認識)が主役であり、生成AIは監査結果の説明や記録の文章化といった補助的な役割にとどまる。この違いを理解しておくと、自社での投資判断がしやすくなる。

代表的な事例を業務領域別に見ていく。

1. **薬歴記録・服薬指導支援(業界最大手クラスの薬局向けクラウド)**: 電子薬歴クラウド「Musubi」を展開するカケハシは2024年9月に薬歴作成への生成AI活用を発表し、先行検証を経て2026年5月11日に「AIアシスタント―音声薬歴生成機能―」を標準機能として全ユーザーへ展開開始した。服薬指導中の会話を音声認識し、生成AIが薬歴の下書きを自動生成する仕組みで、薬剤師がメモを取らずに患者との対話に集中できるようにすることを目的としている。
2. **薬歴記録支援(大手調剤薬局チェーン): 日本調剤「corte」**: 日本調剤は2024年11月13日、会話を録音して生成AIが自動で要約しSOAP形式の薬歴を作成する「corte(コルテ)」を50店舗に先行導入した。効果検証で入力時間の大幅短縮と記載内容の充実が確認され、2025年5月13日に全763店舗への展開を発表した。同社は記録作成時間を平均7割程度削減できると見込んでいる。
3. **薬歴記録支援(大手ドラッグストアチェーン): アインHD・ウエルシア薬局・ツルハHD**
   - アインホールディングスは2026年1〜2月に、2027年4月期までに生成AIを活用した薬歴管理システムを調剤薬局約1,300店に導入する計画を発表した。薬歴記載にかかる時間を半減させ、年間で約50万時間の業務時間削減を見込むほか、2034年4月期までに薬剤師1人あたりの処方箋処理枚数を2024年4月期比4割増(1日30枚)とする目標も掲げ、各薬局に必要な薬剤師数の算出などの経営改善プランもAIが作成する方針である。
   - ウエルシア薬局は2026年8月11日、調剤業務を行う1,949店舗に、患者との対話を録音してAIが薬歴を自動記録する「AI音声薬歴システム」を導入したと発表した。
   - ツルハホールディングスは2024年5月16日、ウィーメックス(旧PHC、電子薬歴システム「メディコム」提供元)のChatGPTと音声認識AIを搭載した薬歴入力支援システムの実店舗トライアル利用を開始し、薬歴作成所要時間の約60%削減を見込むとしている。ウエルシアとツルハは2026年に経営統合を発表しており、両社が個別に進めてきた薬歴AI活用のノウハウが統合後にどう共有されるかは今後の注目点である。
4. **OTC医薬品の接客・登録販売者育成**: ネットパイロティング株式会社は2025年6月5日、ドラッグストア等で働く登録販売者向けに、接客ロールプレイ形式の生成AIチャットボット「トー☆ハンくん」と、知識確認用のQAボット「ホクロヤッコ」の提供を開始した。症状相談への応対を模擬体験しながら自主学習できる設計で、薬機法を踏まえた接客表現の習熟を支援する。医療AI企業のMG-DX(サイバーエージェント系)も、対人業務を支援する次世代薬局ソリューション「AI薬師®」で大規模言語モデルの活用を進め、人手不足解消を掲げる「遠隔接客事業部」を設立している。
5. **在庫・発注最適化**: クオールホールディングスが運営するクオール薬局は、AIスタートアップのLiaroが提供するAI需要予測型の発注最適化ソリューションを導入し、週5回以上処方される医薬品を中心に医薬品の廃棄を9割以上削減、欠品による店舗間配送の必要性も大幅に減らしたと報告している。ドラッグストア大手の中部薬品も、日立システムズのAI需要予測型自動発注システムを2024年5月に全店舗へ導入した。スギ薬局はエクサウィザーズと共同で、売上効率の高い商品の組み合わせを自動算出する「品揃え最適化AI」を開発し、全店展開を進めている。
6. **店舗運営・バックオフィス支援**: 日本調剤は2024年11月7日、店舗業態に特化した法人向けChatGPT「exaBase 生成AI for 店舗」を全746店舗のうち一部店舗に導入した。マニュアルの要約から理解度テストの作成、クレーム対応文案・セールスコピーの作成まで、店舗運営の知見を組み込んだプロンプトを20種類以上搭載している。スギ薬局はAmazon Bedrock(AWSの生成AI基盤サービス)を活用し、年末調整に関する社内問い合わせ対応ボット(約40日で2万件処理、SaaS製品比で約120分の1のコストと報告)と、薬剤師が電話で行っていた店舗間の調剤医薬品在庫確認をAIエージェント化する取り組みを進めている。
7. **電子処方箋・オンライン服薬指導との連携**: 政府は電子処方箋(2023年1月運用開始、医療機関・薬局間で処方情報を電子的にやり取りする仕組み)を2025年夏頃までにほぼ全ての医療機関・薬局へ普及させる方針を示している。この基盤の上で、クオール薬局は2026年6月24日、MG-DXの薬局特化接客AIエージェント「薬局受付AIエージェント」の店頭受付機能「薬局AI受付」の運用を開始し、AIによる音声案内・受付自動化と遠隔スタッフによるフォロー対応を組み合わせて、AI自動受付とオンライン服薬指導のハイブリッド運用を実現している。

## 使いどころ・使い分け

| 業務 | 生成AI・AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| 薬歴(SOAP形式)の下書き作成 | 向く(会話からの要約・構造化が得意) | 記載内容の正確性・薬学的判断の最終確認は必ず薬剤師が行う |
| 登録販売者のOTC接客ロールプレイ・知識確認 | 向く(自主学習・模擬対話) | 実際の販売時の情報提供義務は資格者本人が負う。AIの回答は学習用の参考にとどめる |
| 定番品・処方箋医薬品の需要予測発注 | 向く(処方データ・販売実績の蓄積がある) | 新商品・季節限定品はデータ不足で精度が出にくく、人の判断を併用する |
| 店舗マニュアルの要約・クレーム返信文案・販促文言のドラフト | 向く(下書き高速化) | 薬機法・景表法(誇大な広告表現を規制する法律)上の表現確認は必ず人が行う |
| 服薬指導そのもの(患者への説明・薬学的判断) | 向かない(補助のみ) | 医薬品情報の提供は薬剤師法・薬機法上、資格者本人が担う業務であり代替できない |
| 調剤(計数・混合・分包)の実行 | 調剤ロボットが物理的に担うが、これは従来型のロボティクス・画像認識が主体で「生成AI」とは別の技術領域 | 最終監査(取り間違いの確認)は薬剤師が行う体制が前提 |

### プロンプト例1: 薬歴下書きのセルフチェック(薬剤師向け)

```
以下は生成AIが服薬指導の会話から自動作成した薬歴の下書きです。
薬剤師が最終確認する前提で、次の観点からチェックしてください。

- 患者が話した内容(S:主観的情報)と、検査値など客観的情報(O)が混在していないか
- 生成AIが会話にない内容を補って書いていないか(推測・断定表現がないか)
- 次回の服薬指導で確認すべき事項(P:計画)が明確に書かれているか

[生成AIが作成した薬歴の下書きを貼り付け]

出力は「修正が必要な箇所」「確認が必要な箇所」を分けて箇条書きにしてください。
```

薬歴の最終確定・保存は必ず薬剤師本人が行う。会話に含まれない内容を生成AIが補ってしまう(ハルシネーション)リスクを前提に、下書きは常に元の会話内容と照合する。

### プロンプト例2: 登録販売者のOTC接客ロールプレイ(自主学習用)

```
あなたは市販薬を求めて来店した40代女性のお客様役です。
「風邪のような症状だが熱はない、咳と鼻水がひどい」という設定で、
登録販売者(私)からの問診に自然に答えてください。

一通りの接客が終わったら、以下の観点でフィードバックをください。
- 症状の聞き取りが不足していた点
- 薬機法上、避けるべき断定的な効能表現がなかったか
- 受診勧奨(医療機関へ行くよう勧める)が必要な症状のサインを見落としていないか
```

生成AIとのロールプレイはあくまで自主学習・知識確認の位置づけであり、実際の接客での最終判断・情報提供は登録販売者本人の責任で行う。

### プロンプト例3: 発注判断の一次チェック(需要予測AIの出力解釈補助)

```
以下は需要予測AIが出力した来週の推奨発注数です。
発注担当者が最終判断する前提で、次の点を整理してください。

- 直近の実績と比べて大きく変動している品目とその理由の仮説
- 季節性・地域イベントなど、AIのモデルが反映しにくい要因の候補
- 発注数をそのまま採用してよいと考えられる品目と、人の確認を優先すべき品目の分類

[品目別の推奨発注数・直近実績データを貼り付け]
```

需要予測AIは処方実績・販売実績が蓄積された定番品で精度が高く、新商品・季節限定品は人の判断を併用するのが実務的な使い方である。

## 注意点・よくある誤解

- **薬歴の最終確認は必ず薬剤師が行う**: 生成AIが作成する薬歴はあくまで下書きであり、会話に含まれない内容を補ってしまう(ハルシネーション)リスクがある。各社の導入事例に共通する「AIが下書き、薬剤師が確認・修正」という運用は、薬剤師法上の記録義務を踏まえた標準的な安全策である。
- **登録販売者・薬剤師の資格業務はAIで代替できない**: OTC医薬品の情報提供は登録販売者、調剤・服薬指導は薬剤師が薬機法・薬剤師法上担う業務であり、生成AIチャットボットは学習・下書き支援の位置づけにとどまる。
- **個人情報・要配慮個人情報の取り扱い**: 服薬指導の音声録音・会話内容には病歴等の要配慮個人情報が含まれるため、個人情報保護法に加え、法人契約でデータが学習利用されない設定を確認する([生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md))。まずは薬歴のような機微情報を含む領域よりも、店舗マニュアルの要約や登録販売者の自主学習といった機微情報を含まない領域から試すアプローチも取られている。
- **需要予測AIは「データが蓄積された定番品」で精度が出る**: クオール薬局の事例のように週5回以上処方される医薬品では大きな効果が出ているが、新商品・季節限定品はデータ不足で精度が出にくく、発注担当者の判断を併用する運用が前提となる。
- **薬機法・景表法上の表現規制はAIが生成した文章にも及ぶ**: 販促文言・クレーム返信文案を生成AIで作成する場合も、誇大な効能表現や未承認の効能を示唆する表現になっていないか、資材化する前に人が確認する。
- **2026年度調剤報酬改定との関係**: 2026年度調剤報酬改定は「対物業務から対人業務へ」の転換をさらに促す内容(かかりつけ機能の評価統合、立地依存の減算強化など)となっており、生成AIによる薬歴記録・発注業務の効率化は、単なるコスト削減ではなく、対人業務にシフトするための実務的な手段として位置づけられている。
- **効果測定は「時間」だけでなく「対人業務の質」も見る**: 医療・ヘルスケア領域全般に共通する傾向として、記録時間の短縮そのものよりも、患者との対話に集中できることによる満足度・服薬指導の質の向上といった定性的な効果が語られることが多い。時間短縮だけで効果を評価すると過小評価になりうる。

## 最初の一歩

自店舗・自社で最も負荷が高い定型業務を1つ選び(薬歴記載、登録販売者の接客学習、発注判断など)、まずは患者の個人情報を直接扱わない範囲(登録販売者の自主学習用ロールプレイ、店舗マニュアルの要約など)から生成AI活用を試してみるとよい。
