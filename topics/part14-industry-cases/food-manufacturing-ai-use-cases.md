# 食品製造業における生成AI活用事例

## これは何か

食品製造業(食品・飲料メーカー、惣菜・弁当工場など)は、[製造業における生成AI活用事例](./manufacturing-ai-use-cases.md)が扱う一般の製造業と共通の課題(人手不足・品質のばらつき・需要予測)を抱えつつ、「原料が生鮮で賞味期限が短い」「金属探知機では見つけられない異物(髪の毛・虫・カラの破片など)が混入しうる」「食品表示法・HACCP(危害要因分析重要管理点、食品衛生管理の国際標準)といった規制対応の文書作成が恒常的に発生する」という、この業種特有の悩みを持つ。
本ページは、外食・飲食店の運営を扱う[外食・フードサービス業における生成AI活用事例](./food-service-ai-use-cases.md)とは異なり、食品・飲料を**製造する側**(メーカー・工場)に絞って、新商品開発、AI画像検査による異物・不良品検出、生鮮品の需要予測、食品表示・HACCP文書のドラフト作成、アレルゲンチェック支援といった実在の事例とすぐ使えるプロンプト例を整理する。

## 仕組み・背景

食品製造業でAI・生成AIの活用が広がっている背景は主に3つ。

1. **人手不足と検査員の目視限界**: 食品工場の外観検査は依然として目視検品への依存度が高いが、ひじきや昆布のように一つひとつの形が異なる「個体差の大きい食品」では、人の目では見落としやすい微小な異物(ビニール片、アレルゲン食品に指定された小さなエビ・カニの破片など)が混入するリスクがある
2. **賞味期限の短さゆえの需要予測の難しさ**: 惣菜・弁当・生鮮加工品は在庫を長く持てないため、発注量・製造数の見誤りがそのまま食品ロス(廃棄)か欠品(機会損失)に直結する。天候・曜日・地域イベントなど需要を左右する変数が多く、担当者の経験だけに頼った予測では精度に限界がある
3. **規制対応文書の作成負荷**: 食品表示法にもとづく栄養成分表示・アレルゲン表示、HACCPの記録・手順書は、新商品を出すたびに(あるいは原材料が変わるたびに)作成・更新が必要で、中小の食品メーカーほど専任の表示担当者を置けず負担が大きい

技術的には、(1)ディープラーニングによる画像の異常検知・分類モデルを使ったAI外観検査、(2)POSデータ・気象データ等を学習させた需要予測AI、(3)ChatGPT・Claude・Geminiなど汎用チャットAIによる新商品アイデア出し・表示文書・報告書のドラフト作成、という3つの型で普及が進んでいる。(1)(2)は専用ベンダーのSaaS・システム導入が中心、(3)は商品開発・品質保証・表示担当者が汎用チャットAIを直接使うケースが増えている。

## 使いどころ・使い分け

| 業務 | 主な用途 | 向いているツールの型 |
|---|---|---|
| 新商品・レシピのアイデア出し | 過去の商品データ・嗜好データから新しい食材の組み合わせ・味のバランスを提案 | 汎用チャットAI + 自社の商品・嗜好データを学習させた専用AIエンジン |
| 異物混入検査・外観検査 | 金属探知機で検知できない異物(ビニール片、殻・毛髪、規格外の形状)の画像判定 | AI画像判定サービス(ディープラーニングによる異常検知・分類) |
| 生鮮品・短賞味期限品の需要予測 | 天候・曜日・イベント情報を踏まえた製造数・発注量の予測 | 需要予測特化AI + POS/出荷実績データ連携 |
| 食品表示・栄養成分表示のドラフト作成 | 原材料・レシピ情報から栄養成分表示、原材料表示、アレルゲン表示の下書きを自動生成 | 食品表示特化AI(専用SaaS)、または汎用チャットAI(下書きレベル) |
| HACCP関連文書・食品安全報告書のドラフト作成 | 衛生管理計画、日次記録、逸脱(異常)発生時の対応記録の下書き作成 | HACCP文書作成支援SaaS、または汎用チャットAI(下書きレベル) |
| アレルゲンチェック支援 | レシピ変更時に特定原材料8品目の混入リスクを洗い出す一次チェック | 汎用チャットAI(一次チェックのたたき台。最終判断は不可) |
| サプライヤー・原材料調達分析 | 複数原料候補の価格・品質・供給安定性の比較レポート作成 | 汎用チャットAI(データ整理・比較表作成) |
| パッケージデザインのコピー作成 | 商品パッケージのキャッチコピー・商品説明文の案出し | 汎用チャットAI + デザイナーによる仕上げ |

判断基準:

- **食品安全・法令表示に関わる最終判断**(アレルゲン表示、賞味期限設定、HACCPの管理基準)→ AIは下書き・一次チェックまでとし、最終確認は必ず品質保証部門・有資格者(食品表示診断士等)が行う
- **数値に基づく意思決定**(製造数・発注量・原材料調達先の選定)→ AIはレポート・示唆出しまで、最終判断は生産管理・購買担当者が行う
- **創造的な発想支援**(新商品アイデア、パッケージコピー案)→ AIに複数案を出させ、人が選定・磨き込む使い方が向く

## 実務での使い方

### 事例1: AI画像検査による異物混入・外観不良の検出

株式会社YE DIGITALのAI画像判定サービス「MMEye」は、食品工場の外観検査に広く使われている。お菓子の生産ラインでは半製品段階の外観検査に導入され、従来のルールベース(あらかじめ決めた基準で判定する方式)のシステムでは分類が難しかった不良品の判別に効果を上げている。また、ひじきや昆布など一つひとつの形が異なる個体差の大きい食品では、人の目視では見つけにくいビニール片や、アレルギー表示対象になっている小さなエビ・カニの殻の破片といった異物を的確に検知できるという(専門知識がなくても導入できる点も評価されている)。豆腐の割れ・欠けの検出など、金属探知機では発見できない異物・形状不良の検知にAI画像検査を使う事例は食品業界で広がっている([mmeye.site 導入事例](https://mmeye.site/contents01/)、[PR TIMES(YE DIGITAL)](https://prtimes.jp/main/html/rd/p/000000021.000065567.html))。

**自社への応用ヒント**: 金属探知機・X線検査機で発見できる異物(金属片・骨片)と、AI画像検査でしか発見しにくい異物(ビニール片・毛髪・アレルゲン食材の破片)は種類が異なる。既存の検査機で拾えていない異物の種類を洗い出し、そこにAI画像検査を組み合わせるのが投資対効果を出しやすい。

### 事例2: 賞味期限が短い商品の需要予測・生産計画

惣菜・弁当のように賞味期限が短い商品を扱う食品メーカーでは、過去の販売実績に加えて天気予報・地域のイベント情報・曜日をAIが分析し、製造数を高精度に算出する需要予測の活用が進んでいる。複数工場を持つメーカーでは、数日先の見込み需要量と工場ライン別の稼働時間を組み合わせ、コストが最小となる生産・物流の振り分けパターンを算出する取り組みも報告されている([BrainPad DOORS DX](https://www.brainpad.co.jp/doors/contents/02_ai_case_study_food_manufacturer/)、[GENIEE's library](https://geniee.co.jp/media/cdp/demand-forecasting-food/))。ハウス食品とNECなど、自社単独ではなく業界横断・メーカー横断で需要予測やサプライチェーンの仕組みを構築する動きもある([AI革命メディア](https://ai-revolution.co.jp/media/ai-in-food-production/))。

**コピペで使える製造数提案レポート作成プロンプト例**(需要予測AIやPOSデータの数値を人がまとめ、生産管理会議向けレポートの文章化を汎用チャットAIに任せる想定):

```
あなたは食品メーカーの生産管理担当者です。以下のデータをもとに、
来週の製造数提案レポートを作成してください。最終的な製造数の決定は
生産管理責任者が行うため、あなたの役割は「根拠を整理して提案すること」です。

# 入力データ
- 過去4週間の商品別・曜日別の出荷実績: (ここに数値を貼り付け)
- 来週の天気予報: (例: 週末は気温上昇、惣菜は傷みやすいため製造ロット調整が必要)
- 販売先(スーパー等)からの発注見込み・イベント情報: (例: 月末に大手取引先で催事あり)
- 主要原材料の現在庫と使用期限: (ここに数値を貼り付け)

# 出力形式
- 商品ごとに「予測出荷数」「推奨製造数(通常比+/-%)」「根拠」を表形式で
- 賞味期限の短さを踏まえ、製造数を増減させる場合はロス・欠品それぞれの
  リスクを1〜2行で明記
- レポート末尾に「本提案は目安であり、最終製造数は在庫・需要動向を踏まえて
  生産管理責任者が決定してください」という一文を必ず入れる
```

### 事例3: 新商品・レシピ開発のアイデア出し

味の素は、蓄積してきた1万種類を超えるレシピデータと栄養に関する知見を組み合わせた「献立作成エンジン」を開発し、個人の好き嫌い・運動習慣・減塩ニーズなどの条件に沿った献立を提案する「未来献立®」サービスを2024年3月に開始した(Laboro.AIと共同開発)。前日の食事内容を踏まえてバランスを補う「ツジツマあわせ」機能も備える([Laboro.AI](https://laboro.ai/press/202407311/)、[味の素グループ ストーリー](https://story.ajinomoto.co.jp/health/001.html))。また味の素冷凍食品は生成AIツール「ChatSense」を全社導入し、レシピ開発や商品評価結果の分析といった食品業界ならではの業務に活用している([ChatSense導入事例](https://chatsense.jp/case/ajinomoto-reito))。
日清食品ホールディングスでも、マーケティング部門で生成AIの利用率が9割を超え、過去の商品データや消費者の嗜好データをもとに新しい原材料の組み合わせや味のバランスを提案させ、パッケージデザインのアイデア出しをデザイナーが仕上げに使う運用が報告されている(社内で100種類超の「プロンプトテンプレート」を整備し、事実確認ルールや専門家による最終判断を必須とすることで出力の不正確さやセキュリティリスクに対応している)([AI総合研究所](https://www.ai-souken.com/case/333)、[note](https://note.com/ndot_man/n/na3d90c716ba4))。

**コピペで使える新商品アイデア出しプロンプト例**:

```
あなたは食品メーカーの商品開発担当です。以下の条件で、新商品のアイデアを
5案考えてください。

# 条件
- カテゴリ: (例: 即席麺、冷凍食品、レトルト惣菜など)
- ターゲット層: (例: 単身の30〜40代、健康志向で減塩ニーズがある層)
- 差別化したい軸: (例: 低塩分でも満足感のある味、時短調理)
- 使いたい/使いたくない原材料: (ここに記入)
- 想定売価帯: (例: 300〜400円)

# 各案について出力してほしい内容
1. 商品コンセプト(1〜2行)
2. 主要原材料の組み合わせ案
3. 味・食感の特徴
4. 差別化ポイントが競合とどう違うか
5. パッケージ訴求文案(20〜30文字)

# 注意
- 特定原材料8品目(えび・かに・くるみ・小麦・そば・卵・乳・落花生)を
  使う場合は必ず明記してください
- 実在商品名の模倣にならないよう、コンセプトはオリジナルにしてください
- 提案はあくまでアイデアのたたき台であり、最終的な原材料選定・製法は
  試作・官能評価を経て担当者が決定する前提で出力してください
```

### 事例4: 食品表示・栄養成分表示のドラフト作成

食品表示は、原材料名・添加物・アレルゲン・栄養成分などを食品表示法にもとづき正確に記載する必要があり、特に中小の食品メーカーでは専任担当者がいないケースも多い。「Swallow」(株式会社ROX)はレシピ・原材料情報を入力するだけでアレルギー表示・栄養成分・添加物・名称・内容量などの表示ラベルを自動生成するAIツールで、異能vationで受賞している([ROX](https://www.rox-jp.com/post/食品表示の自動作成ai「swallow」が異能vationで受賞))。「ウラベル」はレシピから食品表示と栄養成分表示をワンクリックで自動作成し、最新の日本食品標準成分表・食事摂取基準に対応する([ウラベル](https://s-hyoji.com/))。これらは表示作成の時間・費用を大幅に削減する一方、最終的な表示内容の適法性チェックは人が行う前提で設計されている。

**コピペで使える栄養成分表示・原材料表示ドラフト作成プロンプト例**(専用ツールがない場合の一次ドラフト用。法的な最終確認は必須):

```
あなたは食品メーカーの表示担当者の下書き作成を補助するアシスタントです。
以下のレシピ情報から、食品表示法の様式に沿った表示のたたき台を作成して
ください。ただし、あなたが作成するのはあくまで下書きであり、最終的な
適法性の確認は表示担当者・品質保証部門が行うことを前提とします。

# レシピ情報
- 商品名: (ここに記入)
- 使用原材料と配合比率(重量順): (ここに記入)
- 添加物: (ここに記入)
- 内容量: (ここに記入)

# 出力してほしい内容
1. 原材料名表示(重量順、添加物は別区分で記載)
2. アレルゲン表示案(特定原材料8品目: えび・かに・くるみ・小麦・そば・卵・乳・
   落花生が含まれる場合は個別表示形式で明記。表示スペースの都合で一括表示に
   する場合の案も併記)
3. 栄養成分表示(熱量・たんぱく質・脂質・炭水化物・食塩相当量)の概算値と、
   実測値での確認が必要な旨の注記
4. 「本表示案は下書きであり、実際の表示前に必ず社内の表示担当者・
   品質保証部門による確認を行ってください」という注記
```

### 事例5: HACCP関連文書・食品安全報告書のドラフト作成

HACCP(危害要因分析重要管理点)は、原材料の受入から出荷までの工程で発生しうる危害要因を分析し、重要管理点(CCP)を定めて記録する食品衛生管理の国際標準で、日本では2021年6月からすべての食品等事業者に制度化された衛生管理の実施が義務付けられている。「HACCP-Planner」のように製品情報・工程・危害要因・CCPを入力すると記録表のたたき台を自動生成するシステムや、「ハサログAI」のように飲食店・宿泊施設向けに衛生管理計画・記録作成を支援するツールが普及している([HACCP-Planner](https://www.haccp-plan.jp/index.html)、[ハサログAI](https://www.haccp-log.jp/%E3%80%8E%E3%83%8F%E3%82%B5%E3%83%AD%E3%82%B0ai%E3%80%8F%E3%81%A8%E3%81%AF%EF%BC%9F/))。定型フォーマットが決まっているHACCP文書は、汎用チャットAIでも「過去の記録の書式」を渡して同じ書式で下書きを作らせる使い方ができる。

**コピペで使える食品安全逸脱(異常)報告書ドラフト作成プロンプト例**(工程で基準からの逸脱が発生した際の一次報告書作成支援。最終承認は品質保証責任者が行う前提):

```
あなたは食品工場の品質保証担当者の報告書作成を補助するアシスタントです。
以下の事実関係から、HACCP逸脱(重要管理点の基準からの逸脱)報告書の
下書きを作成してください。

# 事実関係
- 発生日時・工程: (ここに記入)
- 重要管理点(CCP)と本来の管理基準: (例: 加熱工程、中心温度75℃以上1分間)
- 実際に確認された数値・状況: (例: 中心温度68℃を記録)
- 発見の経緯: (ここに記入)
- その場で行った応急処置: (ここに記入)

# 出力形式
1. 事案の概要(3〜4行)
2. 発生原因の考えられる要因(推測であることを明記)
3. 対象ロットの取り扱い方針の選択肢(例: 出荷停止、再加熱、廃棄)を
   複数提示し、判断は品質保証責任者が行う旨を明記
4. 再発防止のための確認事項リスト(たたき台)
5. 文末に「本報告書は下書きです。原因究明・対象ロットの最終処置・
   再発防止策の決定は品質保証責任者の確認・承認を経てから確定してください」
   という注記
```

### 事例6: サプライヤー・原材料調達分析、パッケージコピー作成

原材料の調達では、複数の候補サプライヤーの価格・供給安定性・品質実績・産地リスクなどを比較する一次分析に汎用チャットAIを使い、比較表のたたき台を作らせる使い方が実務で広がっている(詳細な考え方は[購買・調達職における生成AI活用事例](../part15-job-role-cases/procurement-ai-use-cases.md)を参照)。パッケージデザインのコピー作成では、日清食品の事例のように過去の商品訴求文・キャンペーンメッセージのデータをもとにAIに複数案を出させ、デザイナー・コピーライターが仕上げる分業が一般的である。

## 注意点・よくある誤解

- **食品安全・法令表示の最終判断はAIに委ねない**: アレルゲン表示、賞味期限設定、HACCPの管理基準・逸脱時の対応方針は、生成AIの提案をそのまま採用せず、必ず品質保証部門・有資格者が最終確認する。表示の記載漏れ・誤表示は健康被害や自主回収に直結する重大リスクである
- **特定原材料8品目は法改正で増減する**: 2025年4月から「くるみ」が特定原材料(義務表示対象)に追加され、現在は「えび・かに・くるみ・小麦・そば・卵・乳・落花生」の8品目が義務表示対象となっている。AIに表示案を作らせる際は、プロンプトの前提知識(品目リスト)が最新かどうかを都度確認する必要がある
- **AI画像検査は「導入して終わり」ではない**: MMEyeのような画像判定AIも、検出対象の異物・不良パターンを学習データとして継続的に追加しないと精度が維持できない。金属探知機・X線検査機と役割が異なる(検出できる異物の種類が違う)ことを理解し、既存の検査機とどう組み合わせるかを設計する
- **需要予測AIは長年のデータ蓄積が前提**: 賞味期限の短い商品の需要予測は、POSデータや出荷実績を長期間蓄積して初めて精度が出る。データ基盤が薄い状態でAIツールだけ導入しても効果は限定的
- **生成AIと画像認識AI・時系列予測AIを混同しない**: 本ページで扱った異物検査・需要予測の多くは従来型の機械学習(画像分類・時系列予測)が主役で、生成AI(LLMや対話型AI)は新商品アイデア出しや文書ドラフト作成の部分を補完している。全工程を生成AI単体でまかなえるわけではない

## 最初の一歩

自社で直近に作成した食品表示・HACCP記録・逸脱報告書のいずれか1件を選び、その書式(項目立て)を汎用チャットAIに渡して「同じ書式で次回分の下書きを作らせる」ことから始めるとよい。出てきた下書きを品質保証担当者が何分で確認・修正できるかを試すと、AI活用の効果測定になる。
