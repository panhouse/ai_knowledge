# 暗号資産・仮想通貨取引所業界における生成AI活用事例

## これは何か

暗号資産・仮想通貨取引所(bitFlyer・Coincheck・SBI VCトレード・GMOコインなど、資金決済法上の「暗号資産交換業者」)は、①犯罪収益移転防止法(犯収法。マネー・ローンダリングやテロ資金供与を防ぐために事業者に本人確認や取引記録の保存を義務付ける法律)に基づく厳格な本人確認(KYC: Know Your Customer)と継続的な取引監視(AML: Anti-Money Laundering、資金洗浄対策)、②価格が24時間365日動き続ける市場に伴う問い合わせの多さ、③海外ユーザーを含む多言語対応、という他の金融業態以上に負荷の高い業務を抱える。生成AIは、この「大量データの一次スクリーニング」と「定型文章の自動応答・生成」を担う形で導入が進んでいる。本ページは、銀行・保険・証券を含む金融業界全般を扱う[金融・保険における生成AI活用事例](finance-insurance-ai-use-cases.md)、決済代行・BNPLなどを扱う[決済・フィンテック業界における生成AI活用事例](payment-fintech-industry-ai-use-cases.md)とは切り分け、**暗号資産交換業に固有の本人確認・AML・トラベルルール(暗号資産の送付時に送付人・受取人情報を通知する国際ルール)**に絞って、2026年9月時点の実例を整理する。

## 仕組み・背景

暗号資産交換業者のAI活用は、大きく3つのレイヤーで進んでいる。

1. **コンプライアンス・リスクレイヤー**: eKYC(オンラインで完結する本人確認)における書類の真正性チェック・なりすまし検知、AML取引モニタリングにおける疑わしい取引の一次スコアリング
2. **顧客接点レイヤー**: 口座開設・入出金・パスワード再設定といった定型問い合わせに応えるAIチャットボット、多言語でのサポート
3. **市場情報レイヤー**: オンチェーンデータ・相場データを自然言語で要約するマーケットインテリジェンス

背景には規制の整備がある。2017年施行の改正資金決済法で暗号資産交換業の登録制度が始まり、犯収法により本人確認・疑わしい取引の届出が義務付けられた。2022年4月には日本暗号資産等取引業協会(JVCEA)の自主規制規則としてトラベルルールが導入され、2023年6月の犯収法改正で法定化された。AML・不正検知の分野は2010年代からルールベース・機械学習(統計的にパターンを学習するAI)が主流だったが、大量のルールを定期的に見直す必要があり誤検知(false positive)が多いという課題があった。2021年前後からDataRobotのようなクラウドAutoML(自動で機械学習モデルを構築するツール)により、自社データだけで短期間にAIモデルを内製できるようになり、2024年以降はここに生成AI(LLM)による「スコアの根拠を自然言語で説明する」「自然言語でオンチェーンデータに質問する」層が加わりつつある。業界の姿勢を象徴する動きとして、bitFlyer Holdingsは2026年4月にCEO直轄の「AI戦略室」を新設し、AIとブロックチェーンを掛け合わせた次世代金融インフラの研究開発を掲げている。

## 使いどころ・使い分け

| 業務 | AI活用の向き不向き | 理由 |
|---|---|---|
| 本人確認書類(運転免許証等)の画像解析・真正性チェック | 向く | 改ざん検知・顔照合(liveness detection、なりすまし防止のための生体検知)はAIが得意とする画像解析領域 |
| 取引の異常検知・疑わしい取引の一次スコアリング | 向く | 大量の取引ログからパターンを見つけAIがリスクスコアを付与する一次スクリーニングは、人手では不可能な規模をカバーできる |
| 疑わしい取引の「届出」の最終判断 | 向かない(必ず人が最終判断) | 犯収法上、疑わしい取引の届出をするか否かの最終判断は特定事業者(暗号資産交換業者)の責任。AIのスコアはあくまで一次情報で、コンプライアンス責任者の確認を経る必要がある |
| 口座開設・入出金・パスワード再設定などの定型問い合わせ | 向く | FAQで対応できる定型的な質問が多く、24時間対応が必要な業態と相性がよい |
| 相場変動時の投資判断・値動き予想を利用者に直接回答する | 向かない(要ガードレール) | 断定的な価格予想は利用者保護上のリスクが大きく、誤解を招く広告・勧誘として問題視されうる。AIの回答は一般的な情報提供に限定し、フィルタリングを設ける |
| システム障害・大口出金予定など未公表の内部情報の要約 | 向かない(外部AIへの入力は原則不可) | 一般公開の生成AIサービスに入力すると、情報漏洩やフロントランニング(先回り取引)を招くリスクがある。社内クローズド環境に限定する |

判断に迷う場合は、[生成AIに向く業務・向かない業務の切り分け](../part12-business-practice/ai-task-suitability.md)の基本チェックに加えて、「犯収法上の本人確認・疑わしい取引の届出義務、および資産保全に関わる最終判断を代替していないか」を必ず4つ目の判断軸として加えること。

## 実務での使い方

### 1. eKYC・本人確認の自動化

対面・郵送を経ずにスマートフォンで本人確認を完結させるeKYCは、暗号資産交換業者が最も早くAIを実装した領域である。

| 事業者 | サービス | 内容 |
|---|---|---|
| bitFlyer | クイック本人確認 | 2019年12月開始。スマートフォンで本人確認書類と顔写真・動画を撮影するだけで、情報が一致すれば最短即日で口座開設が完了するeKYC。LIQUID社のeKYC技術を採用 |
| 各社共通 | AI-OCR + 顔照合(liveness detection) | 本人確認書類の文字をAIが自動読み取りし、書類の写真と自撮り動画を照合してなりすまし・偽造書類を検知する仕組みが業界標準になっている |

eKYCベンダーの詳しい比較は[eKYC・本人確認AI企業一覧](../part16-japan-ai-companies/ekyc-identity-verification-ai-companies-japan.md)を参照。

### 2. AML・不正取引検知

- **Coincheck × DataRobot**: 2021年9月、DataRobotのAutoML(自動で機械学習モデルを構築する機能)を活用し、不正取引検知・アンチマネーロンダリング用のAIモデルを開発開始からわずか2ヶ月で内製構築・本番運用に至ったと発表。リスクをスコアリングするだけでなく判断根拠を提示できる点、および「DataRobot MLOps」の併用により手口が変化し続ける不正取引に対してモデルの劣化を自動検知できる点が特徴
- **TRM Labs**: 2025年3月、自然言語の質問をブロックチェーン横断の調査クエリに変換するAIエージェントを発表。パイロット導入では調査にかかる時間が60〜80%短縮したと報告されている
- **Chainalysis**: 数百のクラスタリング・ヒューリスティクスと機械学習を組み合わせ、ウォレットアドレスを実体(取引所・詐欺グループ等)ごとにグルーピングする分析基盤を提供。法執行機関向け調査での採用が多い
- **マネー・ローンダリング対策共同機構(CAML)**: 銀行・暗号資産交換業者などが共同出資する組織で、2025年4月からAIスコアリングサービスの提供を開始。2026年3月には不正利用口座情報の共有システムの開発も進めている

**コピペで使えるプロンプト例(疑わしい取引の一次レビュー・要約ドラフト)**:

```
あなたは暗号資産交換業者のAML担当者です。以下の取引アラート情報を読み、
コンプライアンス責任者向けの一次レビューメモを作成してください。

1. アラートが検知したパターン(入出金の頻度・金額・送付先など)を箇条書きで要約
2. 過去の類似アラートとの共通点・相違点(わかる範囲で)
3. 追加で確認すべき情報(本人確認情報、取引履歴のうち未確認の部分など)
4. このメモはあくまで一次スクリーニングであり、疑わしい取引の届出要否の
   最終判断はコンプライアンス責任者が行う旨を末尾に明記する

[取引アラートの詳細情報を貼り付け]
```

出力はあくまで人間の判断を補助する一次ドラフトであり、届出要否の最終判断・実際の届出はAIに代替させない。

### 3. カスタマーサポート・多言語対応

- **SBI VCトレード × KARAKURI**: 2022年11月、TaoTaoとの合併(2021年12月)・サービス統合(2022年6月)に伴い問い合わせが急増したことを受け、高精度AIチャットボット「KARAKURI chatbot」と有人チャット「KARAKURI talk」を導入。24時間対応の「サポートコンシェルジュ」として運用し、応答率90%・満足率60%を達成
- 暗号資産市場は土日・深夜も価格が動くため、入出金トラブルやログインエラーなど緊急性の高い定型質問にAIチャットボットが一次対応し、複雑な案件のみ有人チャットにエスカレーションする分業が実務的な型になっている

### 4. トラベルルール対応

トラベルルール(暗号資産の出金依頼を受けた交換業者が、出金先の交換業者に送付人・受取人情報を通知する義務)は2022年4月にJVCEA自主規制規則として導入され、2023年6月の犯収法改正で法定化された。2026年8月時点で金融庁が指定する通知対象国・地域は順次拡大されている。現時点でのトラベルルール対応は専用の通知システム(Sygna、TRUSTなど)による自動化が中心で、生成AIの活用はまだ限定的だが、送付先交換業者との情報照合結果を人間が確認する際の要約・差分抽出に生成AIを補助的に使う余地がある。

### 5. 相場・オンチェーンデータのマーケットインテリジェンス

- **Amberdata Intelligence**(Kaikoが2026年6月に買収): 機関投資家向けに、オンチェーンデータ・相場データに自然言語で質問すると即座に回答が得られるAI駆動のマーケットインテリジェンス機能を提供。デリバティブ分析(インプライドボラティリティ等)にも対応
- 国内の暗号資産交換業者自身による相場コメント・レポート生成への生成AI活用は、2026年9月時点ではまだ限定的で、社内の情報収集・ドラフト作成支援としての利用が中心である

### 主要ツール横断の対応(暗号資産交換業界)

| 目的 | 主なツール・サービス |
|---|---|
| 本人確認(eKYC)の自動化 | LIQUID eKYC、TRUSTDOCK、xID などの国内eKYCベンダー(詳細は[eKYC・本人確認AI企業一覧](../part16-japan-ai-companies/ekyc-identity-verification-ai-companies-japan.md)) |
| AML・不正取引検知のAIモデル内製 | DataRobot(AutoML・MLOps) |
| オンチェーン取引の調査・分析 | Chainalysis、TRM Labs |
| 問い合わせ対応・カスタマーサポート | KARAKURI chatbot/talk など国産AIチャットボット(詳細は[AML・取引不正検知AI企業一覧](../part16-japan-ai-companies/aml-fraud-detection-ai-companies-japan.md)) |
| 機関投資家向け相場・オンチェーンデータ分析 | Amberdata Intelligence(Kaiko) |
| 社内の文書作成・調査(汎用生成AI) | 各社が導入する法人向け生成AIプラットフォーム(セキュアな社内環境での利用が前提) |

## 注意点・よくある誤解

- **疑わしい取引の届出の最終判断はAIに委ねられない**: 犯収法上、疑わしい取引に該当するかどうかの届出義務を負うのは暗号資産交換業者自身であり、AIのスコアリングはあくまで一次スクリーニング。最終的な届出要否の判断は必ずコンプライアンス責任者が行う体制を維持する
- **断定的な価格予想・投資助言はリスクが大きい**: 生成AIが「今後値上がりする」「元本は減らない」といった断定的な表現を出力し、それをそのまま利用者への案内に使うと、利用者保護や広告規制の観点から問題になりうる。顧客向けの出力には断定表現をフィルタリングする仕組みを設ける
- **未公表の内部情報を一般公開の生成AIに入力しない**: システム障害情報、大口出金予定、新規取扱い暗号資産の審査状況など未公表の情報を外部の生成AIサービスに入力すると、情報漏洩やフロントランニングのリスクにつながる。社内で完結するセキュアな環境(法人向け生成AI基盤)を用いる。詳しくは[情報漏洩対策の基礎](../part04-risk-security/information-leakage-prevention.md)を参照
- **AMLの「AI」と生成AIを混同しない**: 不正検知AIの中核は依然として機械学習ベースのスコアリングモデルであり、生成AI(LLM)はスコアの根拠説明・レビューメモ作成など付随的な役割を担うことが多い。「生成AIが不正を自動で見抜く」という単純化した理解は避ける
- **数値・残高情報の要約は必ず一次データと突合する**: 入出金額や残高の要約に生成AIのハルシネーション(事実に基づかない出力)が混入すると、金銭トラブルに直結する。カスタマーサポートの回答文も、金額や口座状態に関する記載は必ずシステム上のデータと自動連携・突合させる
- **金融庁のAI関連ガイダンスは暗号資産交換業も対象になりうる**: 金融庁は2026年3月に「AIディスカッションペーパー」第1.1版を公表し、モデルリスク管理・説明可能性・公平性・個人情報保護などをAI活用の論点として整理している。暗号資産交換業者も金融庁監督下の事業者であり、導入前にガバナンス体制の整備が求められる

## 最初の一歩

自社(または担当している)暗号資産交換業者のFAQ・問い合わせテンプレートを1つ選び、生成AIで英語・中国語など多言語の回答文ドラフトを作成し、既存のカスタマーサポート担当者に精度をレビューしてもらうところから始めるとよい。
