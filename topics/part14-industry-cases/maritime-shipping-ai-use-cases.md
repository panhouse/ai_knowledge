# 海運・港湾業界における生成AI活用事例

## これは何か

海運・港湾業界は、燃料費・輸送日数の削減という経済的インセンティブが大きい一方、船舶運航データ・港湾混雑状況・通関書類という構造化しやすいデータを大量に扱う業種であり、AI・生成AIによる最適化の効果が数字で出やすい領域である。本ページは、[物流・運輸における生成AI活用事例](logistics-transportation-ai-use-cases.md)がトラック輸送・2024年問題(トラックドライバーの時間外労働規制強化)を中心に扱うのに対し、船舶運航の最適化・自動運航船・港湾ターミナルの自動化・通関書類の作成支援という、海運・港湾業界に固有の業務に絞って整理する事例カタログである。日本郵船(NYK)・商船三井(MOL)・川崎汽船(K Line)の日本3大海運会社がいずれも2025〜2026年にかけてAI活用を本格導入段階に進めており、実運用フェーズに入った事例が増えている。

## 仕組み・背景

海運・港湾業界のAI・生成AI活用は、大きく4つの領域に分かれる。

1. **船舶運航の最適化・意思決定支援**: 気象予報・海上交通・配船計画などの大量データをAIが分析し、燃費効率の良い航路・速度や配船計画を提案する。日本郵船が開発した船舶情報一元管理システム「SIMS」(Ship Information Management System)は、船舶データをリアルタイムに共有する仕組みで、燃料費を約10%削減したと報告されている([FPTジャパンホールディングス](https://fptsoftware.jp/resource-center/blog/column/ai-applications-in-the-maritime-industry))。日本郵船とグループ会社MTIはグリッドと共同で自動車専用船の配船計画を最適化するAIシステムを開発し、2025年7月から本格運用を開始した。数カ月先までの配船計画について数百万通りの組み合わせを約10分で試算し最適解を導く仕組みで、GHG(温室効果ガス)排出削減にも貢献するとしている([NYKニュース](https://www.nyk.com/stories/04/01/20260518.html)、[Impress dcross](https://dcross.impress.co.jp/docs/usecase/004267.html))。商船三井は2026年7月1日、日本IBMと共同で、世界中を航行するグループ船舶の安全運航を支援する「安全運航支援センター(SOSC)」を中核に、気象・海象や航行状況、地政学動向などの分散情報を一元管理し運航の意思決定を高度化するAIプラットフォームを開発したと発表した([海事プレス](https://www.kaijipress.com/news/shipping/2026/07/202560/)、[MONOist](https://monoist.itmedia.co.jp/mn/articles/2607/02/news031.html))。商船三井は船員の配乗計画(乗組員の乗船スケジュール調整)にもAIを導入し、2025年5月の本格適用以降、計画作成の作業時間を約7割削減したと報告している([日経クロステック](https://xtech.nikkei.com/atcl/nxt/column/18/00678/052200156/))。川崎汽船は約300隻にAIデータ解析を導入し燃費予測精度98〜99%を実現しているほか、船舶の機関室点検業務「M0チェック」をデジタル化する「電子M0チェックシステム」を開発し、2026年7月から管理船へ順次導入している([日本経済新聞](https://www.nikkei.com/article/DGXZQOUC0873P0Y6A600C2000000/))。海外ではAIによる最適航路・速度・トリム(船体傾斜)の調整で、船隊全体の燃料消費を10〜15%削減できるという報告もある([DigitalDefynd](https://digitaldefynd.com/IQ/ai-use-in-the-shipping-industry-case-studies/))。
2. **自動運航船(オートノマスシップ)**: 船員不足・高齢化に対応するため、AIによる航行判断の自動化が国内でも実用段階に入っている。日本財団が主導する無人運航船プロジェクト「MEGURI2040」の第2ステージでは、2026年3月27日、内航貨物船「玄武」を含む実証船4隻が国土交通省の自動運航船認証を取得し、商用運航下でSAE(自動車技術会が定める自動化レベルの国際基準)レベル4相当の自動運航機能を実現したと発表された。単なる実証実験ではなく商用運航での認証取得という点で、自動運航船の社会実装が新たな段階に入ったことを示す事例である([商船三井プレスリリース](https://www.mol.co.jp/pr/2026/26023.html)、[PR TIMES](https://prtimes.jp/main/html/rd/p/000000532.000092744.html))。同財団は2040年までに内航船の50%を無人運航船に転換する目標を掲げている。
3. **船級協会によるAI活用支援**: 船舶の安全基準を審査する船級協会(Classification Society、船舶の設計・建造・運航が安全基準を満たすか検査・認証する第三者機関。日本ではClassNKが代表格)自身もAIの導入を進めている。ノルウェーのDNVは2026年3月24日、AIツール「RuleAgent」を外部公開した。DNVの規則・基準は30,000ページ・60万段落超にまたがるため、自然言語で質問すると該当する規則の要約と原文へのリンクを即座に返す仕組みで、対象は船舶規則(RU SHIP)・洋上構造物規則(RU OU)・クラスガイドライン等に及ぶ([DNVニュース](https://www.dnv.com/news/2026/new-dnv-ai-tool-makes-maritime-rules-easier-to-navigate/)、[Motorship](https://www.motorship.com/monitoring-control-and-digitalisation/dnv-launches-ai-rules-assistant/1508689.article))。あくまで規則検索・要約の効率化であり、最終的な設計適合判断は船級のサーベイヤー(検査官)が行う。
4. **港湾ターミナルの自動化・混雑予測、通関書類・HSコード分類の作成支援**: オランダのロッテルダム港はAIをスケジューリングと動線計画に組み込みコンテナヤードの混雑を抑制し、韓国の釜山港はAI駆動のメタバースシステムで数日先の船舶到着を予測して排出量を監視し、船舶の定時到着率が79%改善、年間730万ドルの追加直接収益が見込まれるという試算が報告されている([globaltrademag](https://www.globaltrademag.com/how-ai-illuminates-the-path-to-efficient-port-management/))。日本でも2026年度予算で、船舶大型化に対応したコンテナターミナル整備やAI活用による港湾業務高度化が進められている([LNEWS](https://www.lnews.jp/2026/04/s0408101.html))。通関書類はHSコード(輸出入する貨物を分類する国際的な商品分類コード)の正確な選定と定型フォーマットへの記入が必要な業務であり、AI-OCR(画像認識で紙の帳票をテキスト化する技術)と生成AIの組み合わせが効果を発揮する。安田倉庫はAI-OCR「スマートOCR」により通関申告書類作成工数を約50%削減しているほか、2026年4月からはHacobuのAI-OCRサービス「MOVO Adapter」を平和島支店に導入し、生成AIで入出荷依頼書の内容を読み取り自動データ化する運用を始めている([LNEWS](https://www.lnews.jp/2026/06/s0602702.html))。貿易DX企業Shippioは2025年9月、AI通関クラウド「Shippio Clear」の提供を開始した。読み取り精度97%のAI-OCRで貿易書類を読み取り、品目ごとの自動計算・正誤確認を行った上でNACCS(輸出入・港湾関連情報処理システム)申告書フォーマットへ自動変換する仕組みで、協和海運との実証では通関業務全体を約7割効率化したと報告されている([Shippioプレスリリース](https://www.shippio.io/news/press-release/shippio-clear/))。NECもHSコード特定業務を生成AIで支援するシステムを開発しており、経験の浅い担当者でも分類候補を絞り込めるようにすることで通関士不足に対応するとしている([日本海事新聞](https://www.jmd.co.jp/article.php?no=298939))。

## 使いどころ・使い分け

| 業務 | AI・生成AIが向く | 向かない/慎重にすべき理由 |
|---|---|---|
| 航路・速度・配船計画の最適化(燃費削減) | 向く(気象・海上交通・配船データの機械学習分析) | 最終的な航行判断は船長・運航管理者が安全性を踏まえて行う |
| 内航船の自動運航(定型航路・低リスク環境) | 向く(MEGURI2040のように認証を取得した範囲では実運用可) | 全船種・全航路への適用にはまだ制約が大きく、緊急時は人による介入が前提 |
| 船級規則・基準の検索(RuleAgentのような用途) | 向く(自然言語での規則検索・要約) | 最終的な設計適合・安全基準の判断は船級のサーベイヤーが行う |
| 港湾ターミナルの混雑予測・スケジューリング | 向く(到着予測・動線計画の自動化) | 荷役作業員の安全管理・緊急時対応は人の判断が必須 |
| 通関書類のHSコード分類・下書き作成 | 向く(AI-OCRと生成AIの組み合わせによる一次分類) | 最終的な申告内容の正確性は通関士・貿易実務担当者が確認する |
| 船舶事故・トラブル対応の一次報告書作成 | 向く(定型フォーマットへの下書き) | 事故原因の特定・責任判断は人が行う |
| 荷主向けの運賃・納期の最終回答 | 限定的 | 市況変動・契約条件を踏まえた最終判断は営業担当者が行う |

## 実務での使い方

### プロンプト例1: 通関書類の記載内容チェック

```
以下の輸出貨物の品目情報をもとに、想定されるHSコード(輸出入貨物の分類コード)の候補を
2〜3つ提示し、それぞれどのような基準で分類されるかを1行で説明してください。
最終的な確定は貿易実務担当者が行うことを前提に、判断の参考情報として整理してください。

[貨物の品目・素材・用途などの情報を記載]
```

出力はあくまで一次候補の提示であり、最終的なHSコードの確定は通関士・貿易実務担当者が行う。

### プロンプト例2: 船舶運航レポートの要約作成

```
以下は今週の船舶運航データ(燃料消費量・航行時間・気象条件)です。
上長への週次報告用に、燃費効率の良かった航路・悪かった航路の傾向を3行程度でまとめてください。
断定的な原因の決めつけは避け、「〜の可能性がある」という推定表現にとどめてください。

[航路別の運航データを貼り付け]
```

原因の最終確認は運航管理部門のヒアリングを経てから報告書に反映する。

## 注意点・よくある誤解

- **航行の最終判断はAIに委ねない**: 航路・速度・配船計画の最適化提案は燃費削減に有効だが、悪天候時の航行可否や緊急時の対応判断は、船長・運航管理者が安全性を最優先に行う。
- **自動運航船の認証はまだ限定的な範囲**: MEGURI2040でSAEレベル4相当の商用運航認証を取得したのは、特定の航路・船種を対象とした実証船4隻にとどまる。全船種・全航路への適用にはまだ制約が大きく、「自動運航船が実用化された」という表現を全面的な無人化と誤解しないよう注意する。
- **船級協会のAIツールは規則検索の効率化であり、適合判断の代替ではない**: DNV「RuleAgent」のようなツールは自然言語での規則検索・要約に強いが、実際の設計・仕様が基準に適合するかの最終判断は船級のサーベイヤーが行う。
- **HSコード分類の最終責任は貿易実務担当者にある**: AIによる一次分類は業務効率化に有効だが、誤分類は関税の追徴課税や通関遅延につながるリスクがある。最終確定は必ず専門知識を持つ担当者が行う。
- **港湾AIターミナルの導入効果は港湾規模による**: ロッテルダム港・釜山港の事例は大規模港湾でのものであり、中小規模の港湾にそのまま同等の効果が見込めるとは限らない。自港の取扱量・インフラ状況を踏まえて投資判断を行う。
- **燃費削減効果や工数削減率は各社の公表事例に基づく個別の数値**: 10〜15%の燃料削減や各社の工数削減率(約50〜70%)は特定の運航条件・業務範囲での報告値であり、船種・航路・業務プロセスによって実際の効果は変動する。

## 最初の一歩

直近の通関書類やHSコード分類の作業を1件選び、チャットAIに分類候補の洗い出しを試させて、貿易実務担当者の確認作業がどれだけ効率化できるかを確認してみる。
