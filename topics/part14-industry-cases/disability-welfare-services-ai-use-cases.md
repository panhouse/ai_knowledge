# 障害福祉サービス事業者における生成AI活用事例

## これは何か

障害福祉サービス事業所(就労継続支援A型・B型、生活介護、放課後等デイサービス、
グループホーム〈共同生活援助〉、相談支援事業所など)は、個別支援計画・支援記録・
モニタリング・国保連請求といった書類作成業務が法令上義務づけられており、
現場の支援員はこの事務作業に多くの時間を割かれている。加えて、サービス管理責任者
(サビ管)・児童発達支援管理責任者(児発管)・相談支援専門員といった有資格者の
不足が慢性化しており、少ない有資格者で計画作成の質を保つことが課題になっている。
本ページは、この**障害福祉サービス事業者**に特化した生成AI活用事例を、
実在するツール・企業の導入例で整理する事例カタログである。

なお、[介護業界における生成AI活用事例](eldercare-ai-use-cases.md)は
介護保険法にもとづく高齢者向け長期ケア(訪問介護・デイサービス・介護施設)を
対象とするのに対し、本ページは障害者総合支援法・児童福祉法にもとづく
障害福祉サービス(就労系・日中活動系・居住系・相談支援)を対象とする。
両者は制度上の根拠法・報酬体系(介護報酬 vs. 障害福祉サービス等報酬)が異なるが、
「訪問介護と居宅介護」「デイサービスと生活介護」のように類似機能のサービスが
並存し、同一法人が両方の指定を受けて運営しているケースも多い。そのため
記録・計画作成の文書負担という課題そのものは共通しており、後述するツールの一部
(かんたん支援記録カンタン支援計画など)は介護・障害福祉の両方を対象にしている。
[医療・ヘルスケアにおける生成AI活用事例](healthcare-ai-use-cases.md)とは、
医師法にもとづく医療行為ではなく、日常生活・就労を支える福祉サービスの
運営業務を扱う点で異なる。

## 仕組み・背景

障害福祉サービスの現場で生成AIが担う役割は、大きく3つに整理できる。

1. **文書作成の下書き自動化**: 面談・支援場面の音声やメモを生成AI(LLMを内蔵した
   専用ソフト、またはChatGPT・Claude・Geminiなどの汎用生成AI)に読み込ませ、
   個別支援計画・支援記録・モニタリング・家族向け報告書などの「たたき台」を作る
2. **アセスメント・計画立案の補助**: 過去の支援記録や本人・家族の希望をもとに、
   課題整理や目標設定、支援内容案を生成AIに提案させる
3. **コミュニケーション支援**: 発語が難しい利用者の意思表示を補う音声認識・
   文章生成、行動の記録・分析を通じた療育メニューの提案など

いずれも共通する前提は、**個別支援計画そのものの決定権・署名責任は
サービス管理責任者・児童発達支援管理責任者・相談支援専門員という
有資格者にあり、生成AIが作るのはあくまで「下書き」「たたき台」**という
位置づけである。この構造は前述の介護分野の「ケアプランはケアマネジャーの
最終確認が前提」という考え方と同じであり、障害福祉サービスの運営基準でも
計画の作成責任者は明確に定められている。

さらに障害福祉サービスは3年に1度の**障害福祉サービス等報酬改定**でルールが
変わる業界であり、令和6年度(2024年度)改定に続き、費用総額の急増
(令和6年度改定後で対前年+12.1%)を受けて令和8年度(2026年度)には
本来のサイクルを前倒しした「臨時応急的な見直し」(期中改定、就労移行支援体制加算・
就労継続支援B型の基本報酬区分・処遇改善加算などが令和8年4月・6月施行で見直された)
が実施された。次の本改定は令和9年度(2027年度)に予定されている。
このように制度変更が頻繁な業界であるため、記録・計画作成ソフトの多くは
「最新の様式・加算要件に対応しているか」が選定基準の一つになる。

## 使いどころ・使い分け

| サービス類型 | 主な計画・記録 | AIが得意な領域 | 人の判断が必須な領域 |
|---|---|---|---|
| 就労継続支援A型・B型 / 就労移行支援 | 個別支援計画、支援記録、面談記録、モニタリング | 面談音声からの記録たたき台作成、作業内容・工賃実績の整理、通所記録の要約 | 工賃・雇用契約に関わる労務判断、適性に応じた作業内容の最終決定 |
| 生活介護 | 個別支援計画、日々の活動記録、健康観察記録 | 日々の活動記録の要約、家族向け通信文の作成 | 医療的ケアが関わる健康状態の判断、リスクの高い行動への対応方針 |
| 放課後等デイサービス・児童発達支援 | 個別支援計画、児童発達支援計画、アセスメントシート、モニタリング | アセスメント結果の整理、計画書のたたき台作成、活動プログラム案のアイデア出し | 障害特性の医学的・心理学的判断、保護者との合意形成 |
| グループホーム(共同生活援助) | 個別支援計画、日々のケース記録、世話人の申し送り | 申し送り文・業務日報の要約、日中活動先との情報共有文の作成 | 生活上のトラブル・安全管理に関わる判断 |
| 相談支援事業所(計画相談支援) | サービス等利用計画、モニタリング報告 | 面談音声からの計画書・モニタリング報告のたたき台作成 | 支給決定に関わる意見具申、複数サービスの調整方針の決定 |

**読み方のコツ**: 表の右列(人の判断が必須な領域)は、いずれも
「本人の権利や生活に直接影響する判断」であり、生成AIに任せてよい範囲では
ない。逆に左列(AIが得意な領域)は「すでに起きたこと・話されたことを
文章として整理する」作業であり、生成AI(LLM)が最も力を発揮する領域と一致する。
サービス類型を問わず、**まず「記録・面談の要約」から着手し、
「計画の中身そのものの立案」は人が最終判断する運用にする**のが安全な導入順序である。

## 実務での使い方

### 代表的なツール・事例

| 領域 | 企業・ツール | 内容 |
|---|---|---|
| 就労系(A型・B型・就労移行) | AURA就労支援(株式会社Jin) | 面談の会話を録音・分析し、個別支援計画書・モニタリング・面談記録の草案を自動作成。2ndLaboの紹介記事では書類作成業務を最大95%削減できるとされる。上位モデル「Aura AI 2.0」は音声データ(最大198分)を17.35秒で処理して書類化し、生成文への人の修正率は平均2.9%という数値が公表されている |
| 相談支援 | AURA相談支援(株式会社Jin) | 相談支援専門員向けに、面談録音から書類下書きを約1分で作成する機能をβ版として全国の相談支援事業所と共創開始 |
| 障害福祉全般・記録ソフト | CareViewer challenge(株式会社Care Viewer) | AI・障がい福祉記録ソフトとして、個別支援計画のテンプレート作成・音声入力に対応。グループホーム向けの料金例は事業所ごと月額1万円+利用者1人あたり400円(例: 利用者10名で月額1万4,000円)で、令和6年度報酬改定にも対応 |
| 障害福祉全般・記録ソフト | かんたん支援記録カンタン支援計画(株式会社エムティー) | ChatGPT APIを組み込み、支援記録(ケース記録・サービス提供記録・経過記録)の要点を要約し、個別支援計画の目標に沿ったアドバイスを提示。グループホームでは支援記録・業務日報・世話人交代の申し送り・日中活動先との情報共有にも使える設計 |
| 放課後等デイサービス・児童発達支援 | AIセラピストco-mii(株式会社ヴィリング×株式会社みやと、2023年10月正式リリース) | 7分野の質問に回答するとアセスメントを実施し、個別支援計画書・専門的支援計画書を半自動作成、療育メニューを提案 |
| 障害福祉・介護・産業保健 | AI支援さん(株式会社パパゲーノ、2024年3月リリース) | 支援現場向けの音声文字起こし・記録作成DXアプリ。初期費用10万円/法人+月額1万円/事業所に加え、AI機能利用分の従量課金がかかる料金体系(2026年時点)。同社は精神・発達障害のある方が働く就労継続支援B型事業所「パパゲーノ Work & Recovery」も運営しており、支援現場発のニーズを反映しやすい |
| 就労移行支援・就労系全般(汎用AI活用) | ERABERU(e-fukushi.jp) | 特定の専用ソフトではなく、就労移行支援の支援員向けにChatGPTへ貼り付けて使う「個別支援計画作成用プロンプト集」を無償公開 |

### コピペで使える実例: 面談メモから個別支援計画の「たたき台」を作る

専用ソフトを導入していない事業所でも、ChatGPT・Claude・Gemini・Copilotなど
汎用の生成AIチャットに面談メモを貼り付ければ、下書き作成は今日から試せる。
**入力する前に、利用者名・住所など個人が特定される情報は伏せ字(A様、B様など)に
置き換えること。**

```
あなたは障害福祉サービス事業所の支援員です。以下は、ご本人・ご家族との面談で
確認した内容のメモです。これをもとに、個別支援計画の原案を「本人の希望」
「支援課題」「長期目標」「短期目標」「具体的な支援内容」の5項目に分けて
箇条書きで作成してください。

【条件】
- 本人の言葉・希望をできるだけそのまま尊重した表現にする
- 断定的な医学的判断や障害特性の診断的な決めつけは書かない
- これはあくまで「たたき台」であり、最終的な内容の確認・修正・決定は
  サービス管理責任者(または児童発達支援管理責任者・相談支援専門員)が
  行うことを前提とする
- 利用者名などの個人が特定される情報は「A様」のように仮名で扱う

【面談メモ】
(ここに面談メモを貼り付ける。氏名など個人が特定される情報は事前に伏せ字にする)
```

### コピペで使える実例: 支援記録から家族向け通信文を作る

```
あなたは障害福祉サービス事業所の支援員です。以下は本日の支援記録のメモです。
これをもとに、ご家族向けの「今日の様子のお知らせ」を作成してください。

【条件】
- 専門用語(アセスメント、ADLなど)は使わず、平易な言葉に言い換える
- 良かった点は具体的なエピソードとして、気になる点は事実ベースで簡潔に伝える
- 障害特性についての断定的な評価やレッテル貼りにあたる表現は避ける
- 分量は250字程度

【本日の支援記録メモ】
(ここに記録メモを貼り付ける)
```

### ツール横断の対応付け

| 業務 | 専用ツールの例 | 汎用生成AIでの代用 |
|---|---|---|
| 面談音声→計画書・記録の下書き | AURA就労支援/AURA相談支援(株式会社Jin) | スマホの音声入力で書き起こし→ChatGPT/Claude/Geminiに整形を依頼(上記プロンプト例) |
| 個別支援計画の原案作成 | CareViewer challenge、かんたん支援記録カンタン支援計画、co-mii | 汎用生成AIにアセスメント内容・面談メモを渡し、上記プロンプト例で下書き作成 |
| 家族・保護者向け報告 | むすぼなAI等の福祉系プラットフォーム(介護分野で先行) | 汎用チャットAIに記録メモを渡し、家族向け文面への言い換えを依頼 |
| 就労移行の自己分析・書類作成支援(利用者本人向け) | ERABERUのAIプロンプト集 | ChatGPTに就労移行支援の職員が用意したプロンプトを使わせる形で本人の自己理解を支援 |

専用ツールは国保連請求・様式出力・既存の障害福祉ソフトとの連携に強みがあり、
汎用生成AIは追加契約なしで今すぐ試せる手軽さに強みがある。まずは汎用AIで
効果を体感し、効果が見えたら専用ツールの本格導入を検討する順序が現実的である。

### 導入コストの参考

専用ツールの月額目安は、AI支援さんが初期費用10万円/法人+月額1万円/事業所
+AI利用の従量課金(2026年時点)、CareViewer challengeのグループホーム向けプランが
事業所ごと月額1万円+利用者1人あたり400円という価格例が公表されている(いずれも
時点により変動するため、契約前に最新の料金ページで確認すること)。また、
令和8年度の処遇改善加算では「生産性向上」区分を満たす手段としてICT機器・
ソフトウェアの導入が有効とされており、加算取得と合わせて導入コストを
検討する事業所も多い。

## 注意点・よくある誤解

- **要配慮個人情報の扱い**: 障害の種類・程度、病歴、支援の経過などは
  個人情報保護法上の「要配慮個人情報」にあたり、取得・第三者提供には
  原則本人(または保護者)の同意が必要である。生成AIに入力する際は、
  まず個人が特定されない範囲(業務日報の定型文づくりなど)から試し、
  個別支援計画・支援記録など要配慮個人情報を扱う業務は、入力データを
  AIの学習に使わない設定や、専用ソフトのように閉域環境が確保できてから
  段階的に広げるのが安全である。ウェブ版の汎用チャットAIに氏名や
  詳細な病歴を直接貼り付けることは避け、伏せ字化や専用ツールの利用を優先する
- **個別支援計画の最終責任は有資格者にある**: 個別支援計画・児童発達支援計画・
  サービス等利用計画は、サービス管理責任者・児童発達支援管理責任者・
  相談支援専門員といった有資格者が作成し、内容に責任を持つものと位置づけられている。
  紹介した専用ツールのいずれも「AIが作るのは草案・たたき台」「最終的な
  確認・決定は有資格者」という設計を前提にしており、生成AIの出力を
  未確認のまま計画書として確定させる運用は避ける
- **アクセシビリティを損なわない設計にする**: 支援の主役は利用者本人であり、
  生成AIツールの導入自体が「本人の意思確認を省略する」方向に働いては
  本末転倒になる。特に発語が難しい利用者・非言語コミュニケーションが
  中心の利用者に関する計画では、AIが生成した文章が本人の実際の意向と
  ずれていないか、支援員が本人・家族に確認するプロセスを省略しないこと
- **音声認識の精度リスク**: 発話が不明瞭な利用者や、複数人が同時に話す
  ケース会議などでは、音声入力の書き起こし精度が下がる場合がある。
  重要な数値(工賃・出席日数など)や固有名詞は、生成AIによる整形後も
  必ず目視で確認する運用にする
- **報酬改定への追随を確認する**: 障害福祉サービス等報酬改定は3年に1度が
  基本だが、令和8年度のように費用急増を受けた期中の「臨時応急的な見直し」も
  起こりうる。専用ツールを選定する際は、様式・加算要件の変更に事業者側が
  迅速にアップデート対応しているか(令和8年度改定・次の令和9年度改定への
  対応方針)を必ず確認する
- **介護分野の事例をそのまま流用しない**: 高齢者介護向けに設計された
  AIケアプラン作成支援ツールは、要介護度や医学的所見をベースにした設計が
  多く、障害福祉サービスが重視する「本人の意思決定支援」「就労・社会参加」
  という観点とは前提が異なる。介護分野の実績が豊富なベンダーであっても、
  障害福祉サービス向けの機能(就労支援の工賃管理、児童発達支援の様式対応など)を
  個別に備えているかを確認する

## 最初の一歩

自事業所の個別支援計画・支援記録・家族向け報告書のうち「毎回ゼロから
文章を書き起こしている書類」を1つ選び、氏名など個人が特定される情報を
伏せ字にしたうえで、上記のプロンプト例を使って汎用の生成AIチャット
(ChatGPT・Claude・Gemini・Copilotなど)に下書きを作らせてみることから
始めるとよい。個人が特定されない業務日報の定型文づくりなど、
要配慮個人情報を含まない範囲から試すと、職員間の合意を得やすい。
