# AIエージェントとは何か:自律型AIの基礎と代表例

## これは何か

ChatGPTやGeminiに「来週の出張の航空券とホテルを探して」と聞いても、返ってくるのは候補の一覧やアドバイスだけで、実際に検索サイトを操作して予約まで進めてくれるわけではない。指示のたびに人間が結果を受け取り、次の指示を出し、また結果を受け取る「1問1答」の繰り返しになる。

**AIエージェント(自律型AI)**は、この「人間が毎回指示を出し直す」手間をなくす仕組みである。目的(ゴール)を1回与えると、AIが自分で作業手順を計画し、Web検索やファイル操作、外部サービスの操作といった「ツール」を使いながら複数ステップの作業を自律的にこなし、必要であれば計画を軌道修正しながら最後まで進める。読者にとっての実感で言えば、「検索エンジン」から「代行してくれる部下」への変化に近い。

## 仕組み・背景

AIエージェントは、次のようなループを自律的に繰り返すことで動く。

1. **計画(Plan)**: ゴールを達成するための手順を考える
2. **ツール使用(Act)**: 検索、コード実行、社内システムやWebサイトの操作、他のAPIの呼び出しなど、AI自身では持っていない情報や実行力を「ツール」を使って補う
3. **観察(Observe)**: ツールの実行結果を確認する
4. **振り返り・再計画(Reflect)**: 結果が想定と違えば、計画を修正して1に戻る。目的を達成できたと判断すればループを終了する

この「AIが会話の外にある機能(ツール)を呼び出す」仕組みは**Function Calling(ファンクションコーリング)**または**Tool Use(ツールユース)**と呼ばれ、AIエージェントを支える基盤技術になっている。またAIエージェントが様々な外部ツール・データソースに接続するための共通規格として、Anthropicが2024年11月に公開した**MCP(Model Context Protocol)**が業界標準になりつつあり、OpenAIやGoogle DeepMind、Microsoftなど主要各社も採用している。

もう1つの重要な違いは「画面を操作する能力」の有無である。従来のAIはテキストのやり取りしかできなかったが、画面を見て(スクリーンショットを読み取って)マウス操作やクリック・入力を自分で行う**Computer Use(コンピュータユース)**と呼ばれる技術が実用化されたことで、Webサイトの予約フォームへの入力や、業務システムでのクリック操作まで代行できるようになった。

### AIエージェントとAGI(汎用人工知能)は別物

「AIエージェント」と「AGI(Artificial General Intelligence、汎用人工知能)」は混同されやすいが、指している範囲が異なる。

| | AIエージェント | AGI(汎用人工知能) |
|---|---|---|
| 位置づけ | 特定の目的・領域の作業を自律的にこなす**実用ツール** | 人間のようにあらゆる知的課題に柔軟に対応できる**汎用的な知能**という概念・目標 |
| 現状 | すでに実用化され、業務で使われ始めている | 現時点では実現しておらず、研究開発中の目標 |
| 例えるなら | 特定業務を任せられる「専門スタッフ」 | あらゆる仕事をこなせる「万能の人材」 |

生成AIやAIエージェントは、AGIに至る技術的な積み重ねの一部と位置づけられることはあるが、「AIエージェントが使えている=AGIに近い」わけではない。AIエージェントは特定の目的に沿ってツールを使いこなす自律実行の仕組みであり、AGIのような汎用知能とは別の概念として区別して理解しておくとよい。

## 使いどころ・使い分け

| 状況 | 向いている選択 | 理由 |
|---|---|---|
| 単発の質問に答えてほしいだけ(調べ物の要約、文章の下書きなど) | 通常のチャットAI(1問1答) | エージェントは複数回のAI呼び出しを行う分、時間もコストもかかる。単純な用途にはオーバースペック |
| 複数ステップにまたがる調べ物(競合調査、市場動向の多角的なリサーチなど) | エージェント型の機能(Deep Research等) | 検索→読み込み→要約→追加検索、を人手を介さず繰り返してくれる |
| 決まった手順を繰り返す定型作業(定型レポートの作成、フォームへの転記など) | 業務用に組んだAIエージェント(Dify等のノーコードツールで構築) | 一度手順を設計すれば、以後は自動で反復実行できる |
| 送金・契約締結・個人情報の削除など、誤ると取り返しがつかない操作 | 人間の最終承認を必須にする(エージェントに完全に任せない) | 自律実行の対象にすると、誤判断がそのまま実行されてしまうリスクがある |

判断の軸はシンプルで、「作業が複数ステップにまたがるか」「間違えたときの被害が大きいか」の2点で考えるとよい。前者が該当すればエージェント化の候補、後者が該当すれば人間の承認ステップ(欧米では**Human In The Loop、日本語では「人間参加型」**と訳されることが多い)を挟む設計にする。

## 実務での使い方

### 今すぐ試せるエージェント的機能

- **OpenAI「ChatGPT agent」(旧称: エージェントモード)**: 2025年7月に、Webサイトを操作する「Operator」と、複数ステップの調査を行う「Deep Research」が統合されて生まれた機能。ChatGPTの入力欄で「agent」を選ぶと、検索・サイト操作・資料の読み込みを自律的に組み合わせて作業してくれる。より深い調査に特化した「deep research」モードも別途選択でき、2026年2月からは特定のMCP・社内アプリに接続して調査対象を絞り込む機能も追加されている
- **Google Geminiのエージェント機能**: ブラウザ操作を行う実験的機能「Project Mariner」は2026年5月にサービス終了し、その技術は「Gemini Agent」(メールの整理やホテル予約の代行など)やGemini in Chromeの自動操作機能に引き継がれている
- **Anthropic Claude Code / Computer Use**: エンジニア向けの自律型コーディングエージェント「Claude Code」は、複数のエージェントを並行実行してタスクを分担させる機能を備える。画面を見てPC操作を代行する「Computer Use」もデスクトップアプリ・API双方で研究プレビュー中
- **ノーコードでの自作**: Difyのような業務アプリ構築ツールでも、LLMに自律的な意思決定をさせる「エージェント」機能があり、検索や画像生成など複数のツールと連携させて自社専用のエージェントを組める(詳細は[Difyとは何か](../part09-nocode-lowcode/dify-basics.md)を参照)

| サービス例 | 位置づけ |

### 料金面の考え方

エージェントは1つの依頼に対して「計画→ツール使用→確認→再計画」を何度も繰り返すため、裏側では通常のチャット利用よりずっと多くのAI呼び出しが発生する。そのため同じ「1回のお願い」でも、通常のチャットに比べて時間もコスト(API利用料やプランの消費枠)もかかりやすい。実際にAnthropicは2026年に、Claude Codeなどのエージェント的な利用を通常のチャット利用と別枠のクレジット制にする方針を打ち出している。エージェント機能を業務に組み込む際は、想定される呼び出し回数を踏まえて料金プランを確認することが重要になる。

## 注意点・よくある誤解

- **自律的に「間違った判断」もする**: エージェントは人間の逐一の確認なしに行動するため、誤ったサイトへの入力や、意図しないファイルの操作など、暴走・誤操作のリスクが通常のチャットAIより大きい。実際に、AIエージェントが自分の行動を制限されたことに反発する挙動や、禁止された操作を別のAIエージェントに肩代わりさせる事例なども報告されている
- **重要な操作には必ず人間の承認を挟む**: 送金、契約締結、データ削除など取り返しのつかない操作は、エージェントに完全に任せず、実行前に人間が確認する「承認ステップ」を設計に組み込む。すべてを人間が逐一確認する必要はなく、リスクの大きさに応じて確認の深さを変える設計が実務では主流になっている。経済産業省の「AI事業者ガイドライン」でも、AIエージェントが外部に対してアクションを実行する場面では、重要な意思決定のポイントで人間の承認を得ることが事実上求められている
- **まだ発展途上の技術である**: 画面操作の精度を測るベンチマークでは、主要なエージェントでも成功率が4〜6割程度にとどまるという報告もあり、「人間と同じように何でもこなせる」と過度に期待するのは禁物。重要度の低い作業から試し、結果を検証しながら適用範囲を広げるのが安全
- **サービス名・統合状況の変化が非常に速い**: OpenAIのOperatorがChatGPT agentに統合されたように、この分野は数か月単位でサービスの改名・統合・終了が起きる。社内資料や記事に具体的なサービス名を書く場合は、必ず執筆時点の公式情報で確認すること

## 最初の一歩

ChatGPTやGeminiで、いつもの「1問1答」ではなく複数ステップにまたがる調べ物(例:「競合3社のサービスを比較して表にまとめて」)を、Deep Research系の機能を選んで1回試し、通常のチャット応答との違いを体感してみる。
