# マーケティング職における生成AI活用

## これは何か

マーケティング職の仕事は「市場・競合を調べる→企画を練る→広告コピーやSNS投稿・記事を量産する→配信する→効果を分析して次に活かす」という一連の業務フローの繰り返しであり、そのほぼ全工程に生成AIを差し込める。とはいえ「AIでマーケティングが変わる」という抽象論だけでは、明日から何をどう変えればよいか分からない。本ページは、文章作成やリサーチの一般論([生成AIによる文章作成・編集の実務活用](./ai-writing-and-editing.md)、[生成AIによる情報収集・リサーチの実務活用](./ai-research-and-information-gathering.md))はそれぞれの専門ページに委ね、マーケティング業務のどのフェーズにAIをどう差し込むかという「業務フローへの実装」に絞って、コピペで使えるプロンプト例つきで整理する。

## 仕組み・背景

マーケティング業務に生成AIが特に効きやすいのは、次の2つの性質を併せ持つタスクが多いからである。

1. **「複数案を出して人が選ぶ」形にしやすい**: 広告コピー、SNS投稿文、メール件名はいずれも「唯一の正解」がなく、複数のバリエーションを試して反応を見る前提の仕事である。AIは1つの完璧な答えを出すのは苦手でも、方向性の異なる案を大量に出す(ブレインストーミング)のは得意という特性と相性がよい。
2. **型(フォーマット)が決まっている**: 広告文の文字数制限、SNSごとの投稿文の作法、メルマガの構成など、あらかじめ型が決まっている文章が多く、AIは型に沿った出力を安定して量産できる。

実際、広告主の86%が生成AIを活用しているとの調査があり、国内でも電通が「∞AI(ムゲンAI)」で市場データ・競合分析から訴求軸を発見しコピーやビジュアルを自動生成する仕組みを、博報堂DYが「バーチャル生活者」でターゲット像の解像度を上げる仕組みを、それぞれ整備している。サントリーの「やさしい麦茶 AI部長」CMのように、AIを企画のフックそのものに使い制作費を約25%削減した事例も出ている。ただし、いずれの事例でも「AIが最終判断まで代行する」のではなく、AIが大量の選択肢・下書きを作り、人間(マーケター)が戦略的な取捨選択とブランドとしての最終判断を行う、という役割分担が共通している。

## 使いどころ・使い分け

### マーケティング業務フェーズ別のAI活用マップ

| フェーズ | 主なタスク | AIの向き・不向き | 主に使うAI機能 |
|---|---|---|---|
| リサーチ | 市場規模・トレンド把握、競合の価格・訴求比較、顧客インサイトの仮説出し | 向く(複数情報源の横断比較) | Deep Research系機能([詳細](./ai-research-and-information-gathering.md)) |
| 企画 | ペルソナ設計、キャンペーンコンセプト立案、コンテンツ企画・記事構成案 | 向く(たたき台・複数案出し) | 通常のチャット(壁打ち) |
| 制作 | 広告コピー・SNS投稿文・メール件名のバリエーション生成、記事本文のドラフト、バナー・画像案 | 向く(型のある文章の量産)。ビジュアルの精密な仕上げや、独自性・ブランドの機微は人が担う | チャット+画像生成、[文章作成・編集](./ai-writing-and-editing.md) |
| 配信 | 配信文面のパーソナライズ、配信タイミング・セグメントの提案、A/Bテスト案の設計 | 向く(パターンの大量生成)。実際の配信実行・効果判定は配信ツール側の役割 | チャット、MA(マーケティングオートメーション)ツールのAI機能 |
| 分析 | 効果データの要約・異常値の発見、レポートのドラフト作成、次施策への示唆出し | 向く(定型的な数値要約・一次仮説出し)。因果関係の断定や重要な予算判断は人が検証 | Advanced Data Analysis等([詳細](../part07-data-analysis/chatgpt-advanced-data-analysis.md)) |

判断の軸はシンプルで、「複数案を作って人が選ぶ・試す」仕事はAIに任せやすく、「一つの正解を最終決定する」仕事は人が主導しAIは材料出しに徹する、という切り分けになる。

### 「量産」と「独自性」のトレードオフに注意

AIによるコピー・投稿文の大量生成は時短効果が大きい一方、同じAIモデル・似たプロンプトを使う競合他社と表現が似通いやすいという副作用がある。差別化したい基幹キャンペーンのコピーはAIに複数案を出させた上で人間が大きく手を入れる、日々のSNS運用のような定型業務はAI比率を上げる、というように「基幹施策か日常運用か」でAI関与度を変えるのが実務的。

## 実務での使い方

### プロンプト例1: 広告コピー案出し(複数パターン+媒体別)

コピーは「1本の正解」を求めず、方向性の異なる案を並べさせてから人が選ぶ使い方が最も効果を出しやすい。

```
あなたは経験豊富なコピーライターです。以下の商品の広告コピー案を作成してください。

## 商品・サービス
[例: 20代女性向けのオーガニックスキンケアブランドの新商品(化粧水)]

## 訴求したいポイント
[例: 無添加・低刺激、1本で化粧水・美容液・乳液の3役]

## ターゲット
[例: 敏感肌に悩む20代後半〜30代前半の女性]

## 出力条件
- 切り口の異なる案を10本(「悩み訴求」「時短訴求」「成分訴求」「体験談風」など複数の型を混ぜる)
- 1本につき全角20文字以内
- それぞれどの切り口(訴求軸)かを一言添える
- 誇大表現・薬機法に抵触しうる表現(「治る」「完治」等)は避ける
```

媒体ごとに文字数・トーンの制約が異なる場合は、1回で複数媒体分を出させると比較しやすい。

```
上記のコピー案のうち3案を選び、以下の媒体向けにそれぞれ調整してください。
- Instagram広告(全角30文字以内、絵文字を1〜2個使用可)
- リスティング広告見出し(全角15文字以内、キーワード「敏感肌」を含める)
- LINE公式アカウントの配信文(全角40文字以内、クーポン訴求を追加)
```

### プロンプト例2: SNS投稿文の量産・A/Bバリエーション作成

1回の依頼で「1週間分・複数トーン」をまとめて出させると、後は選んで微調整するだけの状態にできる。

```
以下の商品について、Instagram・X(旧Twitter)それぞれ向けの投稿文を作成してください。

## 商品・キャンペーン内容
[例: 夏季限定フレーバーの新発売、期間中SNS投稿でクーポンプレゼント]

## ブランドトーン
[例: 親しみやすく、絵文字は控えめ、語尾は「〜です・ます」で統一]

## 出力条件
- Instagram用: 5パターン(それぞれ100字程度、ハッシュタグ5個を末尾に提案)
- X用: 5パターン(それぞれ全角100字以内、ハッシュタグ2個まで)
- 同じ情報を伝える投稿でも、「メリット訴求」「限定感訴求」「共感・体験談風」など切り口を変える
- 事実(発売日・価格・キャンペーン期間)は下記の情報のみを使い、憶測で数値を補わない

## 商品情報
[ここに正確な商品情報・キャンペーン条件を貼り付け]
```

「事実は下記の情報のみを使う」という一文は、ハルシネーション([仕組みと対策](../part04-risk-security/hallucination-and-countermeasures.md))によってキャンペーン期間や価格を勝手に作られる事故を防ぐために重要。

### プロンプト例3: ペルソナ設計

ペルソナ作成でAIの精度を左右するのは「業種」「ターゲット年齢層」「課題」「購買行動パターン」の4要素を具体的に埋められるかどうかである。手元に顧客データ・アンケート結果があれば、それを貼り付けてから作らせると精度が上がる。

```
あなたはマーケティングリサーチの専門家です。以下の情報をもとに、
架空だが解像度の高いペルソナを1名分作成してください。

## 商品・サービス
[例: 中小企業向けの経費精算SaaS]

## ターゲット層の概要
[例: 従業員50〜200名規模の企業の経理担当者]

## 参考データ(あれば貼り付け)
[既存顧客のアンケート結果、購買データの傾向、営業からのヒアリングメモなど]

## 出力形式
以下の項目で1名分のペルソナを作成してください。
- 基本属性(年齢・役職・業務内容)
- 抱えている課題・悩み(業務上のペインポイント)
- 情報収集の方法(どんな媒体・検索キーワードで情報を探すか)
- 意思決定のプロセス(誰の承認が必要か、決め手になる要素)
- この商品に対して響きそうな訴求メッセージ案を3つ

## 注意事項
参考データがある場合はその内容を優先し、矛盾する記述をしないこと。
参考データがない場合は、一般的な業界知見に基づく仮説であることを明記すること。
```

生成されたペルソナは「仮説」であり、実際の顧客インタビューやアンケートで検証してから施策に反映するのが実務的な使い方になる。

### プロンプト例4: コンテンツマーケティングの記事構成案

自社ブログ・オウンドメディアの記事は、AIにいきなり本文を書かせるより、まず構成案(見出し)だけを作らせて確認してから本文を書かせる2段階アプローチが手戻りを減らす(考え方は[生成AIによる文章作成・編集の実務活用](./ai-writing-and-editing.md)の「反復編集の進め方」と同じ)。マーケティング記事特有の観点として、検索エンジン向けのSEOに加えて、ChatGPTやPerplexityなどの生成AI検索に自社コンテンツが引用されやすくする「LLMO(大規模言語モデル最適化)」の視点も踏まえておくとよい。

```
あなたはSEO・LLMO(生成AI検索最適化)に詳しいコンテンツマーケターです。
以下の条件で記事の構成案を作成してください。本文はまだ書かないでください。

## テーマ・想定読者
[例: 「経費精算のペーパーレス化」、読者は中小企業の経理担当者]

## 狙うキーワード
[例: 経費精算 ペーパーレス化 方法]

## 出力条件
- H2見出しを5〜7本、必要に応じてH3見出しも提案
- 各見出しに、読者が知りたいであろう固有名詞・関連トピック(エンティティ)を含める
- 記事の結論・要点を冒頭でも提示できるよう、PREP法(結論→理由→具体例→結論)を意識した流れにする
- 生成AI検索(ChatGPT等)からの引用を狙い、数値・定義・比較表など「引用しやすい要素」を入れる見出しを最低1つ含める
- 競合が書きがちな一般論だけでなく、自社ならではの切り口(実際の顧客事例・データ)を入れる見出しを1つ提案する
```

### 応用: メール件名・配信文のバリエーション出しとデータ分析からのインサイト抽出

メールマーケティングでは、AIに件名を大量生成させてA/Bテストにかける使い方が定着しつつある。従来は2〜3パターンの比較が一般的だったが、AIを使えば10パターン以上を数分で用意でき、開封率データを踏まえた次回改善にも活用できる。

```
以下のメール本文の要点をもとに、開封率を高めるための件名を10パターン作成してください。

## 配信対象
[例: 過去に資料請求をしたが未契約の見込み顧客]

## 訴求したい内容
[ここに本文の要点・キャンペーン内容を貼り付け]

## 出力条件
- 「数字を入れる」「疑問形にする」「限定感を出す」「ベネフィットを直接書く」など
  異なる切り口を最低4種類混ぜる
- 全角20字以内(スマートフォンでの表示崩れを防ぐため)
- 誇大表現・煽り文句(「絶対」「必ず」等)は避ける
- それぞれどの切り口かを一言で添える
```

配信後の効果データ(開封率・クリック率・チャネル別の反応など)をAIに読み込ませてインサイトを抽出する場合は、ChatGPTのAdvanced Data AnalysisやGeminiのデータ分析機能を使うと、CSVをアップロードするだけで集計・グラフ化・傾向の言語化までを一気に行える(詳細は[チャットAIによるデータ分析の基本](../part07-data-analysis/chatgpt-advanced-data-analysis.md)を参照)。「どの訴求軸のクリック率が高いか」「曜日・時間帯による反応の違い」といった一次的な傾向出しはAIが得意な一方、「なぜその傾向が起きたのか」という因果関係の断定はAIの推測にすぎない点に注意し、重要な予算判断の前には人が仮説を検証する。

## 注意点・よくある誤解

- **AIが出した複数案の「選ぶ基準」は人が持つ**: AIは差別化されていない切り口も紛れ込んだ10案を出してくることが多い。ブランドガイドライン・過去の反応データ・薬機法や景品表示法など業界特有の規制に照らして選別する判断軸は、マーケター自身が持っておく必要がある。特に化粧品・健康食品・金融商品などは、AIが生成したコピーがそのまま薬機法・景品表示法に抵触する表現を含むことがあるため、配信・出稿前に必ず法務・規制の観点でのチェックを挟む。
- **量産すると同質化するリスク**: 同じAIモデルを使う競合他社と表現の傾向が似通いやすい。基幹キャンペーンなど差別化が重要な施策では、AI案をそのまま採用せず、人間が大きく手を入れる工程を残す。
- **数値・キャンペーン条件のハルシネーションに注意**: 「いつでも」「初回無料」のような条件をAIが文脈から勝手に補完してしまうことがある。価格・期間・キャンペーン条件は必ず正確な情報を渡し、渡した情報以外を使わないよう指示する(詳細は[ハルシネーションの仕組みと対策](../part04-risk-security/hallucination-and-countermeasures.md))。
- **顧客データ・未公表の販売計画をそのまま貼り付けない**: 顧客の購買データや個人情報を含むファイルをAIに読み込ませる場合、自社の利用規約・データ取り扱いルールを確認する。特に無料プランや外部の専用マーケティングAIツールは学習利用の可否がツールごとに異なる(詳細は[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md))。
- **「AIが分析した」を鵜呑みにしない**: データ分析機能が示す傾向やインサイトは、あくまで統計的な相関の言語化であり、因果関係の証明ではない。特に予算配分や施策継続・中止といった意思決定に使う場合は、AIの示唆を仮説として扱い、追加の検証(小規模テストなど)を挟む。
- **AIツール名を主語にしすぎない**: 本ページで紹介したプロンプトは特定ツールに依存しない汎用的な内容だが、実際にはJasper・Copy.ai・AdCreative.aiのようなマーケティング特化AIツールや、Canva・Gammaのようなビジュアル生成ツールと組み合わせて使うことが多い。特化ツールの選定は自社の予算・既存契約(Microsoft 365、Google Workspaceなど)と相談して決める。

## 最初の一歩

直近で配信予定のSNS投稿かメールマガジンを1本選び、本ページの「プロンプト例2」または「応用」の件名生成テンプレートを使って5〜10パターンの案を出させ、実際に配信・比較する小さなA/Bテストを1回試してみる。
