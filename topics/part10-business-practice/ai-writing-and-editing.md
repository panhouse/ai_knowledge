# 生成AIによる文章作成・編集の実務活用

## これは何か

メールの返信文、会議議事録、提案書、社内稟議など、ビジネスパーソンの業務時間の多くは「文章を作る・直す」作業に費やされている。生成AIは、こうした文章の**叩き台(たたき台。ゼロから作る初稿)を数十秒で用意し、トーン(文章の口調・雰囲気)や長さを指示ひとつで調整できるツール**であり、使いこなせば「書く時間」を「直す・磨く時間」に置き換えられる。本ページでは、ChatGPT・Claude・Copilot・Geminiという主要ツールを横断して、文章作成・編集をどう使い分け、どう指示すればよいかを実務目線でまとめる。

## 仕組み・背景

生成AIが文章作成で担える役割は、大きく4つに整理できる。

1. **叩き台生成**: 目的・宛先・要点を伝えると、ゼロから文章を組み立てる。真っ白な画面に向かう時間をなくす。
2. **リライト・要約**: 既存の文章(会議の文字起こし、長い資料など)を、目的に合わせて短く・わかりやすく作り変える。
3. **トーン調整**: 同じ内容でも「丁寧語⇔カジュアル」「社内向け⇔社外向け」など、読み手に合わせて言葉遣いを変換する。
4. **校正・添削**: 誤字脱字だけでなく、論理の飛躍・冗長表現・敬語の誤りなどをチェックし、改善案を提示する。

これらを実現する土台になっているのが、多くのツールが備える**「ドキュメント編集面」**という仕組みである。チャットのやり取り(会話ログ)とは別に、文章そのものを表示・編集する専用スペースを画面内に持つことで、長文を何度もチャット欄にコピペし直さずに、部分的な修正指示を出せるようになっている。代表例が ChatGPT の「Canvas(キャンバス)」や Claude の「Artifacts(アーティファクト)」だが、この分野は変化が速く、後述のとおり2026年に入って仕様が大きく変わったツールもある。

## 使いどころ・使い分け

まず前提として、AIに「任せてよい部分」と「人が最終責任を持つべき部分」を切り分けることが重要である。

| AIに任せてよい部分 | 人が必ず確認・判断すべき部分 |
|---|---|
| 初稿・叩き台の作成、構成案づくり | 事実関係(数値・固有名詞・日付・契約条件など)の正確性 |
| 表現のバリエーション出し、トーン変換 | 送信先との関係性を踏まえた最終的な言い回しの妥当性 |
| 長文の要約、アクションアイテムの抽出 | 議事録・契約書など「言った/言わない」に関わる内容の一言一句の確認 |
| 誤字脱字・文法チェック、言い換え候補の提示 | 社外に出す文章の最終承認、機密情報が含まれていないかの確認 |

用途別の使い分けの目安は以下の通り。

| 用途 | 向いている使い方 | 注意点 |
|---|---|---|
| 社内メール・チャット返信 | AIに全文の叩き台を作らせ、微修正して送る | 定型化しすぎると「AIっぽさ」が相手に伝わることがある |
| 社外向けメール・案内文 | 叩き台をAIに作らせた上で、事実関係と敬語を人が必ずチェック | 相手企業名・金額・日付の誤りは信頼を損なうため二重確認必須 |
| 議事録 | 文字起こしテキストを渡して要約・決定事項・宿題(アクションアイテム)を抽出させる | 話者の意図を取り違えることがあるため、重要な合意事項は原文と照合する |
| 提案書・企画書のドラフト | 骨子(アウトライン)をAIに作らせ、人が肉付けと差別化ポイントを追加 | 競合分析や独自性の主張はAIの一般論になりがちなので人が補強する |
| プレスリリース・社外公表文 | 型に沿った初稿作成は得意 | 法務・広報の確認プロセスは省略しない。数値の裏取りは必須 |
| 校正・リライト | 誤字脱字、冗長表現、トーン統一の指摘は非常に得意 | 「正しいが不自然」な直しが入ることがあるため、必ず声に出して読む・原文と読み比べる |

## 実務での使い方

### ドキュメント編集面のツール横断対応表(2026年7月時点)

長文を作成・推敲する際は、チャット欄への打ち込みではなく、以下の「ドキュメント編集面」を使うと効率が良い。ただし呼び名・挙動はツールごとに異なり、特にChatGPTは2026年5月に大きな仕様変更があったので注意する。

| ツール | 呼び名 | 呼び出し方 | 特徴 |
|---|---|---|---|
| ChatGPT(GPT-5.5 Instant/Thinking) | 「Writing blocks(ライティングブロック)」 | メール・投稿文などの下書きを頼むと会話内に編集可能なブロックとして自動表示。ブロックを選択して部分修正を指示できる | 2026年5月末のGPT-5.5アップデートで、旧来の右側パネル型「Canvas」がこのモデルでは廃止され、チャットに埋め込む形式に統合された([Krasa.ai](https://www.krasa.ai/news/openai-gpt-5-5-instant-writing-coding-blocks-canvas-removed-may-2026)) |
| ChatGPT(レガシーモデル利用時) | 「Canvas(キャンバス)」 | チャット欄に `/canvas` と入力するか、＋アイコンから選択。10行を超える文章生成時は自動起動することもある | 旧モデル(o3・GPT-4.5等)がサンセット(提供終了)されるまでの期間限定提供。今後は縮小方向([OpenAI Help Center](https://help.openai.com/en/articles/9930697-what-is-the-canvas-feature-in-chatgpt-and-how-do-i-use-it)) |
| Claude | 「Artifacts(アーティファクト)」 | 15行程度を超えるまとまった文章を作らせると自動生成。または「これをArtifactとして作って」と明示的に指示。設定は画面左下の名前→「設定」→「機能」→Artifactsのトグル | Markdown文書は、直したい箇所をドラッグして選択し「Edit with Claude」から部分修正を指示できるのが強み([Claude Help Center](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them)) |
| Microsoft Copilot in Word | Word内の「Copilot」アイコン(ドラフト機能) | 新規の空白行でCopilotアイコンをクリックし、プロンプト欄に指示を入力。既存文章を選択して右クリック→「Copilotで書き直す」でリライトも可能 | 生成後は「保持する/再生成/破棄」を選べる。骨子やアウトラインを与えるほど精度が上がる([Microsoft Support](https://support.microsoft.com/en-us/word/copilot/draft-and-add-content-with-copilot-in-word)) |
| Google Gemini in Docs | 「Help me write」(下部バーまたはサイドパネル) | 文書内の「Help me write」欄、または画面下部バーからプロンプトを入力。文章の一部を選択すればその範囲だけを対象にできる | 2026年のアップデートでDrive・Gmail・Chatの情報を参照して初稿を作る「Help me create」や、複数人の文体を統一する「Match writing style」が追加された([Google Workspace Updates](https://workspaceupdates.googleblog.com/2026/04/new-gemini-capabilities-in-google-docs-help-you-go-from-blank-page-to-brilliance.html)) |

### コピペで使えるプロンプト例

以下はいずれもチャット欄・ドキュメント編集面のどちらに貼っても使えるテンプレートである。【】内を自分の状況に置き換えて使う。

**(1) ビジネスメールの下書き**
```
以下の状況で送るビジネスメールの下書きを作成してください。

宛先: 【取引先の担当者名・会社名、または社内の役職】
目的: 【例: 納期変更のお願い、提案の御礼、資料送付の案内】
伝えたい要点:
- 【要点1】
- 【要点2】
- 【要点3】
トーン: 【丁寧・フォーマル / 親しみやすいがビジネスライク など】
文字数の目安: 【例: 200字程度】

制約:
- 結論を最初の1〜2文で述べてください
- 事実として断定できない内容(金額・日付など)は【】のプレースホルダーのまま残してください
```

**(2) 議事録の要約・アクションアイテム抽出**
```
以下は会議の文字起こしです。この内容から議事録を作成してください。

出力形式:
1. 会議名・日時・参加者(文中に情報があれば抽出、なければ【要記入】と表記)
2. 決定事項(箇条書き)
3. 議論はしたが結論が出なかった論点(箇条書き)
4. アクションアイテム(担当者・タスク内容・期限がわかる場合は明記。表形式で)

注意事項:
- 発言者の意図を推測して勝手に結論を作らないでください
- 憶測が入る場合は「(推測)」と明記してください

--- 文字起こし ---
【文字起こしテキストを貼り付け】
```

**(3) 提案書・資料のドラフト作成**
```
【商材・サービス名】を【対象企業・部署】に提案するための提案書の骨子を作成してください。

前提条件:
- 相手の課題: 【想定される課題】
- 自社の強み: 【差別化ポイント】
- 提案のゴール: 【契約獲得/社内稟議承認/次回商談設定 など】

出力してほしい構成:
1. 課題の整理(相手視点で)
2. 解決の方向性
3. 提案内容の概要(3〜5個の箇条書き)
4. 導入によって期待できる効果(数値は【】のまま仮置きしてよい)
5. 次のアクション(相手に依頼したいこと)

まずは見出しと各セクションの要点だけの骨子を出してください。本文はその後に依頼します。
```

**(4) 文章のトーン調整(丁寧語⇔カジュアル、社内⇔社外向け)**
```
以下の文章を、【社内向けのカジュアルなチャット文 / 社外向けの丁寧なメール文】に書き換えてください。

条件:
- 元の文章が伝えたい要点・結論は変えないでください
- 【カジュアルにする場合】絵文字や口語表現を使ってよいですが、失礼な省略表現(「了解!」など目上の相手には不適切なもの)は避けてください
- 【フォーマルにする場合】敬語の誤用(二重敬語・謙譲語と尊敬語の混同)がないか特に注意してください

--- 元の文章 ---
【書き換えたい文章を貼り付け】
```

**(5) 校正・リライト依頼**
```
以下の文章を校正してください。

チェックしてほしい観点:
1. 誤字脱字・変換ミス
2. 敬語の誤り(二重敬語、謙譲語/尊敬語の混同)
3. 一文が長すぎる箇所(目安: 60字を超える文)
4. 同じ語尾・接続詞の連続使用
5. 論理が飛躍している箇所

出力形式:
- 修正版の全文
- 修正箇所と理由の一覧(箇条書き)

--- 元の文章 ---
【校正したい文章を貼り付け】
```

### 料金面の考慮

個人利用の主要プランはおおむね月額2,000〜3,000円台に収まる。2026年7月時点の目安は以下の通り(為替・為替変動やキャンペーンで変わるため、契約前に必ず公式サイトで最新価格を確認すること)。

- **ChatGPT Plus**: 月額20米ドル。Writing blocks(旧Canvas)を利用可能
- **Claude Pro**: 月額20米ドル。Artifactsは無料プランでも利用できるが、大容量ファイルの永続保存など一部機能はPro以上が対象([Claude Help Center](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them))
- **Microsoft 365 Copilot**: 個人向けはMicrosoft 365 Premiumに統合され月額19.99米ドル。法人向けはBusiness Standard等の既存プランに追加する形で1ユーザーあたり月額18〜32米ドル程度(プロモーション条件により変動)([Velosio](https://www.velosio.com/blog/m365-copilot-pricing-calculator/))
- **Google Gemini(Google AI Pro)**: 月額19.99米ドル。Google Workspace利用企業はBusiness Standard(月額18米ドル/人)以上のプランにGeminiが標準搭載されている([felloai.com](https://felloai.com/gemini-pricing/))

日常的なメール・議事録作成程度であれば、既に契約している業務ツール(Microsoft 365やGoogle Workspace)にAI機能が含まれていないか、追加課金の前にまず確認するとよい。

## 注意点・よくある誤解

- **「AIが書いた文章=そのまま送ってよい」ではない**: 特に数値・固有名詞・日付は生成AIが確率的に「もっともらしい」言葉を選んで作文することがあるため(いわゆるハルシネーション=事実に基づかない生成)、送信前に必ず人が事実確認する。
- **トーンは「一発で完璧」を狙わない**: 一度で理想の文章が出ることは少ない。「もう少し柔らかく」「結論を先に」など、対話を重ねて磨き込む前提で使うと効率が良い。
- **社外秘・個人情報を貼り付けない**: 議事録や提案書には顧客情報・未公開の数値が含まれることが多い。組織で許可されたツール・プランを使い、情報漏洩のリスクを理解した上で扱う(詳細は関連トピック参照)。
- **「AIっぽい文章」になりがちな定型パターンに注意**: 「〜が重要です」「まとめると」といった紋切り型の言い回しが多用される傾向がある。読み上げてみて不自然なら、具体語に置き換えるよう追加指示を出す。
- **議事録の要約は原文との突き合わせが必須**: 特に「決定事項」は、後で「言った/言わない」のトラブルになりやすい。AIの要約を鵜呑みにせず、少なくとも重要な合意部分は文字起こし原文を確認する。
- **ツールの仕様は数か月単位で変わる**: 本ページで触れたChatGPTのCanvas廃止のように、編集画面の名称・挙動が短期間で変更されることがある。定期的に公式ヘルプページを確認する習慣を持つとよい。

## 最初の一歩

今書きかけの社内メールか議事録を1つ選び、上記の「コピペで使えるプロンプト例」のいずれかにその内容を貼り付けて、生成された下書きを実際に修正してみる。まずは1往復の対話でどこまで手直しが減るかを体感することから始めるとよい。
