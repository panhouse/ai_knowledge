# Difyとは何か

## これは何か

「ChatGPTのAPIを使って社内専用のAIチャットボットを作りたいが、エンジニアを抱える余裕がない」という悩みに応えるのがDify(ディファイ)である。オープンソースのLLMアプリ開発プラットフォームで、ドラッグ&ドロップの画面操作だけで、AIチャットボットやワークフロー、社内資料を検索して答えるRAGアプリ、自律的に動くAIエージェントを構築できる。

## 仕組み・背景

Difyは「Production-ready platform for agentic workflow development(エージェント型ワークフロー開発向けの実運用対応プラットフォーム)」と公式に説明されており、主に以下の機能で構成される。

- **ワークフロー**: ビジュアルキャンバス上でノードをつなぎ、AIの処理手順を組み立てる。顧客対応の振り分け、データ取得、タスク自動化などに使う。ワークフローの途中で人間の承認・入力を待つ「人間参加型(Human-in-the-Loop)」ノードも強化され、テキストだけでなくドロップダウン選択やファイルアップロードでの入力待ちにも対応した。
- **チャットボット/チャットフロー**: プロンプトを直感的に編集できる画面(プロンプトIDE)で、モデルの比較や音声合成の追加などができる。モデルの思考過程(Chain-of-Thought)を専用パネルで可視化する機能も追加され、最終回答をシンプルに保ったまま推論過程を確認できる。
- **エージェント/Agent App**: LLMに自律的な意思決定をさせる機能。Google検索や画像生成など50以上の組み込みツールと連携できる。2026年に入り「Agent App」がベータ公開・デフォルト有効化され、コード実行やシェルコマンドを動かせる組み込みサンドボックス、ツール・API呼び出しの「スキル」システム、ワークスペース内でエージェントを使い回す「エージェントロスター」機能が加わった。ただしAgent Appは「信頼できる利用者向け」と公式に注意喚起されており、不特定多数に開放する用途には向かない。
- **RAGナレッジベース**: PDFやPowerPoint等からのテキスト抽出に標準対応し、文書の取り込みから検索までを一気通貫でカバーする。ハイブリッド検索(密ベクトル+疎ベクトル)やFAQ自動生成向けのQ&A抽出モードなど、検索精度を上げる仕組みも継続的に強化されている。
- **MCP(Model Context Protocol)対応**: DifyはMCPの「クライアント」としても「サーバー」としても機能する。クライアントとしてはファイルシステム・GitHub・Slack・DB・ブラウザなど外部のMCPサーバーにエージェントから接続でき、サーバーとしてはDifyで作ったワークフローやエージェントをMCPエンドポイントとして公開し、Claude CodeやCursorなど他のMCPクライアントから呼び出せる。
- **difyctl(CLI)**: ターミナルからDifyのアプリ・ワークフローを実行できるコマンドラインツール。Web UIを開かずに、個人利用のスクリプトやCI/CDパイプラインに組み込める。

ライセンスはApache License 2.0をベースにした独自の「Dify Open Source License」で、自社の1組織内で使う分には商用利用を含めて制限はない。API連携やWebサイトへの埋め込み、共有アプリとしての公開も無償の範囲でよい。ただし、Difyを使って作ったアプリを「マルチテナント型のSaaS」として外部に公に提供する場合は、Difyから書面の許可を得るか商用ライセンス(business@dify.aiへの問い合わせ)の取得が必要になる点に注意。

## 使いどころ・使い分け

| やりたいこと | 向いているツール |
|---|---|
| AIチャット・生成AIを軸にした業務アプリを作りたい | Dify(LLM連携が主軸のエンジン) |
| 複数のSaaS・DBをつないで定型業務を自動化したい | n8n(セルフホスト可能、JavaScript/Pythonでの複雑なロジックにも対応) |
| ノーコードで手軽に業務効率化したい(マーケティング部門中心) | Make |
| セキュリティ・柔軟性を重視したい | n8n |
| 作ったAIエージェントをClaude Code/Cursorなど他のAIツールからも呼び出したい | Dify(MCPサーバーとして公開) |

日本語の解説では「Difyはエンジン(思考・生成の専門職)、n8n/Makeは自動化オーケストレーター(仕事をつなぐ指揮者)」という比喩が使われており、AIによる生成・判断が中心ならDify、システム間連携が中心ならn8n/Makeという住み分けが目安になる。

## 実務での使い方

### Dify Cloud版のプラン体系(2026年7月時点。料金は変更頻度が高いため公式サイト dify.ai/pricing で必ず最終確認すること)

| プラン | 月額 | 主な内容 |
|---|---|---|
| Sandbox(無料) | $0 | Dify提供モデルを試せる200クレジット付与、ストレージ50MB、ドキュメント最大50件。ワークスペース1・メンバー1名 |
| Professional | $59/月(年払いで$590、約$118お得) | ワークスペース1、メンバー3名、アプリ50、月間メッセージクレジット5,000、ナレッジ文書500件、ナレッジ容量5GB |
| Team | $159/月(年払いで$1,590、約$318お得) | メンバー50名、アプリ200、月間メッセージ10,000、ナレッジ文書1,000件、ナレッジ容量20GB |
| Enterprise | 個別見積り(年払いのみ) | SSO・監査ログ・専任サポート・SLAなど法人向け機能 |

いずれの料金もVAT等の税別で、サブスクリプション料金とは別に、OpenAI/Anthropicなど利用するLLMプロバイダーの推論(トークン)課金が発生する点に注意。

### セルフホスト版との違い(3つの選択肢)

Difyのソフトウェア自体(Community Edition)は無料で、Docker Composeを使えば自社サーバーやVPS上に比較的簡単にデプロイできる。基本機能はクラウド版と同等だが、Dify本体のロゴ表示は変更できない。

自社運用には、用途に応じて3段階の選択肢がある。

- **Community(無料)**: 自社利用ならライセンス制限なし。ロゴ・ブランディングは変更不可
- **Premium**: AWS Marketplace等で提供される、自社VPCに1クリックでデプロイできるAMI。ブランディング変更(「Powered by Dify」表示の削除・自社ロゴへの差し替え)が可能。中小規模で自前導入したい場合や、Enterprise導入前のPoC用途に向く
- **Enterprise**: ライセンスキーを適用することで、マルチテナント管理・SSO(SAML/OIDC/OAuth2)・監査ログ・二段階認証などの機能が解放される

自社運用はインフラコストと保守の手間がかかる代わりに、データを完全に自社管理でき、長期的にはコストを抑えられる可能性がある。

### 代表的なユースケース

- **社内問い合わせボット**: 社内規程やマニュアルをナレッジベースとして取り込み、社員からの質問にAIが回答する
- **カスタマーサポートの一次対応**: 顧客の問い合わせ内容を感情分析→返信ドラフト生成→複雑な案件は人間へエスカレーション、という流れをワークフローとして数分で構築できる
- **OpenAI API等との連携**: モデルプロバイダーの設定画面にOpenAIやAnthropicなどのAPIキーを入力するだけで、任意のLLMをDifyのアプリから利用できる
- **社内ツールのMCP公開**: Difyで作った業務ワークフローをMCPサーバーとして公開し、Claude Codeなど社内で使う別のAIツールから直接呼び出す

## 注意点・よくある誤解

- **「無料で使える」と「マルチテナントSaaSとして外部提供できる」は別問題**: 自社利用は無料範囲でも、Difyで作ったアプリを不特定多数向けのSaaS製品として販売する場合はライセンス上の許可が必要になる。この点を見落としたまま外部提供を計画すると、後から契約上の手戻りが発生する。
- **料金・プラン名は変更されやすい**: クラウドサービスの常として、料金体系は改定される可能性がある。記事や社内資料に反映する前に公式サイトで最終確認する。
- **セルフホストは「無料」だが「タダ」ではない**: ソフトウェア利用料はかからないが、サーバー費用と運用の手間というコストが発生する点を導入前に見積もっておく。「ブランディングだけ変えたい」ならCommunityではなくPremium、SSO等が必要ならEnterpriseと、要件に応じて選ぶ層が変わる。
- **Agent Appはまだベータで、無制限公開には向かない**: コード実行・シェルコマンドを扱える分、公式にも「信頼できる利用者向け」と注意喚起されている。社外の不特定多数に触らせる用途では、権限設計やサンドボックスの分離を別途確認すること。

## 最初の一歩

dify.aiでSandbox(無料プラン)のアカウントを作成し、社内FAQを1つナレッジベースに読み込ませて、簡単な質問応答チャットボットを作ってみる。
