# Difyとは何か

## これは何か

「ChatGPTのAPIを使って社内専用のAIチャットボットを作りたいが、エンジニアを抱える余裕がない」という悩みに応えるのがDify(ディファイ)である。オープンソースのLLMアプリ開発プラットフォームで、ドラッグ&ドロップの画面操作だけで、AIチャットボットやワークフロー、社内資料を検索して答えるRAGアプリを構築できる。

## 仕組み・背景

Difyは「Production-ready platform for agentic workflow development(エージェント型ワークフロー開発向けの実運用対応プラットフォーム)」と公式に説明されており、主に4つの機能で構成される。

- **ワークフロー**: ビジュアルキャンバス上でノードをつなぎ、AIの処理手順を組み立てる。顧客対応の振り分け、データ取得、タスク自動化などに使う。
- **チャットボット**: プロンプトを直感的に編集できる画面(プロンプトIDE)で、モデルの比較や音声合成の追加などができる。
- **エージェント**: LLMに自律的な意思決定をさせる機能。Google検索や画像生成など50以上の組み込みツールと連携できる。
- **RAGナレッジベース**: PDFやPowerPoint等からのテキスト抽出に標準対応し、文書の取り込みから検索までを一気通貫でカバーする。多くの競合ツールがRAGを後付け機能として提供するのに対し、Difyは検索機能を中核機能として設計している点が特徴。

ライセンスはApache License 2.0をベースにした独自の「Dify Open Source License」で、自社の1組織内で使う分には商用利用を含めて制限はない。ただし、Difyを使って作ったアプリを「マルチテナント型のSaaS」として外部に公に提供する場合は、Difyから書面の許可を得るか商用ライセンスの取得が必要になる点に注意。

## 使いどころ・使い分け

| やりたいこと | 向いているツール |
|---|---|
| AIチャット・生成AIを軸にした業務アプリを作りたい | Dify(LLM連携が主軸のエンジン) |
| 複数のSaaS・DBをつないで定型業務を自動化したい | n8n(セルフホスト可能、JavaScript/Pythonでの複雑なロジックにも対応) |
| ノーコードで手軽に業務効率化したい(マーケティング部門中心) | Make |
| セキュリティ・柔軟性を重視したい | n8n |

日本語の解説では「Difyはエンジン(思考・生成の専門職)、n8n/Makeは自動化オーケストレーター(仕事をつなぐ指揮者)」という比喩が使われており、AIによる生成・判断が中心ならDify、システム間連携が中心ならn8n/Makeという住み分けが目安になる。

## 実務での使い方

### Dify Cloud版のプラン体系(2026年7月時点の目安。料金は変更頻度が高いため公式サイト dify.ai/pricing で必ず最終確認すること)

| プラン | 月額の目安 | 主な違い |
|---|---|---|
| Sandbox(無料) | $0 | お試し利用向け。ワークスペース1、メンバー1名、アプリ数・ナレッジ容量に制限 |
| Professional | 有料(数十ドル程度) | メンバー数・アプリ数・ナレッジ容量が拡大、APIレート制限なし |
| Team | Professionalより上位 | メンバー数・トリガー実行数がさらに拡大、高度な分析連携が可能 |
| Enterprise | 個別見積り | SSO・監査ログ・専任サポートなど法人向け機能 |

年払いにすると月払いよりまとまった割引が受けられるプランもある。

### セルフホスト版との違い

Difyのソフトウェア自体は無料で、Docker Composeを使えば自社サーバーやVPS上に比較的簡単にデプロイできる。基本機能はクラウド版と同等だが、SSOや監査ログなどの法人向け機能は別途「Dify Enterprise」が必要になる。自社運用はインフラコストと保守の手間がかかる代わりに、データを完全に自社管理でき、長期的にはコストを抑えられる可能性がある。

### 代表的なユースケース

- **社内問い合わせボット**: 社内規程やマニュアルをナレッジベースとして取り込み、社員からの質問にAIが回答する
- **カスタマーサポートの一次対応**: 顧客の問い合わせ内容を感情分析→返信ドラフト生成→複雑な案件は人間へエスカレーション、という流れをワークフローとして数分で構築できる
- **OpenAI API等との連携**: モデルプロバイダーの設定画面にOpenAIやAnthropicなどのAPIキーを入力するだけで、任意のLLMをDifyのアプリから利用できる

## 注意点・よくある誤解

- **「無料で使える」と「マルチテナントSaaSとして外部提供できる」は別問題**: 自社利用は無料範囲でも、Difyで作ったアプリを不特定多数向けのSaaS製品として販売する場合はライセンス上の許可が必要になる。この点を見落としたまま外部提供を計画すると、後から契約上の手戻りが発生する。
- **料金・プラン名は変更されやすい**: クラウドサービスの常として、料金体系は改定される可能性がある。記事や社内資料に反映する前に公式サイトで最終確認する。
- **セルフホストは「無料」だが「タダ」ではない**: ソフトウェア利用料はかからないが、サーバー費用と運用の手間というコストが発生する点を導入前に見積もっておく。

## 最初の一歩

dify.aiでSandbox(無料プラン)のアカウントを作成し、社内FAQを1つナレッジベースに読み込ませて、簡単な質問応答チャットボットを作ってみる。
