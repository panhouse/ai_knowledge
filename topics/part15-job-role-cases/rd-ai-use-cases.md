# 研究開発(R&D)職における生成AI活用事例

## これは何か

研究開発(R&D)の現場では「先行研究を読み込む」「実験計画を練る」「特許明細書を書く」「技術報告書を仕上げる」「他部門に技術内容をわかりやすく伝える」といった、時間のかかる知的作業が積み重なる。生成AIはこれらの作業の下書き・たたき台づくりを大幅に高速化できるが、研究開発領域には「存在しない論文を実在するかのように生成する」「未公開の発明情報を外部AIに入力すると特許の新規性を失いかねない」といった、他部門にはない特有のリスクもある。本ページは、R&D部門での主な活用シーン別に、使うツール・コピペで使えるプロンプト・注意点を整理する。

## 仕組み・背景

汎用チャットAI(ChatGPT・Claude・Gemini)は学習データに基づいて「それらしい」文章を生成する仕組みのため、専門分野の細かい論文情報を聞かれると、実在する複数の論文の内容を混ぜ合わせて存在しない論文タイトル・著者名・数値を作り出すことがある。これは通常のハルシネーション(生成AIが事実と異なる内容を自信満々に生成する現象、詳細は[ハルシネーションとは何か・対策](../part04-risk-security/hallucination-and-countermeasures.md)を参照)の一種だが、研究開発領域では「引用文献がそもそも実在しない」という形で表面化しやすいのが特徴である。

これに対応するため、Elicit・Consensus・SciSpaceのような**専門分野特化の学術AI検索ツール**が登場している。これらは汎用AIのようにWeb全体やモデルの学習データから答えを「生成」するのではなく、Semantic Scholar(1億件超の論文データベース)やClinicalTrials.govなど**実在する論文データベースを直接検索**し、見つかった論文の中身をAIが要約・構造化して返す仕組みになっている。そのため回答の根拠となる論文には必ず実在のリンクが付き、「論文を検索してから要約する」という順序が守られる分、汎用チャットAIより文献調査の信頼性が高くなりやすい。

一方、実験計画の壁打ちや技術文書の平易化のような「専門データベースの検索」を必要としない作業では、汎用チャットAIの方が柔軟で使いやすい。この違いを理解した上でツールを使い分けることが、R&D領域での生成AI活用の土台になる。

## 使いどころ・使い分け

### 主な活用シーンとツールの対応

| 活用シーン | 向くツール | 理由 |
|---|---|---|
| 文献調査・先行研究サーベイ | Elicit / Consensus / SciSpace、または汎用AIのDeep Research機能 | 実在する論文データベースを根拠にできる |
| 実験計画・仮説立案の補助 | 汎用チャットAI(ChatGPT / Claude / Gemini) | 「壁打ち」に強く、自社の実験文脈をその場で伝えながら対話できる |
| 実験データの分析・可視化 | 汎用チャットAIのデータ分析機能 | コードを書いて実行し集計・グラフ化するため数値の再現性が高い |
| 特許調査・特許明細書のドラフト作成 | 特許調査は専用DB(J-PlatPatなど)+AI要約、明細書ドラフトは専用の特許AIツールまたは汎用AI(要弁理士レビュー) | 特許要件(新規性・進歩性)の判断は専門知識が前提 |
| 技術報告書・社内向け技術文書の作成 | 汎用チャットAI | 定型フォーマットへの落とし込み・文章化が得意 |
| 他部門への技術内容の平易な説明資料作成 | 汎用チャットAI | 「読者のレベルに合わせて言い換える」処理が得意 |

### 文献調査ツールの比較(2026年7月時点)

| ツール | 検索対象 | 特徴的な機能 | 料金の目安 |
|---|---|---|---|
| Elicit | Semantic Scholar経由の学術論文1.25億件超、ClinicalTrials.govの臨床試験54万件超 | 論文を表形式に要約する「データ抽出」、PRISMA準拠のシステマティックレビュー支援、複数論文を横断する自動レポート生成 | 無料(Basic)/ Plus 12ドル・Pro 49ドル・Team 79ドル(いずれも/月、年払いで35%オフ) |
| Consensus | 査読付き論文2億件超 | 論文間の意見の一致度を示す「Consensus Meter」、数十本を読み込んで研究ギャップまで示す「Deep Search」 | 無料(Pro回答月15件・Deep Search月3件)/ Pro 10ドル前後(月、学生向けは9ドル) |
| SciSpace | 学術論文全般、PDFのチャット機能 | 論文PDFをアップロードして図表・数式込みで質問できる「Chat with PDF」、150以上のツールを組み合わせるAIリサーチエージェント | 無料(Basic)/ Premium 20ドル(年払い12ドル)/ Lab(5名)100ドル(いずれも/月) |

判断基準は「答えの根拠になる論文リストを人に見せる必要があるか」。社内報告や特許出願の先行技術調査のように**出典の実在性が問われる場面**では専門ツールを使い、逆に「自分の理解を整理したい」「アイデアを広げたい」だけの場面では汎用チャットAIで十分なことが多い。なお、汎用チャットAIのDeep Research機能(仕組み・使い分けの詳細は[生成AIによる情報収集・リサーチの実務活用(Deep Research機能)](../part12-business-practice/ai-research-and-information-gathering.md)を参照)もWeb上の学術情報を横断調査できるが、対象が学術データベースに限定されないため、査読の有無や論文としての実在性の確認はより入念に行う必要がある。

## 実務での使い方

### シーン1: 文献調査・先行研究サーベイ

Elicit・Consensus・SciSpaceのいずれも、テーマや質問文を入力するだけで関連論文を検索し、要約・比較表を作ってくれる。

```
以下のテーマについて、直近5年以内に発表された査読付き論文を中心に調査してください。

【テーマ】リチウムイオン電池の負極材料としてのシリコン系材料の劣化メカニズム
【欲しい出力】
1. 主要な劣化メカニズムの分類(3〜5種類)
2. 各メカニズムに対する対策技術とその効果(論文の出典付き)
3. まだ解決されていない課題(研究ギャップ)
【条件】各論文には必ずタイトル・著者・発表年・リンクを明記すること
```

### シーン2: 実験計画・仮説立案の補助

汎用チャットAIを「壁打ち相手」として使い、実験条件の見落としや仮説の穴を洗い出す。

```
あなたは材料科学の研究アドバイザーです。以下の実験計画について、
実験を始める前にレビューしてください。

【目的】○○樹脂の耐熱性を向上させる添加剤の効果を検証する
【仮説】添加剤Xの配合比率を5%まで増やすほど耐熱温度が上がる
【予定している実験】添加剤Xの配合比率を0%/2%/5%/8%の4条件で作成し、
熱重量分析(TGA)で分解開始温度を比較する

以下の観点でレビューしてください。
1. この実験計画で交絡因子(結果に影響しうる、意図せず変化してしまう要因)になり得るものは何か
2. 対照群・条件数は十分か、追加すべき条件はあるか
3. 想定される結果パターンごとに、次にとるべきアクションを整理してほしい
```

### シーン3: 実験データの分析・可視化

実験で得られた数値データ(CSV・Excel)は、汎用チャットAIのデータ分析機能にそのままアップロードして集計・グラフ化できる。仕組み・操作手順・日本語グラフの文字化け対策などの詳細は[ChatGPTのデータ分析機能(Advanced Data Analysis)の使い方](../part07-data-analysis/chatgpt-advanced-data-analysis.md)を参照。

```
アップロードしたCSVは、添加剤配合比率(%)と熱重量分析による分解開始温度(℃)の
測定結果です(各条件n=3で測定)。

1. 配合比率と分解開始温度の関係を散布図にし、回帰直線を重ねてください
2. 相関係数と、回帰の傾き・切片・p値を教えてください
3. 各条件の測定値のばらつき(標準偏差)も表にまとめてください
```

### シーン4: 特許調査・特許明細書のドラフト作成

特許調査は、AIに検索させる前提として、まずJ-PlatPat(特許情報プラットフォーム)や商用の特許検索DBで対象特許・公報を特定し、その内容を汎用AIに読み込ませて要約・比較させるのが実務的な使い方になる。

```
アップロードした特許公報3件(A・B・C)について、以下を整理してください。
1. 各公報のクレーム(請求項)の技術的な要点を1文で要約
2. 3件に共通する技術要素と、それぞれの差異点
3. 我々が検討している技術(下記【自社技術】)と重なる可能性がある請求項があれば指摘

【自社技術】(発明の概要を記載。※社外秘情報は自社の許可されたAI環境でのみ入力すること)
```

特許明細書そのもののドラフト生成には、発明メモや技術ノートを読み込んで「課題・構成・効果」の特許構造に沿った下書きを作る専用サービス(例: リーガルテック社の「AIドラフト生成機能」など)も登場している。汎用AIで下書きを作る場合は、弁理士・知財部門による確認前提の「一次ドラフト」としてのみ使い、そのまま出願に使わないこと。

### シーン5: 技術報告書・社内向け技術文書の作成

```
以下の実験メモ(箇条書き)を、社内の技術報告書フォーマットに沿って文章化してください。

【フォーマット】背景 / 目的 / 実験方法 / 結果 / 考察 / 今後の課題
【実験メモ】
(実験ノートの箇条書きメモをここに貼り付け)

【条件】
- 数値・単位はメモの記載をそのまま使い、新しい数値を創作しないこと
- 断定できない考察には「推測」「要追加検証」と明記すること
```

### シーン6: 他部門への技術内容の平易な説明資料作成

```
以下は研究部門向けに書いた技術メモです。これを営業部門向けに、
専門用語をできるだけ使わずに3分で読める説明文に書き換えてください。

【読み手】製品の技術的な仕組みは知らないが、顧客への提案には使いたい営業担当者
【アウトプット】
1. この技術が「何を解決するのか」を1文で
2. 従来技術と比べて何が優れているのかを1〜2文で
3. 顧客に説明する際に使えるたとえ話を1つ

【元の技術メモ】
(技術メモをここに貼り付け)
```

## 注意点・よくある誤解

- **存在しない論文・実験結果をAIが生成するリスクは実際に増えている**: 学術論文における捏造引用(実在しない論文をAIが生成して引用する現象)の発生率は、2023年の約2,828論文に1件だったのに対し、2026年初頭には約277論文に1件まで急増したとの大規模調査が報告されている。文献調査にAIを使った場合は、**回答に出てきた論文タイトル・著者名・DOIを実際に検索して実在を確認する**ことを必須の運用にする。Elicit・Consensus・SciSpaceのような専門ツールは実在DBを検索するため相対的にリスクは低いが、それでも要約や解釈の誤りは起こり得るため、重要な結論の根拠になる論文は原典を人が読んで確認する
- **汎用チャットAIに未公開の発明・実験データを入力すると特許の新規性を失う恐れがある**: 特許制度では出願前にその内容が外部に公知(誰でも知りうる状態)になった時点で、原則としてその発明は特許を取得できなくなる。個人向け・無料プランの汎用AIチャットは、入力内容が学習データとして利用される規約になっている場合があり、未公開の発明の詳細をそのまま入力することは、意図せず技術情報を外部に開示するリスクを伴う。社外秘の発明内容を扱う際は、法人契約(Business/Enterprise、学習への非利用がデフォルトの契約)を使う、またはローカルLLM・社内専用環境を使うなど、[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md)に従った運用を徹底する
- **特許明細書のAIドラフトは「下書き」であり出願書類ではない**: 特許要件(新規性・進歩性・記載要件など)の判断や、クレーム(請求項)の権利範囲の設計には専門知識が必要で、AIが生成した文章の完成度は人間の専門家(弁理士)に及ばないとされている。AIドラフトは必ず弁理士・知財部門のレビューを経てから出願する
- **実験データの分析結果も検算する**: データ分析機能はコードを実行して集計するため単純な計算ミスは起きにくいが、「集計軸の解釈」や「外れ値の扱い」を取り違えることがある。重要な数値は元データや統計ソフトの結果と突き合わせて確認する(詳細は[ChatGPTのデータ分析機能(Advanced Data Analysis)の使い方](../part07-data-analysis/chatgpt-advanced-data-analysis.md)の注意点を参照)
- **専門分野特化ツールでも「無料枠」には検索回数・Deep Search回数の上限がある**: 本格的に文献調査に使うなら有料プランへの移行が前提になることが多い。まずは無料枠で自分の研究テーマに合うツールかを見極めるとよい

## 最初の一歩

直近で読み込んだ・読み込もうとしている先行研究のテーマを1つ選び、Elicit・Consensus・SciSpaceのいずれか(無料プランで試せる)にそのテーマを入力して要約レポートを作らせ、出てきた論文のうち2〜3本のタイトルを実際に検索して実在するか確認してみる。
