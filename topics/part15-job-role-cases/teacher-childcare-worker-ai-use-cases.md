# 教員・保育士における生成AI活用事例

## これは何か

本ページは、小中高の学校教員・学習塾講師・保育士という**「子どもと直接向き合う個人」**が、自分の日々の業務(授業準備・採点・所見作成・連絡帳・保育日誌など)に生成AIをどう使うかを扱う。[教育における生成AI活用事例](../part14-industry-cases/education-ai-use-cases.md)が学校・大学・EdTech企業が導入する**教材配信システムやアダプティブラーニング基盤**を組織・業界目線で扱い、[保育・幼児教育における生成AI活用事例](../part14-industry-cases/childcare-early-education-ai-use-cases.md)が保育ICT(情報通信技術)企業のサービスを園・施設目線で扱うのに対し、本ページは**教員・保育士という個人が、自分の手元でチャットAIをどう使えば日々の作業が楽になるか**という業務者目線に絞る。園・学校がすでに保育AI・教材AIを導入している場合はそちらの機能を使えばよいが、そうしたシステムが手元にない教員・保育士のほうが多数派であり、本ページは「今日から個人でChatGPT・Geminiを開いて試せること」を中心に整理する。

学校教員・学習塾講師・保育士を同じページにまとめているのは、いずれも「対象となる子どもの個人情報を扱いながら、文章(授業案・所見・連絡帳など)を日常的に大量生産する」という業務構造が共通しているためである。一方で学校教員は成績評価・入試といった評価責任を負う点、保育士は0〜6歳児の生活記録(午睡・食事・排泄等)が中心になる点で違いもあるため、実務での使い方は学校教員・学習塾講師/保育士に分けて記載する。

## 仕組み・背景

教員・保育士向けの生成AI活用は、店舗スタッフ等と同様に大きく2系統に分かれる。

1. **汎用チャットAI(ChatGPT・Gemini・Copilot等)を個人で使う**: 学校・園がAIツールを契約していなくても、教員・保育士個人が私費/フリープランのアプリを開いて授業案のたたき台や連絡帳の文章を作らせる使い方。導入コストがほぼゼロで今日から始められる反面、入力した文章が学習に使われる設定のままだと情報漏洩リスクがあるため、個人情報の入力可否を自分で判断する必要がある。
2. **教育機関向けに提供される専用プラットフォーム**: Googleは2025年7月に「Gemini in Classroom」を無償提供開始し、2026年5月には日本語にも対応、Google Workspace for Education Fundamentals/Standard/Plusの利用者であれば Google Classroom内のGeminiタブから、授業計画の下書き作成・小テスト作成・単語リスト作成・ルーブリック(評価基準表)作成など30以上の機能を追加費用なしで使える(2026年5月時点)。Microsoftも「Microsoft 365 Copilot for Education」を教育機関向けライセンス(A3/A5等、300シート以上のテナント単位)で提供し、教員向けにはCopilot Chatを無償で使える枠を用意している(2026年8月時点)。これらは学校側が契約していれば教員が個人契約なしに使える点が汎用チャットAI単体との違いになる。

保育・学習塾の現場では、専用プラットフォームよりも**音声入力と組み合わせた文章化ツール**が広がっている。子どもを見守りながらスマホに話しかけると、AIが音声を文字起こしして保護者向けの丁寧な文章に自動変換し、蓄積した音声メモから保育日誌・月案の下書きも生成する、という使い方が2026年時点で複数の保育ICTサービスに搭載されている(詳細は[保育・幼児教育における生成AI活用事例](../part14-industry-cases/childcare-early-education-ai-use-cases.md)を参照)。

学校現場では、文部科学省が2023年7月に公表した「初等中等教育段階における生成AIの利活用に関するガイドライン」を2024年12月に「Ver.2.0」へ改訂し、教職員が校務で使う場面・児童生徒が学習活動で使う場面・教育委員会が押さえる点を整理した。参考資料編には「教職員が校務で利活用する際のチェック項目」が用意されている。さらに2026年6月30日の中央教育審議会「デジタル学習基盤特別委員会」(第10回)では、生成AIパイロット校の実践から①児童生徒の指導に関わる業務の支援(授業準備・部活動・生徒指導等)、②学校運営に関わる業務の支援(教務管理・情報発信・校内研修等)、③外部対応への支援、という3領域の活用例が蓄積されつつあることが報告され、2026年度中に教育委員会担当者向けの校務利活用の手引を作成する方針が示された(ガイドラインのVer.2.1への早期改訂検討も進行中、公表時期は2026年8月時点で未定)。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

学校教員・学習塾講師と保育士では1日の業務の流れが異なるため、それぞれのフェーズに沿ってAIの使いどころを整理する。

**学校教員・学習塾講師**

| 業務フェーズ | 頻度 | AIの使いどころ | 向く担当 |
|---|---|---|---|
| 授業準備・指導案作成 | 毎日〜週数回 | 単元・学年を伝えて授業案の下書き、発問例の案出し | 教員・講師 |
| 教材・ワークシート・小テスト作成 | 週数回 | 既存教材を基にした類題・穴埋め問題・小テストの自動生成 | 教員・講師 |
| 採点・添削・フィードバック作成 | テスト・提出物のたび | 記述式答案への模範解答比較、コメント文案の下書き(最終判定は必ず人が行う) | 教員・講師 |
| 個別の学習教材づくり | 生徒のつまずきが判明した時 | 生徒の誤答パターンを伝え、その子向けの補充問題・解説を生成 | 教員・講師 |
| 通知表所見・指導要録の作成 | 学期末・年度末 | 箇条書きの観察メモから所見文のたたき台を生成 | 教員 |
| 保護者連絡・学級通信 | 随時〜週1回 | 連絡メモを学級通信・お便りの文章に整形 | 教員・講師 |
| 校務文書・会議資料 | 随時 | 議事録要約、行事計画書のたたき台作成 | 教員 |

**保育士**

| 業務フェーズ | 頻度 | AIの使いどころ | 向く担当 |
|---|---|---|---|
| 保育計画(週案・月案)作成 | 週1回・月1回 | 狙い・活動内容の箇条書きからたたき台を生成 | 保育士 |
| 保育日誌・保育記録 | 毎日 | 音声メモ・箇条書きから、その日の記録文を整形 | 保育士 |
| 連絡帳の作成 | 毎日 | 子ども一人ひとりの様子メモを保護者向けの文章に変換 | 保育士 |
| 児童票・要録(育ちの記録)作成 | 年度末 | 一定期間の記録を要約し、振り返り文のたたき台を生成 | 保育士 |
| 活動・製作のアイデア出し | 随時(季節行事の前等) | 年齢・ねらいを伝えて製作活動・遊びの案出し | 保育士 |
| 園だより・クラスだより作成 | 月1回 | 箇条書きの予定・お知らせを文章に整形 | 保育士 |

判断の軸は店舗スタッフ職と同様、「文章の下書きで済む業務」か「評価・診断の責任を伴う業務」かで分けるとよい。授業案・連絡帳の下書きは汎用チャットAIで十分に価値が出るが、成績評価・入試選抜・児童の発達診断のように結果が子ども本人の人生・処遇に直結する判断は、AIに最終決定をさせず必ず人間が確認・決定する運用に留める。

### 使えるツール・構成(汎用チャットAI vs 専用プラットフォーム)

| 業務 | 汎用チャットAI(ChatGPT/Gemini/Copilot)でできる範囲 | 専用プラットフォームが必要な範囲 |
|---|---|---|
| 授業案・教材作成 | 単元・ねらいを伝えての下書き作成、発問例の案出し | 学習履歴と連携した個別最適教材の自動出し分け(atama+、スタディサプリ等) |
| 採点・添削 | 模範解答との比較、コメント文の下書き(選択式・定型記述向け) | ルーブリックに基づく大量答案の一括自動採点(専用採点AI) |
| 所見・要録作成 | 箇条書きメモからの文章化 | 校務支援システムと連携した名簿一括生成・提出管理 |
| 保育日誌・連絡帳 | 箇条書き・音声メモからの文章化 | 保育ICTシステムに蓄積された記録の自動要約(ルクミー「すくすくレポート」等) |
| 保護者・生徒対応のFAQ化 | よくある質問への回答例のたたき台作成 | 学校・園の公式チャットボットとしての常時応答 |

学校・園がすでにGemini in Classroom・保育AI等を契約している場合はそちらを優先して使えばよい。契約がない、または個人の裁量で使える範囲を試したい場合は、無料〜低価格帯の汎用チャットAIから始めるのが現実的である。

## 実務での使い方

### 1. 授業準備・指導案の下書き作成(学校教員・学習塾講師)

**コピペで使える指導案たたき台プロンプト例**

```
あなたは中学校の授業準備を手伝うアシスタントです。
以下の条件で、50分授業の指導案のたたき台を作成してください。

## 授業の基本情報
教科・単元: {{例: 中学2年 数学「連立方程式の利用」}}
生徒の状況: {{例: 計算はできるが文章題への立式でつまずく生徒が多い}}
本時のねらい: {{例: 文章題を連立方程式に立式できるようになる}}

## 出力してほしい構成
1. 導入(5分): 生徒の興味を引く導入の案を2パターン
2. 展開(35分): 段階的な発問例、生徒がつまずきそうなポイントとその声かけ例
3. まとめ(10分): 本時の振り返りを促す発問
4. 補足: 理解が早い生徒向けの発展課題を1つ

## 出力条件
- 事実に基づかない架空の統計・研究成果は含めない
- あくまでたたき台であり、最終的な内容は担当教員が確認・修正する前提で出力する
```

### 2. 採点・フィードバックの下書き(公平性への配慮つき)

記述式の答案にコメントを付ける際、AIに模範解答との比較をさせつつ、最終的な点数判定は教員が行う運用にするのがポイント。ChatGPTのような汎用モデルによる自動採点は、母語が異なる生徒の言い回しを厳しく評価する傾向が研究で指摘されており、検出・採点結果を鵜呑みにしないことが前提になる。

```
あなたは中学校国語の記述式答案へのフィードバック作成を手伝います。
以下の模範解答の観点をもとに、生徒の解答へのコメント案を作成してください。
点数の断定はせず、「この観点は満たしている/一部不足している」という
評価コメントの下書きに留めてください。

## 設問
{{設問文}}

## 採点観点(ルーブリック)
{{観点1: 、観点2: 、観点3: など}}

## 生徒の解答(氏名など個人情報は入力しない。出席番号や「生徒A」で管理)
{{解答文}}

## 出力条件
- 各観点について満たしている点・不足している点を具体的に指摘する
- 生徒を励ます一言を最後に添える
- 最終的な点数・合否判定は教員が行うため、点数そのものは出力しない
```

### 3. 通知表所見・指導要録のたたき台作成

```
あなたは小学校教員の通知表所見作成を手伝うアシスタントです。
以下の観察メモをもとに、150字程度の所見文のたたき台を3パターン作成してください。

## 観察メモ(出席番号で管理、氏名は入力しない)
{{例: 出席番号12番。係活動に積極的。学習面は算数の図形単元でつまずきが
見られたが、休み時間に自主的に復習する姿が見られた。}}

## 出力条件
- 入力された情報以外の事実(架空のエピソード)を勝手に補わない
- 主観的な決めつけ(「性格が悪い」等)を避け、行動事実に基づいた表現にする
- 「学習面を中心にした案」「行動面を中心にした案」「褒める表現を中心にした案」
  の3パターンを出力する
- 出力後は担当教員が氏名を当てはめ、内容の正確性を確認する前提とする
```

### 4. 保育日誌・連絡帳の下書き作成(保育士)

```
あなたは保育士として、保護者向けの連絡帳の文章を作成します。

## 園の方針・トーン
丁寧だが堅すぎない、温かみのある言葉遣い。子どもの成長・頑張りを
ポジティブに伝える。

## 入力するメモ(箇条書き、または音声メモの文字起こし)
{{例: 給食完食/お昼寝スムーズ/制作活動でクレヨンを上手に使えた/
お友達に「どうぞ」ができた}}

## 出力条件
- 3〜4文程度の自然な文章にする
- 個人名はそのまま出力せず「(なまえ)」のようにプレースホルダーのままにする
- 誤字脱字がないか確認したうえで出力する
- 最後に「本日の一言」として保護者への一言を添える

## 出力形式
連絡帳の本文のみを出力してください。前置きや解説は不要です。
```

### 5. 個別のつまずきに合わせた補充教材の生成(学校教員・学習塾講師)

```
あなたは学習塾講師として、生徒の誤答パターンに合わせた補充問題を
作成します。すぐに正解を教えるのではなく、生徒が自分で気づけるような
ヒント付きの問題にしてください。

## 生徒のつまずき
{{例: 分数の割り算で「割る数をひっくり返してかける」というルールを
機械的に適用しているが、なぜそうなるかを理解していない}}

## 出力条件
- ヒント付きの類題を3問作成する
- 最後の1問は「なぜそうなるか」を自分の言葉で説明させる設問にする
- 解答をすぐに示さず、段階的なヒントの形にする
```

## 注意点・よくある誤解

- **児童生徒・園児の個人情報はそのままAIに入力しない**: 個人情報保護委員会・文部科学省ともに、氏名・住所・成績・家庭事情など個人が特定できる情報の入力を避けるよう注意喚起している。プロンプトには出席番号や「生徒A」のような仮名で管理し、無料版の汎用チャットAIでは入力内容が学習に使われる設定になっていないかを事前に確認する。学校・園として法人向けプランを契約する場合は、学習に使われない設定になっているサービスを選ぶ
- **採点・成績評価の最終判断は必ず人が行う**: ChatGPTのような汎用モデルによる自動採点は、母語が異なる生徒の言い回しを厳しく評価する傾向が研究で指摘されている。AIの出力は「採点の下書き・参考コメント」に留め、最終的な点数・合否判定は教員が行う。専用の採点AIを使う場合も同様に、人による確認プロセスを残す運用が前提になる
- **所見・記録は「事実に基づく」原則を崩さない**: 所見・保育記録は、AIが入力されていない出来事を勝手に補って生成してしまう(いわゆるハルシネーション、もっともらしい誤情報を生成する現象)リスクがある。プロンプトには「入力された情報以外の事実を補わない」ことを明記し、出力された文章は必ず担当者が事実確認してから提出・保管する
- **持ち帰り仕事の効率化と労務管理を混同しない**: 保育士は書類作成・製作物の準備などを理由に持ち帰り仕事をする例が一定数あるとされ、勤務先の指示による持ち帰りで残業代が支払われない場合は労務上の問題になりうる。AIによる文章作成の効率化は「持ち帰らずに勤務時間内で終わらせる」ための手段であり、「勤務時間外にAIを使えば早く終わる」という個人の負担軽減策としてすり替わらないよう、園・学校側が業務時間内に完結できる運用を設計する責任を負う
- **AI利用ルールの周知は教育委員会・園の方針を確認してから**: 文部科学省のガイドラインは教職員が校務でAIを使う際のチェック項目を示しているが、自治体・学校によって独自の利用ルール(利用可能なツール、入力禁止情報の範囲等)を定めている場合がある。個人の判断で使い始める前に、勤務先のルールがすでにあるかを確認する
- **「AIが作ったから安心」という思い込みは禁物**: 授業案・所見文・連絡帳のいずれも、AIの出力は一般論としては整っていても、担当している子ども固有の事情・学級の文脈を反映していないことが多い。たたき台として受け取り、担当者本人の知識・観察で必ず補正する前提を崩さない

## 最初の一歩

来週の授業(または来月の保育計画)の指導案・週案を1つ選び、上記の「授業準備・指導案たたき台プロンプト」または「保育日誌・連絡帳の下書き作成」プロンプトにそのまま貼り付けて、AIが出す下書きをどこまで手直しすれば実際に使える内容になるかを一度試してみるとよい。その際、氏名など個人が特定できる情報は入力せず、仮名・出席番号に置き換えることを忘れないようにする。
