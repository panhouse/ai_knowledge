# 人材育成・研修(L&D)担当における生成AI活用事例

## これは何か

人材育成・研修(L&D、Learning & Developmentの略で、社員のスキル向上・能力開発を担う機能)担当は、研修資料・eラーニング教材・ロールプレイ台本・理解度テストなど「教える内容をコンテンツ化する」業務に多くの時間を割く一方、研修効果(受講後に本当に行動が変わったか)の測定が難しいという課題を抱えてきた。本ページは、[人事(HR)職における生成AI活用事例](hr-ai-use-cases.md)が採用・評価・オンボーディング資料作成など人事機能全般を扱うのに対し、教材設計・ロールプレイ練習・スキルギャップ分析という研修(L&D)特有の業務に絞って、生成AIの使いどころを整理する。

## 仕組み・背景

L&D領域での生成AI活用は、大きく3つの系統に分かれる。

1. **汎用チャットAIによる教材ドラフト作成**: 研修の構成案、講義スクリプト、理解度テストの問題文、ロールプレイのシナリオ台本などを、汎用チャットAI(ChatGPT/Gemini/Claude/Copilot)で下書きする使い方。ある製造業の事例では、中堅技能者の作業風景を撮影した動画をGeminiで文字起こしし、ChatGPTでナレーション原稿化、理解度テストはGPTs化して受講者がいつでも復習できる形にするという内製フローが報告されている([バイテックBLOG](https://biz.bytech.jp/blog/e-learning-ai-training/))。
2. **AIロールプレイ(AIロープレ)ツール**: 営業トークやコールセンター応対、管理職の1on1練習などを、AIが顧客役・部下役を演じて疑似体験させる専用ツール。会話の音声・テキストを自動で採点し、フィードバックまで生成する。2026年のトレンドは、声のトーン・表情・ジェスチャーを同時に解析する「マルチモーダル解析」への対応で、テキストの受け答えだけでなく話し方の癖まで評価対象になってきている。Gartnerは2026年までに大企業の60%が従業員育成戦略にAIベースのシミュレーションツールを組み込むと予測しており、導入企業は初年度に300〜500%のROIを報告しているという集計もある([UMU Japan](https://www.umu.co/column/ai-roleplay-2026/))。国内でも、株式会社Sapeetの「SAPI ロープレ」(2026年1月に旧「カルティ ロープレ」から刷新、AIとの対話だけでロールプレイのシーンを自動生成する「シーン作成AI」を搭載)や、PeopleXが2026年1月に開始した「PeopleX AIロープレ」(AIアバターが上司・部下・顧客など役割を演じ分け、複数キャラクターが同時に登場する「マルチペルソナ」形式にも対応)など、専業ベンダーの新規参入・機能拡張が相次いでいる([日本経済新聞](https://www.nikkei.com/article/DGXZQOUC038EY0T01C25A2000000/)、[株式会社Sapeetプレスリリース](https://prtimes.jp/main/html/rd/p/000000093.000026498.html))。
3. **スキルギャップ分析・パーソナライズ学習**: 従業員のスキルデータや業務データをもとに、AIが個人ごとに不足しているスキルを推定し、学習コンテンツを推薦する仕組み。行動データ・評価データ・役割情報をAIが継続的に分析し、スキルが低下しつつある従業員を早期に検知したり、部門横断のスキルインベントリを可視化したりするLMS(学習管理システム)が増えている([elearningtrendz](https://www.elearningtrendz.com/blog/the-state-of-ai-in-corporate-learning/))。国内では、タレントマネジメントシステム「カオナビ」が2026年3月に既存のスキル管理シートをAIが自動で読み取り初期設定する機能を、2026年1月にはダッシュボード上でAIが組織課題を抽出・示唆出しする「AI診断」機能を追加しており、人事データと学習履歴を突き合わせたスキルギャップの可視化が国内ツールでも実用段階に入っている([カオナビ](https://corp.kaonavi.jp/news/pr_20260108/))。

## 使いどころ・使い分け

| 業務 | 汎用チャットAI | 専用AIロープレ/学習プラットフォーム |
|---|---|---|
| 研修構成案・講義スクリプトのドラフト | 向く(下書き作成が主目的) | 対応外(教材制作機能を持つ一部のツールを除く) |
| 理解度テスト・クイズの問題作成 | 向く(GPTs等のカスタムAI化で受講者に公開も可能) | 一部プラットフォームに標準搭載 |
| 営業トーク・接客・1on1のロールプレイ練習 | 限定的(音声・表情の採点機能がない) | 向く(SAPI ロープレ、PeopleX AIロープレ、Sansan Labs「AI営業ロールプレイング」等) |
| スキルギャップの可視化・学習コンテンツの推薦 | 向かない(全社員データの継続分析には不向き) | 向く(LMS(学習管理システム)組み込みのAI機能、カオナビ等のタレントマネジメントシステムのAI診断) |
| 研修効果測定(行動変容の把握) | 向く(受講後アンケートの自由記述要約まで) | 一部の高度なプラットフォームは行動データと連動 |
| 多言語版教材の翻訳・ローカライズ | 向く | 一部プラットフォームに翻訳機能あり |

判断基準は「1対1のインタラクティブな練習・大量データに基づく個別最適化が必要か」で、必要なら専用ツール、そうでなければ汎用チャットAIでの教材ドラフト作成から着手するのが費用対効果が高い。

## 実務での使い方

### プロンプト例1: 研修構成案のドラフト作成

```
あなたは企業研修の設計担当者です。以下の条件で、90分の研修プログラムの構成案を作成してください。

## 対象者
入社2〜3年目の営業職(20名)

## テーマ
既存顧客への「アップセル提案」の進め方

## 出力してほしいもの
1. 研修のゴール(受講後に何ができるようになるか、1文で)
2. アジェンダ(導入・講義・グループワーク・ロールプレイ・振り返りの時間配分)
3. 各パートで使う問いかけ・ディスカッションテーマの案
4. 理解度確認クイズの設問案(5問、選択式)
```

出力された構成案はあくまで叩き台であり、自社の商材知識・過去の失注理由など固有の事例を研修担当者が肉付けする。

### プロンプト例2: 動画教材のナレーション原稿化

```
以下は熟練社員の作業風景を撮影した動画の文字起こしです。この内容をもとに、
新入社員向けの研修動画のナレーション原稿に書き直してください。
- 専門用語には初出で一言説明を付ける
- 1文を短く、聞いて分かる話し言葉にする
- 危険・注意すべき操作の箇所は「ここがポイント」として強調する

[文字起こしテキストを貼り付け]
```

熟練者の作業を撮影 → 音声認識で文字起こし(Gemini等) → チャットAIでナレーション原稿化、という2段階の分業にすると、属人化しがちな技能伝承のコンテンツ化が進めやすい。

### プロンプト例3: ロールプレイ用シナリオ台本の作成

```
新任マネージャー向けの「部下との1on1」ロールプレイ用シナリオを作成してください。

## 設定
部下役: 入社3年目、最近パフォーマンスが落ちているが本人は自覚が薄い

## 出力してほしいもの
1. 部下役を演じる人向けのキャラクター設定(性格・話し方・抱えている事情)
2. マネージャー役が「よくやりがちな失敗パターン」の例
3. ロールプレイ後の振り返りで使う観察ポイント(3〜5項目)
```

専用のAIロープレツールを使う場合は、AI自体が部下役を演じて音声で応答するため、上記のようなシナリオ設計をツールの管理画面に登録して使う流れになる。

### ツール横断の対応表

| 用途 | ツール例 |
|---|---|
| 研修構成案・スクリプト・クイズのドラフト作成 | ChatGPT/Gemini/Claude/Copilot、GPTs化しての社内公開 |
| 営業ロールプレイ・接客ロールプレイ | SAPI ロープレ(旧カルティ ロープレ、シーン作成AIでシナリオも自動生成)、PeopleX AIロープレ(AIアバターが複数役を演じ分けるマルチペルソナ対応)、Sansan Labs「AI営業ロールプレイング」(2026年2月に音声入出力対応) |
| コールセンター応対のロールプレイ・評価 | AmiVoice系のAIロープレサービス、advanced media「AIロープレ」 |
| スキルギャップ分析・学習コンテンツ推薦 | LMS(学習管理システム)組み込みのAI機能(Schoo、AirCourse等)、カオナビの「AIスキル項目インポート」「AI診断」機能 |
| 学習者向けのAIコーチング・質問対応 | LinkedIn Learningの「AI-powered Coaching」(学習ライブラリを参照して個別アドバイス・ロールプレイ練習に応答するチャットボット) |

料金相場は、AIロープレ専用ツールで初期費用0〜100万円・月額固定5〜30万円・ユーザー単価数千円〜数万円という報告がある([UMU Japan](https://www.umu.co/column/ai-roleplay-2026/))。まずは汎用チャットAIで教材ドラフト作成を内製化し、営業・接客など「反復練習が効果を左右する」職種に絞ってAIロープレツールの試験導入を検討するのが現実的な順序である。

## 注意点・よくある誤解

- **AIが作った教材をそのまま配布しない**: 生成AIは一般論としてもっともらしい研修内容を作れるが、自社の商材知識・社内ルール・過去の失敗事例といった固有の文脈は反映されない。必ず研修担当者が事実確認と肉付けを行う。
- **「受講完了率」と「行動変容」を混同しない**: AIロープレは受講完了率や自信度の向上には効果が示されているが、それが実際の業務成果(売上・顧客満足度など)に直結するかは別途の効果測定が必要。
- **評価・査定に直結する場面でのAI判定は補助にとどめる**: ロールプレイのAI採点結果を人事評価にそのまま連動させると、評価の公平性・納得感を損なうリスクがある。最終評価は人によるフィードバックと組み合わせる。
- **受講者の発言・音声・表情データの取り扱いに注意する**: マルチモーダル解析に対応したAIロープレツールは、会話の録音・テキストに加えて声のトーンや表情まで分析対象にする。生体・感情に関わる情報を扱うぶん通常の会話ログより機微度が高いと捉え、利用目的の説明と同意取得、データ保持期間・第三者提供の有無の確認を事前に行う([生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md))。

## 最初の一歩

直近で実施予定の研修を1つ選び、チャットAIに90分研修の構成案とクイズ5問を作らせて、教材準備にかかる時間がどれだけ短縮できるかを試してみる。
