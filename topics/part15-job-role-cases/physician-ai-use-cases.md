# 医師における生成AI活用事例

## これは何か

本ページは、勤務医・開業医が診療の現場で生成AIをどう使っているかを扱う。カルテ(診療記録)の下書き作成、患者への説明文書の言い換え、医学文献・エビデンスの検索、紹介状・診断書のドラフト作成といった、**医師個人が診療の合間に行う文書作成・情報収集業務**にフォーカスする。

隣接ページとの境界を先に整理しておく。看護師・薬剤師・臨床検査技師・診療放射線技師といった**医師以外の医療スタッフ**の活用事例は[看護師・医療スタッフにおける生成AI活用事例](nurse-medical-staff-ai-use-cases.md)で扱い、本ページは医師固有の業務(診断仮説の検討、処方判断、患者への説明責任、学会発表・症例報告など)に絞る。また、病院経営や医療業界全体としてのAI導入動向(電子カルテベンダーの戦略、医療機関のDX投資など)は[医療・ヘルスケアにおける生成AI活用事例](../part14-industry-cases/healthcare-ai-use-cases.md)(業界目線)を参照し、本ページは**医師個人の1日の業務フロー**の目線で書く。

最初に押さえておくべき大前提がある。厚生労働省は2018年12月19日の課長通知で、AIを用いた診断・治療の支援プログラムを医師が利用する場合であっても、**診療の主体は医師であり、最終的な判断の責任は医師が負う**ことを明確にしている。これは医師法第17条(医業は医師でなければ行ってはならない)との関係で示された考え方であり、AIはどれだけ精度が高くても「支援ツール」の位置づけを超えない([m3.com](https://www.m3.com/news/open/iryoishin/653456))。本ページで紹介する使い方も、この前提を踏まえた「下書き・壁打ち・情報整理」の範囲にとどめている。

## 仕組み・背景

医師の生成AI活用は、大きく4つの領域に分かれる。

1. **音声入力によるカルテ・診療文書の下書き作成**: 診察室での医師と患者の会話を音声認識し、生成AIがSOAP形式(S: 主観的情報、O: 客観的情報、A: 評価、P: 計画という診療記録の標準的な書式)などのカルテ下書きに整形する
2. **AI問診による事前情報の構造化**: 患者が受診前にタブレット・スマホで回答した症状を、AIが医学的な文章に翻訳して医師に提示する
3. **医学文献・エビデンス検索**: 症例に関連する最新の論文・診療ガイドラインを、医療特化の検索AIで調べる
4. **患者への説明文書・紹介状・症例報告などの文書ドラフト作成**: 専門的な内容を患者向けにやさしく言い換えたり、紹介状・診断書・学会発表の下書きを作らせたりする

このうち①③④は生成AI(大規模言語モデル)の文章生成能力を使うものだが、放射線科のCT・MRI画像から病変を検出する「画像診断支援AI」は、技術的には従来型の画像認識・物体検知AIが主流であり、生成AIとは異なる技術カテゴリーである。日本医学放射線学会は薬機法上の承認を得たAI画像診断ソフトウェアの一覧を公開しており、AI内視鏡・AI画像読影支援・脳外科手術シミュレーションなどが承認製品として存在する([日本医学放射線学会](https://www.radiology.jp/member_info/ai_softwear_ninsyou.html))。本ページでは主に①③④の「文章を扱う生成AI」を対象とし、画像診断支援AIは薬機法上の医療機器としての性質が異なるため簡単な位置づけの整理のみに留める。

**カルテ下書きの実例**として、JCHO(地域医療機能推進機構)北海道病院など4組織は2026年1月19日、スマートフォンを音声入力端末として使い、診察室での会話から生成AIがカルテの下書きを作成して電子カルテに連携する実証実験を開始した。この仕組みは院内のオンプレミス環境(自院のサーバー内)で生成AIの処理を完結させる点が特徴で、厚生労働省の「ICT機器を活用した勤務環境改善の先駆的取組をおこなうモデル医療機関調査支援事業」に採択されている([NTTドコモビジネス](https://www.ntt.com/about-us/press-releases/news/article/2026/0119.html)、[IT Leaders](https://it.impress.co.jp/articles/-/28877))。音声AIによるSOAP自動生成では、診察が終わった瞬間に8〜9割方完成した文章が画面に提示され、1人あたりのカルテ作成時間が数十秒〜1分程度に短縮されるという報告もある([エムスリーデジカル](https://digikar.m3.com/articles/medical-dx/article108))。

**医療特化型の生成AIプラットフォーム**としては、Ubieが提供する「ユビー生成AI」が2026年1月時点で大学病院10施設以上を含む全国100病院に導入されている。九州がんセンターでは初診カルテ入力の時間を10分短縮、議事録作成の工数を70%削減、琉球大学病院では臨床研究業務を2.33倍に効率化し、緊急転院時の入院初期記録の作成時間を2時間から5分に短縮したとされる(いずれもベンダー公表)([PR TIMES](https://prtimes.jp/main/html/rd/p/000000198.000048083.html))。クリニック向けの「ユビーAI問診」は、患者がタブレットで回答した症状をAIが医師の言葉に翻訳して出力するサービスで、月額約3万円からの価格帯とされる([日経クロステック](https://xtech.nikkei.com/atcl/nxt/column/18/00001/02428/?P=2))。

**制度面**でも、2026年度診療報酬改定でAI活用が加算の評価対象に組み込まれた。生成AIを活用した医療文書(退院時要約・診断書・紹介状等)の原案作成システムを導入し、全職員が常時活用できる研修体制を整えている場合、医師事務作業補助者を実人数の1.2倍(SOAPカルテ作成支援や音声入力システムを組み合わせれば1.3倍)として人員配置基準上算出できるようになった([OPTiM](https://www.optim.co.jp/media/cat-guide/medical_260430-01)、[エムスリーデジカル](https://digikar.m3.com/articles/medical-dx/article84))。医師の働き方改革(2024年4月から時間外労働を原則年960時間・月100時間未満に制限)を進める中で、文書作成の効率化が医師本来の診療業務に時間を戻す手段として位置づけられている。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

医師の診療業務の流れに沿って、どこに生成AIが入るかを整理すると次のようになる。

| 業務フェーズ | 頻度 | AIの使いどころ | 注意度 |
|---|---|---|---|
| 受診前の問診 | 患者ごと | AI問診で患者の症状を事前に構造化し、医師の言葉で提示 | 低(情報整理) |
| 診察中の会話記録 | 診察ごと | 音声認識でSOAP形式のカルテ下書きを自動生成 | 中(内容の確認必須) |
| 診断仮説の検討 | 随時 | 鑑別診断の候補、検査計画の壁打ち相手として使う | 高(最終判断は医師) |
| 文献・エビデンス調査 | 随時〜週次 | 最新のガイドライン・論文を医療特化AIで検索し裏取り | 中(出典確認必須) |
| 患者への説明 | 診察ごと | 専門用語をやさしい言葉に言い換えた説明文のドラフト作成 | 中(誤解を避ける確認) |
| 紹介状・診断書・退院時サマリー | 随時 | 定型文書の下書き作成、電子カルテの記載内容からの要約 | 中(最終記載は医師) |
| 学会発表・症例報告 | 不定期 | スライド構成・アブストラクトのドラフト、関連論文の抽出 | 低〜中(査読前提の下書き) |

判断の軸は、「事実の整理・言い換え・要約」か「医学的な判断そのもの」かで分けるとよい。カルテ下書きや説明文の言い換えはAIが得意な領域だが、鑑別診断・治療方針・処方の決定は、AIの提案を参考情報として扱いつつ、最終判断と責任は常に医師が負う。

### 使えるツール・構成(汎用チャットAI vs 医療特化AI)

| 業務 | 汎用チャットAI(ChatGPT/Gemini/Claude等)でできる範囲 | 医療特化ツールが必要な範囲 |
|---|---|---|
| カルテ下書き作成 | 音声入力機能で話した内容をテキスト化し、書式を整える壁打ち(患者の個人情報は入力しない前提) | オンプレミス完結型の音声認識×生成AI基盤(JCHO北海道病院の実証事例のような専用システム)、電子カルテと連携したSOAP自動生成機能 |
| 文献・エビデンス調査 | 一般的な医学知識の下調べ、英語論文の要約・翻訳の壁打ち(最終的な出典は必ず原著論文で確認) | 査読済み医学論文・診療ガイドラインを直接ソースとし、常に出典を明示するOpenEvidenceのような医療特化検索AI |
| 患者への説明文書 | 個人情報を除いた一般的な病名・治療法の説明文のたたき台作成 | 患者ごとの病態・服薬状況と連携した院内システム、HOKUTOのような医師専用アプリの説明文考案機能 |
| 紹介状・診断書・退院時サマリー | 定型文の言い回し・構成の相談(患者情報は伏せて) | 電子カルテと連携し、患者情報を含めて自動でドラフトを生成する医療文書AI(2026年度診療報酬改定で人員配置上の評価対象になった原案作成システム) |
| 学会発表・症例報告 | スライド構成・アブストラクトの言い回しの相談 | 症例データベースとの連携が必要な統計解析・図表作成は専用統計ソフトと併用 |
| 画像診断支援 | 不可(画像認識・物体検知の技術領域であり、薬機法上の医療機器承認が必要) | 薬機法承認済みのAI画像診断支援ソフトウェア(日本医学放射線学会の認証一覧を参照) |

医師・医学生1,158人を対象にした2026年春のアンケートでは、最も多く使われているAIはChatGPTで医師・医学生ともに約43%だったが、医師では医療特化AIの「OpenEvidence」の利用も目立ち、文献検索・医学情報整理に使う傾向が強いことがわかっている([ケアネット](https://www.carenet.com/news/general/carenet/58981))。OpenEvidenceは査読済み医学論文・国際的な診療ガイドラインを直接のソースとして常に出典を明示する設計で、米国では医師の4割以上が利用しているとされる。日本でも2026年2月頃から医師免許証の画像提示による本人確認で登録できるようになっている([Decades](https://decades.co.jp/openevidence-clinical-guide-202602/))。まずは汎用チャットAIで「言い回し・構成」の壁打ちから始め、患者情報を伴う業務や文献の一次情報としての利用は、院内承認済みのシステムや医療特化AIに切り分けるのが基本線になる。

## 実務での使い方

### 1. 音声入力からのSOAP形式カルテ下書き作成

診察室での会話をICレコーダーやスマホで録音・音声入力し、文字起こしした内容をAIにSOAP形式へ整形させる使い方。**院内で個人情報の取り扱いが許可された環境(オンプレミス型システムや、法人契約で入力データが学習に使われない設定のツール)でのみ行い、患者の氏名・ID等の個人情報を無許可の汎用チャットAIには入力しない**ことが前提になる。

**コピペで使えるSOAPカルテ下書き作成プロンプト例**

```
あなたは医療機関の診療記録作成を補助するアシスタントです。
以下は診察室での医師と患者の会話の文字起こしです。
これをもとに、SOAP形式のカルテ下書きを作成してください。

## 出力フォーマット
S(Subjective/主観的情報): 患者の訴え・自覚症状をそのまま反映
O(Objective/客観的情報): バイタル・診察所見・検査結果など客観的事実
A(Assessment/評価): 会話から読み取れる医師の見解(明言されていない
  推測は行わず、会話内で言及された内容のみを整理)
P(Plan/計画): 治療方針・処方・次回受診の予定など会話内で述べられた内容

## 出力時の注意
- 会話に含まれていない診断・処方は絶対に補完しない
- 聞き取れなかった・曖昧な箇所は「(要確認)」と明記する
- これは下書きであり、最終的な記載内容の確認・修正・確定は
  必ず医師本人が行うことを前提とする

## 会話の文字起こし
{{音声入力・文字起こしの内容をここに貼り付け}}
```

### 2. 患者への説明文書のやさしい言い換え

専門的な病名・治療法の説明を、患者の年齢層・医学的知識レベルに合わせてやさしく言い換える使い方。個人が特定される情報は入力せず、一般的な病態・治療法の説明にとどめる。

```
あなたは患者への説明文書作成を補助するアシスタントです。
以下の医学的な内容を、{{患者の年齢層・想定される知識レベル
(例: 高齢の患者、医学的知識のない成人、小児の保護者)}}にも
理解できるよう、平易な言葉で説明する文章を作成してください。

## 医学的な内容
{{病名・検査結果・治療方針などを記載(患者個人が特定される
  情報は含めない)}}

## 出力時の注意
- 専門用語を使う場合は必ずかっこ内で一言説明を添える
- 不安を過度に煽らない一方で、重要な注意事項(服薬タイミング、
  受診すべき症状など)は明確に伝える
- 断定的な予後の説明は避け、「主治医にご確認ください」という
  一文を末尾に入れる
```

### 3. 医学文献・エビデンスの調査(壁打ち)

症例に関連する最新の知見を調べる前段階として、汎用チャットAIで論点を整理し、最終的な根拠は医療特化検索AIや原著論文・診療ガイドラインで確認する使い方。

```
以下の臨床的な疑問について、考えられる論点・関連しそうな
キーワード・調べるべき診療ガイドラインの候補を整理してください。
ここで出てきた内容は下調べのためのものであり、実際の診療判断は
OpenEvidenceや原著論文・学会ガイドラインで根拠を確認したうえで
行います。

## 臨床的な疑問
{{例: 高齢者の心不全患者における新規経口抗凝固薬の選択基準は？}}

## 出力してほしいもの
1. 論点の整理(考慮すべき因子)
2. 調べるべき診療ガイドライン・学会名の候補
3. 検索に使うと良さそうな英語・日本語のキーワード
```

### 4. 紹介状・退院時サマリーのドラフト作成

電子カルテに記載済みの診療経過を要約し、紹介状や退院時サマリーの下書きを作らせる使い方。2026年度診療報酬改定では、こうした原案作成システムを整備した医療機関に人員配置基準上のメリットが認められている([OPTiM](https://www.optim.co.jp/media/cat-guide/medical_260430-01))。

```
以下は入院患者の診療経過(電子カルテの記載を時系列で並べたもの)
です。これをもとに、退院時サマリーの下書きを作成してください。

## 出力フォーマット
- 入院期間・主病名・既往歴
- 入院時の状態
- 入院中の治療経過(時系列で簡潔に)
- 退院時の状態・処方内容
- 退院後の外来フォロー予定・紹介先への依頼事項

## 診療経過
{{電子カルテの記載内容を時系列で貼り付け}}

## 出力時の注意
- 記載されていない検査値・所見は補完しない
- 下書きであり、最終的な記載内容の確認・確定は主治医が行う前提とする
```

## 注意点・よくある誤解

- **AIの提案は「支援」であり、診断・治療の最終判断と責任は常に医師にある**: 厚生労働省は2018年12月の課長通知で、AIを用いた診断・治療支援プログラムの利用においても診療の主体は医師であり、医師法第17条上の医業として最終的な判断の責任を医師が負うことを明確にしている。AIが出した鑑別診断や治療提案をそのまま採用するのではなく、必ず医師自身の医学的判断を経る運用にする([m3.com](https://www.m3.com/news/open/iryoishin/653456))
- **患者の個人情報を無許可の汎用チャットAIに入力しない**: カルテ下書きや紹介状作成で患者の氏名・生年月日・診療内容を汎用チャットAIの一般ユーザー向けプランに入力すると、個人情報保護法・院内規定に反するリスクがある。院内で承認されたオンプレミス型システムや、法人契約で学習利用がオフになっているツールを使う、または患者情報を伏せ字にしてから入力する運用を徹底する
- **汎用LLMの医学知識は誤り(ハルシネーション)を含みうる**: 汎用チャットAIは学習データの時点で情報が古い場合があり、まれに存在しない論文名や不正確な用量を生成することがある。診療判断の根拠として使う場合は、OpenEvidenceのような出典明示型の医療特化AIや、原著論文・学会の診療ガイドラインで必ず裏取りする
- **画像診断支援AIと生成AIは別物**: 放射線科のAI画像診断支援ソフトウェアは薬機法上の医療機器承認を得た画像認識AIが主流で、ChatGPTのような生成AIとは技術も規制上の位置づけも異なる。未承認の汎用AIに医療画像を読ませて診断の参考にする行為は、薬機法・医師法上のリスクを伴うため避ける
- **AI下書きをそのまま確定保存しない**: カルテ・診断書・紹介状はいずれも法的な記録であり、最終的な記載内容の確認・修正・確定は医師本人が行う。AIが生成した文章に会話内で言及されていない所見や処方が「補完」されていないか、必ず読み返して確認する
- **コピー&ペーストによる患者情報の混入に注意**: 音声入力の文字起こしやカルテ下書きを複数患者分まとめて処理する運用では、別患者の情報が誤って混入するリスクがある。1患者ごとにセッション・チャットを分ける運用にする

## 最初の一歩

まずは患者情報を含まない場面で試す。次の診察後、電子カルテの記載内容(患者の個人情報を伏せた一般的な病態の説明)を使って、上記の「患者への説明文書のやさしい言い換え」プロンプトを一度試し、AIが作った説明文をそのまま患者に渡さず、自分の言葉で調整して使う感覚を体験することが入り口になる。
