# 薬剤師における生成AI活用事例

## これは何か

薬剤師の業務は「調剤・鑑査」「服薬指導」「薬歴記録」「疑義照会」「医薬品情報の検索」「在庫管理」など多岐にわたるが、このうち薬歴記録や添付文書・インタビューフォーム(IF、医薬品の詳細な解説書)の検索といった事務・情報処理系の作業に時間を取られ、本来注力すべき対人業務(患者への服薬指導・アドヒアランス支援)に割ける時間が圧迫されやすい、という構造的な悩みを抱えている。生成AIは、この「対物業務」を圧縮して「対人業務」に時間を振り向けるための道具として、電子薬歴システムへの組み込みという形で急速に普及しつつある。

本ページは、保険薬局・ドラッグストア(調剤併設)に勤務する薬剤師と、病院薬剤師の双方を対象に、薬剤師個人の業務フローに沿って「どこにAIを入れるか」を整理する。同じ薬局・薬剤という題材でも、Part 14「調剤薬局・ドラッグストア業界における生成AI活用事例」は**業界・経営視点**(店舗DX・人手不足対策としての投資判断)を扱うのに対し、本ページは**薬剤師個人の業務手順**に踏み込む。また、医師・看護師の生成AI活用は同じPart 15の別ページ(医師における生成AI活用事例、看護師・医療従事者における生成AI活用事例)で扱っており、本ページは薬剤師固有の業務(調剤・薬歴・医薬品情報管理)に絞る。

## 仕組み・背景

薬局向け生成AIの多くは、電子薬歴システムに組み込まれた形で提供されている。仕組みは概ね共通しており、(1) 服薬指導中の会話をICレコーダーやタブレットのマイクで録音・音声認識でテキスト化し、(2) 生成AIがその内容を薬歴の様式(S/O/A/P形式など)に沿って要約・整形し、(3) 薬剤師が内容を確認・修正してから薬歴として確定する、という3段階になっている。録音・要約を挟むことで、薬剤師は患者と向き合いながら同時に記録を作れるようになる。

医薬品情報の検索では、RAG(検索拡張生成。社内外の文書を検索し、その内容をもとにAIが回答を生成する仕組み。詳細は[RAGの基礎](../part07-data-analysis/rag-basics.md))を使い、添付文書・IF・RMP(医薬品リスク管理計画)といった一次資料を検索対象にすることで、AIが根拠のない回答をする「ハルシネーション」のリスクを下げる構成が主流になっている。ただし根拠文書に載っていない組み合わせを聞かれた場合など、RAGでも誤答は起こり得るため、出典を必ず表示させ一次資料に当たる運用が前提になる。

背景として、2019年の薬機法改正以降、薬剤師の業務は「対物業務(調剤・在庫管理などモノを扱う業務)」から「対人業務(服薬指導・服薬後のフォローなど人に向き合う業務)」へのシフトが政策的に求められてきた経緯があり、薬歴作成や在庫管理といった対物業務の自動化・効率化は、この流れに沿った投資として薬局チェーン各社が積極的に進めている。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

| 業務フェーズ | 具体的な業務 | AIが向いている作業 | 最終判断は薬剤師 |
|---|---|---|---|
| 受付・処方箋鑑査 | 処方内容の妥当性確認、重複投薬・相互作用チェック | 過去の調剤データや相互作用データベースとの照合、異常値のアラート表示 | 疑義照会の要否・調剤の可否判断 |
| 調剤・過誤防止 | 秤量・一包化・監査 | 画像認識による薬剤の取り違えチェック(AIカメラ監査) | 最終鑑査・払い出しの可否 |
| 服薬指導 | 患者への説明、質問対応 | 過去の薬歴・併用薬に基づく説明ポイントの事前提示 | 指導内容そのもの |
| 薬歴記録 | 服薬指導内容の記録(SOAP形式など) | 会話の音声入力→AIによる自動要約・下書き生成 | 内容の確認・修正・確定 |
| 疑義照会 | 処方医への確認連絡 | 照会理由・根拠(添付文書該当箇所)を含む文書のドラフト作成 | 照会の要否、送信文面の最終確定 |
| 医薬品情報(添付文書・IF)検索 | 用法用量・相互作用・禁忌の確認 | RAGによる該当箇所の検索・要約 | 一次資料での裏取り、患者への説明への反映 |
| 患者フォロー・多言語/やさしい日本語対応 | 服薬後のアドヒアランス確認、外国人・高齢者・小児への説明 | 説明文の平易化・翻訳のドラフト作成 | 訳文・平易化文の正確性確認 |
| 在庫・発注管理 | 発注点の設定、欠品・過剰在庫の防止 | 来局予測に基づく半自動発注の提案 | 発注量の最終承認 |
| 学術情報・研修資料作成 | 勉強会資料、新薬情報のまとめ | 文献・添付文書からの要約ドラフト作成 | 内容の正確性確認、出典明記 |

### 汎用チャットAI vs 薬局特化ツール

| 用途 | 汎用チャットAI(ChatGPT/Claude/Gemini等)で足りるか | 薬局特化ツールが必要な理由 |
|---|---|---|
| 薬歴の自動要約 | 個人情報を扱うため契約形態次第でNG(下記「注意点」参照) | 電子薬歴と連携し、患者情報を外部に出さずに要約まで完結できる。カケハシ「Musubi」の生成AI薬歴機能、日本調剤・ソラミチシステム/corte社の「corte」、ソラミチシステム「CARADA電子薬歴Solamichi」のAI音声入力機能などが該当 |
| 疑義照会文書のドラフト | 匿名化・仮名化した内容であれば可(社内で契約したエンタープライズ版が前提) | 過去の疑義照会・調剤データを学習した専用AIの方が、照会理由の妥当性チェックまで自動化できる(例: クラフト×日本IBMの「薬剤師支援AIソリューション(AIPS)」) |
| 添付文書・IFの検索 | 一般的な質問への一次スクリーニングには使える | 一次資料そのものを検索するなら[PMDA医療用医薬品情報検索](https://www.pmda.go.jp/PmdaSearch/iyakuSearch/)や[JAPIC iyakuSearch](https://iyakusearch.japic.or.jp/)が正、RAGで社内文書と横断検索したい場合は専用ツールが有利 |
| 患者向け説明文の平易化・多言語化 | 下書き作成には十分使える | 医療通訳の代替として使う場合は精度検証済みの専用サービス(例: 医療現場向け多言語対応アプリ「Labrila」)や、厚生労働省の多言語説明資料と併用するのが安全 |
| 在庫・発注予測 | 不向き(POSデータ・来局予測との連携が必要) | カケハシ「Musubi AI在庫管理」のような、来局予測モデルを組み込んだ専用ツールが必要 |

## 実務での使い方

### 薬歴記録の効率化(具体的な導入事例)

- **株式会社カケハシ「Musubi」**: 2024年秋に生成AIを使った薬歴作成機能のプロトタイプを発表し、2025年春に本実装した。服薬指導中の会話をタブレットで記録し、生成AIが薬歴のたたき台を自動作成する仕組み([カケハシ プレスリリース](https://prtimes.jp/main/html/rd/p/000000101.000033983.html))。
- **日本調剤の「corte」(ソラミチシステム・corte社と共同開発)**: 服薬指導中の会話を録音し、生成AIが薬歴に必要な情報を自動要約する。2024年11月に50店舗へ先行導入し、2025年5月に全763店舗への導入を決定。薬歴入力の時間を平均7割程度削減できると見込む([日本経済新聞](https://www.nikkei.com/article/DGXZQOUC102W10Q4A111C2000000/)、[流通ニュース](https://www.ryutsuu.biz/it/r051380.html))。
- **アインホールディングス**: 調剤薬局約1,300店舗に生成AIを使った薬歴管理システムを導入し、口頭での服薬指導内容をAIが要約・入力することで薬歴記載時間の半減、薬剤師1人あたりの処方箋処理枚数4割増を目指す計画を公表([日本経済新聞](https://www.nikkei.com/article/DGXZQOFC2196U0R20C26A1000000/))。
- ソラミチシステムが薬剤師約1,000名に実施した調査(2026年公表)では、AI活用への関心は81.2%に上る一方、実際に勤務先薬局でAIを導入している割合は約半数にとどまる。AI導入薬局に勤める薬剤師は、自身の服薬指導への満足度が非導入薬局より高い傾向が示されている([ソラミチシステム プレスリリース](https://prtimes.jp/main/html/rd/p/000000122.000077012.html))。

### 疑義照会文書のドラフト作成(コピペで使えるプロンプト例)

処方医への疑義照会は、電話・FAXのいずれでも「照会理由」「根拠」「確認したい内容」を簡潔にまとめる必要がある。汎用チャットAIを使う場合は、**患者を特定できる情報(氏名・生年月日・保険者番号など)を一切入力せず**、症例を抽象化した上でドラフトを作らせ、最終的な文面と送信判断は必ず薬剤師が行う。

```
あなたは保険薬局に勤務する薬剤師です。以下の状況について、
処方医への疑義照会(FAX送付用)の文書ドラフトを作成してください。

【患者情報】70代・性別非公開・腎機能低下あり(eGFR 35程度、氏名等は非公開)
【処方内容】
- A錠(常用量の上限に近い用法用量で処方)
- B錠(Aと併用禁忌の可能性がある薬剤)
【疑義点】
- A錠とB錠の併用について、添付文書上の相互作用に関する記載を確認したい
- 腎機能を踏まえたA錠の用量調整の要否を確認したい

【出力条件】
- 敬語・丁寧な業務文書のトーンで、A4半分程度の分量
- 「照会理由」「確認事項」「代替案の提案(あれば)」の3項目構成
- 添付文書のどの記載を根拠にしているかを明記する欄を設ける
- 文末に「回答内容」を医師が記入できる空欄を用意する
```

このドラフトは必ず、実際の添付文書・IFの該当箇所を薬剤師自身が確認してから確定させる。AIが生成した「根拠」は仮の記載であり、実物の記載内容と一致するとは限らない。

### 添付文書・インタビューフォームの検索

- 一次資料としては[PMDA 医療用医薬品 添付文書等情報検索](https://www.pmda.go.jp/PmdaSearch/iyakuSearch/)、[JAPIC iyakuSearch](https://iyakusearch.japic.or.jp/)(医療用医薬品約22,000品目・一般用医薬品約11,000品目の添付文書とIFを収録)を必ず使う。
- 製薬企業側では、添付文書・IF・製品概要資料の作成・検索を効率化するRAG搭載の業界特化AI(例: ラクヤク AI)が普及しつつあり、薬局・病院側にもこうした一次情報がAI経由で届く流れが強まっている。
- 薬局・病院薬剤部でAIに医薬品情報を質問する場合は、必ず出典(添付文書のどの章か)を表示させる設定にし、出典のない回答はそのまま服薬指導に使わない。

### 患者向け説明文の平易化・多言語化

高齢者・小児・外国人患者への服薬指導では、専門用語を「やさしい日本語」に言い換えたり、多言語に翻訳したりする下書き作成に生成AIが使える。

```
以下の服薬指導文を、日本語が母語でない成人患者にも伝わる
「やさしい日本語」に書き換えてください。

【元の文章】
「本剤は食後に服用し、グレープフルーツジュースとの
同時摂取は薬物相互作用のリスクがあるため避けてください。
眠気を催すことがあるため、服用後の自動車の運転は控えてください。」

【条件】
- 一文を短く区切る、漢字にはふりがなを付ける想定で書く
- 専門用語(相互作用、自動車の運転を控える、など)は具体的な行動に言い換える
- 箇条書きにする
```

外国人患者向けには、上記のような下書きに加えて厚生労働省の[外国人向け多言語説明資料](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/kokusai/setsumei-ml.html)や、薬局向けの多言語対応アプリ(例: Labrila)など、翻訳精度が検証済みのツールと併用し、AI翻訳のみを最終版として渡さない。

### 在庫・発注予測

カケハシ「Musubi AI在庫管理」は、来局予測モデルとAIを用いて半自動発注・店舗間の在庫融通を行う機能で、2021年の提供開始以降、在庫の20〜30%圧縮、欠品の約20%削減という効果がベンダーから公表されている(ベンダー公表値、[Musubi AI在庫管理](https://musubi.kakehashi.life/ai-zaiko))。発注点の初期設定や大きな需要変動時(新薬発売・季節性感染症の流行など)は薬剤師・管理者の目視確認が必要になる。

## 注意点・よくある誤解

- **要配慮個人情報を無契約の生成AIに入力しない**: 患者の氏名・病歴・処方内容は個人情報保護法上の「要配慮個人情報」に該当し、無料版ChatGPTなど個人契約の汎用AIにそのまま入力すると、外部事業者への第三者提供とみなされ得るリスクがある。使うのであれば、データが学習に使われず利用目的を限定できる法人向けプラン(ChatGPT Enterprise等)を使い、可能な限り匿名化・仮名化してから入力する([note: 遠藤太一氏の解説](https://note.com/taichi_endoh/n/n3392180a0f0f)、[牛島総合法律事務所の解説](https://www.ushijima-law.gr.jp/client-alert_seminar/client-alert/ppc_generativeai/))。
- **薬機法の広告規制に注意**: 患者向け・地域向けの説明資料やSNS投稿をAIに作らせる場合、「体験談」的な断定表現や効能効果の誇大表現は薬機法(医薬品医療機器等法)違反になり得る。広告表現のチェックには専用の生成AIチェックツール(例: Allganize「薬機法チェックLLMアプリ」)を併用する方法もある。
- **AIの回答をそのまま服薬指導に使わない**: RAGで一次資料を検索する構成でも、根拠文書にない組み合わせについては誤った回答(ハルシネーション)が生成され得る。添付文書・IFの実物を必ず確認する。日本病院薬剤師会が2026年2月に公表した「病院薬剤師向け生成AI利活用ガイダンス」も、生成AIを「判断を代替するものではなく、判断を支援する参考ツール」と位置づけている([日本病院薬剤師会](https://www.jshp.or.jp/activity/guideline/20260331.html))。同学会の実態調査(2026年3月公開)では、病院薬剤師351名中56.0%が業務で生成AIを何らかの形で使用していると回答している([J-STAGE論文](https://www.jstage.jst.go.jp/article/jjphcs/52/3/52_136/_article/-char/ja/))。
- **最終判断は必ず薬剤師が行う**: 疑義照会の要否、調剤の可否、服薬指導の内容決定は薬剤師の職能責任であり、AIはあくまで下書き・一次スクリーニングの補助に留める。
- **録音を伴うツールは同意取得を忘れない**: AI薬歴サービスの多くは服薬指導中の会話を録音するため、患者への録音の告知・同意取得を運用ルールとして徹底する。
- **翻訳・やさしい日本語化の下書きは必ず確認**: AIによる訳文・平易化文が不自然になったり、専門的なニュアンス(用量・禁忌など)が抜け落ちたりすることがあるため、患者に渡す前に薬剤師が内容を確認する。

## 最初の一歩

まずは自局で契約している電子薬歴システムに、生成AIを使った薬歴要約機能やAI音声入力機能が(オプションとして)提供されていないかベンダーに確認する。まだ導入していない場合は、法人契約の生成AIで疑義照会文書のドラフトや添付文書の要約を、患者を特定できる情報を含めない形で試してみることから始めるとよい。
