# 栄養士・調理師における生成AI活用事例

## これは何か

栄養士・管理栄養士・調理師の仕事は、病院・介護施設・学校・保育園・社員食堂・飲食店など現場は違っても、「献立を立てる→栄養価とコストを計算する→食材を発注する→大量に調理する→利用者・患者に説明する」という一連の業務を、栄養価の基準・アレルギー対応・食品衛生というミスの許されない制約の中で毎日回す点が共通している。生成AIはこの業務のうち「献立のアイデア出し」「レシピの説明文・栄養指導資料の文章化」「大量調理レシピのスケールアップ計算のたたき台」のような**下書き・発散フェーズ**を大きく速くできる一方、栄養価の確定値・アレルゲンの最終照合・分量計算の正確な換算といった**数値が命に直結する工程**は生成AI単体に任せてはならない、という職業特有の線引きが必要になる。

本ページは、外食チェーン・飲食店の経営視点で発注・需要予測・口コミ対応などを扱う[外食・フードサービス業における生成AI活用事例](../part14-industry-cases/food-service-ai-use-cases.md)(Part14・業種側の視点)とは異なり、**栄養士・調理師という職種個人の業務フロー**(献立作成、栄養計算、発注・食材管理、レシピ開発、アレルギー対応、栄養指導・食育資料作成)に絞って扱う。病院・介護施設側の全体的なAI活用は[医療・ヘルスケアにおける生成AI活用事例](../part14-industry-cases/healthcare-ai-use-cases.md)・[介護業界における生成AI活用事例](../part14-industry-cases/eldercare-ai-use-cases.md)も参照してほしい。

## 仕組み・背景

栄養士・調理師の業務にAIが入り込む場面は、技術的な性質が異なる2種類に分かれる。

1. **数理最適化・組み合わせ最適化ベースの給食管理システム**: 「栄養摂取基準を満たす」「予算・原価率の上限を守る」「同じ食材の使用頻度を分散させる」「厨房機器・調理時間の制約を守る」といった**複数の制約条件を同時に、かつ数値として厳密に満たす**必要がある給食の本番献立作成は、実務では純粋な生成AI(ChatGPTのような大規模言語モデル)ではなく、数理最適化のアルゴリズムを使った専用システムが担っている。給食管理システム「Well-Fed」は栄養摂取基準・栄養バランス・予算・原価率・人気メニュー・調理法・彩り・厨房機器の制約など20項目以上の条件を反映した献立を数理最適化で約10分で自動作成する([Well-Fed「意外とできない？生成AIによる給食の献立作成が難しい理由を解説!」](https://well-fed.jp/columns/20250402/))。給食委託会社LEOCの「Lappy」も数理計画法(数理最適化の一種)を用い、約3,000品目の調理情報・食材価格から最大4週間・5パターンのメニューを提案する仕組みで、これまで1週間あたり約8時間かかっていた発注管理業務を1施設あたり45秒に、1週間分のメニュー作成を55秒に短縮したとされる(いずれもベンダー公表、[食品産業新聞社ニュースWEB](https://www.ssnp.co.jp/feeding/196900/)、[LEOCプレスリリース](https://www.leoc-j.com/news/?p=4058))。味の素とLaboro.AIが共同開発した「献立作成エンジン」も、栄養バランス・調理時間などの条件を指定すると1万件超のレシピデータから献立を提案する仕組みで、同社のWebサービス「未来献立®」に採用されている([Laboro.AI](https://laboro.ai/case/ajinomot-kondate/)、[EnterpriseZine](https://enterprisezine.jp/news/detail/20155))。
2. **生成AI(ChatGPT・Gemini・Claude等)による発散・文章生成**: 献立のアイデア出し、レシピの説明文、栄養指導・食育資料の文章、アレルギー対応チェックリストのたたき台作成など、「厳密な数値の最適化」ではなく「言葉で説明する・幅を広げる」工程に強い。栄養士・調理師個人が日常的に使うのはこちらの型である。

両者は補完関係にあり、NRI Digitalは生成AIと数理最適化を組み合わせた「コンポジットAI」で献立最適化アプリを試作し、生成AIが人間の曖昧な要望(「子どもが喜ぶ献立にしたい」等)を解釈し、数理最適化が栄養バランスなどの厳密な条件を担保する分業を提案している([NRI Digital](https://www.nri-digital.jp/tech/20240919-18800/))。つまり「生成AIに献立を丸ごと作らせる」のではなく、**発散はAI、確定はシステムまたは人**という分業が実務の設計思想になっている。

背景として、少子高齢化による労働人口減少で栄養士・調理師1人あたりの業務量が増えていること、給食は[大量調理施設衛生管理マニュアル](https://www.mhlw.go.jp/file/06-Seisakujouhou-11130500-Shokuhinanzenbu/0000139151.pdf)(厚生労働省、HACCPの考え方に基づく衛生管理基準)という厳格なルールの下で運用されていること、食物アレルギーを持つ児童・患者の増加でアレルギー対応の複雑さが増していることが挙げられる。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

| 業務フェーズ | 主なタスク | 向くツール | 理由・使い分けの考え方 |
|---|---|---|---|
| 献立の方向性・アイデア出し | 季節メニュー案、テーマ献立、利用者の要望を踏まえたたたき台 | 汎用チャットAI(ChatGPT・Gemini・Claude) | 「幅を広げる」工程に強い。ここで出た案はあくまで叩き台で、栄養価・予算の確定はしない |
| 給食の本番献立(栄養価・予算・食材使用頻度の確定) | 栄養摂取基準・原価率・厨房制約を満たす献立の確定 | 給食管理システムのAI機能(数理最適化型: Well-Fed、LEOC Lappy等) | 複数の数値制約を同時に厳密に満たす必要があり、汎用生成AI単体では精度・再現性が不十分 |
| 栄養価計算 | 1食あたりのエネルギー・PFC(タンパク質・脂質・炭水化物)・食塩量などの確定値算出 | 栄養計算ソフト(日本食品標準成分表ベース) | 生成AIは食品成分表を正確に暗記・参照しているとは限らず、カロリー等を実際より少なく見積もる傾向が指摘されている(詳細は「注意点」参照)。確定値は専用ソフトで算出する |
| アレルギー・禁忌食材への対応チェック | 献立に含まれる特定原材料の照合、個別対応食(除去食・代替食)の確認 | 専用のアレルギー管理システム(給食革命、あんしん給食えびす、Aアラーム等)+複数人での目視確認 | 誤配膳は命に関わる事故につながるため、AIの一次チェックだけで済ませず、専用システムと栄養士・調理員・配膳担当者による複数人チェックを併用する(詳細は「注意点」) |
| レシピ開発 | 新メニューのアイデア、味付け・調理法のバリエーション、メニュー説明文 | 汎用チャットAI | 条件(人数・予算・調理器具・食材の在庫消化)を具体的に伝えるほど実用的な案が出やすい |
| 大量調理向けレシピのスケールアップ | 少人数分のレシピを施設の食数(50食・100食等)に換算する下書き | 汎用チャットAI(下書き)+人による検算 | 単純な人数倍の比例計算では、調味料の効き方・加熱時間・水分の蒸発量は変わらないため、AIの計算結果は必ず試作・検算する |
| 発注・食材ロス削減 | 来客数・喫食率の予測に基づく発注量の算出 | 給食管理システムのAI発注機能、需要予測AI | POSデータ・喫食実績など施設側のデータ基盤があってはじめて精度が出る。個店レベルの汎用的な需要予測は[外食・フードサービス業における生成AI活用事例](../part14-industry-cases/food-service-ai-use-cases.md)も参照 |
| 栄養指導資料・食育リーフレット・患者向け説明文書 | 生活習慣病の食事療養説明、食育リーフレット、退院時の栄養指導資料 | 汎用チャットAI(下書き)+栄養士による医学的内容の確認 | 文章の型は繰り返しが多く生成AIが得意な一方、患者の病態・服薬内容に応じた医学的な正確性は必ず栄養士・医師が確認する |

### 判断基準

- **数値が確定値として使われる工程**(栄養価計算、アレルゲン照合、発注量)→ AIは下書き・見積もり・検算補助まで。最終確定は専用システムまたは資格を持つ人が行う
- **文章・説明・アイデア出しが中心の工程**(献立のたたき台、レシピ説明文、栄養指導資料の文章、SNS向け食育コンテンツ)→ 汎用チャットAIをフロントに出してよい
- **給食のように多数の制約条件を同時に満たす必要がある献立**→ 汎用生成AI単体ではなく、数理最適化型の給食管理システムを使う。個人経営の飲食店のような制約条件が少ない場面では、汎用チャットAIでの叩き台作成でも実務上十分な場合が多い

## 実務での使い方

### プロンプト例1: 季節献立・テーマ献立のアイデア出し

```
あなたは(施設種別: 例 特別養護老人ホーム)の栄養士です。以下の条件で、
来月の昼食向け献立アイデアを5案考えてください。

# 条件
- 対象者: 咀嚼・嚥下機能が低下した高齢者(常食は問題ないが硬いものは避けたい)
- 季節・テーマ: (例: 9月、秋の行事食(お月見))
- 使用したい食材(在庫を優先消化したいもの): (例: さつまいも、里芋)
- 避けたい食材・調理法: (例: 骨のある魚、硬い根菜の乱切り)
- 1食あたりの目標エネルギー: (例: 600kcal前後)

# 出力してほしい内容
各案について
1. 主菜・副菜・汁物・主食の構成
2. 咀嚼・嚥下への配慮点(切り方・とろみ等)
3. 行事食としての見た目・盛り付けの工夫

# 注意
- ここで出す案はあくまで叩き台です。栄養価の確定計算はこの後、
  栄養計算ソフトで別途行うため、厳密な数値は不要です
```

条件(対象者の身体特性・季節・在庫食材・目標エネルギー)を具体的に伝えるほど、施設の実情に近い案が出てくる。ここで出た案は栄養価未確定の叩き台であることを明示し、栄養計算ソフトでの確定計算に進む前提で使う。

### プロンプト例2: 大量調理向けレシピのスケールアップ(下書き・要検算)

```
以下の4人分のレシピを、50人分に換算してください。ただし、
単純な人数倍の比例計算では現場で失敗しやすいため、
注意点も併記してください。

# 元のレシピ(4人分)
(材料・分量・調理手順を貼り付け)

# 出力してほしい内容
1. 各材料を50人分に換算した分量(4人分の12.5倍を基本としつつ、
   調味料は倍率通りにすると味が濃くなりやすい点を踏まえた
   調整案も併記)
2. 大量調理特有の注意点(加熱時間・水分の蒸発量・鍋の深さによる
   熱の通り方の違いなど)を3〜5点
3. 「この換算結果は目安であり、実際の分量は試作して味見のうえ
   調整してください」という一文を末尾に必ず入れる
```

生成AIは分量の単純な倍数計算はできるが、大量調理では調味料・水分・加熱時間が人数に比例しないため、実際の調理現場では必ず試作・味見で検算する。プロンプルには最初から「注意点も出させる」よう指示しておくと、AI自身に単純計算の限界を明示させやすい。

### プロンプト例3: アレルギー対応チェックリストの下書き作成

```
以下の献立とアレルギー物質の一覧をもとに、特定原材料が含まれる
メニューのチェックリストを作成してください。これはあくまで
一次チェックの下書きであり、最終確認は栄養士・調理員が
現物と照合して行います。

# 献立(1週間分、メニュー名と主な食材)
(貼り付け)

# 確認したい特定原材料8品目
卵、乳、小麦、えび、かに、そば、落花生、くるみ

# 出力してほしい内容
1. メニューごとに、含まれる可能性のある特定原材料をリストアップ
2. 「使用食材名からは特定原材料の使用が明確に判断できない」項目は
   その旨を明記し、原材料表示の確認が必要と示す
3. リストの末尾に「本リストはAIによる一次確認であり、最終判断は
   食材の納品書・原材料表示を確認した栄養士・調理員が行うこと」
   という注意文を必ず入れる
```

このプロンプトの目的は「AIに最終判断をさせる」ことではなく、**見落としを減らすための一次スクリーニング**に使うことにある。実際の現場では、この下書きに加えて給食向けアレルギー管理システム(給食革命、あんしん給食えびす、Aアラーム等)による原材料データベースとの照合、配膳時の複数人チェックを重ねる運用にする。

### プロンプト例4: 栄養指導資料・食育リーフレットの文章化

```
あなたは(施設: 例 総合病院)の管理栄養士です。以下の内容を、
患者さん・保護者向けの食育リーフレットの文章にしてください。

# 伝えたいポイント(専門的なメモ)
(例: 糖尿病の食事療養における「カーボカウント」の基本、
炭水化物量を把握して食べる量を調整する考え方)

# 読み手
(例: 診断されたばかりで栄養の知識があまりない成人患者)

# 出力条件
1. 専門用語(カーボカウント、GI値など)は初出で一言説明を入れる
2. 「なぜそれが大事か」から書き始め、理屈の説明を先にしない
3. A4用紙1枚に収まる分量(見出し3〜4個、各200字程度)
4. 最後に「疑問点は主治医・担当の管理栄養士にご相談ください」と
   明記する
5. 医学的な数値(推奨摂取量の具体的な数字等)は本文中に断定的に
   書かず、「担当の管理栄養士が個別に設定します」という表現にする
```

医学的な数値をAIに断定させないよう指示しておくことが重要。文章の型・言い換え・読みやすさの調整はAIに任せてよいが、患者の病態・服薬内容に応じた数値の確定は栄養士が行う前提を崩さない。

### ツール横断の対応付け(2026年8月時点)

|---|---|---|
| 献立のアイデア出し・叩き台 | ChatGPT・Gemini・Claude | 給食管理システムのAI献立提案機能(Well-Fed、LEOC Lappy、味の素×Laboro.AI「献立作成エンジン」など。数理最適化ベース) |
| 栄養価計算(確定値) | — (見積もり・検算補助のみ) | 栄養計算ソフト(日本食品標準成分表準拠。東経システム、ソフトム等の給食システムに標準搭載) |
| アレルギー対応チェック | — (一次チェックの下書きのみ) | 給食アレルギー対応支援システム(インフォファーム「給食革命」、eBASE「あんしん給食えびす」、「Aアラーム」等) |
| レシピ開発・説明文 | ChatGPT・Gemini・Claude | — |
| 発注・食材ロス削減 | — | 給食管理システムのAI発注提案機能(LEOC Lappy等)、需要予測AI(食品ロス削減については[外食・フードサービス業における生成AI活用事例](../part14-industry-cases/food-service-ai-use-cases.md)も参照) |
| 栄養指導資料・食育リーフレット | ChatGPT・Gemini・Claude | 管理栄養士監修レシピ・献立提案サービス(おいしい健康 for Medical等、医療従事者向け機能を持つものもある) |

**料金の考え方**: 汎用チャットAIは個人利用であれば無料版でも下書き作成には十分な場合が多く、業務で本格的に使うなら有料プラン(ChatGPT Plus 月20ドル程度など。詳細は[ChatGPTのプラン比較](../part03-ai-chat-tools/chatgpt-plan-comparison.md)等の各ツール解説ページを参照)を検討する。一方、数理最適化型の給食管理システム(Well-Fed、L-Palette+Lappy等)は施設単位の契約でシステム利用料がかかり、個人が単独契約するものではなく、施設・運営法人が導入を判断する。栄養士個人としては「所属先が導入している専用システムの機能を使いこなす」ことと「汎用チャットAIで自分の下書き作業を速くする」ことの両方を押さえておくと業務範囲が広い。

## 注意点・よくある誤解

- **生成AIの栄養価計算は正確とは限らない**: ChatGPTのようなチャットAIは、実際のポーションサイズやブランド固有の栄養データベースにアクセスしているわけではなく、学習データからの統計的な推測でカロリー・栄養素を出力する。個人の食事管理向けアプリでの検証では、実際より少なめのカロリーを出力する傾向が指摘されている([みんな栄養に頼りすぎてる「ChatGPTの栄養計算は『正確』か?」](https://www.y-shinno.com/chatgpt-nutrient-calculation-accuracy/))。給食・患者向けの栄養価は、日本食品標準成分表に基づく専用の栄養計算ソフトで確定値を出し、生成AIの数値をそのまま献立表・栄養指導資料に転記しない。
- **アレルギー対応はAIの一次チェックだけで済ませない**: 食物アレルギーの誤配膳・誤食は命に関わる事故につながる。AIによる献立とアレルゲンの照合はあくまで見落とし防止の一次スクリーニングであり、給食向けアレルギー管理システムでの原材料データベース照合、栄養士・調理員・配膳担当者による複数人での目視確認という、AI導入前から続く「多重チェック」の体制を省略してはならない。
- **大量調理のスケールアップは単純な倍数計算では失敗する**: 生成AIに「◯人分を◯人分に」と頼むと、材料をすべて同じ倍率で機械的に掛け算した数値を返しやすい。実際の大量調理では調味料の効き方・加熱時間・水分の蒸発量・鍋の深さによる熱の通り方が人数に比例しないため、AIの換算結果は必ず試作・味見で検算する。
- **数理最適化型の給食管理システムと汎用生成AIを混同しない**: 「AIで献立を自動作成できる」という言葉には、ChatGPTのような生成AIと、Well-FedやLEOC Lappyのような数理最適化ベースのシステムの両方が含まれる。栄養摂取基準・予算・食材使用頻度など複数の数値制約を同時に厳密に満たす必要がある給食の本番献立には、生成AI単体ではなく専用システムを使う。
- **HACCP・食品衛生に関わる判断はAIに委ねない**: [大量調理施設衛生管理マニュアル](https://www.mhlw.go.jp/file/06-Seisakujouhou-11130500-Shokuhinanzenbu/0000139151.pdf)に基づく加熱温度・二次汚染防止・調理従事者の健康管理などの衛生管理判断は、AIに文章を整理させることはできても、最終的な運用判断・記録の正確性は資格を持つ現場責任者が担保する。
- **患者・利用者向け説明文の医学的正確性は必ず人が確認する**: 栄養指導資料・食育リーフレットの文章表現(言い換え・読みやすさ・構成)はAIに任せてよいが、対象者の病態・服薬内容に応じた摂取量・制限事項などの医学的な数値は、AIに断定させず、栄養士・医師が個別に確認・設定する。

## 最初の一歩

来月分の献立や新メニューのうち、まだ方向性が固まっていないもの1件を選び、本ページの「プロンプト例1: 季節献立・テーマ献立のアイデア出し」を試してみる。出てきた案はあくまで叩き台として扱い、栄養価の確定は必ず普段使っている栄養計算ソフトで行う習慣から始めるとよい。
