# 人材紹介エージェント(キャリアアドバイザー)における生成AI活用事例

## これは何か

人材紹介会社で日々、求人企業の採用ニーズを聞き取る**RA(リクルーティングアドバイザー)**と、求職者と面談してキャリア相談に乗る**CA(キャリアアドバイザー)**は、1日に何件もの面談・書類作成・文面作成をこなす「テキスト生成が業務量の大半を占める」仕事の典型である。求人票の要約、候補者の職務経歴書の要約、スカウト文、推薦文、面談メモのCRM(顧客関係管理システム)入力まで、生成AIで下書きできる部分は多い一方、「誰を推薦するか」「誰にスカウトを送るか」という最終判断まで機械任せにすると、職業安定法上の差別禁止規定に抵触したり、求職者との信頼関係を損なったりするリスクがある。本ページは、人材紹介会社のRA/CAが**自分の日々の面談・提案・書類作成の中で**生成AIをどう使うかを、業務フェーズに沿って整理する。

隣接ページとの境界線は次のとおり。

- [人材紹介・人材サービス業における生成AI活用事例](../part14-industry-cases/staffing-recruiting-industry-ai-use-cases.md)(Part 14)は、ビズリーチAI・Indeed Talent Scout・LinkedIn Hiring Assistantのような「マッチングプラットフォームが企業として組み込むAI機能」を、**人材紹介というビジネスそのもの**の視点で扱う。本ページ(Part 15)は、そうしたプラットフォームを使う・使わないにかかわらず、**1人のRA/CAが自分の端末で日々の面談・提案・文面作成にどうAIを使うか**という個人の業務フローに焦点を当てる
- [人事(HR)職における生成AI活用事例](hr-ai-use-cases.md)(Part 15第6章)は、1社の内部で自社の採用・人事を行う「事業会社側の人事担当者」の話。本ページは、複数の求人企業・複数の求職者を同時に仲介する「人材紹介会社側のRA/CA」の話であり、扱う候補者・求人の母数と、それに伴う個人情報の取扱件数の桁が異なる

## 仕組み・背景

RA/CAの業務は「大量の非構造化情報(面談内容・職務経歴・求人要件)をテキスト化・要約し、相手に合わせて文面に組み立てる」仕事が中心のため、生成AIとの親和性が非常に高い。個人の業務での活用は大きく3系統に分かれる。

1. **汎用チャットAI(ChatGPT/Gemini/Claude)を自分でプロンプトを書いて使う**: 求人票・レジュメの要約、スカウト文・推薦文の下書き、企業リサーチなど、その場でコピペして使う運用
2. **人材紹介業務特化の生成AI・音声AIエージェント**: 面談を録音するだけで職務経歴書・推薦文・キャリアシート・面接想定問答をAIが自動生成するタイプ。ZENoffice「MENDAN」やROXX「AIアシスタント by zcareer platform」が代表例
3. **自社が利用する人材紹介プラットフォーム・ATS(採用管理システム)に組み込まれたAI機能**: ビズリーチAIの求人自動作成機能、dodaダイレクトの検索条件自動生成機能など。RA/CA個人が意識せずとも日々の画面操作の中で使っていることが多いが、機能自体の詳細は前述のPart 14該当ページに譲る

具体例として、ZENoffice(大阪)の「MENDAN」は、CAが面談前にレコーディングボタンを押すだけで、面談音声から職務経歴書ドラフト・推薦文・キャリアシート・履歴書を数分で自動生成し、CRMへの反映・企業への送付まで自動化する「書類作成エージェント」を提供している。2026年8月時点で公表されている効果として、書類作成にかかる工数を1人あたり月平均約20時間削減、書類作成業務量を62%削減、書類通過率を約3.1ポイント改善、書類作成のリードタイムを12日から6.3日に短縮したという実績が公表されている。同社は求職者との面談内容から面接で聞かれそうな質問と回答の方向性を整理する「面接対策資料生成」機能や、面談中にリアルタイムで求人候補を提示する音声AIマッチング機能も展開している。

ROXX(転職メディア「Re就活」等を運営)は2026年5月、グループ会社が運営するZキャリアプラットフォーム(ZCP)の加盟企業向けに開発していたAI機能を「AIアシスタント by zcareer platform」として外部の人材紹介会社にも展開開始した。求職者との面談内容や過去の選考データを分析し、CAに最適な支援プラン・ネクストアクションを提案する機能で、支援プランをゼロから考える負荷の軽減を狙う。2026年5〜6月には初期費用無料・月額利用料3か月無料の先着キャンペーンを実施した。

専業ツールを導入していない中小の人材紹介会社・個人エージェントであっても、汎用チャットAIへのコピペ運用で下書き作業の多くを代替できる。ただし、いずれの系統も「求職者・求人企業の非公開情報を入力する」行為であることに変わりはなく、扱い方は本ページ後半の注意点に沿う必要がある。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

| フェーズ | 主担当 | 課題 | AIの役割 | 最終判断は誰が行うか |
|---|---|---|---|---|
| 求人受託・求人票の作成 | RA | 求人企業へのヒアリング内容を求人票・紹介文の体裁に落とし込む作業に時間がかかる | ヒアリングメモ・商談音声から求人票・紹介文のたたき台を生成 | 求職者への提示前にRAが事実関係を確認 |
| 候補者の母集団形成・スカウト | RA/CA | 大量の候補者に個別最適化した声かけをする時間がない | 候補者の職務経歴書を読み込ませ、パーソナライズしたスカウト文・声かけ文を生成 | 送信前にCA/RAが内容を確認 |
| レジュメ・職務経歴書の一次確認 | CA | 応募・登録が集中すると書類確認の工数が膨らむ | 職務経歴書の要約、求人要件との合致点・不足点の整理 | 推薦候補として残すかどうかはCAが判断 |
| 面談準備 | CA | 面談前に求職者の経歴・転職軸を素早く把握したい | 事前アンケート・過去のやり取りから確認したい論点・深掘り質問を整理 | 面談の進め方はCAが決める |
| 面談記録・書類化 | CA | 面談後即日〜翌日提出が求められることも多く、職務経歴書・推薦文・キャリアシート作成が重なると時間が足りない | 面談音声・メモから職務経歴書・推薦文・キャリアシートのドラフトを自動生成 | 最終文面はCAが確認・修正してから企業へ提出 |
| 企業へのご推薦・推薦文作成 | CA/RA | 推薦文は紹介先企業ごとにトーン・重視ポイントが異なる | 転職理由・強み・懸念点を要約し、紹介先企業向けのトーンで生成 | 事実と異なる誇張がないか、CAが必ず確認する |
| 求職者の面接対策支援 | CA | 求職者ごとに企業研究・想定質問の準備に時間がかかる | 企業の直近ニュース・業績・求める人物像をリサーチし、想定質問と回答の方向性を整理 | 企業固有の非公開情報を含めていないか、最終アドバイスはCAが行う |
| クロージング・内定後フォロー | CA/RA | 内定通知・条件交渉・辞退引き止めの文面作成に神経を使う | 状況に応じた連絡文面の下書き、条件比較表の作成 | 送信前に必ず人が確認、特に条件交渉はCA/RAが主導する |

**読み方のコツ**: 表の上側(求人票作成・スカウト文・書類の一次整理)は「AIに作らせて人が仕上げる」領域として定着しつつあるのに対し、下側(推薦文・面接対策・クロージング)は求職者・求人企業との信頼関係に直結する領域であるため、AIの下書きをそのまま送らず、必ず自分の言葉として確認してから使うことが重要になる。

### AIの関与度で見た判断基準

| 関与度 | 業務例 | 理由 |
|---|---|---|
| AIにドラフトを作らせてよい(人が確認・編集して確定) | 求人票の要約、スカウト文・推薦文の下書き、面談メモの要約、企業リサーチのまとめ | 誤りがあっても送信前のレビューで補正でき、最終責任はRA/CAに残る |
| AIは情報整理のみに使い、評価・推薦順位は人が決める | 応募書類・レジュメと求人要件の突合、候補者の強み・弱みの整理 | 求人企業に「誰を推薦するか」を決めるのはCAの職務そのものであり、AIのスコアをそのまま推薦順位にすると差別的スクリーニングのリスクを負う |
| AIに任せない | 内定可否の予測を求職者に断定的に伝える、複数候補者の優劣を機械的にランキングして企業に一括提示する | 求職者の人生に直結する判断を、検証されていないAIのスコアだけで行うと、後で「なぜその評価だったか」を説明できなくなる |

## 実務での使い方

### 使えるツール・構成

| 用途 | 汎用チャットAIで足りるか | 専用ツールが有利な場面 |
|---|---|---|
| 求人票・スカウト文・推薦文の下書き | 足りる(ChatGPT/Gemini/Claudeにテキストを貼るだけ) | 面談音声からの自動生成やCRMへの自動反映まで求める場合はMENDAN等の専業ツールが有利 |
| 職務経歴書・レジュメの要約 | 足りる | 応募が集中する繁忙期は、要約をバッチ処理できるATS組み込みAIの方が効率的 |
| 面談記録の自動書類化 | 手動での音声文字起こし+要約プロンプトで代替可能だが手間がかかる | 面談ごとに複数書類(職務経歴書・推薦文・キャリアシート)を同時生成したい場合はMENDANのような録音起点の専業ツールが向く |
| 企業研究・面接対策資料 | 足りる(Perplexity、ChatGPT/GeminiのWeb検索機能で企業の直近ニュース・決算・求める人物像を調べる) | 非公開の求人情報を扱う点は汎用AI・専業ツールとも同じ制約を受けるため、社内で許可されたデータの範囲に限定する |
| 面談支援・提案プラン作成 | 一部代替可能(面談メモを貼って支援プランのたたき台を作らせる) | 過去の選考データ・成約実績まで踏まえた提案は、ROXX「AIアシスタント by zcareer platform」のような自社データ連携型のツールが強い |

汎用チャットAIを使う場合、法人契約でオプトアウト設定(入力データをモデル学習に使わない設定)が確認できているプランを使うのが前提になる。個人のPlus/無料プランで候補者の実名入り情報を扱うのは避ける。

### コピペで使えるプロンプト例

#### 1. 求人票の要約・候補者向け紹介文の作成(RA/CA共通)

```
あなたは人材紹介会社のコンサルタントです。以下は求人企業からのヒアリングメモです。
候補者に紹介する際に使う「求人紹介文」を作成してください。

【企業】従業員120名のBtoB SaaS企業(人事労務系SaaS)
【募集職種】カスタマーサクセス
【必須要件】BtoB SaaSでのCS経験2年以上
【歓迎要件】人事・労務領域の実務経験
【アピールポイント】離職率が業界平均より低い、リモート可、裁量労働制

出力構成: 3行サマリー / 仕事内容 / 必須・歓迎要件 / 働き方・待遇 / この求人を薦めたい理由(コンサルタントの一言)
求人企業から直接聞いていない推測情報(年収の言い切りなど)を書いていないか、
最後にセルフチェックして指摘してください。
```

#### 2. 候補者ごとのスカウト文面(パーソナライズ)

```
以下の求人内容と候補者の職務経歴書(要約)をもとに、
この候補者向けにパーソナライズしたスカウトメッセージを作成してください。

【求人内容】(貼り付け)
【候補者の職務経歴書要約】(貼り付け)

条件:
・候補者のこれまでの経験のうち、求人内容と特に合致する点を1〜2点具体的に引用する
・「あなたの経歴を拝見し」で始まる定型文にせず、なぜ声をかけたのかが伝わる文にする
・文字数は400字以内、返信のハードルを下げる一文を末尾に入れる
・年齢・性別・国籍・家族構成など職業安定法上配慮すべき属性には触れない
```

#### 3. 面談メモからの推薦文ドラフト(要約・トーン調整)

```
以下は求職者との面談メモです(氏名・連絡先は削除済み・匿名化済み)。
紹介先企業向けの推薦文のドラフトを作成してください。

【面談メモ】(貼り付け)
【紹介先企業のカルチャー】チームワーク重視、若手にも裁量を渡す社風

出力構成:
1. 転職理由(事実ベースで簡潔に)
2. 強み・実績(数字があれば具体的に)
3. 懸念点・企業側が確認すべき点(誇張せず正直に)
4. この候補者を薦める理由(コンサルタントとしての所見)

面談メモに書かれていない実績や経験を推測で補わないでください。
不明な点は「要確認」と明記してください。
```

#### 4. 企業研究・面接想定問答の作成(求職者への面接対策支援)

```
求職者の一次面接を控えています。以下の情報をもとに、面接対策資料を作成してください。

【応募企業】(会社名・部署名)
【求職者の職務経歴】(要約を貼り付け)
【求人票の必須・歓迎要件】(貼り付け)

依頼内容:
1. 応募企業の直近1年の主要ニュース・決算動向・注力事業を、出典付きで3つまとめてください
2. 上記を踏まえ、一次面接で聞かれそうな質問を8問(経験の深掘り4問、志望動機系2問、
   カルチャーフィット系2問)作成し、それぞれに「求職者の経歴のどこを使って答えると
   説得力が増すか」のヒントを1行添えてください
3. 企業研究の内容は必ず出典を明記し、推測にはその旨を明記してください
```

### ツール横断の対応表

| やりたいこと | 汎用チャットAI | 人材紹介業務特化ツール |
|---|---|---|
| 求人票・紹介文・スカウト文の下書き | ChatGPT / Gemini / Claude | ビズリーチAI「求人自動作成機能」(詳細はPart14参照) |
| 面談音声からの職務経歴書・推薦文・キャリアシート自動生成 | 音声文字起こし+要約プロンプトで部分代替可 | MENDAN「書類作成エージェント」(ZENoffice) |
| 支援プラン・ネクストアクションの提案 | 面談メモを貼って壁打ち | ROXX「AIアシスタント by zcareer platform」 |
| 企業研究・面接対策資料の作成 | Perplexity、ChatGPT/GeminiのWeb検索機能 | MENDAN「面接対策資料生成」機能 |
| 面談記録のCRM反映 | 手動での要約貼り付け | MENDAN、amptalkなど商談音声→CRM自動反映型ツール |

料金は2026年9月時点で、MENDAN・ROXX「AIアシスタント by zcareer platform」ともに定価の月額料金表は公開されておらず、いずれも問い合わせ・導入企業向けの個別見積もりが基本(ROXXは2026年5〜6月に初期費用無料・月額利用料3か月無料の先着キャンペーンを実施した)。

## 注意点・よくある誤解(その職種特有の落とし穴)

- **求職者の履歴書・職務経歴書を無許可の生成AIにそのまま入力しない**: 法人契約でオプトアウト設定が確認できていないツール(個人のChatGPT無料版など)に、氏名・連絡先入りの職務経歴書を貼り付けるのは情報漏洩リスクが高い。社内ルールで許可されたツールを使う、または匿名化した上で利用するのを徹底する(詳細は[生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md)を参照)
- **推薦文のAI生成は「誇張・虚偽表示」のリスクを伴う**: AIに推薦文を書かせると、面談メモにない実績や強みを"それらしく"補完してしまうことがある。求人企業に提出する推薦文は事実確認が生命線であり、AI出力を鵜呑みにせず、面談メモにない記載がないか必ず突合する
- **職業安定法上の差別禁止規定はRA/CA個人の日々の判断にも及ぶ**: 職業安定法第3条・第5条の5および職業紹介事業者等指針(平成11年労働省告示第141号、最終改正: 令和4年4月1日)は、性別・年齢・国籍・思想信条・社会的身分など「社会的差別の原因となるおそれのある事項」を理由に求職者を不利に扱うことを禁じている。AIにスカウト対象や推薦順位を提案させる際、こうした属性を判断材料に含めていないかを個人レベルでも確認する
- **面談の録音・AI解析には求職者・求人企業への説明と同意が前提**: MENDANのような面談音声を録音してAIに解析させるツールを使う場合、録音していること・AIで解析することを面談冒頭で相手に伝え、同意を得ておく。無断録音は信頼関係を損なうだけでなく、個人情報の取扱いに関するトラブルの原因にもなる
- **求人企業から預かった情報を、無関係な別の案件への営業や候補者開拓に転用しない**: RAが求人企業からヒアリングした非公開の事業計画・組織課題などを、AIへの入力を通じて他の商談の"参考"として横流しするのは、守秘義務違反や個人情報の目的外利用に該当しうる。案件ごとに情報の利用範囲を区切る
- **AIが書いた企業研究資料の事実確認を怠らない**: 面接対策のための企業リサーチをAIに任せると、決算数値や役員名などを誤って生成する(ハルシネーション、事実と異なる内容をもっともらしく生成する現象)ことがある。求職者に渡す前に、企業の公式サイト・適時開示情報などの一次情報で裏取りする(詳細は[ハルシネーションとは何か・対策](../part04-risk-security/hallucination-and-countermeasures.md)を参照)
- **「AIの提案どおりに動く」がクセになると、RA/CAの付加価値が失われる**: AIが代替しやすいのは定型的な書類作成・要約であり、求人企業との折衝(RA)や求職者との信頼関係構築(CA)といった対人業務そのものはAIでは代替しにくい。書類作成の時間を削減した分を、面談の質や企業への提案の深さに再投資する意識を持つ

## 最初の一歩

直近で担当した求人1件・候補者1名を選び、上記「候補者ごとのスカウト文面」または「面談メモからの推薦文ドラフト」のプロンプトを、氏名等を伏せた状態でChatGPT/Gemini/Claudeに貼って試してみる。自分がいつも書いている文面と読み比べ、どこを直せば実際に使えるかを確認するところから始める。
