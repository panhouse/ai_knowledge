# 税理士における生成AI活用事例

## これは何か

税理士は、税理士法上の資格者として「税務代理」(申告・申請を本人に代わって行う)、「税務書類の作成」(申告書・届出書等を作成する)、「税務相談」(税金の計算・申告に関する相談に応じる)という3つの業務(税理士法2条)を、原則として税理士(または税理士法人)しか行えない**独占業務**として担う。生成AIは、税務相談への回答下書きや申告書類のチェック、クライアントとの連絡文面の作成など「本人に代わって出す最終回答の手前」の作業を大きく速くできる一方、税務相談・税務代理という業務そのものはAIに置き換えられる領域ではなく、**税理士でない者(AIサービス自体を含む)が有償で税務相談を行うことは税理士法52条(税理士業務の制限)に抵触しうる**という、他の職種にはない固有の法的制約が常につきまとう。本ページでは、税理士事務所・税理士法人における生成AI活用の具体的な場面と、この法的制約・責任の所在をどう管理するかを整理する。

本ページは同じ第7章の2ページと明確に切り分ける。**[経理・財務職における生成AI活用事例](finance-accounting-ai-use-cases.md)**は企業が**自社の**帳簿・決算を作る側(依頼する側)の業務を扱い、**[公認会計士・監査法人職員における生成AI活用事例](cpa-external-auditor-ai-use-cases.md)**は上場企業等の財務諸表を**独立した第三者として検証する**会計監査を扱う。本ページが扱うのは、税理士事務所・税理士法人が**個人・法人の顧客(クライアント)**から依頼を受けて、確定申告・法人税申告・税務相談・税務調査対応などを行う業務であり、「顧客の代わりに税務判断を行い、その結果に法的責任を負う」という、経理職にも公認会計士にもない立場が前提になる。

## 仕組み・背景

税理士業務における生成AI活用は、大きく4つの層で進んでいる。

1. **汎用チャットAI(ChatGPT/Claude/Geminiなど)による下調べ・下書き作成**: 税制改正・通達の一次リサーチ、税務相談への回答ドラフト、クライアント向け説明文・お知らせ文面の作成などに使われる。あくまで「税理士が最終確認・修正して出す」ことが前提の下書き作業である。
2. **会計・税務ソフトのAI機能**: freee会計、マネーフォワード クラウド、TKC(FX2・PX2・ASP1000Rなど)、弥生といった主要ソフトはいずれも、証憑のAI-OCRデータ化、過去データからの勘定科目推測、申告書の記載漏れ・数値の整合性チェックといった機能を組み込んでおり、税理士事務所が担当する記帳代行・申告書作成の下準備を効率化している。
3. **個人・フリーランス向けの簡易AI税務相談ツール**: freeeは2026年2月、ChatGPT向けアプリ「freee確定申告」の提供を開始した。ゼロからAIに生成させるのではなく、freeeに所属する税理士が実際に回答した1万件超の相談実例からAIが最適な回答を抽出して提示する方式を採り、「AIが独自に判断を下す」リスクを抑える設計になっている。マネーフォワードも2026年の確定申告シーズン限定で「MF確定申告AI」を全ユーザーに無償提供し、チャット形式での質問対応、必要書類のチェックリスト生成、青色申告と白色申告の比較シミュレーションなどを行う。国税庁自身も、AIチャットボット「ふたば」で年末調整・所得税・消費税・インボイス制度に関する定型的な相談に24時間対応している。これらは税理士に相談する前の一次窓口として個人事業主・フリーランスに使われる一方、税理士事務所の顧客がこうしたツールの回答を鵜呑みにして相談に来るケースも増えている。
4. **税理士業界団体によるガイドライン整備**: 税理士業務での生成AI活用が広がる中、大手税理士法人が独自の「生成AI利活用ガイドライン」を策定・公表する動きが先行しており、①顧客情報をAIに入力する際は個人名・法人名・マイナンバー等を伏せる匿名化の徹底、②AI出力の税務判断の最終責任は税理士本人が負い、AIへの責任転嫁はできないこと、③AIを利用した旨を顧客に事前説明することが望ましいこと、などが共通して盛り込まれている。TKC全国会や日本税理士会連合会(日税連)も、AIを前提とした税理士業務のあり方について検討を進めており、税理士とAIの「協働モデル」を業界標準として位置付ける方向性が示されつつある。

## 使いどころ・使い分け

税理士業務では「下調べ・下書き・チェックの効率化」と「税務相談・税務代理という独占業務そのものの遂行」を明確に線引きすることが最重要になる。

| 業務フェーズ | AI活用の向き不向き | 理由 |
|---|---|---|
| 税制改正・通達・裁決事例の一次リサーチ | 向く(裏取り必須) | 検索・要約は速いが、条文番号・施行日・適用要件の誤り(ハルシネーション)が起こりうるため、原典(法令・国税庁タックスアンサー)での確認が必須 |
| 証憑のデータ化・記帳代行の下準備 | 向く(要確認) | AI-OCRによる自動仕訳は速いが、勘定科目・消費税区分の最終判断は担当者が確認する |
| クライアントからの税務相談への回答ドラフト作成 | 向く(下書きのみ、税理士名での回答は不可) | 論点整理・条文の当てはめ案までは速く作れるが、個別事情への当てはめと最終回答は有資格者が行う。顧客に直接AIの回答をそのまま転送しない |
| 申告書類のドラフト作成・記載漏れチェック | 向く(下書き・一次チェックのみ) | 会計データからの下書き生成、控除の適用漏れ・転記ミスの一次スクリーニングに有効。最終数値の確定と押印(電子署名)は税理士が行う |
| クライアント向け説明文・お知らせ文面の作成 | 向く | 税制改正のお知らせ、資料依頼メールなど定型文面の作成は生産性向上効果が大きい |
| 税務調査での資料整理・想定問答の下書き | 向く(下書きのみ) | 過去のやり取り・帳簿からの論点整理は有効。調査官との実際のやり取り・主張の最終判断は税理士が行う |
| 相続税・資産税の財産評価シミュレーション | 向く(要検証) | 概算・複数パターンの試算は速いが、非上場株式評価や特例適用の可否など個別性の強い判断は専門知識で検証する |
| 税務相談・税務代理そのもの(有償で顧客に直接回答・申告代理) | 向かない | 税理士法2条の独占業務であり、無資格の主体(AIサービス単体を含む)が担うことは同法52条に抵触するリスクがある |

判断に迷う場合は、Part 12「[生成AIに向く業務・向かない業務の切り分け](../part12-business-practice/ai-task-suitability.md)」の3チェック(入力が構造化されているか/成果物の良し悪しを基準化できるか/反復回数が多いか)に当てはめて仕分けるとよい。税理士業務ではこれに加えて「その出力が顧客への最終回答・申告書としてそのまま外に出ないか(必ず有資格者のレビューを経ているか)」を4つ目の判断軸として必ず加える。

## 実務での使い方

### 1. クライアントの税務相談への回答ドラフト作成(コピペ用プロンプト例)

```
あなたは税理士事務所の実務担当者です。以下のクライアントからの税務相談について、
回答案の論点整理をしてください。

# クライアントからの相談内容
[ここに相談内容をそのまま貼り付け。ただし顧客名・法人名・マイナンバー・
具体的な取引先名は「A社」「Bさん」等に置き換えて匿名化してから貼り付けること]

# 出力してほしい内容
1. 相談内容に関係しそうな税法上の論点を箇条書きで列挙する
2. 論点ごとに、根拠となりそうな法令・通達・タックスアンサーの項目名を挙げる
   (条文番号や通達番号は「要確認」と明記し、断定しない)
3. 追加でクライアントに確認すべき事実関係があれば列挙する
4. 一般的な考え方の整理にとどめ、このクライアントの個別事情への最終的な
   当てはめや結論は書かない

# 注意
- 出力はあくまで担当税理士が検証するための論点整理であり、
  この内容をそのままクライアントに送付しない前提で作成すること
```

出てきた論点整理は、必ず国税庁「タックスアンサー」や法令・通達の原文と担当税理士が突き合わせたうえで、最終的な回答文は税理士自身の言葉でまとめ直す。AIの出力をコピーしてそのまま顧客に送ることは避ける。

### 2. 会計・税務ソフトのAI機能(2026年時点)

| ソフト | 主なAI機能 | 特徴 |
|---|---|---|
| freee会計/freee申告 | AI-OCRによる証憑データ化、ChatGPT向けアプリ「freee確定申告」(2026年2月提供開始、税理士回答1万件超からの回答抽出方式) | 個人事業主の確定申告での「AIが独自判断で答えを作らない」設計を前面に出す |
| マネーフォワード クラウド確定申告/クラウド会計 | 「MF確定申告AI」(2026年確定申告シーズン限定で無償提供、チャット質問対応・必要書類チェックリスト生成・青色/白色比較シミュレーション)、法人向けには「マネーフォワード AI Cowork」による記帳・請求書処理の自動化 | 個人向け(確定申告AI)と法人向け(AI Cowork)で提供形態を分けている |
| TKC(FX2・PX2・ASP1000Rなど) | AI-OCRによる証憑読み取り、相続税申告書のレイアウト変更を含むAI-OCR対応の拡充(2026年) | 全国の税理士事務所(TKC全国会加盟事務所)が共通基盤として利用する業界特化型システムで、事務所間のデータ・処理品質の標準化を重視 |
| 弥生会計/やよいの青色申告 | 銀行・カード明細からの勘定科目自動推論、「弥生会計Next」の経営相談チャット(β) | 段階的な自動化を志向し、中小企業・個人事業主の実務に寄り添う方針 |
| 国税庁チャットボット「ふたば」 | 年末調整・所得税/消費税申告・インボイス制度に関する定型相談への24時間AI回答 | 税理士に相談する前の一次窓口として顧客が利用するケースが増えており、その回答を前提に相談に来る顧客への説明対応も必要になる |

**手順の目安(freee確定申告のChatGPTアプリの場合)**: 顧客に案内する場合は、ChatGPTアプリストアで「freee確定申告」を検索・追加 → 確定申告に関する質問を入力 → 税理士回答実例に基づく回答が提示される、という流れになる。事務所側では、このツールの回答内容と、実際に顧客の申告内容が食い違うケースがないか、初回の申告時は特に目を通しておくと顧客対応がスムーズになる。

### 3. クライアント向け連絡文面の作成(コピペ用プロンプト例)

```
あなたは税理士事務所の広報担当です。以下の税制改正の概要を基に、
顧問先向けのお知らせメール文面を作成してください。

# 税制改正の概要
[改正内容の要点を箇条書きで貼り付け]

# 条件
- 対象読者は経理担当者ではない中小企業の経営者・個人事業主
- 専門用語には一言説明を添える
- 「詳細は個別にご相談ください」という一文で締める
- 具体的な数値・適用時期は入力した情報の範囲でのみ書き、憶測で補わない
```

### 4. 申告書類の記載漏れ・整合性の一次チェック

会計データと入力済みの申告書ドラフトをAIに読み込ませ、「扶養控除の記載漏れがないか」「前年の申告データと比較して大きく変動している科目はどこか」といった一次スクリーニングに使う。ここでの役割はあくまで「見落としの洗い出し」であり、控除の適用可否や税額の最終確定は税理士自身が行う。

## 注意点・よくある誤解

- **AIによる税務相談・税務代理は税理士法違反リスクを伴う**: 税理士法52条は税理士(法人)以外が税理士業務(税務相談・税務代理・税務書類の作成)を行うことを禁じており、違反した場合は2年以下の懲役または100万円以下の罰金の対象になりうる。事務所内でAIを「下書き作成の補助」として使う分には問題ないが、AIの回答をそのまま無資格のスタッフや顧客向けの正式回答として出す運用、あるいは税理士が関与しないAIサービスが有償で個別具体的な税務相談に答える運用はグレーゾーンであり、AIの精度が上がるほど「無資格での税理士業務」に該当するリスクが高まるという指摘もある。事務所としては「最終的な回答・申告書は必ず有資格者の名前で、有資格者が検証してから出す」運用を徹底する。
- **顧客の機密財務情報の匿名化は必須**: 個人名・法人名・マイナンバー・具体的な取引先名を含んだままAIに入力すると、守秘義務違反や情報漏洩のリスクになる。相談内容をAIに渡す前に固有名詞を伏せる、法人向け・エンタープライズプラン(学習利用オプトアウトが可能なプラン)を使うといった対策を事務所のルールとして明文化しておく。
- **最終責任は常に税理士本人が負う**: AIの出力を根拠に誤った申告・助言を行っても、責任をAIやAIベンダーに転嫁することはできない。税理士には依頼者の説明や提出資料に漫然と依拠せず自ら精査する義務(資料の精査義務など)が判例上求められており、AIが作った下書きも「精査すべき資料の一つ」として扱う必要がある。
- **ハルシネーションによる存在しない条文・通達の引用**: 生成AIは、それらしい条文番号や通達番号、裁決事例をもっともらしく作り出すことがある(詳細は「[生成AIのハルシネーションと対策](../part04-risk-security/hallucination-and-countermeasures.md)」を参照)。税務判断の根拠として使う法令・通達・タックスアンサーの記載は、必ず国税庁の原典やe-Gov法令検索で裏取りする。
- **簡易AI税務相談ツールを勧める・案内するときの温度感**: freee確定申告のChatGPTアプリやマネーフォワードのMF確定申告AI、国税庁の「ふたば」は個人事業主の一次相談窓口として有用だが、あくまで一般論の回答にとどまる。顧問先には「個別の事情(特例の適用可否、複数の所得区分がある場合など)は必ず顧問税理士に確認してから申告してほしい」と案内し、ツールの回答だけで判断しないよう伝えておく。

## 最初の一歩

直近でクライアントから受けた税務相談を1件選び、固有名詞を匿名化したうえで生成AIに論点整理をさせ、自分が普段行っている一次リサーチの結果とどれくらい重なるか・どこにハルシネーションや見落としがあるかを比べてみる。
