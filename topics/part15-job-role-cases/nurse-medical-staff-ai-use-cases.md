# 看護師・医療従事者における生成AI活用事例

## これは何か

本ページは、看護師・看護助手・臨床検査技師・介護職員といった**病院・診療所で働く臨床現場の個人**が、日々の業務で生成AIをどう使うかを扱う。具体的には、口頭で行っている申し送り・看護記録の音声入力からの下書き生成、患者・家族向け説明資料の「やさしい日本語」化、外国人患者との会話支援、勤務シフトの希望調整、院内研修資料の自習用Q&A化といった、**臨床スタッフ個人が勤務時間内に手を動かす場面**にフォーカスする。

隣接ページとの境界を先に整理しておく。[医療・ヘルスケアにおける生成AI活用事例](../part14-industry-cases/healthcare-ai-use-cases.md)は病院・企業という**経営・導入主体の視点**で、アンビエントAIスクライブや画像診断支援AI、医薬品開発など病院全体・業界全体の導入事例を扱うカタログである。それに対して本ページは、**看護師個人が自分の当直・勤務の中でどう使うか**という一段下のレイヤーを扱う。同じ「OPTiM AI ホスピタル」のような製品でも、Part 14では「病院がどう導入したか」を書き、本ページでは「看護師が申し送り前にどう入力するか」という使う側の手順を書く、という役割分担になる。[製造・建設現場の作業員・現場監督における生成AI活用事例](frontline-worker-supervisor-ai-use-cases.md)とは「PCではなくスマホで、音声を軸に使う現場職」という制約を共有する隣接ページであり、あわせて参照するとよい。

## 仕組み・背景

看護師の働き方には、他のオフィスワーカーと大きく異なる制約がある。

- **交代勤務で「申し送り」という口頭引き継ぎが業務の中核**にある。日勤・準夜勤・深夜勤の交代のたびに、受け持ち患者の状態・処置・注意点を次の担当者に口頭+紙またはカルテ入力で伝える必要があり、この作成・整理に時間がかかる
- **手がふさがっている・清潔操作中でキーボードに触れない**場面が多く、記録は「あとでまとめて入力」になりがちで、記憶が薄れた状態での記録漏れ・遅延が発生しやすい
- **患者・家族への説明は、医学的に正確でありながら平易な言葉に翻訳する能力**が求められる。専門用語のまま話しても伝わらず、かといって不正確な単純化は誤解を招く
- **夜勤を含む変則勤務のシフト調整**は、個々の希望・法定の勤務間インターバル・夜勤回数の上限などを同時に満たす必要がある複雑な最適化問題であり、看護師長の大きな負担になっている

この制約から、看護師向けの生成AIの主戦場は「**話した内容をAIが整形する**」音声入力ベースの記録支援と、「**専門用語を患者向けの言葉に変換する**」説明資料の平易化に集中している。実際、2026年に入り、病院向け生成AIサービスの多くが申し送り・記録支援機能を強化する動きが相次いだ。

**院内システム型(病院が導入する専用サービス)**では、株式会社オプティムの「OPTiM AI ホスピタル」がver.3.1(2026年7月提供開始)で申し送り業務支援機能を強化し、録音データのアップロードによるカルテ記載文の自動生成、期間を指定した看護サマリーの自動生成(「過去24時間の状態変化」「入院期間中の経過要約」など目的別の要約)に対応した([OPTiM公式](https://www.optim.co.jp/newsdetail/20260722-pressrelease-01))。また、独立行政法人国立病院機構大阪病院では、富士通Japan・フォーティエンスコンサルティングと2026年2月に協定を結び、年間約1.6万件にのぼる退院サマリー作成と看護申し送りの要点整理に生成AIを活用するプロジェクトを開始し、2026年6月の本稼働を目指した([IT Leaders](https://it.impress.co.jp/articles/-/29012)、[富士通公式](https://global.fujitsu/ja-jp/subsidiaries/fjj/news/press-releases/2026/0219-01))。音声認識大手アドバンスト・メディアも医療向けAI音声認識記録支援サービス「AmiVoice iNote」を展開しており、看護記録・申し送りメモの音声からの下書き作成に対応する。

**個人のスキル習得型**では、DXHR株式会社が2026年5月に看護・介護職向けの業界特化型生成AI活用eラーニング(全12章・12時間)の提供を開始した。「スマホの音声入力×AI」を軸に、記録・申し送り・観察アセスメント・患者家族対応・シフト作成まで現場業務全域を体系的に学べる構成になっている点が特徴で、PCの院内システム導入を待たずに、看護師個人が汎用チャットAIのスキルを身につける動きも並行して進んでいる([PR TIMES](https://prtimes.jp/main/html/rd/p/000000067.000073863.html))。

なお医療・ヘルスケア分野での生成AI利用には業界横断のガイドラインが存在する。非営利法人 医療AIプラットフォーム技術研究組合(HAIP)は「医療・ヘルスケア分野における生成AI利用ガイドライン(第2版)」を2025年7月に発行し、個人情報保護法・医療情報システムの安全管理に関するガイドライン(いわゆる「3省2ガイドライン」)との関係を整理したうえで、医療機関が生成AIを利用する際の実務対応をまとめている([HAIP公式](https://haip-cip.org/news/20250711/))。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

看護師・臨床スタッフの1勤務の流れに沿って、どこに生成AIが入るかを整理すると次のようになる。

| 業務フェーズ | 頻度 | AIの使いどころ | 向く担当 |
|---|---|---|---|
| 受け持ち患者の情報収集・カンファレンス準備 | 毎勤務開始時 | 電子カルテの経過記録を期間指定で要約させ、状態変化の把握を短縮 | 看護師全般 |
| 看護記録・経過記録の作成 | 随時(処置・観察のたび) | 音声で話した観察内容をSOAP形式など院内フォーマットの記録文に整形 | 看護師・看護助手 |
| 勤務交代時の申し送り準備 | 毎勤務終了時 | 受け持ち患者ごとの申し送り要点を、記録から自動抽出・箇条書き整理 | 看護師 |
| 患者・家族への説明資料作成 | 随時(入院時・処置前後) | 医師の説明内容や検査結果を「やさしい日本語」に変換した説明メモを作成 | 看護師・医療ソーシャルワーカー |
| 外国人患者とのコミュニケーション | 随時 | 問診・症状確認・生活指導の会話を多言語に翻訳、簡単な受け答えの支援 | 看護師・受付スタッフ |
| 勤務シフトの希望調整 | 月次 | 個々の希望日・夜勤回数の上限・法定の勤務間インターバルを踏まえたシフト案のたたき台作成 | 看護師長・主任 |
| 院内研修・自己学習 | 随時 | 院内研修資料や看護手順書をもとにした自習用Q&Aの生成、新人教育の質問対応 | 教育担当・新人看護師 |

判断の軸は、[製造・建設現場の作業員・現場監督における生成AI活用事例](frontline-worker-supervisor-ai-use-cases.md)と同様、「**患者の個人情報を含まないか**」がまず第一の分岐になる。研修資料のQ&A化やシフト調整のたたき台作成は患者情報を含まないため、法人契約の汎用チャットAIでも比較的着手しやすい。一方、看護記録・申し送り・患者説明資料の作成は患者の氏名・病状・治療内容そのものを扱うため、後述する「入力してよい環境か」を必ず確認したうえで、原則として院内承認済みの専用システム・閉域環境を使う必要がある。

### 汎用チャットAI vs 専用ツールの使い分け

| 業務 | 汎用チャットAI(法人契約・院内承認済みの範囲)でできること | 専用ツール・院内システムが必要な範囲 |
|---|---|---|
| 看護記録・経過記録の作成 | 匿名化した架空事例での書き方の練習・型の習得 | 実際の患者記録は電子カルテ連携済みの専用サービス(OPTiM AI ホスピタル、AmiVoice iNoteなど)を使用 |
| 申し送りメモの整形 | 個人が特定されない一般的な状態像の文章整形練習 | 実患者の申し送りは院内承認済みのシステムか、少なくとも入力データを学習に使わない設定の法人契約環境 |
| 患者説明資料のやさしい日本語化 | 疾患名・検査名など一般的な医学用語の平易な言い換えの下書き(患者個人の情報は入れない) | 個別の検査結果・既往歴を踏まえた説明は院内承認済み環境、最終確認は必ず医師・看護師 |
| 外国人患者との会話支援 | 定型的な問診項目・生活指導の翻訳の下書き | 誤訳が命に関わる場面(症状の緊急度判断、同意説明)は医療通訳専用サービス・医療通訳者の同席 |
| シフトの希望調整 | 希望条件を伝えてたたき台の考え方を相談する壁打ち(個人名を出さない範囲) | 実際の希望シフト表・勤務実績データの投入は専用シフト作成システム(セルヴィスEX、シフッタ、ほすぴタッチ等) |
| 院内研修資料のQ&A化 | 公開されている医学知識・院内で配布済みの研修資料をもとにした問題作成・要約 | 院内マニュアル全体を検索対象にするなら、RAG構成のナレッジ検索システム |

小規模なクリニック・訪問看護ステーションであれば、まずは患者情報を含まない領域(研修資料のQ&A化、シフト調整の考え方の相談)から汎用チャットAIを試すのが着手しやすい。急性期病院など患者数・記録量が多い施設では、電子カルテと連携した専用の記録支援サービスへの投資対効果が大きくなりやすい。

## 実務での使い方

### 1. 音声入力による看護記録・経過記録の下書き作成

処置直後、患者のそばで話した観察内容を、院内フォーマット(SOAP形式など)の記録文に整形させる使い方。**院内承認済みの環境・院内システムでのみ実施し、実際の患者名・病状を含む内容を個人の無料アカウントのチャットAIに入力しない**ことが大前提になる。

**コピペで使えるプロンプト例(院内承認済み環境での利用を想定)**

```
あなたは看護記録の作成を支援するアシスタントです。
以下は、患者の観察内容を音声で話した内容の文字起こしです。
これをSOAP形式(S:主観的情報、O:客観的情報、A:アセスメント、
P:計画)に整形してください。

## 出力時の注意
- 話し言葉のフィラー(「えーっと」「あの」など)は削除する
- バイタルサイン等の数値は聞き取れる範囲でそのまま転記し、
  不明瞭な箇所は「(要確認)」と明記する
- アセスメント(A)は観察事実から読み取れる範囲にとどめ、
  診断に類する断定的な記述はしない
- 最終的な記録内容の正確性は記載者本人が確認する前提とする

## 音声入力の文字起こし
{{音声入力でそのまま話した内容をここに貼り付け}}
```

### 2. 勤務交代時の申し送りメモの整理

自分の勤務時間中の出来事を、受け持ち患者ごとに申し送り用の要点に整理させる使い方。OPTiM AI ホスピタルのように電子カルテと連携した専用サービスでは、期間を指定するだけで経過を自動要約できるが、専用システムがない環境でも音声入力+整形プロンプトで同様の効果が得られる。

```
以下は、私が受け持った患者{{人数}}名について、勤務中の
出来事を音声で話した内容の文字起こしです。
患者ごとに、次の交代スタッフへの申し送りメモとして
整形してください。

## 出力フォーマット(患者ごとに)
- 病室・氏名(院内呼称ルールに従う)
- 本日の状態変化(バイタル・症状の変化)
- 実施した処置・与薬
- 次の勤務で特に注意してほしいこと
- 医師への報告・確認が必要な事項(あれば)

## 音声入力の文字起こし
{{話した内容}}
```

### 3. 患者・家族向け説明資料の「やさしい日本語」化

医師の説明内容や院内の疾患説明用紙を、患者・家族にも伝わる平易な言葉に変換する使い方。**個別の患者の検査値・既往歴などの個人情報は入力せず**、疾患名・検査名・処置名など一般的な医学知識の言い換えにとどめて使うのが安全な範囲になる。

```
以下の医療用語を含む説明文を、中学生でも理解できる
「やさしい日本語」に書き換えてください。
専門用語は残しつつ、初出で()内に簡単な言い換えを添えてください。
一文はできるだけ短くし、不安をあおる表現は避けてください。

なお、この説明文はたたき台であり、実際の患者説明の際は
個々の病状に応じて医師・看護師が内容を確認・修正することを
前提にしています。

## 元の説明文
{{疾患名・検査・処置の一般的な説明文(患者個人の情報は含めない)}}
```

### 4. 外国人患者との会話支援(定型的な問診・生活指導)

問診票の質問や、退院後の生活指導といった定型的な内容を多言語に翻訳する使い方。緊急度の判断や同意説明など誤訳が重大な結果につながる場面では、医療通訳専用サービスや医療通訳者の同席に切り替える運用とセットにする。

```
以下の問診項目・生活指導の文章を、{{英語/中国語/ベトナム語/
やさしい日本語}}に翻訳してください。医療現場での使用を想定し、
症状の程度・期間を尋ねる表現は曖昧さを避け、明確な言い回しに
してください。緊急性が疑われる症状に関する質問は、
翻訳とあわせて「早急な確認が必要な項目」として印を付けてください。

## 問診項目・生活指導文
{{定型的な問診票の質問文、退院後の生活指導文など}}
```

### 5. 勤務シフトの希望調整のたたき台作成

看護師長・主任が、各スタッフの希望日・制約条件を整理してシフト調整の考え方を相談する使い方。実際のシフト表作成は専用システム(セルヴィスEX、シフッタ、ほすぴタッチ等)やExcelマクロが担うことが多いが、条件の整理・優先順位付けの壁打ちには汎用チャットAIも活用できる。

```
以下は当病棟の来月のシフト希望条件です。
公平な調整の考え方・優先順位のつけ方について、
案をいくつか提示してください。実際の割り当てには反映せず、
あくまで調整方針の相談として答えてください。

## 制約条件
- スタッフ数・夜勤対応可能人数
- 各自の希望休・夜勤回数の上限
- 勤務間インターバル(法定基準)
- 有資格者(プリセプター等)の配置ルール

{{具体的な人数・条件を記載}}
```

### 6. 院内研修資料の自習用Q&A化

院内で配布済みの研修資料・看護手順書をもとに、新人看護師が自習できる一問一答形式の教材を作らせる使い方。国家試験の学習支援(誤答選択肢の自動生成研究なども進んでいる領域)と同様の発想で、院内固有の手順の定着にも応用できる。

```
以下は当院の看護手順書の抜粋です。この内容の理解度を
確認するための一問一答形式のQ&Aを10問作成してください。
新人看護師の自己学習を想定し、単純な暗記ではなく
「なぜその手順が必要か」を問う設問も含めてください。
最後に模範解答と、間違えやすいポイントの解説を付けてください。

## 手順書の抜粋
{{院内で配布済みの研修資料・手順書のテキスト}}
```

## 注意点・よくある誤解

- **実患者の情報を個人の無料アカウントに入力しない**: 看護記録・申し送り・患者説明資料には患者の氏名・病状・検査結果といった要配慮個人情報が含まれる。個人契約の無料版チャットAIに入力すると、入力内容が学習に利用される設定になっている場合があり、情報漏洩・目的外利用のリスクになる。HAIP(医療AIプラットフォーム技術研究組合)のガイドラインが指摘するように、「学習をオフにする設定」だけでは、医療情報システムの安全管理に関するガイドライン(いわゆる3省2ガイドライン)が求める水準を満たさない場合があるため、院内の承認プロセスを経た専用サービス・閉域環境の利用が基本になる([HAIP公式](https://haip-cip.org/news/20250711/))
- **AIの出力は下書きであり、最終確認・署名の責任は本人にある**: OPTiM AI ホスピタルのような専用サービスも「AIが生成した出力内容は担当医師・看護師が確認・承認した上で活用する」運用を前提にしている([OPTiM公式](https://www.optim.co.jp/newsdetail/20260722-pressrelease-01))。看護記録の法的な作成責任は記載者本人にあり、AIの下書きをそのまま転記・確定させることは避ける
- **音声入力の聞き取りミスは記録の正確性に直結する**: 病棟は環境音や早口の会話が多く、バイタルサインの数値(体温・血圧・SpO2等)や薬剤名・単位が誤変換されやすい。数値・固有名詞は記録確定前に必ず読み返して確認する
- **「やさしい日本語」化・多言語翻訳は医学的な正確性を犠牲にしないよう確認する**: 平易にする過程で情報が単純化されすぎたり、症状の緊急度に関するニュアンスが失われたりすると、患者・家族の判断を誤らせるおそれがある。特に外国人患者対応では、緊急度の判断や治療への同意説明など重大な場面は、汎用翻訳ではなく医療通訳専用サービスや医療通訳者の同席に切り替える
- **シフト調整AIは「たたき台」であり、法令・労使協定の最終確認は人が行う**: 夜勤回数の上限、勤務間インターバル、有給休暇の取得促進などは労働基準法や36協定に関わる。AIが提示した案をそのまま確定させず、労務担当・師長が法令適合性を確認する
- **職能団体・学会単位のガイドライン動向を継続的に確認する**: 2026年8月時点で日本看護協会が単独の生成AI利用ガイドラインを公表している情報は確認できていないが、医療AIプラットフォーム技術研究組合(HAIP)やヘルスケア産業協会など業界横断のガイドラインは随時改訂されている。自院の情報システム部門・医療安全管理部門が最新のガイドラインを把握しているか確認したうえで導入する

## 最初の一歩

まずは患者情報を含まない領域から着手する。院内で配布済みの看護手順書や研修資料を1つ選び、法人契約(または院内承認済み)のチャットAIに貼り付けて、上記の「自習用Q&A化」プロンプトで新人教育用の一問一答教材を作らせてみる。効果を体感したうえで、記録・申し送り業務への展開は情報システム部門・医療安全管理部門との相談を経てから進めるとよい。
