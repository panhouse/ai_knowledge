# 社会保険労務士(社労士)における生成AI活用事例

## これは何か

社会保険労務士(社労士)は、就業規則の作成・労働社会保険手続き・給与計算・労務相談という「書類作成」「調査」「相談対応」の比重が高い業務を扱う士業であり、生成AIによる時間短縮効果が特に出やすい職種のひとつ。一方で、手続き代行や帳簿書類の作成には社労士法で定められた独占業務(1号・2号業務)が絡み、扱うデータにはマイナンバーや傷病名など機微な個人情報が含まれるため、「どこまでAIに任せてよいか」の線引きが他の職種以上にシビアになる。本ページは、社労士事務所・企業の労務担当が実務でAIをどう使い分けているかを、業務フェーズに沿って整理する。なお「人材サービス業」としての切り口(採用代行・人材紹介での活用)は[Part 14 士業・専門サービス](../part14-industry-cases/_index.md)を、企業側の人事(HR)職としての切り口は[人事(HR)職における生成AI活用事例](hr-ai-use-cases.md)を参照。本ページは社労士(または企業内で社労士業務相当を担う労務担当者)という**職種の業務フロー**に焦点を当てる。

## 仕組み・背景

社労士業務でAI活用が広がった背景には3つの流れがある。

- **労務管理SaaSへのAI機能の内蔵**: SmartHRは2025年7月下旬から、社内の人事労務規程を学習させて従業員からの問い合わせに自動回答する「AIアシスタント」機能の提供を開始した。給与計算ソフト(freee人事労務、ジョブカン給与計算など)側でも、随時改定(月額変更)対象者の自動判定や、証憑をAI-OCR(画像から文字を読み取るAI技術)で読み取って賃金台帳・保険料控除一覧を自動生成する機能が広がっており、算定基礎届・月額変更届のような定型手続き書類は「AIが下書きを作り、人が確認して提出する」フローに置き換わりつつある。
- **汎用LLMによる調べもの・文書ドラフトの効率化**: ChatGPT・Claude・GeminiなどはWeb検索や長文の要約・比較ができるようになり、就業規則の初稿作成、助成金の該当性の一次リサーチ、労働基準法・育児介護休業法などの改正点の整理といった「1号・2号業務そのものではないが、その手前の調査・下書き」作業に使われている。ある社労士事務所ではAI研修導入後、就業規則ドラフト作成時間が65%減、助成金提案書作成時間が72%減、年間換算で1,400時間の業務削減につながったという事例が報告されている。
- **業界団体によるガイドライン整備**: 全国社会保険労務士会連合会は2024年9月9日、会員向けに「社会保険労務士向け生成AI活用ガイドブック」と解説e-ラーニングを公開し、士業として生成AIをどう業務に取り入れるかの公式な指針を示した。以降、各都道府県の社労士会・事務所単位でも独自の生成AI利用ガイドラインを整備する動きが続いている。

いずれの仕組みでも、AIが行っているのは「頻出する条文・書式パターンからの下書き生成」や「入力された文書の要約・照合」であり、個別の企業の労使関係の実情や、依頼者本人の症状・生活実態を踏まえた最終判断まではできない。**手続きの代行・帳簿書類の作成の確定・労務相談への回答の最終責任は、常に社労士本人(または企業内の労務担当者)が負う**という前提を理解しておく必要がある。

## 使いどころ・使い分け

社労士業務は「AIに下書き・一次整理を任せてよい範囲」と「専門家の判断・押印・提出行為として必ず人が確定させる範囲」の差が大きい。業務フェーズに沿って整理する。

| 業務フェーズ | AIが担う範囲 | 人(社労士・労務担当)が必ず担う範囲 |
|---|---|---|
| 就業規則・雇用契約書のドラフト作成 | 業種・規模・要望を踏まえたたたき台生成、条文の言い回し候補、法改正箇所の反映漏れチェック | 労使協定との整合性確認、個別企業の実情に即した条件設定、最終確定・届出 |
| 給与計算・社会保険手続き書類(算定基礎届・月額変更届等)の下書き・チェック | AI-OCRによる証憑読み取り、対象者の自動判定、入力ミスの一次スクリーニング | 標準報酬月額の最終確認、随時改定の要否判断、電子申請の実行・押印 |
| 労務相談への一次対応(社内FAQ・チャットボット) | 就業規則・法令に基づく一般的な質問への24時間automatic回答、よくある質問の一次振り分け | 個別の解雇・懲戒・ハラスメント案件など専門判断が必要な相談への最終回答 |
| 助成金・補助金の該当性リサーチ | 制度の概要整理、公募要件との突き合わせの一次スクリーニング、提案書のたたき台 | 最新の公募要領との厳密な照合、申請書類の最終確定・提出 |
| 法改正・通達の調査 | 改正内容の要約、影響範囲の一次整理、顧問先向けニュースレターの下書き | 一次情報(官報・厚労省通達原文)での裏取り、個別企業への当てはめ |
| 障害年金など個人の申請書類作成支援 | 病歴・就労状況等申立書のたたき台、ヒアリング内容からの文章化 | 医証との整合性確認、本人の実態に即した最終内容確定・提出 |

使い分けの判断基準は「この出力を鵜呑みにして進めた場合、本人(依頼者)や企業に不利益が生じないか」。**独占業務(1号・2号業務)にあたる手続きの確定行為・帳簿書類の最終確定は必ず有資格者が行い、AIは調査・下書き・一次チェックまでに留める**のが実務的な線引きになる。

## 実務での使い方

### 1. 就業規則・雇用契約書のドラフト作成

```
あなたは社会保険労務士です。以下の条件で就業規則の「服務規律」の条文案を
作成してください。

【企業情報】
- 業種: 小売業(店舗スタッフ約30名、正社員・パート混在)
- 就業形態: シフト制、変形労働時間制を導入予定
- 特に定めたい事項: 私物のSNS投稿に関する情報漏洩防止、副業の許可制、
  カスタマーハラスメントを受けた際の対応(会社が従業員を守る旨)

【出力形式】
1. 条文案(条番号付き)
2. 各条文について、根拠となる法令(労働基準法・個人情報保護法等)を注記
3. 就業規則本則との整合性で確認が必要そうな箇所があれば末尾に一覧化

※これはたたき台です。最終的な条文の確定は社労士が行うことを前提に、
迷う点は断定せず選択肢を示してください。
```

### 2. 労働社会保険手続き書類のチェック(算定基礎届の一次確認)

```
以下は、ある従業員の4〜6月の支払基礎日数と報酬月額の一覧です。
標準報酬月額の算定基礎届の作成にあたり、次の観点で一次チェックしてください。

【チェック観点】
- 3か月の平均が現在の標準報酬月額と2等級以上の差があり、
  随時改定(月額変更届)の対象になる可能性がないか
- 支払基礎日数が17日未満の月が含まれていないか(算定対象から除外すべきか)
- 通勤手当・残業手当の算入漏れがないか

【データ】
(ここに月別の支払基礎日数・報酬月額を貼付)

※最終的な標準報酬月額の確定・電子申請は人が行います。
あくまで見落とし防止のための一次チェック結果として、根拠条文とあわせて出力してください。
```

### 3. 労務相談の一次対応(社内FAQボット)

顧問先の担当者や従業員からの定型的な質問には、就業規則・自社規程をRAG(検索拡張生成、社内文書を検索してから回答させる方式)で読み込ませたチャットボットが向く。SmartHRの「AIアシスタント」機能はこの用途に特化しており、社内規程を学習させて「テレワークの利用条件は?」といった質問に24時間自動回答させる仕組みを提供している。

```
あなたは当事務所の顧問先向け労務相談一次対応AIです。
添付した当該企業の就業規則・36協定の内容のみを根拠に回答してください。
資料に記載がない、または個別の解雇・懲戒・ハラスメント案件など
専門判断が必要な相談については、推測で答えず
「担当社労士に確認が必要な内容のため、追ってご連絡します」と回答してください。

質問: 有給休暇を時間単位で取得できるか。
```

### 4. 助成金・補助金の該当性リサーチ

```
以下の企業の状況について、活用できる可能性のある雇用関係助成金を
リストアップしてください。

【企業情報】
- 従業員数: 45名(製造業)
- 直近の取り組み: 60歳以上の従業員の定年後再雇用制度を新設予定
- 課題: 若手社員の離職率が高く、キャリアアップ支援策を検討中

【出力形式】
1. 該当しそうな助成金の名称と概要
2. 主な受給要件(あくまで一次情報として)
3. 「最新の公募要領・支給要件は厚生労働省の公式ページで必ず確認してください」
   という注記を末尾に必ず入れる
```

### 5. 法改正・通達の調査(顧問先向けニュースレター下書き)

```
2026年に施行予定の労働関連の法改正のうち、従業員100名規模の
サービス業の顧問先に影響が大きいものを3つ選び、
顧問先向けニュースレターの下書きを作成してください。

- 各改正点について「何が変わるか」「いつまでに何をすべきか」を3行以内で要約
- 専門用語(施行日、経過措置など)は初出で一言説明を付ける
- 断定的な表現は避け、「詳細は厚生労働省の公式情報でご確認ください」を末尾に付す
```

### 使えるツール・構成

| ツール・機能 | 位置づけ | 特徴・2026年8月時点の動向 |
|---|---|---|
| SmartHR「AIアシスタント」 | 労務管理SaaSに内蔵された従業員向け一次対応AI | 2025年7月下旬提供開始。社内規程を学習させ、従業員からの人事労務に関する問い合わせに自動回答。類似・重複した問い合わせ対応の削減を狙う機能 |
| freee人事労務 / ジョブカン給与計算 | 給与計算SaaSのAI機能 | 随時改定対象者の自動判定・月額変更届の自動作成、AI-OCRによる証憑読み取りなど、算定基礎届・月額変更届の下書き作成を自動化 |
| ChatGPT / Claude / Gemini(汎用AI) | 就業規則ドラフト・助成金リサーチ・法改正要約の汎用エージェント | 労務特化ツールほどの網羅性は保証されないが、条文ドラフト・議事録作成・顧問先向け文書作成など裾野の広い業務に安価に使える。機密情報の入力ルールを個別に確認する必要がある |
| 障害年金業務特化AI(shogaiGPT等) | 障害年金申請書類(病歴・就労状況等申立書等)のドラフト作成支援 | ヒアリング内容から申立書のたたき台を生成し、書類作成時間を短縮する事例が報告されている。最終的な医証との整合性確認・提出判断は社労士が行う |
| 全国社会保険労務士会連合会「社会保険労務士向け生成AI活用ガイドブック」 | 業界団体による公式指針 | 2024年9月9日公開。会員向けに生成AIの業務活用の考え方・注意点を整理した解説e-ラーニングとセットで提供 |

汎用AIは「ドラフト作成・要約・リサーチ」に、労務管理SaaS内蔵のAI機能は「定型手続き・従業員向け一次対応の自動化」に向く。両者は排他ではなく、事務所の規模や顧問先数に応じて併用するのが一般的になっている。

## 注意点・よくある誤解

- **独占業務(1号・2号業務)にAIを「代行」させる設計は業務独占違反のリスクがある**: 社労士法上、労働社会保険の手続き代行(1号業務)と就業規則・帳簿書類の作成(2号業務)は社労士の独占業務。給与計算そのものは独占業務ではないが、給与計算結果から賃金台帳を自動生成するところまでAIが行い、社労士(または企業内の適法な担当者)の確認を経ずに完結させる設計は、業務独占の観点でリスクが指摘されている。AIはあくまで事務所・企業内部の業務支援ツールとして使い、最終的な確定・提出行為は有資格者が行う体制を明文化する。
- **マイナンバー・傷病名などの機微情報は原則そのまま入力しない**: マイナンバーは番号法(マイナンバー法)で利用できる事務が限定されており、汎用の生成AIに入力してよい情報ではない。氏名・住所・傷病名など個人を特定できる情報も同様で、入力する場合はマスキング(伏せ字化)するか、入力データを学習に使わない設定の法人向け・API契約プランを使うのが基本線になる。障害年金の申立書のようにセンシティブな健康情報を扱う業務では特に注意が必要。
- **AIの出力は「一次ドラフト」であり「専門家の最終判断」ではない**: 就業規則の条文案も助成金の該当性判断も、AIは頻出パターンからの一次整理をしているに過ぎず、個別企業の労使関係の実情や依頼者本人の生活実態までは踏まえられない。最終的な条文確定・支給要件の当てはめ・提出判断は必ず社労士(または企業の労務責任者)が行う体制にする。
- **助成金・法改正情報は必ず一次情報(厚生労働省の公式ページ・官報)で裏取りする**: 助成金の支給要件や法改正の施行日は頻繁に更新され、AIの学習データが古い場合や、生成AI特有のハルシネーション(事実と異なる情報をもっともらしく生成する現象)により実在しない要件を出力するリスクがある。顧問先に案内する前に必ず公式情報と突き合わせる。
- **業界団体のガイドラインを一度は確認する**: 全国社会保険労務士会連合会が2024年9月に公開した「社会保険労務士向け生成AI活用ガイドブック」など、士業としての生成AI活用の考え方を整理した公式資料が既に存在する。自己流のルールだけに頼らず、所属する都道府県社労士会や連合会の指針も確認しておくと、後から運用を修正する手間が減る。

## 最初の一歩

直近で作成した就業規則の一部条文や、算定基礎届のチェック対象者データ(いずれもマスキングした匿名サンプル)を上記のプロンプトに貼って試し、AIが提示したチェック項目と自分が普段確認している観点にズレがないかを確認してみる。
