# 獣医師における生成AI活用事例

## これは何か

獣医師は、問診・触診・検査・画像診断・治療方針の決定・カルテ記載・飼い主への説明・
投薬管理・紹介状作成・文献調査までを、動物病院1人〜数人の獣医師体制でこなすことが多く、
診療そのものに集中する時間を事務作業が圧迫しやすい。本ページは、**獣医師個人が診療の
各局面で生成AIをどう使い、どこで人の判断を守るか**を業務フローに沿って整理する。

動物病院という「事業」としての生成AI活用(予約対応チャットボット・ペット保険の請求処理・
EC商品説明文など)は
[ペット関連産業における生成AI活用事例](../part14-industry-cases/pet-care-industry-ai-use-cases.md)
で扱っており、AIスクライブ(カルテ自動作成)・画像診断AIの主要ベンダー一覧もそちらに
まとめてある。本ページは重複を避け、**個々の獣医師が診療の現場でAIをどう使い分けるか**
(特に投与量計算・鑑別診断の壁打ち・文献検索・飼い主への説明準備)に絞って書く。

## 仕組み・背景

獣医師が使うAIは、大きく2系統に分けて理解すると使い分けがしやすい。

1. **汎用生成AI(ChatGPT・Claude・Gemini等)**: 文章の下書き・要約・言い換え・
   アイデア出しが得意。学習データは獣医学に限らず広く、次に来る単語を予測する
   仕組みのため、**数値計算(投与量計算など)や事実確認には向かない**。
2. **獣医療特化AI**: カルテ音声を認識してSOAP形式(主観情報・客観情報・評価・計画)に
   構造化するAIスクライブ、X線・超音波画像を解析する画像診断AI、検証済みの
   処方集(フォーミュラリー)データベースと連携した投与量計算AIなど。
   汎用AIに獣医学の専門知識・構造化ルール・検証済みデータベースを組み合わせている点が
   汎用チャットAIとの違いで、臨床判断に近い用途ほど特化AIを使うのが安全。

米国動物病院協会(AAHA)とDigitail社が2023年12月〜2024年1月に実施した調査
(獣医療従事者3,968人が回答)では、**39.2%がすでに業務でAIツールを使用しており、
利用者の69.5%は毎日または毎週使用している**。主な用途は画像診断、事務作業、
音声のテキスト化(カルテ起こし)で、最も多かった懸念(70.3%)は
「AIの正確性・信頼性」だった([AVMA Journals](https://avmajournals.avma.org/view/journals/ajvr/86/S1/ajvr.24.10.0293.xml)、[dvm360](https://www.dvm360.com/view/survey-results-show-how-veterinary-professionals-use-ai-tools))。

日本獣医師会(JVMA)は「愛玩動物における遠隔診療の適切な実施に関する指針」(2022年)など
獣医療の実施方法に関する指針を公表しているが、2026年8月時点で**生成AI利用に特化した
公式ガイドラインは確認できていない**。日本獣医生命科学大学が学生・教職員向けの
生成AI利用ガイドラインを公表しているが、これは学修・研究における利用が対象で、
臨床現場での利用を直接規定するものではない
([日本獣医生命科学大学](https://www.nvlu.ac.jp/universityguidance/generativeai.html/))。
現時点では、既存の個人情報保護法や動物病院の内規に沿って自院のルールを定める必要がある。

## 使いどころ・使い分け

| 業務 | 汎用チャットAI(ChatGPT/Claude/Gemini) | 獣医療特化AI | 必ず人(獣医師)が行う理由 |
|---|---|---|---|
| 診察中の会話→カルテ(SOAP)下書き | 不向き(録音・専門用語の構造化が弱い) | 向く(AIスクライブ。詳細は[ペット産業ページ](../part14-industry-cases/pet-care-industry-ai-use-cases.md)) | 誤変換・聞き取りミスは診療記録の正確性に直結するため必ず確認・修正 |
| 投与量計算・薬物相互作用の確認 | **使わない**(数値計算・事実確認は苦手、危険な誤答の実例あり) | 検証済み処方集(Plumb's等)と連携したAI・ツールを使う | 最終的な投与量決定・処方は獣医師の責任 |
| 鑑別診断の壁打ち・見落とし防止 | 補助として使える(思考の幅を広げる目的に限定) | 画像診断AI(X線・超音波の一次スクリーニング) | 確定診断・治療方針の決定は必ず獣医師が行う |
| 文献・エビデンスの検索・要約 | 向く(Perplexity Academic・Consensus等) | 専門データベース(VIN、PubMed等)と併用 | エビデンスレベル・引用元の実在確認は人が行う |
| 紹介状・診断書・検査依頼書の下書き | 向く(定型フォーマットの整形) | 電子カルテ連携型AIなら検査データを自動反映できる | 送付前に内容の正確性を必ず確認 |
| 飼い主への説明準備(想定問答・言い換え) | 向く(専門用語のかみ砕き) | - | 終末期・重篤な病状説明はAI任せにせず自分の言葉で伝える |

## 実務での使い方

### 業務フェーズ別の活用マップ

1. **問診・診察中**: AIスクライブが会話を録音し、SOAP形式のカルテ下書きを自動生成
   (ツール一覧・国内外の比較は[ペット産業ページ](../part14-industry-cases/pet-care-industry-ai-use-cases.md)参照)。
2. **検査・画像診断**: X線・超音波画像をAIが一次スクリーニングし、骨折・腫瘍・異物などの
   所見候補を提示。感度・特異度にはばらつきがあるため、見落とし防止の補助と割り切る。
3. **治療方針の検討**: 鑑別診断の候補出し(壁打ち)や、最新の治療プロトコルの
   エビデンス確認に文献検索AIを使う。
4. **投与量・薬物相互作用の確認**: 検証済みの処方集データベースと連携したAI・計算ツールを使い、
   汎用チャットAIの暗算的な回答はそのまま処方に反映しない。
5. **カルテ確定・紹介状/診断書作成**: スクライブが出したSOAP下書きを人が確認・修正し、
   専門医への紹介状や飼い主への診断書は汎用チャットAIで文面を整える。
6. **飼い主への説明**: 診断結果・治療方針をかみ砕いて説明するための想定問答を事前に準備する。

### プロンプト例1: 鑑別診断のブレインストーミング(壁打ち用)

```
以下の症例情報から考えられる鑑別診断を、可能性の高い順に5つ挙げてください。
- あくまで検討の壁打ち相手として使うので、断定的な診断は避け
  「除外すべき理由」「追加で確認すべき検査」もセットで示してください
- 出典が明確でない治療プロトコルは提案しないでください

## 症例情報
[動物種・年齢・性別・体重・主訴・現病歴・身体検査所見・これまでの検査結果を記載]
```

出力はあくまで思考を広げるための補助であり、確定診断・治療方針の決定は獣医師が行う。

### プロンプト例2: 専門医への紹介状の下書き作成

```
以下の診療情報をもとに、専門医への紹介状の下書きを作成してください。
- 「紹介目的」「現病歴」「これまでの検査結果と治療内容」「紹介先への質問事項」の
  4項目で構成する
- 敬語・医療文書としての形式を守り、簡潔にまとめる

## 診療情報
[動物種・年齢・主訴・経過・検査結果・実施した治療・紹介したい理由を記載]
```

固有名詞・数値(検査値・投薬量)は下書き後に必ず原本のカルテと突き合わせて確認する。

### プロンプト例3: 飼い主への説明の想定問答づくり

```
以下の診断結果を、獣医学の知識がない飼い主に説明する際の想定問答(Q&A)を
作成してください。
- 専門用語は使う場合、初出で必ずかみ砕いた言い換えを付ける
- 「飼い主が不安に思いそうな質問」を5つ想定し、簡潔な回答例を付ける
- 断定的な予後の言い切りは避け、口頭で補足する前提の文面にする

## 診断結果・治療方針
[診断名・重症度・治療の選択肢・費用感の概要を記載]
```

終末期医療や安楽死に関わる説明では、この想定問答はあくまで準備用のメモにとどめ、
実際の会話では自分の言葉と間合いで伝える。

### 文献・エビデンス検索の使い方

Perplexity(Academicモード)やConsensusのような文献検索AIは、
「◯◯という治療法に有効性のエビデンスはあるか」といったYes/No型の臨床疑問や、
最新の症例報告・治療プロトコルの要約収集に向く
([Perplexityの基本](../part08-specialized-ai-tools/perplexity-basics.md))。
ただし、獣医学領域は人医学に比べて査読論文の絶対数が少なく、
存在しない論文や人医学の知見をそのまま獣医療に当てはめた回答が混じることがあるため、
提示された論文タイトル・DOIを実際にPubMedやVINで開いて実在を確認してから
臨床判断の参考にする。

### ツール横断の対応表

| 用途 | 主なツール例 |
|---|---|
| カルテ自動作成(AIスクライブ)・画像診断AI | [ペット産業ページ](../part14-industry-cases/pet-care-industry-ai-use-cases.md)の一覧を参照(VetRec・Talkatoo・ScribeNote・国内のAI動物病院SOAP・Vetty・VetAsis、SignalPET・Vetology等) |
| 投与量計算・薬物相互作用チェック | VetGeni(739種の薬剤・6万件超のQ&Aを収録したAI検索型の薬剤データベース、Wiley社ライセンスの薬理情報を利用)、Plumb's Veterinary Drug Handbook(検証済み処方集) |
| 文献・エビデンス検索 | Perplexity(Academicモード)、Consensus、PubMed、VIN(Veterinary Information Network) |
| 紹介状・診断書・飼い主向け説明文の下書き | ChatGPT、Claude、Gemini等の汎用チャットAI |

投与量計算に特化したツールの中には、AI(大規模言語モデル)に数値を生成させるのではなく、
検証済みの処方集データから計算式で投与量を算出し、確認できない場合は
警告を出す設計のものもある(VetDoze等)。「AIが答えを生成する」方式と
「AIが検索・整理し、数値は検証済みデータベースの計算式から出す」方式の違いを
意識してツールを選ぶとよい([VetSoftwareHub](https://www.vetsoftwarehub.com/article/veterinary-ai-scribe-pricing-comparison-2026))。

## 注意点・よくある誤解

- **汎用チャットAIに投与量計算をさせない**: 大規模言語モデルは「それらしい文章」を
  生成する仕組みであり、検算や事実確認をしているわけではない。ある獣医師が
  ChatGPTに投与量を尋ねたところ、一見もっともらしいが実際には危険な誤った数値が
  返ってきたという実例が報告されている([Dr. Erik Johnson](https://drjohnson.com/chatgpt-a-i-and-dosing/))。
  投与量・薬物相互作用は必ず検証済みの処方集・専用データベースで確認する。
- **画像診断AI・鑑別診断の壁打ちは「補助」**: AIが提示した所見・候補に引きずられて
  思考停止しないこと。画像診断AIの精度限界は
  [ペット産業ページ](../part14-industry-cases/pet-care-industry-ai-use-cases.md)の
  該当節を参照。
- **AIスクライブの誤変換はそのままカルテに残さない**: 聞き取りミス・専門用語の誤変換が
  診療記録に残ると、後日の医療過誤対応や保険請求で不利になりうる。確定前に必ず
  獣医師が内容を確認・修正する。
- **文献検索AIのハルシネーション**: 存在しない論文や、人医学の知見をそのまま
  獣医療に当てはめた回答が混じることがある。引用元の実在確認を怠らない。
- **飼い主・診療情報の入力管理**: カルテ音声や既往歴には飼い主の個人情報が含まれる。
  法人向け・学習利用オフの契約プランを選び、汎用チャットAIの無料版に
  生の診療情報を貼り付けない([生成AI利用における情報漏洩対策](../part04-risk-security/information-leakage-prevention.md))。
- **業界固有のガイドラインは未整備**: 2026年8月時点で日本獣医師会による
  生成AI利用の公式指針は確認できていない。既存の個人情報保護法や自院の内規を
  ベースに、入力してよい情報の範囲・AIの出力を確定前に必ず人が確認するルールを
  自院で定めておく。

## 最初の一歩

次に迷いのある症例に当たったとき、確定診断ではなく「鑑別診断のブレインストーミング」
限定でChatGPTかClaudeに壁打ちしてみて、自分の見立てと突き合わせてみる。
投与量の確認には汎用チャットAIではなく、検証済みの処方集(Plumb's等)を使う習慣を崩さない。
