# 医療事務・クリニック受付職における生成AI活用事例

## これは何か

医療事務・クリニック受付は、目の前の患者対応と、鳴り続ける電話、山積みのレセプト(診療報酬明細書)作成、問診票の入力を同時にこなす「マルチタスクが常態化した職種」である。人手不足が慢性化する一方、レセプトの記載ミスは医療機関の収益に直結し、患者対応の質は医療機関の評判を左右するため、負荷を減らしつつミスも減らす両立が求められる。本ページは、受付・電話対応、レセプト作成支援、問診票のデジタル化、患者向け案内文書の多言語対応、保険資格確認という医療事務特有の5業務に絞り、生成AI・AIをどう組み込むかを整理する。なお、医師・看護師本人の診療記録作成(アンビエントAIスクライブ等)や、病院・薬局という業種側の事例は扱わない(末尾「関連トピック」を参照)。

## 仕組み・背景

医療事務の現場で使われているAIは、大きく3つの技術に分けられる。

1. **音声認識+生成AI**: 電話の会話をテキスト化し、生成AIが応答文や要約を作る仕組み。IVRy(アイブリー)のようなAI電話サービスや、Ubie生成AIの問診サマリー生成がこれにあたる。
2. **ルールベース+機械学習のレセプトチェック**: 過去の査定・返戻データを学習し、レセプトの記載内容が診療報酬のルールに合っているかを点検する仕組み。「AIレセチェッカー」「チェックアイDX」などがこの方式で、社会保険診療報酬支払基金(レセプト審査を行う公的機関)自体もAIによる振分機能を審査実務に導入している。生成AIによる文章作成というより、異常検知・分類に近い技術である点に注意。
3. **オンライン資格確認(マイナ保険証)**: 生成AIではなく、マイナンバーカードの健康保険証利用によって保険資格をその場でオンライン照会する仕組み。AIではないが、医療事務の資格確認業務を大きく変えた基盤として押さえておく必要がある。

2026年6月施行予定の令和8年度診療報酬改定では、医師事務作業補助者が生成AIを活用した文書作成補助体制を整備している場合、1人を最大1.3人相当として配置人数にカウントできる評価が新設された。医療事務の生成AI活用が診療報酬上の加算要件にまで組み込まれ始めている点は、2026年時点の大きな変化である。

## 使いどころ・使い分け

| 業務フェーズ | 何をするか | 全自動化 vs 人間介在の目安 |
|---|---|---|
| 予約受付・電話対応 | 診療時間・空き状況・休診案内などをAI電話が自動応答、通話内容を要約してLINE等に通知 | 定型の問い合わせ(診療時間、予約可否、持ち物)は自動化しやすい。症状の緊急度判断や複雑な予約変更は有人対応に引き継ぐ |
| 問診票のデジタル化・要約 | タブレット・スマホで患者が回答した問診内容をAIが要約し、電子カルテに転記しやすい形に整形 | 要約・整形は自動化。医学的な緊急度判定はAIの参考情報にとどめ、最終判断は医師が行う |
| レセプト作成支援 | 診療内容からレセプトの下書きを作成し、査定・返戻されやすい記載をAIが事前に検知 | 下書き生成・点検の一次スクリーニングは自動化してよいが、請求確定前の人間による最終確認は必須(査定・返戻は医療機関の収益に直結するため) |
| 患者向け案内文書・多言語対応 | 診療案内・同意書・注意事項などを「やさしい日本語」や外国語に自動変換 | 下書きは自動化、医療的な正確性が問われる文書(同意書・服薬指導)は必ず有資格者が確認してから配布する |
| 保険資格確認 | オンライン資格確認システムでマイナ保険証・資格情報をその場で照会 | AIというより公的インフラの活用。手入力ミス・失効保険証の見落としを防ぐ運用の徹底が主眼 |

判断の軸は、カスタマーサポート職と同様「間違えたときに『言い直せば済む』か、『請求ミス・医療事故につながる』か」。レセプトと問診票の医学的判断はAIに丸投げしないという原則を徹底する。

## 実務での使い方

### 1. 予約受付・電話対応の自動化

IVRy(アイブリー)のようなAI電話サービスは、診療時間・予約状況・休診案内などの定型問い合わせに自動応答し、通話内容をテキスト要約してLINEやチャットに通知する。月額2,980円〜(1日100円からの従量プランもあり)、初期費用0円で最短1日から導入可能なプランがあり、実際にクリニックでは月1,200件の電話のうち400件(約33時間相当)を自動化できた事例や、歯科医院で応答漏れの解消と折返し対応の迅速化が報告されている。

**コピペで使える電話自動応答シナリオ設計プロンプト例**(IVRy等の応答シナリオ・FAQ設定に利用)

```
あなたは〇〇クリニックの電話受付AIです。以下のルールで応答してください。

## 応答ルール
- 診療時間・休診日・予約可否・持ち物(保険証等)についてのみ即答する
- 症状の相談・緊急性の判断・薬の相談は絶対に行わず、
  「その内容は受付にお繋ぎしますので少々お待ちください」と案内する
- 予約の変更・キャンセルは受付日時と患者名を復唱確認したうえで
  スタッフへの引き継ぎメモに残す
- 語尾は丁寧語で統一する

## 診療時間・休診日情報
{{診療時間・休診日をここに記載}}

## 患者からの問い合わせ
{{音声認識テキストがここに入る}}
```

### 2. 問診票のデジタル化・要約

Ubie生成AIは2026年1月時点で大学病院10施設以上を含む全国100病院に導入され、月間利用数10万セッションを突破している。タブレット・スマホで患者が回答した問診内容を、電子カルテに転記しやすい形式に要約する機能が中心的な用途で、クリニック規模ではAI問診(月額目安3万円前後〜)と電子カルテAIの組み合わせが費用対効果の面で選ばれやすい。

### 3. レセプト作成支援・査定/返戻の事前検知

レセプト(診療報酬明細書)は記載ミスがそのまま査定(減点)・返戻(差し戻し)による減収に直結する専門性の高い業務であり、専用のAIレセプトチェックツールが普及している。

| ツール | 提供元 | 主な機能 |
|---|---|---|
| Reze | Reze | 生成AIでレセプト業務を自動化。レセプト・審査結果を一元管理し返戻・査定対応漏れを防止 |
| AIレセチェッカー | Medical AI LAB / 日本データー | 過去の査定データを学習し、点検要否を判定。査定分析ツールで次回以降の対策も支援 |
| チェックアイDX | ニチイ学館 | クラウド型レセプトチェックソフト。点検結果をAIが学習し、点検ロジックが医療機関ごとに成長する |

社会保険診療報酬支払基金(レセプトを審査する公的機関)自体も、AIによる振分機能を実装し、コンピュータチェックで完結するレセプトと審査委員の目視が必要なレセプトを機械学習で仕分けている。これは医療機関側のレセプトチェックAIと同じ発想が審査側にも実装されている好例で、「AIが通しやすい記載の型」を事前に押さえておくと差し戻しを減らせる。

**コピペで使えるレセプト記載チェック依頼プロンプト例**(生成AIチャットで下書き点検に使う場合。実際のレセプト提出には専用ソフトの併用が前提)

```
以下は診療内容のメモです。レセプト記載でよく問題になる観点
(病名と処方・処置の整合性、算定漏れの可能性がある加算、
 保険適用外の可能性がある項目)について、確認すべき点を
箇条書きで指摘してください。実際の点数計算や最終判断はしないこと。

## 診療内容メモ
{{診療内容・処方・処置の記録}}
```

### 4. 患者向け案内文書・多言語対応

厚生労働省は外国人患者向けの多言語説明資料(問診票・同意書・施設案内など)を13言語で公開しており、まずはこれをベースに使うのが最も確実な出発点になる。それに加えて、DeepLのような医療分野対応のAI翻訳や、専門用語をかみ砕いた「やさしい日本語」への自動変換ツール(やさにちリライト+等)が、案内文書の多言語化・平易化の下書き作成に使われている。

**コピペで使えるやさしい日本語変換プロンプト例**

```
以下の医療案内文を、日本語を母語としない方や小学校高学年でも
理解できる「やさしい日本語」に書き換えてください。
- 専門用語は言い換えるか、初出時に一言説明を加える
- 一文を短く区切る(目安30〜40字以内)
- 二重否定・敬語の多用を避ける
- 内容や指示(服薬回数・受診タイミングなど)は変えない

## 変換対象の案内文
{{案内文の原文}}
```

多言語版・やさしい日本語版とも、最終配布前に医療従事者による内容確認を必ず挟む(専門用語の意味が翻訳過程で変わるリスクがあるため)。

### 5. 保険資格確認業務の効率化

オンライン資格確認(マイナ保険証によるオンライン照会)を導入すると、保険資格をその場で確認できるため、資格過誤によるレセプト返戻の削減、期限切れ保険証の見落とし防止、手入力の手間削減につながる。生成AI自体の機能ではないが、医療事務のフロント業務を変えた基盤インフラとして、レセプトAI・問診AIと合わせて導入状況を点検しておきたい。

### ツール横断の対応付け

| 業務 | 代表ツール | 主な機能 |
|---|---|---|
| 電話自動応答 | IVRy(アイブリー) | 予約・診療時間案内の自動応答、通話要約通知 |
| 問診AI | Ubie生成AI | 問診回答の要約・カルテ転記用整形 |
| レセプトAI | Reze / AIレセチェッカー / チェックアイDX | レセプト下書き作成・査定/返戻の事前検知 |
| 多言語・やさしい日本語 | 厚労省多言語説明資料 / DeepL / やさにちリライト+ | 案内文書の翻訳・平易化 |
| 保険資格確認 | オンライン資格確認システム(マイナ保険証) | 保険資格のリアルタイム照会 |

## 注意点・よくある誤解

- **患者の個人情報を無料の汎用チャットAIに入力しない**: 患者名・生年月日・住所・保険証番号・カルテ番号など個人が特定できる情報は入力しないのが大原則。相談する場合は「70代女性、高血圧で通院中」のように匿名化した表現に置き換える運用を院内ルールとして徹底する
- **レセプトの最終判断はAIに任せない**: レセプトチェックAIは査定・返戻されやすい記載を検知する「一次スクリーニング」であり、点数計算や提出の最終判断は必ず有資格の医療事務担当者が行う。ハルシネーション(もっともらしい誤情報の生成)により誤った算定根拠を提示するリスクもゼロではない
- **問診AI・電話AIは医学的判断をしない設計にする**: 症状の緊急度判定や診療内容の相談を自動応答に任せると、対応の遅れが患者の不利益に直結する。緊急性が疑われる問い合わせは必ず人間へエスカレーションする設計にする
- **多言語・やさしい日本語変換は「下書き」までと割り切る**: 専門用語の意味が翻訳・平易化の過程で変わることがあるため、同意書・服薬指導など医療的正確性が求められる文書は配布前に有資格者が確認する
- **診療報酬改定の加算要件を確認する**: 令和8年度診療報酬改定で医師事務作業補助体制加算の配置人数換算に生成AI活用が組み込まれた。自院が対象要件を満たしているかは、改定内容を都度確認する

## 最初の一歩

厚生労働省の多言語説明資料ページから自院で使う言語の問診票・案内文を1枚ダウンロードし、実際に外国人患者・高齢患者向けの案内に使えそうか確認してみる。
