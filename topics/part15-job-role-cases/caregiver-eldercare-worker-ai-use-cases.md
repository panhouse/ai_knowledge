# 介護職員における生成AI活用事例

## これは何か

本ページは、特別養護老人ホーム・介護付き有料老人ホーム・訪問介護・デイサービスなどで働く**介護職員(ケアワーカー・介護福祉士)個人**が、自分の日々の業務(記録作成・申し送り・家族対応・夜勤シフト・新人指導など)に生成AIをどう使うかを扱う。

[介護業界における生成AI活用事例](../part14-industry-cases/eldercare-ai-use-cases.md)が、事業者・自治体・大手プラットフォーマーが提供するツール(CareWiz、SOIN、むすぼなAI等)を**事業所・業界の導入事例**として整理しているのに対し、本ページは同じ道具立てを**現場の介護職員一人ひとりの1日の業務フロー**に沿って並べ直し、「どの場面で・どう話しかければ・何が返ってくるか」という手元の使い方に絞る。ツール名・企業名の詳細な導入事例は上記の業種別ページを参照されたい。本ページはその「材料」を、記録→申し送り→家族連絡→シフト→見守り→新人育成という現場の時系列で束ね直したものである。

## 仕組み・背景

介護職員向けの生成AI活用は、大きく3系統に分かれる。

1. **介護記録ソフトに組み込まれた音声入力AI**: 利用者名と介助内容を話しかけるだけでAIが介護記録の文言に自動整形する仕組み。株式会社エクサウィザーズの「CareWiz ハナスト」(旧称「CareWiz 話すと記録」)は、株式会社ケアコネクトジャパンの介護記録ソフト「CAREKARTE(ケアカルテ)」専用の音声入力アプリとして提供され、介助で両手がふさがっている場面でもスマートフォンに話しかけるだけで記録化できる。介護保険大手のカイポケ(株式会社エス・エム・エス)も、2026年3月に株式会社ウェルモと戦略的パートナーシップを締結し、ウェルモの音声テキスト化AI「ミルモレコーダー」(2024年11月26日正式リリース、月額3,500円〜で40時間利用可能な料金プランを提供)をカイポケ利用事業所へ提供開始した。エス・エム・エスの発表では、AI要約と業務自動化(RPA)の連携により記録業務を最大95%削減した事例も紹介されている。
2. **汎用チャットAI(ChatGPT・Claude・Gemini・Copilot等)を職員が自分で使う**: 専用ツールを事業所が導入していなくても、職員個人が音声入力の書き起こしメモをチャットAIに貼り付けて記録・報告文の下書きを作らせる使い方。導入コストがほぼゼロで今日から試せる反面、入力した内容が要配慮個人情報(病歴・要介護度など)を含む場合は情報漏洩リスクを職員自身が判断しなければならない点に注意が必要。
3. **見守りセンサー・カメラ×AIによる異常検知**: 居室のカメラやセンサーの映像・データをAIが解析し、転倒・離床・徘徊の予兆を検知して職員へ通知する仕組み。名古屋市のOpt Fitが提供する見守りカメラ「KaigoDX」は、AIが映像を解析して離床・転倒・離設(施設外への抜け出し)を検知しインカムやパソコンに通知するほか、検知前後の映像を自動でリスト化して事故発生時の記録・原因究明に使える構成をとっている。

背景には、厚生労働省が推計する介護職員の深刻な人手不足(2040年度に約57万人不足)と、記録業務が職員の職務時間の一定割合を占め残業要因になっているという構造的な課題がある。厚生労働省は2025年4月の「2040年に向けたサービス提供体制等のあり方に関する中間とりまとめ」で生成AIによるケアプラン原案作成の効率化を明記しており、令和8年度は「介護テクノロジー導入支援事業」として見守りセンサー・インカム・介護記録ソフトを組み合わせた「パッケージ型」導入への補助率を最大4/5まで引き上げるなど、現場への普及を後押ししている。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

介護職員の1日〜1か月の業務フローに沿って、AIがどこに入るかを整理する。

| 業務フェーズ | 頻度 | AIの使いどころ | 主な担当 |
|---|---|---|---|
| ケア記録・介護記録の作成 | 訪問・介助のたびに毎日 | 音声入力の書き起こしを介護記録の文言に自動整形 | 介護職員・訪問介護員 |
| 申し送り事項の要約 | 勤務交代のたびに毎日 | 1日分の記録から「次の勤務者が読むべき要点」だけを抽出・要約 | 介護職員・看護職員 |
| 家族向け報告文の下書き | 週次〜月次 | 専門用語(バイタル、ADL等)を家族向けの言葉に言い換えて文面化 | 介護職員・生活相談員 |
| ケアプラン原案の下書き | 半年ごと更新+随時 | アセスメント内容からケアプラン(第1表・第2表)の叩き台を作成 ※最終作成・確定はケアマネジャー | ケアマネジャー(介護支援専門員) |
| 夜勤・シフト作成 | 月1回+随時調整 | 資格・希望休・二人夜勤等の制約を踏まえた勤務表叩き台の作成、加算算定様式の出力 | シフト作成担当・サービス提供責任者 |
| 見守り・転倒予兆の検知と記録連携 | 常時(夜間中心) | センサー・カメラ映像をAIが解析し転倒・離床・徘徊の予兆を通知、検知映像を記録として自動保存 | 夜勤職員・介護職員全員 |
| 新人職員のOJT・研修資料作成 | 随時(入職時) | 既存マニュアルをAIに読み込ませ、ナレーション付き研修動画・理解度テストを自動生成 | 教育担当・主任・施設長 |

**読み方のコツ**: 「記録」「申し送り」「家族向け報告」は自然言語の要約・言い換えが中心のため、汎用チャットAI(LLM)がそのまま活躍しやすい。一方「見守り・転倒予兆検知」はセンサー・カメラ映像を解析する専用AI、「シフト作成」は制約条件を解く最適化AIが中心であり、いずれも文章を生成する生成AIとは仕組みが異なる。「介護のAI」を検討するときは、自分がテキストの下書きを作りたいのか、異常を検知したいのか、条件を満たす組み合わせを探したいのかを先に切り分けると、ツール選びで迷いにくい。

### 使う/使わない の判断基準

- **使う**: 記録・申し送り・家族向け文面など「事実を分かりやすい言葉に整える」作業。AIが下書きを作り、職員が事実確認して確定するという役割分担がはっきりしている業務
- **使わない/慎重にする**: ケアプランの最終確定、医療的判断を伴う記述(病名の推測など)、利用者の要配慮個人情報を含む内容を学習利用ありの無料AIサービスにそのまま入力すること。いずれも「AIは下書き、最終判断は人」という原則を崩さない範囲で使う

## 実務での使い方

### 使えるツール・構成

| 業務 | 専用ツールの例 | 汎用生成AIでの代用 |
|---|---|---|
| 音声入力→記録作成 | CareWiz ハナスト(エクサウィザーズ、CAREKARTE専用)、ミルモレコーダー(ウェルモ、カイポケ連携) | スマホの音声入力機能で書き起こし→ChatGPT/Claude/Geminiに整形を依頼 |
| 申し送り要約 | 上記記録ソフトの要約機能 | 1日分の記録メモをチャットAIに貼り付け、下記プロンプト例で要約 |
| 家族向け報告書 | むすぼなAI(やさしい手)、milmo AIプラットフォーム(ウェルモ) | 汎用チャットAIに記録メモを渡し、家族向け文面への言い換えを依頼 |
| ケアプラン原案作成 | SOIN(そわん)、AIケアプランナー(チャーム・ケア×NTT DXパートナー) ※詳細は[介護業界における生成AI活用事例](../part14-industry-cases/eldercare-ai-use-cases.md)参照 | ChatGPT/Claude/Geminiにアセスメント内容を渡し、下記プロンプト例で叩き台作成 |
| シフト作成 | miramos(コニカミノルタQOLソリューションズ) | 制約条件をすべて指示に含めれば叩き台は作れるが、加算要件チェックや様式出力は専用ツールに分がある |
| 見守り・転倒予兆検知 | KaigoDX(Opt Fit)、mirAI-EYE(グローリー)等の見守りAIカメラ | 汎用生成AIでは代用不可(専用のセンサー・カメラ+画像解析AIが必要) |
| 新人研修・OJT | 各種研修動画制作サービス | NotebookLM(Google)に既存マニュアルを読み込ませ、ナレーション付き解説音声・動画・確認クイズを自動生成 |

まず専用ツールを持たない事業所・個人でも、汎用チャットAIとスマホの音声入力を組み合わせれば「記録」「申し送り」「家族向け報告」は今日から試せる。専用ツールは介護記録・請求システムとの連携や行政提出様式への自動出力に強みがあるため、汎用AIで効果を体感してから本格導入を検討する順序が現実的である。

### コピペで使える実例1: 申し送り事項の要約

```
あなたは介護施設の夜勤明けの介護職員です。以下は本日1日分のケア記録メモです。
次の勤務者(日勤職員)が読むべき「申し送り事項」を、以下の形式で要約してください。

【条件】
- 「体調・様子の変化」「対応が必要な事項」「家族・関係者からの連絡」の3項目に分ける
- 数値(体温・血圧・食事量など)は原文のまま省略せず転記する
- 憶測や医学的な断定(病名の推測など)は書かない
- 各項目3行以内、合計10行程度に収める

【本日のケア記録メモ】
(ここに音声入力の書き起こしや手元メモを貼り付ける)
```

### コピペで使える実例2: 家族向け「今週の様子のお知らせ」

```
あなたは介護施設の生活相談員です。以下は本日のケア対応記録(音声入力を書き起こしたメモ)です。
これをもとに、ご利用者のご家族向けに送る「今週の様子のお知らせ」の文面を作成してください。

【条件】
- 敬語・丁寧な言葉遣いで、専門用語(バイタル、ADLなど)は避けて言い換える
- 良い変化は具体的なエピソードとして、体調面の変化は事実ベースで簡潔に伝える
- ご家族が不安にならないよう、断定的な医学的判断(病名の推測など)は書かない
- 分量は300字程度

【本日の記録メモ】
(ここに音声入力の書き起こしテキストを貼り付ける)
```

### コピペで使える実例3: ケアプラン第2表の原案叩き台(ケアマネジャー向け)

```
あなたはケアマネジャー(介護支援専門員)の作成補助アシスタントです。
以下はアセスメントで確認した利用者の状態です。
ケアプラン第2表(生活全般の解決すべき課題・目標・サービス内容)の原案を、
「課題」「長期目標」「短期目標」「サービス内容」の4項目に分けて箇条書きで
作成してください。これはあくまで叩き台であり、最終的な内容の確認・修正・
決定はケアマネジャーが行うことを前提としています。

【アセスメント内容】
(ここに利用者の状態・本人と家族の希望などのメモを貼り付ける)
```

### 料金の目安(2026年8月時点)

- 汎用チャットAI(個人利用): ChatGPT・Gemini・Claude等の有料プランは月1,000〜3,000円程度から
- 音声入力AI(専用): ミルモレコーダーは月額3,500円〜(キャンペーン時3,000円〜、40時間利用)、介護ソフト組み込み型は月5,000円〜5万円程度と幅がある
- 見守りAIカメラ: KaigoDXは初期費用0円のレンタルプランも用意されている(具体的な月額は施設規模・カメラ台数により見積もり)

本格導入時は、令和8年度「介護テクノロジー導入支援事業」(見守りセンサー・インカム・介護記録ソフトを組み合わせた「パッケージ型」で最大4/5、単体導入で最大3/4の補助率)の対象になりうるため、事前に自治体窓口やベンダー経由で対象可否を確認するとよい。

## 注意点・よくある誤解

- **要配慮個人情報の外部AIサービスへの入力リスク**: 利用者の病歴・要介護度・障害の有無などは個人情報保護法上の「要配慮個人情報」にあたる。個人情報保護委員会は2023年6月の「生成AIサービスの利用に関する注意喚起等について」で、生成AIに個人情報を入力する場合はもともとの利用目的の範囲内かを確認すること、AIサービス側が入力データを機械学習に使う設定の場合は個人情報の「第三者提供」にあたり本人同意が必要になりうることを注意喚起している。無料の汎用チャットAIに利用者の実名・症状をそのまま貼り付けるのは避け、学習利用オフ設定が確認できるサービスや、施設で契約している法人プランを使う
- **AI要約による記録の抜け漏れ**: 申し送りの要約をAIに任せきりにすると、AIが「重要でない」と判断して省いた情報(実は次の勤務者に必要だった一言)が抜け落ちる恐れがある。AIの要約はあくまで下書きとして扱い、原文の記録メモも必ず残し、要約結果を作成者本人が確認してから共有する運用にする
- **ITリテラシーのばらつきへの配慮**: 介護現場はベテラン職員の比率が高く、新しいツールへの不安から「操作が難しそう」という抵抗感が導入の壁になりやすい。導入時はいきなり全員に使わせるのではなく、若手職員をリーダーとした少人数の推進チームで先行導入し、実際に触れて負担軽減を体感してもらってから全体へ広げると定着しやすい
- **ケアプランはケアマネジャーの最終確認が前提**: AIが作るケアプラン原案はあくまで叩き台であり、居宅サービス計画書の作成・確定はケアマネジャー(介護支援専門員)の責任である点は業種別ページと同様にここでも変わらない
- **音声認識の精度リスク**: 高齢の利用者や方言を含む発話、マスク着用時の聞き取りにくさなどで書き起こし精度が下がる場合がある。バイタル値など重要な数値は必ず目視で確認する運用にする

## 最初の一歩

今日の勤務のケア記録・申し送りメモのうち1件を、上記「コピペで使える実例1」のプロンプトのままChatGPT・Claude・Geminiいずれかに貼り付けて要約させてみる。利用者の実名を伏せた状態(仮名やイニシャルに置き換える)で試すと、社内合意を得やすく最初の一歩として始めやすい。
