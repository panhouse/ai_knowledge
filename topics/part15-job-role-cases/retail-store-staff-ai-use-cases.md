# 店舗・販売スタッフ職における生成AI活用事例

## これは何か

本ページは、スーパー・コンビニ・アパレル・専門店などの**店舗現場で働く「人」**——販売スタッフ、店長、SV(スーパーバイザー、複数店舗を巡回指導する管理職)——の日々の業務に生成AIをどう組み込むかを扱う。[小売・流通・ECにおける生成AI活用事例](../part14-industry-cases/retail-ai-use-cases.md)が「業界としてどんな需要予測・自動発注システムが導入されているか」という**業種目線**の事例集であるのに対し、本ページはシフト作成、発注の下書き、POP・販促物のコピー作成、接客トークのロールプレイ練習、クレーム対応の振り返り、新人教育といった、**店舗スタッフ個人が日常業務でチャットAIをどう使うか**にフォーカスする。[アパレル・ファッション業界における生成AI活用事例](../part14-industry-cases/apparel-fashion-ai-use-cases.md)ともあわせて参照するとよい。

店舗の現場は、本社のオフィスワーカーと違って「PCに向かう時間が短い」「シフト制で研修時間が取りにくい」「アルバイト・パートを含む入れ替わりの多い組織」という制約があり、生成AIの使い方も本社部門とは異なる工夫が必要になる。本ページでは、その制約を踏まえた具体的な活用場面とプロンプト例を整理する。

## 仕組み・背景

店舗スタッフ向けの生成AI活用は、大きく2つの系統に分かれる。

1. **汎用チャットAIをスマホから使う「個人利用」型**: ChatGPT・Gemini・Copilotなどのアプリをスタッフ個人または店長がスマホで開き、POPの文言案出しや接客トークの壁打ち相手として使う。導入コストがほぼゼロで今日から始められる一方、店舗の売上データ・顧客情報とは連携していないため、あくまで「文章の下書き」「壁打ち相手」としての利用にとどまる。
2. **店舗運営システムに組み込まれた「業務システム」型**: シフト管理システムのAI自動作成機能、コンビニ・スーパーの自動発注システム、AIロールプレイ研修ツールなど、特定の業務に特化してPOSデータ・勤怠データ・過去の対応履歴と連携する専用ツール。精度は高いが、導入・契約が必要でスタッフ個人の裁量では選べないことが多い。

発注領域では、AIがPOSデータ(販売時点情報管理データ)・天候・曜日・過去の売れ行きから発注数を推奨する仕組みがすでに大手チェーンで実用段階に入っている。ローソンは2015年からAIを使った「セミオート発注」を導入し、2024年7月には次世代発注システム「AI.CO(AI Customized Order)」を全国店舗に展開、セミオート発注と計画発注を合わせて1日1人当たり2時間の作業時間削減を実現したと報告している。ファミリーマートもAIが発注推奨値を自動算出する仕組みで、発注業務の時間を1週間あたり約6時間削減したとしている。これらは基本的に本部が導入する専用システムであり、個々のスタッフが選ぶものではないが、「発注はAIが叩き台を出し、人間が最終確認・調整する」という役割分担の型は、後述するシフト作成やPOP作成にも共通する考え方として参考になる。

接客・研修領域では、AIアバターを相手に接客・営業トークを練習し、AIが会話内容を自動解析してフィードバックする「AIロープレ」ツールが2025〜2026年にかけて急速に普及した。実際の顧客の前で失敗する前に、時間・場所を問わず何度でも反復練習できる点が、教育担当者の工数削減と新人の早期戦力化の両面で評価されている。

海外の動きとしては、Home Depotが2025年に生成AIによる顧客向け案内「Magic Apron」を開始し、2026年1月にはGoogle Cloudとの提携拡大により、店舗スタッフが商品の場所や専門知識をその場で調べられる機能や、画像を使った案内機能の店舗展開を発表している。人事労務クラウドのWorkdayも2026年春に「Frontline Agent」の提供を予定しており、シフト交代の申請ルーティングや勤務時間の上限チェックをAIエージェントが自動処理し、早期導入企業では管理者のシフト調整にかかる時間を最大9割削減したという結果を公表している。日本では専業のシフト管理SaaSがAIによる自動作成機能を搭載する形で同様の機能を提供している。

## 使いどころ・使い分け

### 業務フェーズ別の活用マップ

店舗スタッフ・店長の1日〜1週間の業務の流れに沿って、どこに生成AIが入るかを整理すると次のようになる。

| 業務フェーズ | 頻度 | AIの使いどころ | 向く担当 |
|---|---|---|---|
| 週次シフト作成 | 週1回 | 希望シフト・法定労働時間・繁閑予測をもとにたたき台を自動作成 | 店長・SV |
| 発注 | 毎日〜週数回 | 過去の売れ行き・天候・イベント情報から発注数の叩き台を提案 | 店長・発注担当 |
| 開店前ミーティング・朝礼原稿 | 毎日 | 前日の売上・注意事項を箇条書きから話し言葉の原稿に整形 | 店長 |
| POP・販促物のコピー作成 | 随時(新商品入荷時・季節催事前) | キャッチコピー・商品説明文の案出し、Canva等と組み合わせたデザイン化 | 販売スタッフ・店長 |
| 接客対応中 | 常時 | (直接使用は難しいが)よくある質問への回答をあらかじめFAQ化しておく | 販売スタッフ |
| 閉店後の振り返り・クレーム対応記録 | クレーム発生時 | 対応内容の要約、詫び状・再発防止メモの下書き作成 | 店長・対応者本人 |
| 新人教育・OJT | 入社時・随時 | 接客ロールプレイ相手、マニュアルのたたき台作成、作業動画からの手順書生成 | 店長・教育担当・新人本人 |
| 月次の店舗ミーティング資料 | 月1回 | 売上データの要点整理、店舗課題の言語化 | 店長・SV |

判断の軸は、「文章・アイデアの下書きで済む業務」か「実データと連携した精緻な数値計算が要る業務」かで分けるとよい。シフトのたたき台作成やPOPのコピー出しは汎用チャットAIで十分に価値が出るが、発注数の精密な予測やシフトの法令チェックの自動化は専用システムの領域になる。

### 使えるツール・構成(汎用チャットAI vs 専用ツール)

| 業務 | 汎用チャットAI(ChatGPT/Gemini/Copilot等)でできる範囲 | 専用ツールが必要な範囲 |
|---|---|---|
| シフト作成 | 手書きの希望シフトをテキスト化して「たたき台」を作らせる、パターンの整理 | 勤怠データとの自動連携、労働基準法(36協定・休憩・勤務間インターバル等)の自動チェックと警告、シフト交代のワークフロー化(例: シフト管理SaaS各種、Workday Frontline Agentのようなエージェント型) |
| 発注 | 前週の売上メモから発注量の考え方を整理する壁打ち | POSデータ・天候・曜日別の需要予測に基づく自動推奨(コンビニ・スーパー各社の自動発注システム) |
| POP・販促物作成 | キャッチコピー・商品説明文の案出し、Canva等のデザインツールと組み合わせた仕上げ | 大量点数を一括生成するAPI連携・テンプレート化(EC出品文の自動生成ツールなど) |
| 接客ロールプレイ練習 | 簡易的な役割演技(AIに「クレーム客」を演じてもらう)は可能 | 音声認識による感情・話速の数値評価、店舗業種別のシナリオライブラリ(AIロープレ専業サービス) |
| クレーム対応の振り返り | 対応内容の要約、詫び状・再発防止メモの下書き | 複数店舗のクレームを横断集計してパターン抽出・傾向分析 |
| 新人教育・マニュアル作成 | 手順のテキスト化、Q&A形式のミニテストの作成 | 作業動画からの自動マニュアル生成、進捗管理・習熟度トラッキング |

小規模店舗・個人商店であれば、まずは無料〜低価格帯の汎用チャットAI(ChatGPTの無料版・Gemini等)で「シフトのたたき台」「POPのコピー」「クレーム対応の下書き」を試すだけでも十分に工数削減効果が出る。複数店舗を抱えるチェーンでSVが横断管理する場合は、シフト・発注・研修それぞれの専用システムへの投資対効果を個別に検討するのが現実的な順番になる。

## 実務での使い方

### 1. シフト作成のたたき台をAIに作らせる

店長が紙やLINEで集めたスタッフの希望シフトを、チャットAIにテキストで貼り付けて初期案を作らせる方法。実際の確定・法令チェックは店長が必ず目視で行うことが前提になる。

**コピペで使えるシフト作成たたき台プロンプト例**

```
あなたは小売店舗のシフト作成を手伝うアシスタントです。
以下の情報をもとに、来週(月〜日)のシフト表のたたき台を
時間帯別・スタッフ名で表形式で作成してください。

## 店舗の営業時間
10:00〜21:00(コアタイムは12:00〜19:00に2名以上配置)

## 必要人数の目安
平日: 各時間帯2名以上／土日祝: 各時間帯3名以上

## スタッフと希望・制約
- Aさん(社員): 月〜金フル出勤可、土日休み希望
- Bさん(学生アルバイト): 週3日・1日5時間まで、22時以降不可
- Cさん(主婦パート): 平日10:00〜15:00のみ可
- Dさん(高校生アルバイト): 22時以降・週28時間超は不可、テスト期間(来週水木)は休み希望

## 出力時の注意
- 学生・高校生アルバイトの法定労働時間の上限に抵触しないよう組む
- 各シフトの間に十分な休息時間を確保する
- 判断に迷う配置があれば「要確認」として理由とともに明記する
- あくまでたたき台であり、最終確認は店長が行う前提で出力する
```

### 2. 発注の考え方を整理する壁打ち

自動発注システムを持たない中小店舗では、チャットAIに前週の実績メモを読み込ませ、発注量を考える上での論点を洗い出させる使い方が現実的。数値の断定はさせず、判断材料の整理にとどめるのがコツ。

```
以下は先週の日別売上メモです。今週の発注量を考えるうえで
注意すべき点(欠品リスク・廃棄リスクが高そうな商品、
イベント・天候による変動要因)を箇条書きで指摘してください。
発注数そのものの断定は避け、「増やす方向で検討」
「様子見でよい」という程度の目安にとどめてください。

## 先週の売上メモ
{{商品別・日別の売上実績や気づいたことを貼り付け}}

## 今週の予定・注意事項
{{近隣イベント、天候予報、催事の有無など}}
```

### 3. POP・販促物のコピー作成

新商品の入荷や季節催事の際、商品の特徴やターゲット層をチャットAIに伝えるだけで複数のキャッチコピー案を出させ、採用した案をCanvaなどのデザインツールに流し込んで仕上げる二段構えが定番の型になっている。

```
以下の商品のPOP用キャッチコピーを5パターン考えてください。
条件は以下の通りです。

## 商品情報
商品名: {{商品名}}
特徴: {{素材・機能・味などの特徴}}
価格: {{価格}}
ターゲット: {{例: 30代女性、子育て世帯 など}}

## コピーの条件
- 1つにつき15文字以内で、店頭で3秒で読める長さにする
- 誇大広告・断定的な効能表現(「必ず」「絶対」等)は避ける
- ポップな口語調のもの、価格訴求型のもの、シーン訴求型のものを
  それぞれ最低1案ずつ含める
```

### 4. クレーム対応の振り返りと再発防止メモ

クレーム対応の直後、対応者本人か店長が経緯をチャットAIに要約させ、詫び状の下書きと社内共有用の再発防止メモを同時に作らせる方法。個人情報の取り扱いには細心の注意が必要(後述)。

```
以下は店舗でのクレーム対応の経緯メモです。
これをもとに、
1. 社内共有用の対応記録(いつ・誰が・何が起き・どう対応したか)
2. お客様宛のお詫び文の下書き(丁寧語・断定的な補償額は書かない)
3. 同じことを繰り返さないための店舗内での改善アクション案
の3点を作成してください。顧客の氏名・連絡先など個人が
特定できる情報は、記録用の出力からは伏せ字([氏名]等)にしてください。

## クレーム対応の経緯メモ
{{対応者が書いた経緯メモ}}
```

### 5. 新人教育・接客ロールプレイ練習

新人がAIを「お客様役」に見立てて接客トークを練習し、フィードバックをもらう使い方。音声入力に対応したチャットAIアプリであれば、実際に声に出して練習できる。より本格的にやりたい場合は、SAPIロープレ(旧カルティロープレ)やAmiVoice RolePlayのような、AIアバターとの対話や音声解析(発話時間・感情変化などの数値化)に対応した専業サービスの導入を検討する。

```
あなたは少し気難しいお客様役を演じてください。
私(新人販売スタッフ)が接客トークを話しかけるので、
お客様として自然に反応し、時々厳しめの質問(値引き交渉、
他店との比較、クレームめいた発言)も交えてください。
一通りのやり取りが終わったら、良かった点と改善点を
「敬語」「傾聴」「提案の具体性」の3観点でフィードバックしてください。

## 想定シーン
{{例: アパレル店でのコーディネート提案、家電量販店での価格交渉 など}}

それでは、私から接客を始めます。
「いらっしゃいませ。本日はどのようなものをお探しですか。」
```

### 6. マニュアル・OJT資料のたたき台作成

ベテランスタッフの作業手順を口頭で説明したものやメモをチャットAIに渡し、新人向けの手順書・チェックリストの形に整形させる。作業を撮影した動画をアップロードできるツールであれば、動画から手順書のたたき台を自動生成する使い方も広がっている。ChatGPT・Geminiともに画像・簡単な動画の読み取りに対応しており、レジ操作や品出しの手順を写真付きで整理する用途に使える。

## 注意点・よくある誤解

- **顧客の個人情報をそのままAIに貼り付けない**: クレーム対応記録や接客メモには、氏名・電話番号・購入履歴など個人を特定できる情報が含まれやすい。無料版の汎用チャットAIに生の情報を貼り付けると、入力内容が学習に使われる設定のままになっている場合があり、社外への情報流出リスクになる。伏せ字化してから入力する、法人契約のエンタープライズ版(学習に使われない設定のもの)を使うなど、[情報漏洩・データ管理](../part04-risk-security/)の章の考え方に沿った運用にする
- **シフトのたたき台は必ず人間が法令チェックする**: AIが作成したシフト案は、労働基準法上の休憩時間・勤務間インターバル・年少者(高校生アルバイト等)の労働時間上限などを見落とすことがある。「AIのたたき台→店長が労務ルールの観点で最終確認」という二段構えを崩さない。専用のシフト管理システムは法令チェック機能を搭載しているものが多いが、汎用チャットAIで作らせた案にはその保証がない点を混同しないこと
- **店頭に出す文言はAIの出力をそのまま貼らない**: POPや店内アナウンス文は、誇大広告・景品表示法(不当な表示を規制する法律)に触れる表現をAIが提案してしまうことがある。「絶対」「必ず治る」といった断定的・効能訴求的な表現がないか、価格や数量の表記に誤りがないか、出す前に必ず人の目で確認する
- **接客ロールプレイの「模範解答」を鵜呑みにしない**: AIが提示する接客トークは一般論としては整っているが、自社の商品知識・接客方針(例: 特定の言い回しを禁止しているブランドなど)を反映していないことが多い。ロールプレイの練習台としては有効でも、最終的な「正解」は店舗のOJT担当者が確認・補足する
- **アルバイト・パートの多い職場ではAI利用ルールの周知が漏れやすい**: 本社主導でAI利用ガイドラインを整備しても、シフト制で研修に参加できないアルバイトには伝わっていないことが多い。朝礼・掲示・チャットツールなど複数の経路で「何を貼っていいか・いけないか」を周知する
- **「効率化」だけで終わらせない**: シフト作成や発注のたたき台作成でスタッフの時間が浮いても、その時間を接客の質の向上に回す運用まで設計してはじめて投資対効果が出る。時間削減の数字だけを追うと、単に人員を減らす方向にしか使われず現場の疲弊を招くことがある

## 最初の一歩

来週分の希望シフト表(手書き・LINEのメモで構わない)を、上記のシフト作成たたき台プロンプトにそのまま貼り付けて、AIが出す案が実際の店舗ルールとどこまで合うか、どこを店長が手直しする必要があるかを一度試してみる。
