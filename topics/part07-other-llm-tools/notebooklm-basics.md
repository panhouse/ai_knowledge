# NotebookLMの使い方

## これは何か

NotebookLMは、アップロードした資料(PDF・Googleドキュメント・音声・URLなど)**だけ**を根拠にAIが回答してくれる、Googleのリサーチ特化ツール。通常のChatGPTやGeminiは学習データ全般や外部知識を使って答えるため、社内規程や特定の会議資料について聞いても一般論が混ざったり、根拠不明の回答(ハルシネーション、AIがもっともらしい嘘をつくこと)が返ってきたりする。NotebookLMは回答の範囲を「ユーザーが渡したソースの中」に限定し、さらに回答の各文に出典箇所へのリンクを付けるため、「その情報がどの資料の何ページ・何行目に書いてあるか」をその場で検証できる。大量の資料を読み込んで正確に質問応答したい業務に向いたツールである。

## 仕組み・背景

NotebookLMは、RAG(Retrieval Augmented Generation、検索拡張生成)という仕組みをベースにしている。ユーザーが答えを聞くと、AIはまず自分の記憶ではなく、渡された資料の中から関連する箇所を検索し、その部分だけを根拠に回答を組み立てる。関連する記述が資料内に見つからない場合は「資料には記載がありません」といった趣旨の回答をするのが基本動作で、これが通常の生成AIより事実に忠実(グラウンディングされている、と表現される)な理由になっている。実際、第三者の検証記事でも、同じ質問に対するハルシネーション率はGeminiやChatGPTの単体利用より低いという報告がある(ただし「起きない」わけではなく、あくまで低減される、という程度に理解しておくとよい)。

裏側のモデルはGoogleのGeminiで、Googleアカウントがあれば無料で使い始められる。個人向けには無料版のほか、Google AI Plus / Pro / Ultraの各プランに「NotebookLM Plus」相当の上位機能がセットで付いてくる。企業向けには、Google Cloud IAMによるアクセス制御やVPC Service Controls、顧客管理の暗号化(Cloud KMS)に対応した「NotebookLM Enterprise」も用意されている。

## 使いどころ・使い分け

| 用途 | 向いているツール |
|---|---|
| 社内規程集・契約書・会議議事録など手元の資料の内容を正確に検索・要約したい | NotebookLM |
| 大量の論文・レポートを読み込んで根拠付きで質問応答したい | NotebookLM |
| 移動中・作業中に資料の内容を「ながら聞き」したい | NotebookLM(Audio Overview) |
| 一般的な知識を聞きたい、資料にない発想を広げたい | ChatGPT / Geminiアプリ本体 |
| 企画書・メール文面などクリエイティブな文章を新規に作りたい | ChatGPT / Geminiアプリ本体 |
| 最新のニュースやWeb全体を横断して調べたい | Geminiアプリ(Deep Research)やPerplexityなど検索特化AI |

判断基準はシンプルで、**「答えの根拠を渡した資料の中だけに限定したいか」**がYesならNotebookLM、Noなら(＝外部知識も使って自由に考えさせたいなら)通常のChatGPT/Geminiを使う。なお2026年時点ではGeminiアプリ内にも「ノートブック」機能が追加されNotebookLMと相互同期する動きが進んでいるが、資料に厳密に根拠付けた調べものをする用途では、単体アプリとして機能が作り込まれているNotebookLMを使うほうが安定している。

## 実務での使い方

### ノートブックの作成とソースの追加

1. notebooklm.google.com にGoogleアカウントでログイン
2. 「新規作成」(または「+ 新しいノートブック」)をクリック
3. 「ソースを追加」画面で、以下のいずれかの方法で資料を取り込む
   - PDF・Word(docx)・テキスト/Markdown・CSV・PowerPoint(pptx)などのファイルをドラッグ&ドロップ
   - GoogleドライブからGoogleドキュメント・スプレッドシート・スライドを選択
   - ウェブページのURLを貼り付け(ペイウォールのあるページや会員限定ページは非対応)
   - 字幕付きの公開YouTube動画のURL(音声そのものではなく、字幕から書き起こしたテキストのみが取り込まれる)
   - 音声ファイル(MP3/WAVなど)や画像(PNG/JPEGなど)
   - テキストを直接貼り付け
4. ソースを追加すると、NotebookLMが自動でノートブックのタイトルと概要を生成する

ソース数の上限は無料版で1ノートブックあたり50件、Plus以上ではさらに拡大される(1ソースあたりの上限は約50万語相当)。社内規程集や複数年分の議事録など、量が多い場合はテーマごとにノートブックを分けて管理するとよい。

### チャットで質問する

画面右側(またはPCでは中央)のチャット欄に質問を入力すると、追加した資料の範囲内で回答が生成される。回答文中の数字(引用番号)をクリックすると、根拠になった資料の該当箇所がハイライト表示され、その場で一次情報を確認できる。

コピペで使える質問プロンプト例:

```
この資料に書かれている「解約時の違約金」の条件を、
発生条件・金額・例外規定の3点に分けて箇条書きでまとめてください。
資料に記載がない項目は「記載なし」と明記してください。
```

```
アップロードした3つの会議議事録から、
共通して繰り返し議題に上がっている論点を抽出し、
それぞれについて誰がいつ何を発言したかを時系列で整理してください。
```

### 要約・FAQ・スタディガイドの自動生成(Studio機能)

ソースを追加すると、画面右側の「Studio」パネルから以下のような成果物をワンクリックで自動生成できる。

- **概要(サマリー)**: ノートブック全体の要点を自動要約
- **よくある質問(FAQ)**: 資料の内容をもとにQ&A形式の一覧を生成
- **学習ガイド/クイズ**: 資料の理解度を確認するための問題を自動作成(学習・研修資料の復習に便利)
- **マインドマップ**: 資料の構造・論点の関係を図として可視化
- **レポート**: ブログ記事・ブリーフィングメモなど指定した形式でまとめ直す

### Audio Overview(音声解説)の作り方

複数資料の内容を、男女2人の掛け合い(ポッドキャスト風)の音声で解説してくれる機能。

1. Studioパネルの「音声概要」(Audio Overview)から「音声を生成」をクリック
2. 必要に応じて「カスタマイズ」で、聞き手の想定(初心者向け/専門家向けなど)や取り上げてほしい論点を指示文で指定
3. 数分待つと3〜25分程度の音声ファイルが生成される。再生しながらチャットで割り込み質問することも可能

Audio Overviewは2025年4月末から日本語を含む50以上の言語に対応しており、Googleアカウントの言語設定(または「出力言語」設定)に応じて日本語での生成もできる。移動時間中に会議資料や長文レポートを「ながら聞き」する用途で重宝する。無料版は生成回数に1日あたりの上限があり、Plus以上のプランでは上限が引き上げられる。なお、アニメーション付きの高機能な動画解説(Video Overview、Cinematic Video Overviews)は上位プラン限定の機能として提供されている。

### ツール横断の対応付け

NotebookLMの「手元の資料だけを根拠に回答させる」という考え方は、他ツールでも別の名前で提供されている。

| 概念 | NotebookLM | ChatGPT(GPTs) | Dify |
|---|---|---|---|
| 根拠資料を渡す機能 | ソースの追加 | GPTsの「ナレッジ」ファイル | ナレッジベース |
| 回答の出典表示 | 引用番号クリックで該当箇所を表示 | 標準では明示されないことが多い | 検索結果のチャンクを表示可能 |
| 音声への変換 | Audio Overview | 標準機能なし(別途音声合成が必要) | 標準機能なし |

### 料金の目安(2026年7月時点)

NotebookLM自体は無料でも主要機能を使えるが、Googleの個人向けAIプラン(Google AI Plus/Pro/Ultra)に加入すると、ノートブック数・ソース数・1日あたりのチャット回数やAudio Overview生成回数の上限が段階的に引き上げられる。具体的な上限値・価格は改定が頻繁なため、契約前に必ず[NotebookLM公式ヘルプの「アップグレード」ページ](https://support.google.com/notebooklm/answer/16213268)で最新値を確認すること。

## 注意点・よくある誤解

- **「絶対にハルシネーションしない」わけではない**: 資料内の記述に忠実に答える設計だが、複数資料をまたいだ複雑な質問や、資料の記述が曖昧な場合には誤読が起きることもある。重要な数値・条件は必ず引用リンクから元の記述を確認する習慣をつける。
- **無料版のデータ学習利用は個人利用と組織利用で扱いが異なる**: Google Workspace(有償エディション)でNotebookLMを使う場合、アップロードした内容・質問・回答はAIモデルの学習にも人によるレビューにも使われない。個人のGoogleアカウントでの無料利用でも基本的に学習には使われないが、ユーザーが手動で「フィードバックを送信」した内容はGoogleの担当者が確認する可能性がある点は区別して理解しておく。機密性の高い社内資料を扱う場合は、組織のGoogle Workspaceアカウント(必要に応じてNotebookLM Enterprise)で利用するのが安全側の選択になる。
- **ソースの「量」より「粒度」が精度を左右する**: 目次や免責事項、フッターの定型文などノイズになりやすい部分が多いPDFをそのまま入れると、要約やチャットの精度が落ちることがある。可能であれば本文だけを整えたテキスト・Googleドキュメントの形で入れる方が検索精度が上がる。
- **URLソースはページの本文テキストしか取得できない**: ペイウォール付きページや、JavaScriptで動的に表示される内容は取り込めないことがある。重要なウェブ記事はPDF化してから追加する方が確実。
- **YouTubeソースは字幕(文字起こし)のみが対象**: 音声・映像そのものの情報(話し方のニュアンスや画面表示)は反映されない。

## 最初の一歩

手元にある社内マニュアルや直近の会議議事録を1つNotebookLMに読み込ませ、「この資料の要点を3つに整理して」「◯◯についての決定事項は?」と質問し、引用番号から元の記述を確認する一連の流れを体験してみる。
