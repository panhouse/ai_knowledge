# 生成AIによる画像・ビジュアル作成の実務活用(資料・広告・SNS用画像)

## これは何か

「スライドの表紙に合う画像がない」「SNS広告のバナーを今日中に3パターン用意したい」「サービス紹介資料に載せるアイコンや完成イメージ図がない」——こうした場面で、デザイナーへの発注やストックフォトの選定に時間をかけずに、文章で指示するだけでその場に必要な画像を作れるのが生成AIの画像生成機能である。ChatGPT・Gemini・Copilot・Canva等のAI画像生成機能そのものの使い方は各ツールのページに譲り、本ページでは「業務のどの場面で」「どう指示すれば」「どこに気をつければ」使い物になる画像に仕上がるかという、業務目線の使い方を整理する。

## 仕組み・背景

画像生成AIは大きく2つの使われ方に分かれる。1つは「たたき台をゼロから作る」使い方(社内資料の挿絵、SNS投稿の下書きなど、多少の粗さは許容される用途)。もう1つは「既存の素材やブランド資産を土台に、一貫性のあるバリエーションを作る」使い方(会社ロゴ・製品写真・過去の広告デザインを参照画像としてアップロードし、それに似せた新しい画像を生成する)。ChatGPTのGPT Image 2やGemini(Nano Banana Pro)は、テキストプロンプトだけでなく複数枚の参照画像(ロゴ・配色見本・製品写真など)を同時に読み込ませて、それらの特徴を保ったまま新しい構図やシーンを生成できるようになっており、「毎回バラバラの雰囲気の画像しかできない」という初期の弱点は実務上かなり解消されてきている([Google DeepMind: Nano Banana Pro](https://blog.google/intl/ja-jp/company-news/technology/nano-banana-pro/))。

一方で、画像生成AIは「言われた通りの絵は描けるが、社内のブランドガイドライン・過去の広告のトンマナ(トーン&マナー)・法務上のNG表現を自分では判断しない」という前提は変わっていない。ロゴの位置、禁止色、注意書きの要否といった業務上のルールは、プロンプトや参照画像として明示的に与えない限り反映されず、最終チェックは常に人が担う。

## 使いどころ・使い分け

業務でよくある画像ニーズを、向いているアプローチ別に整理する。

| 業務シーン | 向いているアプローチ | 理由・使い方の要点 |
|---|---|---|
| 社内プレゼン・資料の表紙や挿絵 | ChatGPT / Gemini / Copilotのチャットで直接生成 | 対外的な品質基準は低め。文章生成と同じ画面で数十秒〜数分で複数案を試せる。[生成AIによるプレゼン資料・ドキュメント作成の実務活用](./ai-presentation-and-document-creation.md)の資料作りの一部として組み込むのが自然 |
| スライド内の簡単な図解・アイコン(フローチャート、比較アイコン等) | Napkin等のtext-to-visualツール、またはチャットAIへの直接依頼 | 構造化されたテキストを渡すと図解案を複数提示してくれる。1枚単位の部分利用に向く |
| SNS投稿・広告バナーの下書き(社内レビュー前のたたき台) | ChatGPT / Gemini / Canva AI | A/Bテスト用に複数パターンを一度に出させ、社内レビューでどの方向性が良いか絞り込む用途に向く。この段階では商用利用可否よりスピードを優先してよい |
| 実際に配信する広告・SNS投稿の最終画像 | Canva(ブランドキット適用)/ Adobe Firefly(商用利用向けライセンス)/ 有料プランでの生成+人によるチェック | 対外公開物は著作権・商標・薬機法/景品表示法上の表現チェックが必須になるため、無料プランや検証段階のツールをそのまま出稿に使わない |
| 会社ロゴ・製品写真を使ったモックアップ(新製品の使用イメージ、パッケージ案) | 参照画像アップロード機能があるツール(ChatGPT・Gemini・Canva) | 自社のロゴ・製品写真をアップロードし、「この製品をオフィスで使っているイメージを作って」のように指示すると、実物に近い構図のモックアップができる。実写合成のように見えるため、AI生成である旨の社内ルール確認は特に重要 |
| 資料・スライド全体で統一感のあるアイコンセットが欲しい | 1回のプロンプトでまとめて生成、または生成した1枚を参照画像にして残りを生成 | 別々に生成すると線の太さ・配色がずれやすい。「このアイコンと同じテイストで、他に◯個作って」と直前の生成物を参照させると統一感が保ちやすい |
| ブランドの世界観を作り込む、広告のキービジュアル | Midjourney、Adobe Firefly等の専門ツール+デザイナーによる仕上げ | 完成度・アート性が求められる最終アセットは、AI生成だけで完結させず人の手による調整を挟む方が安全 |

判断の軸は2つ。「社内向けのたたき台か、社外に出す最終物か」(前者は手軽な生成で十分、後者は商用利用条件の確認とデザイナーの仕上げを挟む)と、「1枚で完結するか、複数枚で統一感が要るか」(後者は参照画像・スタイル引き継ぎの機能を持つツールを選ぶ)。

## 実務での使い方

### コピペで使えるプロンプト例1: スライドの表紙・見出し画像

```
社内プレゼン資料の表紙に使う画像を作ってください。
テーマ: [例: 来期の新規事業提案]
雰囲気: [例: 明るく前向きな印象、フラットデザイン]
配色: [例: 会社のコーポレートカラーである青と白を基調]
アスペクト比: 16:9
画像内に文字は入れないでください(タイトルはスライド側で追加するため)
```

「文字は入れない」は必須の一文にしておく。スライドソフト側でタイトルを重ねる前提なら、AIに文字を書かせて位置がずれるより、無地に近い背景画像として作らせた方が扱いやすい。

### コピペで使えるプロンプト例2: SNSバナー・広告用(LinkedInヘッダーの例)

```
LinkedInの会社ページに設置するヘッダー画像を作ってください。
サイズ比率: 4:1程度の横長(LinkedInヘッダー推奨サイズに近い比率)
業種: [例: BtoB向けSaaS(勤怠管理サービス)]
雰囲気: 信頼感のあるビジネストーン、過度に派手にしない
含める要素: 抽象的なグラフィック(直線・グラデーション)のみ。人物やロゴは含めない
配色: コーポレートカラー(#003366系の紺と白)を基調に
3パターン、背景の抽象パターンだけ変えて提案してください
```

InstagramやX(旧Twitter)向けの正方形バナーも同じ型で、アスペクト比と「含める要素」の指定だけ変えれば流用できる。**キャッチコピーを画像内に文字として入れる場合は必ず生成後に目視で誤字・文字崩れを確認する**(日本語の文字精度はモデルにより差が大きい)。

### コピペで使えるプロンプト例3: 資料用アイコンセット(統一感を持たせる)

```
社内資料で使うアイコンを6個、同じテイストで作ってください。
テイスト: ミニマルなラインアイコン、線の太さは均一、角丸
モチーフ: 「売上」「顧客」「時間」「品質」「コスト」「リスク」の6つの概念
配色: 単色(グレーまたは会社のアクセントカラー1色)
背景は透過、またはすべて同じ単色背景で統一してください
一度に6個まとめて、同じ画像内にグリッド状に並べて出力してください
```

まとめて1回で生成させると、後から1個ずつ足すより線の太さ・配色のズレが起きにくい。追加が必要になった場合は、既存のアイコン画像を参照画像として添付し「このセットと同じテイストで、もう2個追加して」と依頼する。

### コピペで使えるプロンプト例4: 製品・サービスの利用イメージ(モックアップ)

```
(自社製品の写真を添付した上で)
添付した製品写真を使って、実際にオフィスで使われているシーンの
イメージ画像を作ってください。
シーン: [例: 明るいオフィスでノートPCの横に製品が置かれている]
雰囲気: 自然光が入る清潔感のあるオフィス
製品のデザイン・ロゴは添付写真から変えないでください
```

自社ロゴ・製品写真をアップロードして「変えないでください」と明示しても、細部(ロゴの書体・製品の形状)が微妙に変化することがあるため、最終的に使う前に元の写真と並べて誤差を確認する。

### ツール横断の対応表(2026年7月時点)

| ツール | 画像生成機能 | 参照画像・ブランド一貫性の機能 | 無料プランでの商用利用可否の目安 |
|---|---|---|---|
| ChatGPT | GPT Image 2(ChatGPT Images 2.0) | 画像添付でロゴ・製品写真を参照させた編集・生成が可能。同一スレッド内での反復修正が強み。詳細は[ChatGPTの画像生成機能](../part03-ai-chat-tools/chatgpt-image-generation-feature.md)を参照 | OpenAIの利用規約上、有料・無料とも生成物の商用利用自体は認められているとされるが、権利関係の法域差や実在ブランド・人物の扱いには注意([同ページの注意点](../part03-ai-chat-tools/chatgpt-image-generation-feature.md#注意点よくある誤解)を参照) |
| Gemini(Google) | Nano Banana Pro(Gemini 3 Pro Image) | 最大14枚程度の参照画像(ロゴ・配色見本・製品写真等)を同時に読み込ませ、一貫したスタイルで複数シーンを生成可能 | Google AI Pro/Ultra等の有料プランでの利用が業務用途では前提になりやすい。プラン別の条件は都度公式情報で確認 |
| Microsoft Copilot(Designer) | Image Creator | ブランドの参照画像アップロードには対応するが、社内テンプレートとの統合はPowerPoint内のCopilotほど強くない | **無料版(個人アカウントでのDesigner)は非商用利用が前提とされており、商用利用にはMicrosoft 365 Copilotの契約(Copilot Copyright Commitmentの対象)が必要**。契約前に必ず自社の契約形態を確認する |
| Canva(Magic Media / AI画像生成) | Dream Lab等のAI画像生成 | ブランドキットを登録しておくと、ロゴ・配色・フォント・ブランドボイスを踏まえた画像を生成できる。Webサイト/PDFからブランドキットを自動抽出する機能もある | Canva Pro以上でブランドキット機能・全AI機能が解放。無料プランは機能・商用利用条件ともに制限あり |
| Adobe Firefly | Firefly画像生成 | スタイル参照・構造参照機能でブランドの見た目を踏襲可能 | 有料のCreative Cloud/Firefly for Enterprise契約者には著作権侵害を巡るIP補償(indemnification)が提供される。無料アカウントは対象外 |
| Claude(Anthropic) | ネイティブな画像生成機能なし | — | Claudeは2026年7月時点でChatGPTやGeminiのような「文章で頼んで画像を作る」機能を持たない。画像に関する業務(構図の相談、代替テキストの作成、他ツール用プロンプトの設計)の壁打ち相手として使い、実際の生成は上記の画像生成AIに任せる分業が現実的 |

「素早くたたき台を出したいだけ」ならChatGPT・Gemini、「ブランドキットで統一感を管理したい」ならCanva、「商用利用のIP補償を重視する」ならAdobe Firefly(有料契約)、という大まかな使い分けになる。料金・利用条件は変動が速いため、契約前に各社の公式ページで最新情報を確認すること。

## 注意点・よくある誤解

- **「無料プランで作った=商用利用OK」とは限らない**: ツールによって無料版と有料版で商用利用可否が明確に分かれている場合がある(例: Microsoft Designerの無料版は非商用が前提)。広告やSNS投稿など対外的に出す画像は、使っているプラン・契約形態が商用利用に対応しているかを必ず確認してから使う。
- **著作権は自動的にクリアではない**: 生成した画像の著作権の扱いは法域によって異なり、AIのみが生成した作品には「人間の創作性」が認められず著作権登録ができないとされるケースもある。また実在のロゴ・キャラクター・著名人に似た画像を広告等に使うと、著作権よりも先に商標権・パブリシティ権の侵害が問題になりやすい。日本国内では2025年11月に、AI生成画像を無断で書籍表紙に使用した著作権法違反の摘発事例も出ている。詳細は[生成AIの著作権リスクと実務での注意点](../part04-risk-security/copyright-risks-in-generative-ai.md)を参照([文化庁: AIと著作権について](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html))。
- **AIが作った画像でも「優良誤認」等の広告規制は免除されない**: 効果を誇張した表現やビフォーアフター風の演出をAI画像で作ると、景品表示法上の「優良誤認表示」などに抵触するリスクがある。AI生成画像であることは法的な免責にはならず、広告・SNS投稿として出す前に必ず人がレビューする体制を敷く。
- **AI生成であることの開示が必要な場面がある**: 実写に見えるレベルのモックアップやフェイク的な演出をSNS広告に使う場合、プラットフォームによってはAI生成コンテンツのラベル表示を求められることがある。実在の人物に似せた画像や、実写と誤認されやすい合成画像は特に注意する。
- **社内ブランドガイドラインはAIに伝えないと反映されない**: 「うちの会社らしい配色・トーン」はAIには分からない。ブランドキット機能があるツールでは事前登録し、ない場合はプロンプトで配色コード・NG表現(例: 特定の演出は使わない)を明示する。
- **統一感を出すには「まとめて生成」または「参照画像を使い回す」**: アイコンやSNS投稿画像を1枚ずつ別々に依頼すると、線の太さ・配色・雰囲気がバラつきやすい。可能な限り1回のプロンプトでセットとしてまとめて生成するか、気に入った1枚を参照画像として次の生成に使い回す。
- **文字入りの画像は必ず目視確認**: キャッチコピーや数値をAIに書かせた画像は、文字化け・誤字が残っていることがある。特に外部公開前は文字部分を拡大して確認する工程を挟む。

## 最初の一歩

直近で必要になっている社内資料またはSNS投稿を1つ選び、本ページの「スライドの表紙・見出し画像」または「SNSバナー」のプロンプト例を使って画像を1〜3パターン生成してみる。生成後は、使っているプラン(無料か有料か)で商用利用が認められているかを1回確認する習慣をつける。
